# Лимит ИИ — в деньгах, а не в запросах (бриф «ИИ-польза», Р-11)

- **Дата:** 2026-10-16
- **Инициатор:** владелец — бриф «ИИ-польза», раунд 2 (ответ «в деньгах»; $2 — дефолт по рекомендации). Резюме брифа
  подтверждено 2026-10-16 без правок (`memory/backlog/ИИ-польза/ИИ-польза-brief.md`). Файл записал составитель бэклога
  «ИИ-польза».
- **Меняет:** Р-8 бэклога «ИИ» (`memory/backlog/ИИ/00-backlog.md` §2).

## Было ➔ Стало

- **Было (Р-8 «ИИ»):** лимит — env `AI_MONTHLY_LIMIT`, **30 запросов** в месяц на семью (разборы + пачки продавцов +
  скриншоты), месяц — по Алматы; кончился — 429 `ai_limit`, «ИИ вернётся 1 <месяца>».
- **Стало (Р-11 «ИИ-польза»):** лимит — **деньги**, одно значение на все семьи, env, старт **$2 в месяц на семью**.
  Считается по уже хранимому `app.ai_usage.cost_micros` (микродоллары, целые), месяц — по Алматы. Кончился — то же 429
  `ai_limit` и «ИИ вернётся 1 <месяца>». Счётчик запросов остаётся — для админки, лимитом не служит. В админке рядом с
  «≈ $» — лимит семьи.
- **Причина:** функции стоят по-разному (разбор Opus ≈ $0,03–0,06, имена подписок / фраза / чек на Haiku ≈ $0,001–0,002 —
  исследование `memory/backlog/ИИ/research-2026-10-16.md`); 30 штук то режут дешёвое, то не держат дорогое. Разбор теперь
  приходит сам — считать его штукой нечестно.

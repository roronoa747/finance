## Было ➔ Стало

### Вопрос 1 (Х-9) → Р-18. Адрес «Открыть» раздела — RZ-13

- **Было:** раздел `cat` → `/month?cat=<categoryId>` — лист раздела **текущего** месяца; полосы «Куда ушло» и находки — о
  месяце находок (`findMonth`: пока ничья выписка не дошла до 7-го — прошлый). Нажал «Кафе · 95 000» под «в сентябре» —
  открылся лист «Кафе» октября с почти нулём; месяц на листе не назван.
- **Стало:** строка «Куда ушло» и «Открыть» совета раздела открывают лист раздела **того месяца, что на картинке**:
  `/month?month=<месяц находок>&cat=<categoryId>` (`month` — только когда он не текущий); на листе — название месяца;
  у закрытого (прошлого) месяца — без «Изменить» (план раздела общий на будущее — правка из прошлого месяца сбивала бы).
- **Причина:** правило 12 — «нажатие ведёт туда, куда ждёшь»: цифра в строке и цифра в листе — одна.

### Вопрос 2 → Р-8. «Работа ИИ» — RZ-14

- **Было:** крупно — N операций, строкой — «нашёл K · ≈ X ₸ в год».
- **Стало:** крупно — «≈ X ₸», подпись «в год уходит на найденное», строка «K находок из N операций». X = 0 (советы не
  о находках) — как было: крупно N операций, «нашёл K». Числа и формулы (Р-19) — те же, считает код.
- **Причина:** деньги — то, ради чего читают; операции — объём работы, вторичны.

### Вопрос 3 → показ совета и инструкция модели — RZ-15

- **Было:** подпись крупной цифры — `about` факта (служебная строка для модели: «новое регулярное списание «…», которого
  нет в плане — за год»); модель повторяла ту же сумму в тексте под крупной цифрой.
- **Стало:** короткую подпись считает код по виду находки («за год · Магазин у дома») — хранится у совета рядом с фактом;
  в инструкцию модели — одна фраза «Число из figure приложение покажет крупно над текстом — в text его не повторяй.»;
  замер ≥ 8 живых разборов, финальный текст инструкции — в SESSION Блока 3 дословно (Р-24).

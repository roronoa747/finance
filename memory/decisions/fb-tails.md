# Хвосты бэклога «Фидбек» — судьбы (владелец, 2026-10-23)

Ответы владельца на закрытии бэклога (три раунда вопросов с рекомендациями после 🏁 Блока 5).

**Чинить — в новый бэклог** (начать с брифа, правило 1 CLAUDE.md):
- **Х-21** «нашли N в выписке» — только похожее на платежи (подписки, связь, кредиты, коммуналка); кофейня и такси мимо.
- **Х-7** вторая подписка у того же продавца через «В платежи» — правило платежа по продавцу **и сумме** (рядом с Х-21).
- **Х-20** «В платежи» у строки кредита — в форму кредита с остатком, а не в подписку.
- **Х-22** первый запуск на Android — плитки только при двух путях; с одним — фото мечты, заголовок и кнопка.
- **Х-1** разбор ИИ ждёт, пока подтянутся выписки (не «K находок из 0 операций»).
- **Х-5** лист раздела платежей «Недели» — крупная сумма и список считаются одинаково (как на «Месяце»).
- **Х-6** «Месяц → Траты» — тихая строка «Платежи без отметки», чтобы сумма строк сошлась с «потрачено».
- **Х-14** лист «Наличные» (и переводы людям) — без плана и «обычно 0», только операции.
- **Х-3** «Мне вернули» — добавить возвраты «+» от того же магазина, что и покупка. **Уточнение владельца:** «там ещё
  кешбэк есть, путаница будет» — начисления кешбэка и бонусов кандидатами возврата не предлагать.
- **Х-2** ответы «Нет, это другое» / «Потом» по операции — в личный документ (видны всем телефонам человека).

**Принятый долг:** **Х-4** (партнёр на минуту видит итог без «Мне вернули» — сходится на следующем синке).

**После MVP:** **Х-19** (снос v3 фронт + Go одним заходом, Р-26).

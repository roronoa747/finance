**Стало:**
- **Вариант Г.** Находки, их выбор и кнопки считает код (`lib/finance.ts`, телефон по своим операциям): у каждой карточки
  одно действие с призывом — «Разобрать» (переводы людям → «Кому → что» / «Мне вернули»; не разобрано), «Отметить
  разовой» (крупная покупка у нового продавца; неделя дороже обычной), «На что?» (наличные → заметка), «В платежи»
  (регулярное вне плана, `prefill`), «Перенести в мечту» (привычки), «Сделать» (мелочь, мечта раньше), «Поставить план»
  (план не по факту; растёт второй месяц). «Выходные» — без кнопки, картинкой в «Куда ушло». Отброшены: «после зарплаты»,
  подписки без использования, комиссии, пиковые дни.
- «Куда ушло» — на всю сумму трат: продавцы · люди · наличные · платежи.
- **Модель** пишет только первую карточку — одну главную мысль месяца (и какая карточка следом), числа ссылками `{fN}`.
  Оценка ≈ 9 ₸ за разбор на Opus 5.5 (Sonnet 5 ≈ 4 ₸, Haiku 5.5 ≈ 0,2 ₸); **модель выбирается по живому замеру FB-17 на
  2–3 моделях, цена показывается владельцу до включения** (`owner-ai-cost-per-tap`). Семья без платного ИИ получает те же
  карточки кода без первой (вариант А).
- Имена людей и переводы модели не уходят (только доля); имена получателей видит лишь хозяин операций на своём экране.
- **Р-18 — отчёт свой у каждого:** находки и кнопки — по своим операциям; общие цифры семьи (остаток, мечты) — общие, как на

  на пару (Г на Opus ≈ 54 ₸ в месяц при 3 разборах у каждого).

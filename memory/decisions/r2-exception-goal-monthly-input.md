# Исключение из зафиксированного решения: Р-2 (эталон — React) бэклога `паритет-react-vue` — взнос цели полем, а не ползунком

- **Дата:** 2026-09-25
- **Инициатор:** Владелец проекта («ползунок жутко неудобно»)
- **Решение:** Р-2 (`memory/archive/паритет-react-vue/00-backlog.md` §2)

## Было ➔ Стало

- **Было:** экран цели — как React: «Откладывать в месяц» задаётся ползунком (`<Slider>`,
  `src/screens/GoalDetail.tsx:122-127`; во Vue — `<input type="range">`, `views/GoalDetail.vue`,
  шаг 5 000, границы 40 %…260 % нынешнего взноса).
- **Стало:** Р-2 в силе, ещё одно исключение: на экране цели «Откладывать в месяц» вводится
  **числом в поле** (`NumFieldBlur` кита): сохраняется, когда уходишь из поля, с «Сохранено»
  (`useSavedMark`); ноль и пустое не пишутся; ползунок и подписи его границ убираются. Подсказка
  «Чтобы успеть за год, нужно N в месяц» остаётся. Viewer поля не видит — только сумму (как Р-13
  RP). Крупная сумма, дата «Цель закроется в …» и режимы «Считаем от даты / от суммы» — как были.

## Причина изменения

Ползунок неудобен: шаг 5 000 и узкие границы вокруг нынешнего взноса не дают поставить нужную
сумму, на телефоне палец сбивает значение. Нужную сумму семья знает заранее — её проще ввести.

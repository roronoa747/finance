# Вид главных экранов: «Неделя» с планом, «Месяц» с малым кольцом, «Деньги» ровно, заметка с датой, первый запуск «сначала траты» (владелец, 2026-10-23)

**Повод.** Исследование FB-18 (Блок 5 «Фидбек», Р-21): артефакт «до | после» 390 px на демо —
https://claude.ai/artifact/AvUr9PagMTq3Lv1CBBcM7c (Handoff в `memory/backlog/Фидбек/block-5-look/SESSION.md`). Ответ
владельца: «1 б, только полоска другого цвета; 2 б, и галочку другую — она не подходит по дизайну; 3 ок; 4 б; 5 да,
супер; ещё я вчера Фигму подключил — сразу сделай в Фигме всё сначала».

**Решения:**
- **«Неделя» — вариант Б.** Шапка в два яруса: ‹неделя› и сумма недели слева, кружки выписок с «+» мелко справа; под
  суммой — **план недели полосой** и строка «план недели N · осталось M». Полосы «осталось» у строк разделов уходят в
  лист раздела. **Строка «Не разобрано» сама нажимается** — отдельного чипа «Разобрать» нет (правка владельца в Figma
  2026-10-23: «логично, строчка и есть кнопка»; счётчик вопросов — подписью строки). **Цвет полосы — `--brand`** (вариант А; владелец 2026-10-23 по комментариям Figma: «передумал, пусть будет А»). Нужен расчёт
  плана недели (из плана месяца трат по разделам; формула — составителю).
- **«Месяц» — вариант Б.** Вместо кольца 236 px — **малое кольцо ~112 px слева от «Остаётся»**, справа крупно сумма и
  «Хватит?» / «✦ Разбор» строкой; разделы «Платежи · Траты · Цели и фонды» под ним, видны без прокрутки. Дуги — те же
  `parts`, зарплаты снаружи кольца не рисуются. **Отметка «пришла» у зарплаты — вариант Ж: строка участника подсвечена** мягким фоном (скругление 12, без ✓ и
  точек; ждущая зарплата — сумма `--ink-2` и подпись); **цвет подсветки** владелец выбирает в Figma из 6 оттенков
  (ok-soft / brand-soft / surface-2 / цвет участника 14 % / gold-soft / ok 12 %) — комментарий «вот так можно, только
  цвет подобрать».
- **Палитра Figma = `style.css`** (комментарии владельца: фон желтоват, В и П «стоковые»): переменные коллекций «Тема ·
  Светлая» и «Тема · Тёмная» приведены к токенам `frontend/src/style.css` 2026-10-23 (`canvas #f2f2f0`, `pa #4f7a63`,
  `pb #7d6a9e` и т. д.); источник истины — `style.css`, Figma повторяет.
- **«Деньги» — как предложено.** «Капитал · Долги · История» — сегмент, как на «Плане»; у каждой строки слот слева (значок
  счёта / кружок «чей» у платежа), суммы одной колонкой без «₸» в списках, одна тонкая черта перед «Добавить»;
  **карточку зарплат с экрана убрать** (они на «Месяце»).
- **Заметки — вариант Б, заметка себе с датой.** Заводится в «+ → Заметка» (текст, дата, сумма по желанию), личная
  (личный документ), **всплывает карточкой на своей неделе** над разделами с ✓ «сделано»; заметка у траты («Что это
  было», Р-3) остаётся как есть. Новое хранение в `privateDoc`.
- **Первый запуск — «сначала траты».** Мечта остаётся первой (образ продаёт), затем экран «Тратьте как обычно» с одной
  кнопкой «Загрузить выписку» (тихо — «Позже»; Apple Pay — второй путь), зарплату и план не спрашиваем. Через ~2 недели
  выписок — точка на «Месяце» и кнопка **«План по факту»** в строке «Траты» → лист плана по разделам из «обычно» →
  «Поставить». Нужен расчёт «обычно» по 2–4 неделям (`usualSpend` сейчас — по полным месяцам).
- **Макеты — сначала в Figma.** Владелец подключил Figma (тариф Pro с 2026-10-22, лимит Starter снят): экраны «после»
  собираются в файле «Family Finance — B2C» (`qBsIBtTRI4MIaRa6b8Eli9`, страница «03 Экраны») до постройки; открытые
  визуальные выборы (цвет полосы недели, отметка «пришла») — рядом вариантами, владелец выбирает в Figma. Эталон для
  `/ux` Блока 5 — эти макеты.

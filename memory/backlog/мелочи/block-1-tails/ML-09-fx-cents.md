# ML-09 — Центы в валютной сумме не теряются (фронт)

Блок 1 · MVP · Репо/каталог: `frontend/src/lib/num.ts`, `frontend/src/components/kit/NumField.vue` · Зависит от: ML-08 · Роли: member

## Контекст (что уже есть)

Хвост §4 `идея-и-редизайн` **1000** (жив, сверено 2026-10-08); решение — **Р-13** этого бэклога (вариант (б): поле
валютной суммы принимает запятую/точку и округляет до целого при сохранении; модель данных не меняется — суммы в валюте
целые, Р-70/Р-75 `идея-и-редизайн`).

- `components/kit/NumField.vue` (prop `kind: NumKind = 'money'|'int'|'rate'`) → `clean(raw, kind, prev)`
  (`lib/num.ts:26-36`): для `money` `s.replace(/\D/g,'')` — «9,99» → «999». Запятую держит только `rate`. Есть ещё
  `kit/NumFieldBlur.vue`. Внутренний разбор — `numValue` (num.ts:55-60); `parseMoney` (`lib/money.ts:45-48`) тоже режет.
- Поля сумм в валюте: `SalarySheet.vue`, `SalaryDialog.vue`, `SalaryRow.vue`, `SalaryExchange.vue`, `FxRateSheet.vue`,
  `capital/NewObligationSheet.vue`, `ObligationSheet.vue`, `NewAccountSheet.vue`, `AccountSheet.vue`, `MarkSheet.vue`,
  `CapitalSalaries.vue` (выбор валюты — `kit/CurrencyChips.vue`).

## Задача

1. Новый `kind: 'fx'` в `num.ts`/`NumField`: принимает одну запятую или точку и до двух знаков после; значение поля —
   целое, округлённое `Math.round` (9,99 → 10; 9,49 → 9). Тенге (`money`) — как было.
2. Поля, где выбрана валюта ≠ KZT, используют `kind: 'fx'` (одно место выбора `kind` на поле — без копий логики).
3. Под полем в момент округления — короткая подсказка «Округлим до 10 $» (одна строка, правило 12).

## Тесты

- `num.test.ts`: «9,99» → 10, «9.49» → 9, «1 000,5» → 1001 (округление по `Math.round`), две запятые — вторая
  отбрасывается; `money` по-прежнему без запятой.
- DOM одного валютного листа (например, `NewObligationSheet`): ввод «9,99 $» сохраняет 10.

## Критерии приёмки

- На стенде: подписка «9,99 $» сохраняется как 10 $ (≈ по курсу в тенге), а не 999 $.
- `npm run build && npx vitest run` зелёные.

## Вне скоупа

- Хранение центов, дробные деньги в состоянии — запрещено (правило 6).

## Задача

1. Собрать всех кандидатов, отсортировать по силе (правило семьи раньше эвристик, затем близость к окладу, затем
   дата), `taken` назначать глобально по этому порядку.
2. `answerIncome` отмечает строки правила за прошлый месяц, как `acceptMatch` (из хвоста).

## Тесты

- `matching` тест: те же строки в двух порядках → один и тот же кандидат (строка правила); эвристика берёт пару, только
  если правила нет.
- `Start` тест: «Да» на вопрос дохода не создаёт второе правило зарплаты.

## Критерии приёмки

- На стенде (первый запуск, выписка с переводом другого отправителя перед зарплатой): август отмечен зарплатой по

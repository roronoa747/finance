## Задача

1. `DebtsWidget`: строка долга человеку рядом с кредитами (имя, остаток, полоса «погашено», платёж; без ставки и
   «до когда» — срок в листе); под долгами — свёрнутая строка «Людям · N · <сумма в месяц>», раскрывается списком
   платежей людям (нажатие — лист платежа).
2. «Отдал» — небольшой кнопкой в строке долга человеку (сумма — платёж месяца, правится в листе) → `markPaid('credit',
   …)`; отмечено → ✓ у суммы в той же строке (правило 12 «смысловой флоу»). Viewer — без кнопки.
3. `CreditSheet` для `person`: без банковских полей (ставка, ГЭСВ, «Посчитать досрочно»), остаток, платёж, «Отдал»,
   правка, удаление.
4. Платёж людям в плане месяца — как обычный платёж (его «Оплатил» уже там).

## Критерии приёмки

- Стенд, 390 px, обе темы, member и viewer — экраны совпадают с утверждённым макетом ML-14.
- `npm run build && npx vitest run` зелёные. В Handoff — главное действие, у какого предмета, что в подсказке, что
  скрыто (правило 12).

## Вне скоупа

- Несколько «Отдал» в одном месяце (частями чаще раза в месяц) — одна отметка на месяц, сумма правится; иначе — хвост.

# MGV-13 — Экраны Goals.vue, GoalDetail.vue, Deposit.vue (фронт)

Блок 5 · MVP · Каталог: `frontend/` · Зависит от: MGV-12 · Роли: все

## Контекст (что уже есть)
- Завершена задача MGV-12 (`Capital.vue`).
- Хранилище `useFinanceStore`: `goals`, `accounts`, методы `addGoal`, `updateGoal`, `removeGoal`, `depositToGoal`, `withdrawFromGoal`.
- Финансовая математика: `goalMonths`, `emergencyCoverage`.
- Палитра цветов: `frontend/src/lib/palette.ts`.
- Эталонная реализация экранов:
  - `src/screens/Goals.tsx`
  - `src/screens/GoalDetail.tsx`
  - `src/screens/Deposit.tsx`
- Текущий маршрут `/goals` в роутере использует `PlaceholderView.vue`.

## Задача
1. Создать экраны:
   - `Goals.vue` (`frontend/src/views/Goals.vue`):
     - Список финансовых целей (подушка безопасности, крупные покупки, отпуск).
     - Прогресс-кольца `Ring.vue`, накопленная сумма, целевая сумма, ежемесячный взнос.
     - Кнопка создания новой цели с выбором названия, суммы, ежемесячного взноса и цвета.
   - `GoalDetail.vue` (`frontend/src/views/GoalDetail.vue` или модальное окно цели):
     - Детальный просмотр цели, срок закрытия, история пополнений/списаний.
     - Редактирование параметров цели.
   - `Deposit.vue` (`frontend/src/views/Deposit.vue` или модальное окно операции):
     - Внесение денег в цель или снятие со счета.
     - Выбор счета списания/зачисления и пересчет остатков.
2. Зарегистрировать маршрут `/goals` в `frontend/src/router/index.ts`.

## Тесты
- Юнит-тесты операций с целями: пополнение, частичное снятие, вычисление сроков достижения.
- Компонентные тесты рендеринга списка целей и детального экрана.

## Критерии приёмки
- Экран `Goals.vue` открывается по вкладке «Цели» и при клике на цели из других экранов.
- Пополнение и снятие корректно изменяют `have` цели и баланс счета.
- `npm test && npm run build` проходит чисто (0 ошибок).

## Вне скоупа

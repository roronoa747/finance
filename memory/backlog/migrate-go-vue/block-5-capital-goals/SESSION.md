- **Синхронизация таба вишлиста (`?tab=wish`):** кнопка «Покупка в дом» из меню `AppShell.vue` вела на `/goals?tab=wish`, однако вкладка не реагировала на query URL. Добавлена двусторонняя реактивная синхронизация `tab` с `$route.query.tab`.

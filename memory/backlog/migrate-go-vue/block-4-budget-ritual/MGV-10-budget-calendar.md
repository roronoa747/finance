## Задача
1. Создать компонент `Budget.vue` (`frontend/src/views/Budget.vue`):
   - Переключатель трёх режимов просмотра через `Segmented.vue`:
     - **«План» (`plan`)**:
       - Карточка дохода семьи: сумма зарплат, полоса участников (`CategoryBar`), список участников с окладами и днями выплат.
       - Модальное окно или форма изменения оклада участника (добавление новой версии оклада с текущей даты).
       - Разделы расходов по категориям (`d1`–`d5`): расчётные обязательства (`d1` жильё, `d2` кредиты, `d3` цели) и настраиваемый бюджет на быт (`d4`). Поле ввода для изменения суммы `d4` через `setCategoryAmount('d4', ...)`.
     - **«Календарь» (`calendar`)**:
       - Месячная сетка дней с понедельника по воскресенье (`WEEKDAYS`), пустые клетки (`leadingBlanks`), дни (`daysInMonth`).
       - Маркеры событий на днях календаря (зарплаты, списания обязательств, кредитов, взносов в цели) с цветами категорий.
       - Выбор активного дня по клику, отображение списка событий выбранного дня под календарём и суммарного итога дня.
     - **«Список» (`list`)**:
       - Хронологический список всех списаний и поступлений месяца с датами, названиями, суммами и навигацией в соответствующие разделы.
       - Итоги месяца: сумма обязательств, взносов в цели и чистый свободный остаток.
2. Подключить `Budget.vue` к маршруту `/budget` в `frontend/src/router/index.ts` вместо `PlaceholderView`.

## Тесты
- Юнит-тесты фильтрации и группировки событий календаря по дням (`events`, `dayEvents`).
- Тест изменения суммы категории `d4` в `financeStore`.
- Компонентный тест рендеринга `Budget.vue` во всех трёх режимах (`plan`, `calendar`, `list`).

## Критерии приёмки
- Экран `Budget.vue` доступен по вкладке «Бюджет» в `AppShell.vue`.
- Переключение между «План», «Календарь» и «Список» работает без перезагрузки и отображает соответствующие блоки данных.
- В календаре корректно рассчитываются дни недели и смещение начала месяца.
- Все числа форматируются через `money.ts` и `num.ts`.
- `cd frontend && npm test && npm run build` проходит чисто (0 ошибок).

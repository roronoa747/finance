# MGV-11 — Экран Ritual.vue (высвобождение средств) (фронт)

Блок 4 · MVP · Каталог: `frontend/` · Зависит от: MGV-10 · Роли: все

## Контекст (что уже есть)
- Завершена задача MGV-10 (`Budget.vue`).
- Баннер высвобождения средств в `Overview.vue` ведёт на `/ritual`.
- В `finance.ts` есть функции расчёта эффектов:
  - `nextChange(o, key)` — обнаружение снижения платежа (`delta < 0`).
  - `goalMonths(need - have, monthly)` — срок достижения цели в месяцах.
  - `prepayment(principal, rate, payment, extra)` — ускорение закрытия кредита и экономия на процентах при добавлении к платежу.
  - `emergencyCoverage(total, mandatory)` — покрытие расходов подушкой безопасности.
- Модуль дат: `monthAfter`, `monthFromAfter`, `monthInAfter`.
- Хранилище `useFinanceStore`: цели `goals`, кредиты `credits`, метод `mutateHouseholdDoc`.
- Эталонная реализация экрана: `src/screens/Ritual.tsx`.
- Текущий маршрут `/ritual` в роутере временно использует `PlaceholderView.vue`.

## Задача
1. Создать компонент `Ritual.vue` (`frontend/src/views/Ritual.vue`):
   - Проверка наличия запланированного высвобождения средств (`freed = nextChange(o, key)` с отрицательной дельтой).
   - Если высвобождения нет: понятная заглушка с объяснением и кнопкой перехода на главную страницу (`/`).
   - Если высвобождение есть:
     - Заголовок с освобождающейся суммой (`total = Math.abs(freed.change.delta)` ₸ в месяц) и датой вступления в силу.
     - Интерактивное распределение суммы шагами по 10 000 ₸ (`STEP`):
       - Накопления по существующим целям (`goals`).
       - Досрочное погашение кредита (`credits`).
       - Качество жизни / текущее потребление (`life`).
     - Счётчик остатка нераспределённой суммы (`left = total - used`).
     - Интерактивные кнопки `+` и `-` для каждой корзины распределения.
     - Текстовый вывод реального финансового эффекта в реальном времени под каждой корзиной (на сколько месяцев быстрее закроется цель, сколько тенге сэкономится на процентах по кредиту).
     - Кнопка подтверждения: при нажатии сохраняет обновлённые ежемесячные взносы в цели (`goal.monthly += alloc[g.id]`), запускает синхронизацию `syncHousehold()` и перенаправляет на `/`.
2. Подключить `Ritual.vue` к маршруту `/ritual` в `frontend/src/router/index.ts` вместо `PlaceholderView`.

## Тесты
- Юнит-тесты логики распределения:
  - Сумма шагов не может превышать общую освободившуюся сумму (`left >= 0`).
  - Расчёт текстовых эффектов для целей и кредита.
- Компонентные тесты:
  - Рендеринг пустого состояния (нет высвобождений).
  - Рендеринг активного ритуала с корзинами распределения.
  - Применение изменений в `financeStore` при подтверждении.

## Критерии приёмки
- При переходе с баннера `Overview.vue` или по прямой ссылке `/ritual` открывается экран ритуала.
- При отсутствии будущих снижений платежей показывается информативная заглушка.
- При наличии высвобождения интерактивно меняются доли, динамически пересчитываются эффекты экономии и сроков.
- Подтверждение корректно обновляет состояние казны.
- `cd frontend && npm test && npm run build` проходит чисто (0 ошибок).

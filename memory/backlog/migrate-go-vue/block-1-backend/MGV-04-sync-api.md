# MGV-04 — API синхронизации household_docs и private_docs с ревизиями (бэкенд)

Блок 1 · MVP · Каталог: `backend/` · Зависит от: MGV-03 · Роли: все

## Контекст (что уже есть)
- Аутентифицированный контекст запроса с `user_id` и `household_id`.
- Логика ревизий:
  - Сервер хранит `rev bigint` и `data jsonb`.
  - При отправке клиент передает `last_seen_rev` и `data`.
  - Если на сервере `current_rev == last_seen_rev`, то сервер обновляет `data`, инкрементирует `rev = rev + 1`, сохраняет и возвращает `200 OK` с новым `rev`.
  - Если на сервере `current_rev > last_seen_rev` (конкурентная правка от партнёра), сервер возвращает `409 Conflict` вместе с актуальным документом сервера, чтобы клиент произвёл слияние (`merge.ts`) и повторил отправку.
- `private_docs`:
  - Ключ `(household_id, user_id)`.
  - Сервер физически фильтрует по `user_id` из JWT — партнёр ни при каких обстоятельствах не может запросить чужой документ.

## Задача
1. Реализовать HTTP-эндпоинты синхронизации семейного бюджета (`internal/handlers/sync.go`):
   - `GET /api/sync/household` — возвращает `{ rev, data, updated_at, updated_by }`.
   - `POST /api/sync/household` — принимает `{ last_seen_rev, data }`.
     - При успехе: обновляет запись, инкрементирует `rev`, возвращает `{ rev, data, updated_at }`.
     - При конфликте версий: возвращает HTTP 409 с `{ error: "conflict", server_doc: { rev, data } }`.
2. Реализовать HTTP-эндпоинты личного кошелька:
   - `GET /api/sync/private` — возвращает личный документ текущего пользователя.
   - `POST /api/sync/private` — сохраняет личный документ с проверкой ревизии.
3. Проверить строгую валидацию ролей: роль `viewer` не имеет права делать POST-запросы на обновление семейного бюджета.

## Тесты
- Интеграционный тест оптимистичной блокировки: два параллельных запроса с одинаковым `last_seen_rev` — один проходит с 200, второй получает 409 с актуальным документом.
- Тест изоляции безопасности: User B отправляет запрос на личный документ — получает только свои данные, данные User A недоступны.

## Критерии приёмки
- Эндпоинты `/api/sync/household` и `/api/sync/private` полностью работают.
- Конфликты версий отдают `409 Conflict`.
- `cd backend && go test -v ./...` все тесты зеленые.

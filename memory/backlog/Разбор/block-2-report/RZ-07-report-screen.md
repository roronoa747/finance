## Задача

1. `components/ai/AiReport.vue` — оверлей `fixed inset-0` слой 50, фон `--canvas`, `role="dialog"`, `aria-label` «Разбор
   месяца»; пропы `open`, `monthKey`, `review: AiReview | null`, `example?` (демо), `card?: number | null` (номер совета
   для старта); emits `close`, `refresh`. Структура: сверху полоски-прогресс (по карточке, активная — `--brand`, `aria-hidden`),
   ✕ (`aria-label` «Закрыть»); лента карточек `overflow-x-auto snap-x snap-mandatory` без видимой полосы прокрутки, каждая
   карточка `w-full h-full snap-center`; нажатие по правой/левой трети карточки — следующая/предыдущая (`scrollTo`);
   свайп вниз от верха (`touchstart`/`touchend`, порог 80 px) — закрыть; активная карточка — по `scroll` (`IntersectionObserver`
   или по `scrollLeft`). Открыт → `markReviewSeen` (как `openReview`).
2. Карточки v3 (по порядку Р-2):
   - **«Работа ИИ»**: заголовок «Работа ИИ», крупно `plain(work.ops)` + подпись «операций просмотрено», строка
     «нашёл K · ≈ X ₸ в год» (без «≈ X», если 0; `money`); под ней тихо — повод и день («1 ноября · начался месяц» /
     «после зарплаты» / «обновили»).
   - **«Куда ушло»** — оболочка карточки и строка `where` модели здесь; полосы — RZ-08 (компонент `WhereBars` получает
     `whereRows`); до RZ-08 — временный список «раздел · сумма».
   - **Совет** (до 3): заголовок `title`, крупно `figure.value` (если есть) с подписью `figure.about` (`--ink-2`, одна
     строка, `clip`), текст одной строкой-абзацем, внизу карточки **одна** кнопка: `do` — `Button` брендовая `md`
     «Сделать» (участник, кандидат применим — как `fresh` листа; сделан — «✓ Сделано» вместо кнопки) → `DoSheet` поверх
     (z 60); `open` — `Button` брендовая `md` «Открыть» → `router.push(openPath(target))`, отчёт закрывается. Viewer: у
     `do` — без кнопки (текст остаётся), `open` — есть.
   - **«Итог прошлого месяца»** (есть `reviewOutcome`): строки «Сделано ✓ / не сделано» по советам, разделы «<раздел>:
     N · обычно M», «мечта «…»: было к <месяцу>, стало к <месяцу>»; нет данных — карточки нет.
   - Низ последней карточки: «Подсказка ИИ · <день> · что ушло» (раскрывает `factsLines`, прокручивается внутри карточки),
     «Обновить» `ghost sm` (условия `canRefresh` из листа), состояния `reviewState` («Думаю…», лимит, «Не вышло») — как в
     листе; демо — «Пример», без дня и «Обновить».
   - Разбор v1/v2 — одна карточка «Разбор»: Хорошо · Риск · Шаг(и) текстом; у v2 «Сделать» как было (`fresh`/`done`); затем
     низ. Разбора нет (запрос идёт / не вышло) — одна карточка состояния.
3. `MonthPlan.vue`: `useQuerySheet('review')` вместо `reviewOpen`; `card` — `route.query.card` (число); `openReview` → при
   наличии разбора `router.push({query: {...route.query, review: '1'}})`, иначе прежняя логика (согласие, запрос), отчёт
   показывает состояние; `<AiReport … />` вместо `<AiReviewSheet … />`. Кнопка ✦ — пока прежняя (пилюля — RZ-08).
4. Снести `AiReviewSheet.vue`, `AiReview.dom.test.ts` (перенести нужные проверки в `AiReport.dom.test.ts`); `ReviewDot.dom.test.ts`
   — обновить под оверлей.
5. Тосты: отчёт выставляет `data-sheet-open` на `html` (как `Sheet`), чтобы тост «В плане месяца · Отменить» был поверх
   (z 65) — или свой слой; проверить `elementFromPoint` в DOM-тесте, как у Х-15.

1. X > 0: крупно «≈ X ₸» (`money(yearly)`), подпись «в год уходит на найденное», строка «K находок из N операций»

2. X = 0 — как было: крупно N, «операций просмотрено», «нашёл K».
3. DESIGN.md §5 (абзац «Разбор v3», карточка «Работа ИИ») — новый вид.

## Тесты

- DOM: X > 0 — крупная цифра «≈ 720 000 ₸», подпись, строка «4 находки из 1 240 операций»; X = 0 — прежний вид;
  склонения (1 находка, 21 операции).

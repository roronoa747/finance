## Задача

1. **Проверка доступности (до кода, в Handoff с источниками и датой):** регионы Gemini API и
   условия бесплатного тарифа; Южная Корея; актуальная модель бесплатного тарифа со
   структурным JSON-ответом. Корея недоступна → стоп, вопрос владельцу.
2. Ключ: владелец создаёт в Google AI Studio → `memory/secrets/gemini.md`, env `GEMINI_API_KEY`,
   модель — `GEMINI_MODEL` с дефолтом из п. 1; без ключа ИИ выключен (не в `ValidateProduction`).
3. Пакет `internal/ai`: клиент Gemini (текст → структурный JSON по схеме, таймаут, лимит
   размера ответа, ошибки: нет ключа / 429 / 5xx / таймаут); ни запрос, ни ответ, ни ключ не
   логируются.
4. `POST /api/ai/categories` (member; `ai_enabled` иначе 503): тело `{names: string[] (≤ 50, ≤ 80
   символов каждое), categories: {id, name}[] (≤ 40)}` → в модель уходит **только** список
   названий и названия разделов + фиксированная инструкция (казахстанские продавцы, ответ —
   id раздела из списка или `null`); ответ `{items: [{name, categoryId | null}]}`;
   `categoryId` вне присланного списка → `null`. Гвард: название с 6+ цифрами → 400.
   429 → 429 «попробуйте позже»; таймаут/5xx → 502.
5. `/auth/me` → `ai_enabled: bool`. README: переменные, ручка, что уходит.

## Тесты

- Клиент на `httptest`: запрос содержит только названия и разделы (тест фиксирует отсутствие
  чего-либо ещё: id семьи, email, сумм), ключ в заголовке/параметре по документации API, схема
  ответа; 429 → своя ошибка; таймаут; ответ с чужим id → `null`.
- Хендлер: viewer → 403; без ключа → 503; > 50 названий → 400; цифры 6+ → 400.
- `config_test.go`: прод без ключа валиден.

## Критерии приёмки

- `go build/vet/test` + корень `api/` зелёные; CI зелёный; Handoff — источники проверки
  региона/тарифа/модели; живой вызов локально с ключом на 10 названиях из топа незнакомых
  (B2C-08) — разумные разделы; из `icn1` — смоук приёмки.

# B2C-32 — Фронт: «спросить ИИ» в разборе, экран «что уйдёт в Google» (фронт)

Блок 6 (условный) · MVP · Каталог: `frontend/src/views/Week.vue`, `components/`, `api/client.ts`, `stores/` · Зависит от: B2C-31 · Роли: member

## Контекст (что уже есть)

- Р-12 (кнопка «спросить ИИ», уходят только названия, честный экран «что уйдёт в Google»);
  Р-28 RP — в экране прямо сказано, что на бесплатном тарифе Google может использовать
  присланное для обучения и показывать разметчикам. `DESIGN.md` §6 — тексты (если дизайн-блок
  их не дал — написать в тоне §6 и показать владельцу в Handoff).
- Неделя `/week` (B2C-21): предпросмотр с незнакомыми продавцами и карточки решений (раздел
  через `Select`, правило → личный документ, пересчёт итогов — B2C-07/B2C-15). `/auth/me` →
  `ai_enabled` (B2C-31); ручка `POST /api/ai/categories`. Стор auth хранит `me`.
- Разделы трат — `spendCategories`; правила — `merchantRules` (B2C-02).

## Задача

1. Кнопка «Спросить ИИ» в списке незнакомых (только если `ai_enabled`, есть сеть, ≥ 1
   незнакомого; не в демо) → `Sheet` «Что уйдёт в Google»: список названий, которые будут
   отправлены (ровно тот массив, что уйдёт), фраза про бесплатный тариф и обучение, «Отправить» /
   «Не надо».
2. Ответ → у каждого незнакомого предложение раздела **предзаполнено, но не применено**: «ИИ
   предлагает: Продукты — Да / Другой раздел»; «Да» → правило (как ручной ответ); массовое «Принять
   все» — с явной кнопкой. `null` → без предложения.
3. Ошибки: 429 / 502 / сеть — спокойный текст, ручной выбор всегда доступен; 503 (выключено) —
   кнопки нет (флаг из `me`).
4. Настройки → «Разбор выписок»: строка «ИИ для незнакомых названий: включён на сервере /
   выключен» (информационно) и ссылка на политику (раздел про Gemini).

## Тесты

- Стор/клиент (фейковый `ApiClient`): тело запроса = названия + разделы, ничего больше;
  ответ → предложения; `null`; 429 → текст.
- SSR/DOM: кнопка только при `ai_enabled` и незнакомых; лист «что уйдёт» показывает те же
  названия; «Да» пишет правило; демо — кнопки нет.
- e2e `b2c-block6-ai.test.ts`: загрузка с незнакомыми → ИИ → принять → правило в личном документе
  партнёру не видно; итоги пересчитаны.

## Критерии приёмки

- Браузер (стенд с ключом): сценарий на настоящей выписке; во вкладке Network тело запроса —
  только названия и разделы; `npm run build && npm test` зелёные.

## Вне скоупа

- Автоприменение предложений, ИИ-разбор бюджета, скриншоты — после MVP.

**Цель блока:** незнакомые названия продавцов можно разложить по разделам одной кнопкой
«спросить ИИ» — с честным экраном, что именно уходит в Google, и без единой суммы или имени;
без кнопки приложение работает так же. **Блок открывается только записью «Блок 6 открыт» в §4
индекса** (замер B2C-08 против порога Р-29); иначе — пропускается.

## Промпт исполнителя — уровень build · Opus 5 · effort high (ultrathink)

```

```

Блок-специфика:

- **Предусловие:** в §4 индекса стоит «Блок 6 открыт». Стоит «отменён» — остановиться и
  сообщить владельцу (следующий — Блок 7).
- Ветка `b2c-block-6-ai-optional` от `main`. Push — с согласия; прод не трогать.
- Задачи: B2C-31 (Go; **сначала** проверка региона/тарифа/модели по источникам — стоп при
  недоступности из `icn1`) → B2C-32.
- Ключ — владелец (Google AI Studio) → `memory/secrets/gemini.md`, env `GEMINI_API_KEY`; в
  доки — имя. Ничего из запросов/ответов — в логи и Handoff.
- Верификация — стандарт §6; браузер: Network — тело запроса только названия и разделы.
- Следующий шаг — `/critic идея-и-редизайн 6 ultracode`.

# B2C-87 — Очередь и «главная = первая» на «Мечтах» и «Желаниях» (фронт)

Блок 14 · MVP · Репо/каталог: `frontend/src/views`, `components/kit` · Зависит от: B2C-85 · Роли: member (viewer —
без перестановки)

## Контекст (что уже есть)

- «Мечты» — `views/Dreams.vue` (220 строк): герой `main = mainGoal(goals)` ~48, остальные `others` ~49, плитка
  «Желания»; `mainGoal` — `finance.ts` ~2492. «Сделать главной» — мелкая ссылка в `views/GoalDetail.vue` ~295
  (`setMainGoal`). «Желания» — `views/Wishes.vue` (318 строк, `liveWishlist` ~66, без сортировки; списки по людям —
  `people/:slot`).
- Очередь и стор — B2C-85 (`queueOf`, `wishQueue`, `moveInQueue`, `moveWish`, `makeMain`). Перетаскивания в проекте
  нет, библиотек нет — свой компонент на pointer-событиях (Р-84: без новых зависимостей). Анимации — токены
  `--motion-*`, «уменьшить движение» — без анимации (Р-45).
- Решения: Р-84 (удержал — перетащил; герой — первая цель, не фонд и не долг; «Сделать главной» заметно; цели среди
  целей, желания среди желаний), правило 12.

## Задача

1. `kit/` — сортируемый список: удержание ~300 мс поднимает карточку (тень `--shadow-lift`), перетаскивание пальцем
   и мышью, автопрокрутка у края, отпускание — `move(id, index)`; клавиатура — «выше/ниже» в меню карточки
   (доступность). Скролл страницы не ломается коротким касанием.
2. `mainGoal` — первая цель очереди (`queueOf`), не фонд и не долг; все потребители (`Dreams`, главный экран,
   `GoalDetail`, «Неделя») берут её.
3. «Мечты»: список целей — в порядке очереди с перестановкой; герой меняется сразу после переноса наверх. Фонды на
   «Мечтах» — по макету B2C-84 (рядом с мечтами, Р-82).
4. Меню карточки цели (и `GoalDetail`): «Сделать главной» — заметный пункт (не мелкая ссылка), переносит наверх.
5. «Желания»: свой порядок с перестановкой (`wishQueue`); превращения в цель нет.
6. Viewer — без перестановки и пункта меню.

## Тесты

- DOM: перенос цели вверх — она герой; «Сделать главной» — наверх; желания переставляются и порядок переживает
  перезагрузку; viewer — без ручки перетаскивания.
- Компонент: удержание < порога — не перетаскивание (скролл), отмена за краем, клавиатурные «выше/ниже».
- `mainGoal`: фонд наверху — герой следующая цель.

## Критерии приёмки

- `npm run build && npm test` зелёные.
- Стенд 390 px, обе темы, телефонная эмуляция касаний: перестановка целей и желаний, герой сменился; партнёр видит
  новый порядок после синка; снимки «макет | стенд».

## Вне скоупа

- Очередь в самом плане месяца — B2C-88 (тот же компонент). Превращение желания в цель — не делаем.

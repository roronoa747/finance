## Контекст (что уже есть)

## Задача

1. Демо: «План месяца» правдоподобен с первого экрана (две зарплаты, одна пришла и не отложена — брендовая кнопка
   видна; платежи с плательщиками; траты обоих с фактом; очередь с фото, одна цель на паузе; подсказка «всё в долг»).
2. e2e `e2e/b2c-block14-month-plan.test.ts`: план на две зарплаты; вкл/выкл цели — остаток и даты; перенос в очереди
   — герой «Мечт»; желания переставляются; смена плательщика; «Отложить по плану» и повтор; viewer; старые адреса →
   `/money`; два клиента — порядок и пауза сливаются.
3. Сверка: план на настоящих данных владельца (на его машине) против ручного расчёта — таблица в Handoff; иначе
   синтетика.
4. Снимки «макет | стенд» 390 px в обеих темах: верх «Денег», очередь, траты каждого, «Мечты» с героем, «Желания»,
   viewer, прошлый месяц — артефактом (для приёмки, Р-41).

## Задача

Новые чистые функции (имена — ориентир; JSDoc по-русски):

1. **`monthPlan(state, ctx: { key, totals, spendCategories, uploads })`** (книга и обмены — `state.book`,
   `state.fxExchanges`, как у остальных расчётов после Блока 13) →
   `{ income: { total, byPerson[] (ожидается, пришло) }, dues[] (сумма, дата, плательщик, оплачено), spend[] (по людям
   и разделам: план, факт|null), queue[] (цель/фонд/долг: плательщик, взнос месяца, дано, дата «к <месяц>», на паузе),
   rest, byPerson[] (зарплата − платежи − траты − взносы → «хватает» / «не хватает N»), short }`. Шаги строго по Р-79;
   очередь получает остаток сверху вниз, каждой — не больше её `monthly` (фонд — до порога; долг — сумма карточки или
   шаг плана); выключенные — 0.
2. **Даты:** у каждой цели — месяц достижения с учётом очереди (что получит в этом месяце и дальше при той же сумме);
   у карточки долга — «к какому месяцу закроем» (`creditOutlook` с доплатой). Выключил цель — даты остальных и остаток
   пересчитаны (функция чистая, вызов с другим `pausedAt`).
3. **`allInDebt(state, ctx)`** — подсказка «всё в долг — закроете к N»: если все цели выключить и остаток в досрочку.
   `null` без процентных долгов.
4. **`planSave(plan, person)`** → что записывает «Отложить по плану» для плательщика: взносы целей и фондов (`once`),
   досрочка (если плательщик карточки долга), части записи. Повторно за месяц — пусто (по записи `allocations`).
   **`planFromSource(state, ctx, source)`** — Р-86 для «остались деньги?», «освободится», «долг закрыт».
5. **История:** `monthPlanPast(state, key)` — сводка прошлого месяца из записей (пришло, оплачено, отложено,
   потрачено), только чтение; прошлые `kind: 'breakdown'` читаются.

## Тесты

- Ручной расчёт (числа в комментарии): семья — Ильяс 1 500 € (Блок 13) + Аруна 450 000 ₸; квартира 250 000
  (Аруна), кредит 80 000 (Ильяс), подписка $15; траты обоих; три цели и два фонда в очереди → `rest`, `byPerson`,
  даты; сумма всех частей = доход до тенге.
- Не хватает: доход меньше платежей + трат → цели 0, `short` > 0; верх очереди получает первым.
- Вкл/выкл: выключил верхнюю — следующая получает её деньги, дата сдвигается, `allInDebt` считает.
- Плательщик: перенос платежа на другого меняет «хватает» обоих, общий итог тот же.
- `planSave`: второй вызов за месяц пуст; записи старого разбора месяца не ломают расчёт.
- `planFromSource`: три источника.

  артефактом (числа и итоги, до тенге), Handoff «Часть 2»; **остановиться, не начиная B2C-87**. Замечания — первыми
  в третьей сессии (`B2C-8x: ворота — …`).

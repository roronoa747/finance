# Блок 4 — Фундамент для чужих · сессии

**Цель блока:** в приложение может войти незнакомая семья — через Google, шаг «с кем», без
мастера; её данные можно удалить одной кнопкой; есть домен, политика и проверенная база;
лэндинг с демо ведёт к «Начать»; владелец видит цифры удержания. После блока — веб-проверка
гипотезы на 5–10 семьях.

Сессии: исполнитель ✅ 2026-10-08 · критик ⬜ · приёмка ⬜ · ревью backend ⬜ · ревью frontend ⬜ · клинап ⬜

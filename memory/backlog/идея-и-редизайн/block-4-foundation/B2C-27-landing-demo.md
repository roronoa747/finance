## Задача

1. `views/Landing.vue` (`/` для анонима; вошедший на `/` видит приложение): секции по
   `DESIGN.md` §6 — фраза-идея, три образа (мечта, свобода, утечки), как это работает (выписка
   раз в неделю → картина → мечта ближе), «выписка не покидает телефон», для кого, кнопки
   «Попробовать» (демо → `/`) и «Начать» (→ `/access` с Google), футер: политика (`/privacy`),
   контакт, ссылки на магазины (появятся в Блоках 7–8 — слоты). Десктоп — та же страница шире
   (картинки телефона по центру). Ленивый чанк; изображения `loading="lazy"`.
2. `index.html`: `<title>`, `<meta name="description">`, OG-теги (картинка из `public/landing/`),
   `lang="ru"`. Имя продукта — из `DESIGN.md` §1.
3. Демо → Google: вопрос «Взять то, что вы заполнили в демо?» — состояние, а не экран:
   `localStorage['ff_demo_pending']` ставится при входе из демо, гард роутера ведёт на экран
   вопроса, пока не отвечено; «Да» → `adoptDemo` в новую семью после «с кем» (только при
   создании семьи; при входе по коду — отбрасывается с текстом, как Р-32 RP); закрытие
   приложения между — вопрос остаётся.
4. `/access` — только вход (Google, dev-форма); ссылки «Назад к описанию» → лэндинг.
5. e2e: аноним `/` → лэндинг; «Попробовать» → демо без запросов; демо → Google (фейк) → «с кем»
   → «Взять?» → «Да» → документ семьи = демо-документ; закрыть/открыть между — вопрос
   остался; вход по коду из демо — не перенесено.

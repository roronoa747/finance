## Задача

1. **Создание цели** «На что копим?»: шаблон или своё фото (B2C-17) → название (из шаблона) →
   сумма → срок (месяц) → взнос считается (`goalMonthly`), «будет вашей в …»; первая цель —
   `main`. Тот же поток — в первом запуске (B2C-19) и по «+».
2. **Экран цели** `/goals/:id` по дизайну: фото-герой с процентом, «будет вашей в», взносы
   (`Sheet`), «Сделать главной», «Поделиться» (B2C-20), правка, удаление; viewer — без форм.
   Хвосты: месяц взноса и серия по `monthKey` (Алматы); цена «дорожает» — горизонт до
   `goalDoneMonth`.
3. **Экран участника** `/people/:slot`: его желания (фото, цена, ссылка), «Добавить» (в свой
   список — `by` = свой слот), покупки «Уже купили»; чужой список — «Добавить подарок-сюрприз»
   → запись в **своём** личном документе `privateDoc.gifts[]` (`{ id, forSlot, name, price,
   photoId?, bought } & Tracked`; фото со скрытым признаком) — автор видит его в списке адресата
   с пометкой «видите только вы», адресат — нет. `mergePrivateDocs` — `gifts` по id.
4. **«Это приближает»**: `finance.ts` — `closerWish(wishes, amount, mode)` — какое некупленное
   желание с ценой становится ближе от суммы (разовой или ежемесячной) и на сколько; показ одной
   строкой в результате досрочки и в раскладке зарплаты (B2C-21 подключит).
5. Общий список желаний (вкладка «покупки» на `/`? — по `DESIGN.md` §3) — общий компонент
   списка, без дублирования с экраном участника.
6. Старые `Goals.vue` вкладки — по таблице §3: цели живут на `/` (B2C-14), покупки — экран
   участника и общий список.

# B2C-20 — Карточка для сторис без сумм (фронт; Р-10)

Блок 3 · MVP · Каталог: `frontend/src/lib/storyCard.ts` (новый), `views/GoalDetail.vue`, `components/` · Зависит от: B2C-17 · Роли: member, viewer (тоже может поделиться)

## Контекст (что уже есть)

- Р-10: карточка «накопили 60 % на Японию» / «отказались от 3 подписок» — картинка с фото
  цели и процентом через системное «Поделиться»; **без сумм**. `DESIGN.md` §7 (размеры, слои,
  шрифты, что не печатается).
- Фото цели — `photoUrl(id)` (B2C-17, object URL); процент — `goalHave/need`; отменённые
  подписки месяца — обязательства с `isSubscription` и `deletedAt` в месяце (надгробие RP-09).
- Web Share API: `navigator.canShare({ files })` — Android Chrome и iOS Safari умеют делиться
  файлами; иначе — скачивание (`<a download>`). Тесты — Node без canvas: композиция и тексты —
  чистые функции; рисование проверяется в браузере.

## Задача

1. `lib/storyCard.ts`: `storyText(kind, data)` → строки карточки («62 % до Японии», «Отказались
   от 3 подписок», подпись приложения) — **без сумм** (гвард в функции: ни одной цифры с «₸»,
   ни `need`/`have` в тексте); `layoutStory(size)` — координаты слоёв по `DESIGN.md` §7;
   `renderStory(canvas, { image, texts, layout })` — рисует (фото cover + затемнение + текст),
   возвращает `Blob` webp/png.
2. Кнопка «Поделиться» на экране цели и в итоге месяца (при отказе от подписок): предпросмотр
   карточки (в `Sheet`) → «Поделиться» (`navigator.share` с файлом) или «Сохранить» (скачать).
   Нет фото — фон по `hue` цели.
3. Шрифты для canvas — те же семейства (загрузка через `document.fonts.load` до рисования).

## Тесты

- `storyCard.test.ts`: тексты для процентов (0, 62, 100), подписок (1, 3, 5 — склонения
  `plural`); гвард сумм (попытка передать сумму → в тексте её нет); `layoutStory` по размерам.
- DOM-тест кнопки: `canShare` есть → вызван `share` с файлом; нет → ссылка `download`.

## Критерии приёмки

- Браузер (стенд, телефон или эмуляция): карточка 1080×1920 с фото и текстом в обеих темах
  (тема не влияет — карточка одна), «Поделиться» открывает системный лист на телефоне
  владельца (проверка в приёмке/смоуке); в картинке нет сумм.
- `cd frontend && npm run build && npm test` зелёные.

## Вне скоупа

- Друзья, лента, реакции — после MVP. Карточки других видов («30 дней без кредитки») — после MVP.

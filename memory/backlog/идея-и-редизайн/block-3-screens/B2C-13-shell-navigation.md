## Задача

1. Маршруты по `DESIGN.md` §2: `/` (Мечты — B2C-14), `/week` (B2C-21; до неё — экран
   `/statements` из B2C-07 под этим адресом), `/money` (список входов — B2C-21), `/money/budget`,
   `/money/capital`, `/money/capital/:id`, `/money/plan`, `/goals/:id`, `/people/:slot`
   (B2C-18), `/settings`, `/start` (B2C-19); **старые пути — редиректы** (`/budget` → `/money/
   budget`, `/capital` → `/money/capital`, `/goals` → `/`, `/ritual` → `/week`, `/plan` → `/money/
   plan`, `/statements` → `/week`) — установленные PWA и ссылки не ломаются. `HomeView.vue`
   удалить.
2. `AppShell`: вкладки и «+» по §2/§5 на компонентах кита (B2C-12); заголовки по маршруту;
   шапка: аватары ведут на `/people/:slot` (B2C-18; до неё — без действия), `SyncBadge`,
   шестерёнка → `/settings`; **«Советник» ✨ убрать** вместе с `onSparkleClick`.
3. Лист «+» на `Sheet` кита (Escape, фокус, `--scrim`): действия по §2 — «Загрузить выписку»
   первым (`/week?upload=1`), «Мечта», «Покупка», «Доход», «Обязательство или кредит вручную»
   (второй уровень); viewer — лист без действий правки.
4. `/settings` (`views/Settings.vue`): «Оформление» (`AppearancePanel` — на `Sheet` или прямо на
   экране), имя, семья (участники, «Пригласить», «По коду» — пока текущие механики), заглушки-
   секции под напоминание (Блок 5) и удаление аккаунта (Блок 4) **не заводить** — секции появятся
   своими задачами.
5. Шторка синка: текст «Сотрутся общие счета…» (хвост PV), остальное как есть.
6. Тесты и e2e: обновить ссылки на пути; сценарии, проверяющие вкладки/лист «+», — на новые.

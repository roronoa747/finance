## Контекст (что уже есть)

- Р-9: фото цели и желания — в своей таблице Postgres через Go-ручку загрузки; сжатие на
  телефоне (~100 КБ, webp). Скрытые подарки (Р-9 RP): фото скрытого видит только автор — Go
  проверяет владельца при выдаче. Viewer данные не меняет. Матрица прав — §3 индекса и §3 RP
  (чужая семья и чужое скрытое — 404, не 403).
- Роутер `backend/server/server.go`: защищённая группа, роль в хендлере; хелперы
  `decodeJSONBody`, `respondJSON`; бинарное тело — `http.MaxBytesReader`. Репозитории:

  репозитория и миграции `000002`).
- Миграции: следующая — `000003_photos.sql` (номер сверить по каталогу), `app.`-квалификация,
  только добавление. Vercel: тело ≤ 4,5 МБ; регион `icn1`.
- Тесты: хендлеры на моках, `TestPostgres*` (`internal/testdb`), `server_e2e_test.go`.

## Задача

1. Миграция `000003_photos.sql`: `app.photos` — `id uuid pk`, `household_id` FK CASCADE,
   `user_id` FK CASCADE (автор), `hidden boolean`, `content_type text` (`image/webp`,
   `image/jpeg`), `bytes bytea`, `size int`, `created_at`. Индекс `(household_id)`.
2. Ручки (защищённые):
   - `POST /api/photos?hidden=0|1` — тело — байты картинки, `Content-Type` из белого списка,
     лимит 512 КБ; проверка сигнатуры (webp/jpeg) → 400; только `member` (403); ответ 201 `{id}`.
   - `GET /api/photos/{id}` — своя семья; `hidden` — только автору, иначе 404; чужая семья —
     404. Заголовки: верный `Content-Type`, `Cache-Control: private, max-age=31536000, immutable`,
     `X-Content-Type-Options: nosniff`.
   - `DELETE /api/photos/{id}` — автор; не-скрытое — любой `member` семьи (записать выбор в
     README); viewer — 403; нет — 404.
   - Байты в SQL — через `[]byte` параметр **проверить в PG-режиме с `binary_parameters=yes`**
     (`bytea` в отличие от `jsonb` принимает binary; тест в CI гоняет оба DSN).
3. Репозиторий `PhotoRepository` (pg + мок), `server.Repos.Photos`, README.
4. `runLiveServerE2EFlow` — загрузка и выдача (оба режима).

## Тесты

- Хендлеры на моках: member 201 и id; viewer 403; неверный тип / подмена сигнатуры 400; > 512 КБ
  → 413; выдача своей семье байт-в-байт; чужой семье 404; скрытое партнёру 404, автору 200;
  удаление по правилам; заголовки кэша и nosniff.
- `TestPostgres…`: миграция на чистой и мигрированной БД; те же сценарии; каскад при удалении
  пользователя/семьи; оба DSN.

## Задача

1. Модель: `Goal.main?: boolean` (+ `updatedAt`); `mainGoal(goals)` в `finance.ts` — живая
   цель с `main`, при двух — с поздним `updatedAt`, без пометки — первая живая; стор
   `setMainGoal(id)` (снимает у остальных). Слияние — как поля цели (LWW).
2. Расчёты (`finance.ts`, целые тенге):
   - `weekPicture(totals, categories, people, weekKey)` → строки по разделам с суммой обоих и
     долей, список участников без загрузки за неделю (`uploads` по периоду — параметр).
   - `freeByFact(state, totals, monthKey)` → «Свободно до конца месяца» = доход месяца
     (`totalIncome`) − обязательства и кредиты месяца по плану (`monthDues`, с учётом отметок) −
     взносы в цели по плану (`goalSavings`-месяц) − **траты по выпискам обоих за месяц** по
     разделам, кроме помеченных `plannedElsewhere` (кредиты, коммуналка, аренда — они уже в
     `monthDues`; флаг — поле `SpendCategory.plannedElsewhere`, в дефолтном списке B2C-02
     проставить). Нет ни одной загрузки за месяц → показывать план (`budgetAmounts.free`) с
     подписью «по плану».
   - `nextDecision(state)` → одна карточка: незнакомые продавцы недели (счёт) → ждущие
     сопоставления (B2C-15, после неё) → `salaryOpen` («Пришла?») → `keepQuestions` →
     `monthEndAsk` → шаг плана `stepDue` → `null`; у каждой — текст из `DESIGN.md` §6 и маршрут.
   - Хвосты: `untilPayday` — день `min(payday, daysInMonth)` и окно три месяца.
3. `views/Dreams.vue` (маршрут `/`): герой (фото/заглушка, «До мечты: N%» = `have/need`, «будет
   вашей в <месяц>» из `goalDoneMonth`, нет цели → «На что копите?» → создание B2C-18), плитки
   других мечт, полоса недели (+ «без выписки <имя>»), «Свободно до конца месяца», карточка
   решения (`nextDecision`) → маршрут. Ничего не считать в компоненте.
4. `Overview.vue` — удалить после переноса всего полезного: «История семьи», итог месяца и
   «Впереди» уезжают на второй уровень (B2C-21 — до неё временно доступны по `/money`), тесты
   переносятся.

## Задача

1. `lib/statements/firstRun.ts` (чистые функции): по операциям одной выписки —
   `detectIncome(ops)` → кандидаты дохода (крупные регулярные приходы: сумма, день),
   `detectRecurring(ops)` → повторяющиеся списания (по нормализованному продавцу/получателю:
   ≥ 2 раза за период или типичные признаки — кредит, аренда, связь, подписка), каждый с
   предложенным видом (`obligation` с разделом d1/d3/d4, `credit`, `subscription`).
2. `views/Start.vue` (`/start`, ленивый): шаги по одному экрану — (1) «Загрузите выписку»
   (тот же поток B2C-07; «Введу вручную» → короткая форма дохода и дня зарплаты); (2) вопросы
   по одному: «Это ваш доход? <сумма> <день>» → `Person.salary/payday`; «<продавец> — это
   аренда / кредит / подписка / нет?» → `addObligation` (сумма, день, раздел) или `addCredit`
   (сумма платежа; остаток и ставка — «можно позже», кредит без ставки помечен, как долг «по
   сроку» PV-03) — не более 7 вопросов, остальное «позже в Неделе»; (3) картина месяца
   (`weekPicture`/месяц); (4) «На что копим?» — создание цели (B2C-18) или «пока без цели»;
   (5) «Пригласить партнёра» (код; «позже») → `finishSetup()` → `/`.
   Партнёр по коду: шаги (1)–(2) для себя, без (4)–(5); `people[slot]` создаётся с именем
   регистрации, если его нет.
3. Роутер: гард ведёт на `/start` вместо `/setup`; `/setup` → редирект `/start`. `Setup.vue`,
   `lib/setup.ts` и их тесты удалить; e2e, где мастер — на новый поток (по существу).
4. Демо: стартует с примером, у которого есть итоги выписок и главная цель с шаблоном
   (без фото) — «Попробовать» показывает новый главный (лэндинг — Блок 4).

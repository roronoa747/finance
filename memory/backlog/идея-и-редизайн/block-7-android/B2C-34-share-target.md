# B2C-34 — «Поделиться выпиской → в приложение» (share target оболочки Android)

Блок 7 · MVP · Каталог: `frontend/android/`, `frontend/src/lib/platform.ts`, `views/Week.vue` · Зависит от: B2C-33 · Роли: member

## Контекст (что уже есть)

- Р-18: «Поделиться выпиской из банка → в приложение» — через share target оболочки (бывший
  RP-19 «поделиться → в приложение» переосмыслен: не желание, а выписка). Приложение Kaspi
  отдаёт выписку PDF через системное «Поделиться»; Freedom — PDF/xlsx (по `CORPUS.md`).
- Поток загрузки (B2C-07/B2C-21): `/week?upload=1` принимает файл → разбор на устройстве.
  Оболочка B2C-33: плагины, `isNative()`.
- Приём `ACTION_SEND` в Capacitor: официального плагина нет; варианты — community-плагин приёма
  intent или свой маленький плагин (Java/Kotlin, ~60 строк: intent-filter в манифесте, чтение
  `EXTRA_STREAM` в байты/base64, событие в JS). Выбор — исполнителя с обоснованием (поддержка,
  размер, безопасность чтения URI).
- PWA Web Share Target (манифест) для файлов требует `POST` + обработчик в SW — **не делаем**
  (веб-путь — выбор файла; магазины — оболочка).

## Задача

1. `AndroidManifest.xml`: intent-filter `ACTION_SEND` (и `SEND_MULTIPLE`) для `application/pdf`
   и xlsx-типа (если формат в корпусе); приложение появляется в системном листе «Поделиться».
2. Приём: плагин/обработчик передаёт в JS имя, тип и содержимое файла (base64 или временный
   путь через `Filesystem`); JS → `/week?upload=shared` → тот же поток разбора; приложение
   было закрыто → холодный старт с ожидающим файлом (обработать после входа и загрузки
   документа; нет входа → файл отбрасывается с текстом).
3. Ограничения: размер ≤ 20 МБ, тип вне списка → спокойный текст; viewer → текст «загружать
   выписки может участник».

## Тесты

- Чистая функция `sharedPayloadToFile(payload)` (тип, имя, байты) с тестами; SSR `Week` —
  состояние «получена выписка из „Поделиться“».
- Ручная проверка на телефоне: Kaspi → выписка → «Поделиться» → приложение → разбор.

## Критерии приёмки

- На Android владельца: из Kaspi «Поделиться» PDF → приложение открывает неделю с разбором
  (горячий и холодный старт); веб-сборка не тронута (`e2e/` зелёный).

  нет.

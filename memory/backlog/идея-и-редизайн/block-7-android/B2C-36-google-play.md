# B2C-36 — Google Play: аккаунт, листинг, форма данных, закрытое тестирование → прод (релиз)

Блок 7 · MVP · Каталог: `frontend/android/` (release-сборка), `memory/backlog/идея-и-редизайн/block-7-android/STORE.md` (новый), лэндинг (бейдж) · Зависит от: B2C-34, B2C-35 · Роли: владелец (аккаунт, подписи), агент (материалы, шаги)

## Контекст (что уже есть)

- Р-17 (бесплатно, без покупок), Р-18 (аккаунт Google Play 25 $ принят; релиз через магазин;
  Android первым), Р-14 (политика на домене — B2C-26; удаление аккаунта — B2C-24). Тексты
  магазина — `DESIGN.md` §6 (короткое ≤ 80 знаков, полное ≤ 4000), скриншоты — с дизайна или
  реального телефона.
- Play Console требует: подпись приложения (Play App Signing: ключ загрузки генерируется
  локально — keystore и пароли **только** в `memory/secrets/android/`), листинг (название,
  описания, иконка 512, графика 1024×500, скриншоты телефона ≥ 2), категория «Финансы»,
  анкету возрастного рейтинга, **форму «Безопасность данных»** (что собираем: email, имя,
  финансовые операции; шифрование в пути; удаление по запросу — в приложении; передача
  третьим лицам — Google вход; Gemini — только по действию пользователя, если включён),
  политику конфиденциальности (URL), целевую аудиторию 18+, декларации (финансовые
  функции — не кредитор), доступ для проверки (демо + тестовый вход: описать «Попробовать»).
- Дорожки: внутреннее тестирование (владелец, партнёр) → закрытое (5–10 семей по ссылке) →
  производство. Версии: `versionCode` растёт с каждой сборкой, `versionName` = версия
  `frontend/package.json` (задать 1.0.0).
- **Публикация в производство — только в деплоящей роли (приёмка блока) с «да» владельца**;
  эта задача доводит до внутреннего тестирования.

## Задача

1. `STORE.md`: чек-лист Play Console по шагам (аккаунт → приложение → подпись → листинг →
   формы → дорожки), готовые тексты (из `DESIGN.md` §6), ответы формы данных построчно, список
   скриншотов с именами файлов (`frontend/public/store/android/*.png`, снятые с телефона в
   обеих темах), ссылка на политику; что делает владелец, что агент.
2. Release-сборка: ключ загрузки (владелец генерирует по инструкции; в секреты),
   `./gradlew bundleRelease` (AAB), `versionCode`/`versionName`; сборочная памятка в
   `frontend/android/README.md`.
3. Загрузка AAB на внутреннее тестирование (владелец — Play Console; агент — через MCP, если
   подключение появится), установка на оба телефона из Play; смоук по чек-листу (вход,
   выписка через «Поделиться», пуш, сторис).
4. Лэндинг: бейдж «Доступно в Google Play» со ссылкой (слот B2C-27) — включается после выхода
   в производство (флаг/константа).

## Тесты

- Нет кода; проверка — установка из внутренней дорожки на двух телефонах и смоук.

## Критерии приёмки

- Приложение на внутренней дорожке, оба телефона установили из Play, смоук пройден; `STORE.md`
  заполнен; форма данных и политика приняты консолью без замечаний.

## Вне скоупа

- Выход в производство — приёмка блока (деплоящая роль, с «да» владельца). Покупки,
  подписки — не-скоуп (Р-17). iOS — Блок 8.

**Факты после Блока 1** (критик Блока 1, 2026-09-27; по коду и корпусу владельца):

- **Что знает приложение об операции** (личная, партнёру не видна): дата; сумма в целых тенге
  (минус — списание); банк (Kaspi / Freedom); вид — покупка, перевод человеку/от человека,
  перевод между своими, наличные, комиссия, прочее; **продавец как печатает банк** — у Freedom
  латиницей и с городом («YANDEX.GO ALMATY KZ» → для сравнения «yandex go»), у Kaspi — как в
  приложении, много «ИП <фамилия>» и «TOO "…"»; у переводов людям — **«Имя Ф.»** (не полное
  ФИО); раздел трат или «не разобрано»; флаг «между своими» (не трата). Номеров карт/счетов и
  полных ФИО нет нигде.
- **Разделы трат** — 17 по умолчанию: Продукты, Кафе и рестораны, Транспорт, Связь и интернет,
  Подписки, Здоровье и аптеки, Дом и быт, Одежда и покупки, Развлечения, Переводы людям, Кредиты
  и рассрочки, Коммуналка, Образование, Путешествия, Наличные, Комиссии, Прочее (+ «Не
  разобрано»). У каждого — оттенок из палитры (часть повторяется — цвета решает дизайн);
  переименование и цвета — Блок 3 (B2C-21). Это **не** разделы бюджета d1–d5.
- **Что видит партнёр:** итоги по разделам за неделю (ISO, пн–вс по Алматы) и месяц — суммы до
  тенге, сумма обоих; записи загрузок «кто · банк · период · сколько операций». Операций и
  продавцов партнёра — нет (экран честно говорит «у партнёра они в его телефоне»).
- **«Без выписки <имя>»** — участник, у которого нет загрузки, чей период задевает текущую
  неделю.
- **Незнакомое:** на корпусе владельца словарь не узнаёт ~28 % строк трат (~16 % суммы); **57 %
  из них — «ИП <фамилия>»** (магазин у дома, по названию не угадать). Вопрос «куда отнести» —
  группа по продавцу или получателю: название, сколько раз, сумма, выбор раздела / «внутренний
  перевод» / «кому → что» (текст, например «няня»). Ответ — память навсегда (следующие выписки
  раскладываются сами). Пропустить можно — останется «не разобрано». Подпись «кому → что» пока
  нигде не показывается (хвост §4 — место для неё решает дизайн).
- **«Это перевод партнёру?»** — подсказка, когда имя получателя совпадает с именем участника
  («Дана К.» ↔ «Дана»); «да» — переводы между вами не траты.
- **Выписка:** только PDF из приложения Kaspi / Freedom; период «с даты по дату», обычно до 3
  месяцев (Kaspi ~345, Freedom ~600 операций за 3 месяца); разбор на телефоне 1–3 с, файл не
  уходит. Операции в USD/EUR (Freedom) пропускаются — экран пишет «В валюте — N: их пока не
  считаем». **Зарплаты в корпусе нет** (как банк её печатает — неизвестно): доход в первом
  запуске угадывается по крупным регулярным приходам.
- **Повтор того же файла** — «Все N уже были — ничего не удвоится»; без сети — «N операций
  отправятся при сети. Итоги уже посчитаны».
- **Сейчас на экране `/statements`** (черновой, до редизайна): кнопка «Загрузить выписку» →
  предпросмотр (операций, «уже были», списания / поступления / между своими, подсказки о
  партнёре, незнакомые с выбором) → «Отправить» / «Отмена»; картина — таблица «раздел · неделя ·
  месяц · Всего», тап по разделу — свои продавцы с выбором раздела задним числом; список
  загрузок семьи. Входы — «+» («Загрузить выписку» первым) и карточка в Ритуале.
- Для макетов — правдоподобные данные: 8–12 разделов с тратами за неделю, 1–2 незнакомых,
  «без выписки» у одного из пары.

## Задача

Страница «03 Экраны» в Figma (компоненты — на странице «00 Компоненты»: кнопки, карточки,
герой мечты, полоса недели, карточка решения, плитка шаблона, строка операции, вкладки):

1. **Главный «Мечты»**: герой (фото цели, «До мечты: 62 %», «будет вашей в мае 2027»), другие
   мечты плитками, картина недели по разделам (обе выписки; состояние «без выписки <имя>»),
   «Свободно до конца месяца», ближайшее решение недели (одна карточка). Состояния: нет цели;
   цель без фото; ещё нет выписок.
2. **«Неделя»**: до загрузки (напоминание, кнопка), предпросмотр разбора (период, число
   операций, суммы, внутренние переводы), **карточки «одно решение за раз»** (незнакомый
   продавец → раздел; «похоже, платёж по Автокредиту — отметить?»; «это зарплата Ильяса?»;
   «оставить подписку?»), итог недели, «пришла зарплата → разложить».
3. **Первый запуск** (флоу из 6–7 экранов): лэндинг → Google → «с кем» (один / создать / по
   коду) → загрузить выписку (или «введу вручную») → вопросы по одному → картина месяца →
   «на что копим» (шаблон + срок) → главный.
4. **Мечты подробно**: экран цели (фото, прогресс, «будет вашей в», взносы, «поделиться»),
   создание цели с выбором шаблона (5 типов + направления, своё фото), список желаний участника,
   подарок-сюрприз (виден только автору).
5. **Карточка для сторис** (1080×1920): фото цели + «62 % до Японии» + имя приложения; без сумм.
6. **«Деньги»** (второй уровень): вход-список (Бюджет, Капитал, План, Вклад) и один экран
   внутри (Капитал) в новом стиле — остальные экраны второго уровня переносятся на кит без
   перерисовки.
7. **Настройки**: оформление, имя, напоминание (день и час), «с кем» / код партнёра, удалить
   аккаунт, политика.
8. **Лэндинг** (`/`): фраза-идея, три образа, «Попробовать» (демо) и «Начать» (Google), для
   кого, приватность («выписка не покидает телефон»), телефон и десктоп.
9. Навигация: нижние вкладки (по умолчанию «Мечты · Неделя · Деньги» + «+»), лист «+».
10. **Утверждение владельца** по группам экранов (AskUserQuestion; правки — ещё круг); итог — в
    SESSION.md «Приёмка».

## Тесты

- Нет кода. Проверка — каждый экран есть в светлой и тёмной версии; тексты на русском; суммы
  в макетах — целые тенге с пробелами (как `money()` приложения); карточка сторис без сумм.

## Критерии приёмки

- Все экраны п. 1–9 в Figma, компоненты на «00 Компоненты», ссылки на фреймы — в `DESIGN.md`
  §2 (B2C-11 дописывает); утверждение владельца записано.

## Задача

1. Референсы: собрать 12–20 экранов из списка брифа (Mobbin или публичные страницы магазинов и
   пресс-киты), по каждому — одна строка «что берём» (герой с фото, кольцо прогресса, недельный
   отчёт, карточка сторис, тон текста). Разместить на странице Figma «01 Референсы»; в
   `DESIGN.md` — список со ссылками на источники (не картинки).
2. Мудборд: **две** направления (не больше) на странице «02 Мудборд» — палитра (светлая и
   тёмная), типографика, характер фото, сетка и радиусы, 2–3 ключевых компонента в наброске
   (герой мечты, карточка решения, полоса недели); у каждого — 3 строки «почему». Рекомендация
   агента — одна из двух.
3. Фраза-идея: три варианта (дефолт брифа + два), с подписью для лэндинга и для магазина
   (одна строка ≤ 80 знаков); рекомендация.
4. Принципы дизайна (5–7 строк: мечта — герой; одно решение за раз; цифры крупно, кнопок мало;
   без сравнений участников; тёмная тема равноправна; фото — настоящие, не стоковые лица) —
   в `DESIGN.md` §1.
5. **Утверждение владельца** (AskUserQuestion: направление, фраза; при правках — ещё круг).
   Итог — в `DESIGN.md` §1 и в SESSION.md («Приёмка» — что утверждено, дата).

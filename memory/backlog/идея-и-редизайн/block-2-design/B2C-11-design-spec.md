## Задача

`DESIGN.md` (в git, без картинок; ссылки на фреймы Figma):

1. **§1** — направление, фраза-идея, принципы (из B2C-09).
2. **§2 Карта экранов и навигации**: маршруты (`/`, `/week`, `/money/*`, `/goals/*`,
   `/settings`, `/start`, лэндинг), вкладки, лист «+», ссылки на фреймы Figma каждого экрана и
   состояния.
3. **§3 Таблица «что есть → где живёт» — финал** (каждая строка черновика брифа + всё, что
   нашлось в коде: экраны, окна, действия «+», Ритуал, План, Вклад, калькуляторы, «Советник»,
   мастер, демо): главный / второй уровень (где именно) / под капотом / убрать. Утверждает
   владелец.
4. **§4 Токены**: цвета светлой и тёмной темы (hex, имена в терминах существующих токенов —
   `--canvas`, `--surface*`, `--ink*`, `--brand*`, `--pa/--pb`, `--d1..d5`, `--warn*`, `--gold*`,
   `--scrim` + новые), радиусы, тени, отступы, типографика (семейства, размеры, веса, где
   крупные цифры), иконки. Если шрифты меняются — только Google Fonts, названия и веса.
5. **§5 Компоненты → кит**: какие существующие компоненты остаются как есть, какие меняют вид,
   какие новые (герой мечты, полоса недели, карточка решения, плитка шаблона, строка операции,
   вкладки) — пропсы и состояния словами; правило: цвет только из токенов.
6. **§6 Тексты**: заголовки экранов, тексты карточек решений («похоже, это платёж по …»),
   пустые состояния, «без выписки <имя>», подписи первого запуска, лэндинг (полностью), тексты
   магазинов (короткое и полное описание — заготовка для Блоков 7–8), тон (мы, без упрёков).
7. **§7 Карточка сторис**: размеры, слои, шрифты, что никогда не печатается (суммы).
8. **§8 Чек-лист переноса** для B2C-12…B2C-21: порядок, что проверить в обеих темах, ширина 390.
9. **Утверждение владельца** таблицы §3 (AskUserQuestion) — в SESSION.md «Приёмка».

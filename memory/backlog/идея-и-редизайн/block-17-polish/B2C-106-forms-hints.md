# B2C-106 — Формы с подсказками: кнопка не блокируется молча, поле подсвечено (фронт)

Блок 17 · MVP · Репо/каталог: `frontend/src/components/kit/`, `components/ui/`, листы и формы · Зависит от: B2C-105
(ворота) · Роли: member, viewer

## Контекст (что уже есть)

- `:disabled` — ~40 файлов `.vue` (`grep -rln ":disabled" frontend/src --include=*.vue`): листы `components/capital/*`,
  `components/goals/*`, `MarkSheet`, `SalaryDialog`, виды `GoalNew`, `Start`, `Access` …; кнопка неактивна, пока форма
  не заполнена — без объяснения (отзыв специалиста).
- `kit/Sheet.vue` — оболочка листа (props `open`, `title`, `z`; emit `close`); **своей главной кнопки нет** — кнопки в
  слоте каждого листа. `ui/Button.vue` (prop `disabled`, стили `ui/button.ts` — `disabled:opacity-50`),
  `kit/NumField.vue` и `kit/Field.vue` (стиль `aria-invalid:border-destructive` уже есть, ошибки-строки нет).
- Цвета — только токены `src/index.css` (у ошибки — `--destructive` или ближайший токен из `DESIGN.md`).

## Задача

1. Общий механизм в `kit/` (Р-114): поле получает ошибку (`Field`/`NumField`: `aria-invalid`, одна строка под полем),
   форма по нажатию главной кнопки проверяет поля по порядку, первое неверное — подсвечено, прокручено в видимую
   часть листа и в фокусе; данные не сохраняются. Форма решает, какие правила; механизм — один на все.
2. Перевести все листы и формы с «молчащей» `disabled` на этот механизм. `disabled` оставить только по смыслу (viewer,
   идёт сохранение) — тогда рядом одна строка «почему» (или кнопки нет вовсе, как у viewer сейчас).
3. Тексты ошибок — короткие: «Введите сумму», «Больше нуля», «Выберите счёт» (правило 12, одна строка).
4. Handoff — список переведённых листов и где `disabled` остался с причиной.

## Тесты

- DOM-тест механизма (`kit/*.dom.test.ts`): пустая форма → нажатие → ошибка у первого поля, фокус на нём, `submit` не
  вызван; исправил → ошибка ушла, `submit` вызван.
- DOM-тесты 3+ живых листов (новая цель, новый кредит, лист зарплаты): кнопка нажимается и называет пустое поле.
- `grep -rn ":disabled" frontend/src --include=*.vue` — остались только перечисленные в Handoff.

## Критерии приёмки

- На телефоне: пустая форма любого листа → видно, что заполнить, без поиска; `npm run build && npx vitest run` зелёные.

## Вне скоупа

- Серверная валидация Go; новые поля и правила, которых нет сейчас; геометрия листов (B2C-109).

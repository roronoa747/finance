# B2C-107 — Прокрутка: позиция вкладки, «назад» — на место, новый экран — сверху (фронт)

Блок 17 · MVP · Репо/каталог: `frontend/src/components/AppShell.vue`, `frontend/src/router/` · Зависит от: B2C-105
(ворота) · Роли: member, viewer, демо

## Контекст (что уже есть)

- Прокручивается не окно, а `<main ref="mainEl">` в `components/AppShell.vue` (~стр. 181); `watch(route.path)` (~стр.
  108–118) **обнуляет** `scrollTop` при каждой смене пути — поэтому «назад» и возврат на вкладку теряют место. По
  `path`, не `fullPath`: «Капитал» открывает окна параметром адреса (Б-15) — список не прыгает; это сохранить.
- `router/index.ts` (~стр. 125, `createRouter`) — `scrollBehavior` нет (и не поможет: окно не прокручивается).

## Задача

1. Запоминать `scrollTop` `<main>` по ключу экрана (path; для вкладок — их корень) перед уходом (Р-115).
2. «Назад» (popstate / `router.back`, жест iOS) → вернуть сохранённую позицию после отрисовки экрана (данные могут
   прийти позже — дождаться высоты или повторить на `nextTick`/кадр).
3. Переход вперёд на новый экран → сверху (как сейчас). Переключение вкладки нижней навигации → позиция этой вкладки.
4. Смена только query (окна «Капитала») — не трогать прокрутку, как сейчас.

## Тесты

- DOM/роутер-тест (memory history): прокрутили «Деньги» → открыли экран цели (сверху) → назад → та же позиция; вкладка
  «Мечты» → «План» → «Мечты» — позиция «Мечты»; query-переход не меняет `scrollTop`.

## Критерии приёмки

- На телефоне (стенд 390 px): «назад» → то же место; новый экран — сверху; `npm run build && npx vitest run` зелёные.

## Вне скоупа

- Позиция внутри листов (`Sheet`) и горизонтальных каруселей; сохранение между перезапусками приложения.

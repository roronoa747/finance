## Задача

1. Тишина (Р-116) по макету: убрать подзаголовки с именами; дубль «Капитал»; на «Мечтах» — «<цель> · <месяц год>»,
   «Свободно … · до зарплаты N дней», «к <месяц>» у цели — в экран цели / лист; на «Плане» — «прошлая неделя — …»,
   «↑N %», ряд «! 1» + сетка, точка у «Месяц» — по макету; у зарплат «ждём/пришла <дата>» — в лист зарплаты. Ничего не
   теряется: каждое убранное число есть в своём предмете — перечислить в Handoff «откуда → куда».
2. Геометрия (Р-117) вкладок и экрана цели: размеры кнопок по уровню из макета (в `button.ts`, не по месту), сетка и
   отступы, кнопки не жмутся; без своих цветов — токены.
3. Handoff по каждому экрану (правило 12): главное действие и у какого предмета, что в подсказке, что скрыто.

## Тесты

- Обновить DOM-тесты, которые проверяли убранные подписи (не удалять проверку числа — перенести на его предмет).
- DOM: шапка вкладок без имён; на «Мечтах» нет «до зарплаты N дней», а на экране цели срок есть.

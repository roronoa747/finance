# Блок 5 — Недельный ритм · сессии

**Цель блока:** приложение само зовёт загрузить выписку — пуш обоим в выбранный день и час по
Алматы, отдельно напоминает отставшему партнёру, а картина недели честно показывает «без
выписки <имя>»; ритм «раз в неделю» держится не памятью, а уведомлением.

Сессии: исполнитель ⬜ · критик ⬜ · приёмка ⬜

**Факты кода после Блока 4** (критик Блока 4, 2026-10-09; подробно — §6 индекса «После Блока 4»):

- **Ветка** — от `main` после деплоя и 🏁 Блока 4 (L: клинап деплоит). Миграция пуша — **`000007_push.sql`** (Блок 4
  занял `000005_google_auth`, `000006_events`); `cmd/migrate` ждёт 13 таблиц — B2C-29 повышает до 14.
- **Ручки пуша — в подгруппу семьи** `family.Use(auth.RequireHousehold)` (`server/server.go`): семья, роль и слот —
  из базы на каждом запросе (`auth.GetHouseholdID/GetRole/GetSlot`), без семьи — 409. `cron` — вне защищённой группы,
  по `CRON_SECRET`.
- **Удаление аккаунта** (`repository/account_repo.go`) — явный список `DELETE … WHERE user_id`: `push_subscriptions`
  дописать туда (и в `mock_account.go`), даже при `ON DELETE CASCADE`; тест `account_pg_test.go` — таблица пуста.
  Последний участник уносит семью — настройки дня/часа на `households` уходят с ней.
- **События:** `push_open` уже в CHECK `app.events` и в `EventKind` (`stores/events.ts`) — миграция не нужна;
  `useEventsStore().track('push_open')`, в демо и без входа — ничего; очередь сбрасывается при выходе.
- **Настройки** (`views/Settings.vue`): «Семья» — участники с ролями из `auth.members` (`fetchMembers` →
  `GET /api/household/members`; имя и кружок — из документа по слоту), viewer виден; без семьи экран — только выход и
  удаление (гард пускает `/who`, `/settings`, `/admin`). Карточку «Напоминание» ставить для вошедших с семьёй.
- **Отставший партнёр** — по `statement_uploads` (`user_id`, `created_at`); имя для текста пуша — `household_members.
  display_name` (почту не отдаём). Кого будить — только по `household_members`: ушедший (удалил аккаунт) остаётся в
  `people` документа живой записью, а новый по коду может быть в слоте `c` (возврат приёмки Б4, В-1).
- **Прод:** `register` в проде нет — тестовых пользователей на проде не заводить; смоук — аккаунты владельца.

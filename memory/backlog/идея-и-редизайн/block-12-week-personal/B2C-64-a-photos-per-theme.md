# B2C-64-а — Несколько фото на тему цели (фронт) · клинап Блока 12

Блок 12 · MVP · Репо/каталог: `frontend/src/` · Зависит от: B2C-64 · Роли: member · Делает: клинап, до деплоя

## Контекст (что уже есть)

- Владелец на приёмке Блока 12 (2026-10-03): «фоток для целей мало» → уточнено: **несколько фото на тему**, выбрать
  своё; делать в клинапе, блок принят.
- `lib/goalTemplates.ts`: `GoalTemplate { id, name, type, photo, hue }`, по одному шаблону-типу на тему (11 тем,
  `GOAL_TYPES`), у «Путешествия» — ещё 10 направлений (`TRAVEL_DIRECTIONS`, `type: 'travel'`, свой `id`).
- `views/GoalNew.vue`: сетка тем (`TemplateTile`) → у «Путешествия» под сеткой ряд «Куда» (`Chip`, `pickDirection`,
  `template.value = d`) → «Дальше». Цель хранит `template` (id шаблона), фото — `attachTemplate(tpl)` (скачать,
  сжать, загрузить своим фото), автор — `photoCredit`.

## Задача

1. Данные: у каждой из 10 тем без направлений (кроме «Путешествия») — ещё 2–4 фото тем же форматом, отдельными
   шаблонами того же `type` с id `<type>-2`, `<type>-3`… (`name` — название темы, автор и ссылка — лицензия
   Unsplash, не Plus; правила кадров B2C-64 п. 2 — «Хадж, Умра» без людей, «Ребёнок» без лиц детей крупно).
2. Экран: выбрали тему → под сеткой ряд маленьких фото-вариантов этой темы (первый — фото плитки), нажатие
   меняет `template`; у «Путешествия» — как сейчас, ряд «Куда». Без новых заголовков и пояснений (правило 12), ряд
   — по образцу «Куда», сетка тем не меняется.
3. Сетка плиток и старые цели не меняются (id прежних шаблонов те же).

## Тесты

- `goalTemplates.test.ts`: у каждой темы, кроме «Путешествия», 3–5 фото; `unsplashId`/`pageId` уникальны; формат
  автора и ссылки.
- `GoalNew` (SSR/DOM): выбор темы показывает её варианты; выбор варианта → цель с `template` варианта и его автором.
- Доступность новых `templateImageUrl(t, 600)` — скрипт в scratchpad (200, `image/*`), итог — в «Итогах пост-приёмки».

## Критерии приёмки

- Снимок «Новая цель» с рядом вариантов в обеих темах — владельцу вместе со смоуком клинапа.
- `cd frontend && npm run build && npm test` зелёные.

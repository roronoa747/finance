## Задача

1. `Person.emoji?: string | null`, `Person.color?: 'pa' | 'pb' | 's1' | 's3' | 's6' | 's8' | null` (ключ токена,
   список — данными в `palette.ts`); слияние — как у остальных полей `Person` (LWW записи).
2. `personColor` / `Avatar` берут выбранный цвет, иначе `--pa`/`--pb` по слоту; смайлик вместо буквы (размер шрифта
   под кружок); `Avatar` получает участника из стора по `id` (потребители не меняются); `WishRow` — через ту же
   функцию.
3. Экран (или лист) «Свой кружок» из «Настроек» — только для своего участника: большой кружок, «Смайлик» (буква +
   11 смайликов макета), «Цвет» (6 токенов); выбор применяется сразу (без «Сохранить»), синк как у имени.
4. Контраст: буква и смайлик читаемы на каждом из 6 цветов в обеих темах (`--dot-ink` ≥ 3:1 к фону — гвард); цвет,
   совпавший с партнёрским, допустим (буква/смайлик различают).
5. **Ворота владельца** после задачи: статусы §4, Handoff «Часть 1», снимки «макет | стенд» 390 px в обеих темах —
   «Неделя» с пачкой (B2C-61) и «Выписками» (B2C-62), «Свой кружок», кружки на трёх вкладках; показать владельцу
   артефактом и **остановиться, не начиная B2C-64**.

## Критерии приёмки

- Кружок со смайликом и выбранным цветом — на всех экранах (шапка, «Доход», «История», цель, желания) у обоих
  телефонов; без выбора — буква, как было.
- `cd frontend && npm run build && npm test` зелёные; ворота пройдены («дальше» — запись в SESSION).

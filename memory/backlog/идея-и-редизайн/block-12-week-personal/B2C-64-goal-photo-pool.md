  шаблонов (5 типов + 10 направлений); `templateImageUrl(t, width)` → `images.unsplash.com/<id>?w=…&q=80&fm=jpg&fit=crop`,

- `goalTemplates.test.ts`: уникальные id и `pageId`, формат автора и ссылки, `hue` из `HUE_KEYS`, 5 типов, 8–12
  направлений, `place` по карте, точный формат URL.
- Unsplash из этой среды — через браузер (Chrome; память «Stand & e2e gotchas»).

## Задача

1. Новые шаблоны (тип — новый `GoalType` на каждый или общий «событие» — на выбор исполнителя, в Handoff): свадьба,
   ребёнок, учёба, ремонт, подушка, хадж и умра; ещё 0–4 по смыслу (новоселье, своё дело, отпуск у моря — дефолт
   составителя, без перебора). У каждого — фото Unsplash с автором и ссылкой (лицензия Unsplash), `hue`.
2. Фото «Хадж, Умра» — уважительное (Мекка / Медина / Кааба издали, без людей крупным планом); «Ребёнок» — без лиц
   детей крупно; «Подушка» — спокойный образ (копилка, дом) — подбор на усмотрение, все кадры — на снимках приёмки.
3. `PhotoPicker` показывает новые плитки без новой разметки (если сетка — по типам, новые идут своей группой).

## Тесты

- `goalTemplates.test.ts`: границы количества обновить; каждый новый тип есть; ссылки и авторы по формату; ни один
  `unsplashId` не повторяется.

- `cd frontend && npm run build && npm test` зелёные.

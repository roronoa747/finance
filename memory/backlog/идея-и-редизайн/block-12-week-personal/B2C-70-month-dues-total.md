# B2C-70 — Сумма платежей месяца: осталось и всего (фронт) · возврат смоука Блока 12

Блок 12 (возврат смоука) · MVP · Репо/каталог: `frontend/src/` · Зависит от: — · Роли: все (чтение) · Ветка: `b2c-block-12-smoke`

## Контекст (что уже есть)

- Владелец после Блока 12 (2026-10-03): «платежи в октябре ещё делать — сверху или где-то общую сумму остатка для
  оплаты в текущем месяце и общую сумму». Выбрал макет: первая строка карточки «Платежи» — «Осталось в октябре»,
  сумма крупно, под ней «из 450 000 ₸»; всё оплачено — «Всё оплачено · 450 000 ₸».
- `components/money/CapitalLists.vue`, раздел «Платежи»: тег в шапке «N из M оплачено» (`duesTag`, B2C-59) и список
  строк `PaymentLine` + группы подписок (`groupTotal`). Сумм месяца на экране нет.
- `lib/finance.ts` `monthDues(state, key): MonthDue[]` — **одно правило** платежей месяца («до зарплаты», календарь,
  «Впереди»): `{ targetId, name, day, amount, paid }`; у отмеченного `amount` — из отметки, как в строке «Оплатил»,
  так что итог сходится со строками. Годовое не в свой месяц и сама группа подписок — не входят (дети группы — входят).
- Типографика: `@utility type-label`, `type-num` (`style.css`, клинап Б9 Н-7); месяц в предложном падеже —
  `MONTHS_PRE` (`PaymentLine.vue`).

## Задача

1. `lib/finance.ts`, рядом с `duesTag`: `duesTotals(dues: Pick<MonthDue, 'amount' | 'paid'>[]): { total: number;
   left: number } | null` — `total` = сумма всех, `left` = сумма неоплаченных; платежей нет — `null`. Целые тенге,
   никакого нового правила — только сложение `monthDues`.
2. `CapitalLists.vue`: один `computed` `dues = monthDues({ obligations, credits, payments }, key)` — на нём и
   `duesStatus` (сейчас считает отдельно), и `totals = duesTotals(dues)`. Первая строка карточки «Платежи» (над
   `PaymentLine`), только при `totals`: подпись `type-label` «Осталось в <месяце>» (`MONTHS_PRE`), сумма крупно
   (`type-num`, как у виджетов «Денег»), под ней `text-ink-3` «из <total> ₸». `left === 0` → подпись «Всё оплачено»,
   сумма — `total`, строки «из …» нет. Тег «N из M оплачено» в шапке остаётся. Без подсказок и кнопок (правило 12);
   цвета — токены.
3. Пустой список («Платежей пока нет») — строки нет. Viewer и демо — видят (чтение).

## Тесты

- `finance` (рядом с тестом `duesTag`): `duesTotals` — три платежа, один оплачен суммой из отметки → `total`, `left`;
  все оплачены → `left: 0`; пусто → `null`.
- `CapitalLists.test.ts` («Деньги»: … «Платежи»): строка «Осталось в <месяце>» с суммами; после отметки «Оплатил» —
  `left` меньше на сумму отметки (число из `monthDues`, не из экрана); все оплачены → «Всё оплачено · <total> ₸»;
  платежей нет → строки нет. Дети группы подписок считаются в `total` один раз.

## Критерии приёмки

- На проде у владельца: «Деньги → Платежи» — сверху «Осталось в октябре» и «из …»; отметил платёж — остаток уменьшился
  ровно на него. Снимок в обеих темах.
- `cd frontend && npm run build && npm test` зелёные.

# B2C-69 — Свой смайлик с клавиатуры (фронт) · возврат смоука Блока 12

Блок 12 (возврат смоука) · MVP · Репо/каталог: `frontend/src/` · Зависит от: B2C-63 · Роли: member (только свой кружок) · Ветка: `b2c-block-12-smoke`

## Контекст (что уже есть)

- Владелец после Блока 12 (2026-10-03): «я бы ещё больше смайликов добавил»; на вопрос «сколько» выбрал **любой
  смайлик с клавиатуры телефона** (не расширение списка).
- `views/MyCircle.vue`: сетка 6 колонок — буква + 11 смайликов `PERSON_EMOJI` (`lib/palette.ts`), нажатие →
  `finance.setPerson(slot, { emoji })`. `Avatar.vue` печатает `person.emoji` текстом (размеры 30/34/96, шрифт
  16/18/48). Ни телефон (`setPerson`), ни сервер (документ семьи для Go непрозрачен) смайлик не проверяют.

## Задача

1. **Проверка «ровно один смайлик»** — чистая функция в `lib/palette.ts` рядом с `PERSON_EMOJI`:
   `oneEmoji(text: string): string | null` — первый графемный кластер (`Intl.Segmenter`, запас — `Array.from`),
   принимается, если он один и содержит код с `\p{Emoji_Presentation}` или `\p{Extended_Pictographic}`.
   Принимает: 🦊, 👨‍👩‍👧, 🏳️‍🌈, 🇰🇿. Отклоняет: `''`, `'ab'`, `'7'`, `'🦊🐻'` (две графемы), буквы с пробелами.
2. **Экран «Свой кружок»**: в сетке смайликов последняя плитка — поле ввода (тот же квадрат `bg-surface-2`,
   placeholder «＋»), одно действие: нажал → клавиатура → вставил смайлик → он сразу выбран и показан в этой плитке и
   в кружке сверху. Если текущий смайлик не из списка — он и показан в этой плитке как выбранный. Невалидный ввод —
   поле очищается, ничего не пишется, без текста ошибки (правило 12). `aria-label` «Свой смайлик».
3. `Avatar.vue` — проверить флаги и ZWJ-смайлики в 30/34/96 (один глиф, не вылезает); при необходимости
   `whitespace-nowrap`/`overflow-hidden`.
4. Список `PERSON_EMOJI` не меняется; документ семьи — поле `emoji` как есть (строка).

## Тесты

- `palette.test.ts`: `oneEmoji` на примерах из п. 1.
- `MyCircle` (DOM, по образцу существующих тестов экрана): ввод «🐼» → `setPerson` с `{ emoji: '🐼' }`, плитка
  отмечена; ввод «ab» → ничего не записано, поле пустое.

## Критерии приёмки

- На телефоне владельца: вставить смайлик с клавиатуры → кружок меняется у себя и у партнёра после синка.
- Снимок «Свой кружок» с полем в обеих темах.
- `cd frontend && npm run build && npm test` зелёные.

## Вне скоупа

- Расширение `PERSON_EMOJI`; смайлик у партнёра из своего телефона (только свой — Р-61); картинка вместо смайлика.

# B2C-74 — Новый свой смайлик заменяет старый (фронт) · возврат смоука 2 Блока 12

## Контекст (что уже есть)

- Смоук владельца 2 (2026-10-03): «тяжело понять, что надо переключить на другой, чтобы старый свой стёрся». Решение
  владельца: **новый заменяет старый** — нажал на плитку, вставил — встаёт вместо прежнего, без выбора из списка.
- B2C-69 (`views/MyCircle.vue`): плитка-поле `<input :value="custom">` — в поле стоит прежний свой смайлик; вставка
  дописывается к нему → две графемы → `oneEmoji` (`lib/palette.ts`) отклоняет → поле возвращается к старому
  (отклонение 1 исполнителя Б12, принято критиком — для невалидного ввода остаётся верным).

## Задача

1. **Последний смайлик ввода** — чистая функция в `lib/palette.ts` рядом с `oneEmoji`: `lastEmoji(text): string | null`
   — последняя графема (`Intl.Segmenter`, запас `Array.from`), если она проходит `oneEmoji`; иначе `null`.
2. `MyCircle.vue` `onOwnEmoji`: брать `lastEmoji(field.value)` вместо `oneEmoji` — «🐼» + вставили «🦊» → пишется 🦊,
   поле показывает 🦊. Невалидная вставка (буквы, цифры) — поле возвращается к прежнему своему, ничего не пишется (как
   сейчас). Дополнительно — при фокусе выделить содержимое поля (`select()`), чтобы вставка заменяла и на клавиатурах,
   где это работает; основная гарантия — п. 1.
3. Без подписей, подсказок и текста ошибки (правило 12); список `PERSON_EMOJI`, `Avatar` и документ не меняются.

## Тесты

- `palette.test.ts`: `lastEmoji` — «🐼🦊» → 🦊, «🦊» → 🦊, «🐼a» → null, «👨‍👩‍👧» → он же, «🇰🇿🇺🇸» → 🇺🇸, `''` → null.
- `MyCircle.dom.test.ts`: свой 🐼 выбран → ввод «🐼🦊» → `setPerson({ emoji: '🦊' })`, плитка показывает 🦊 (обновить
  прежний кейс «🐼🦊 → остаётся 🐼» — он теперь неверен); «🐼ab» → ничего не записано, поле — 🐼.

## Критерии приёмки

- Стенд: свой 🐼 → нажать плитку, вставить 🦊 → кружок 96 и плитка — 🦊, на сервере `emoji: 🦊`.
- На телефоне владельца: сменить свой смайлик на другой свой одной вставкой; партнёр видит новый после синка.
- `cd frontend && npm run build && npx vitest run` зелёные (e2e Б12 часть 7 — проверить, что не опирается на старое
  поведение «две графемы → прежний»).

- Кружок — `kit/Avatar.vue` (после B2C-63 — со смайликом и цветом).

## Задача

1. Функция в `finance.ts` (рядом с `weekPicture`, тем же правилом перекрытия): по участникам — загружена ли
   выписка за неделю и когда (дата записи загрузки → короткий день недели).
2. Карточка «Выписки» сверху «Недели» (над карточкой недели), когда в семье ≥ 2 участников: строка на участника —
   галочка, кружок, имя, «вт» / «ещё нет». Даты недели в заголовок карточки **не** добавлять — они уже в шапке
   (хвост «даты дважды» не умножаем; отклонение от макета — в Handoff).
3. Своя строка «ещё нет» — нажатие открывает загрузку (то же действие, что «Загрузить выписку»); строка партнёра —
   не кликабельна. Все загружены — карточка остаётся с двумя галочками (тихо).
4. Viewer видит карточку без действий.

## Критерии приёмки

- На стенде: A загрузил — у A галочка и день, у B «ещё нет»; B загрузил — обе галочки на обоих телефонах.
- `cd frontend && npm run build && npm test` зелёные.

## Задача

1. Очередь: `allocate` → карточка **«Пришла зарплата»** по `asUsual`: сумма, полоса статей, «Как в <месяце> ·
   останется N ₸», брендовая «Разложить как обычно» (одно нажатие — `breakdownEffects` + запись, без экрана; затем
   короткое «Разложено» в карточке), тихая «Изменить» → экран-кольцо. Без плана (`orderedAt` нет) — одна
   брендовая «Разложить» → «Ваш порядок» (Р-55). Порядок очереди — прежний (Р-43, изменение 2026-10-02).
2. Входы на разбор: «Пришла зарплата» в сводке «Денег» (после отметки — на разбор этой зарплаты), «Распределить»
   (`freed`), «остались деньги?» (`rest`), момент «долг закрыт» (`credit`), `@allocate` истории, нажатие на виджет
   «Доход» (заголовок/сумма; строки участников — по-прежнему `SalaryDialog`) — разбор последней пришедшей зарплаты
   месяца, иначе — план месяца без кнопки.
3. Редирект `/week/salary?…` → разбор с теми же параметрами; `salaryAllocationPath` ведёт на разбор.
4. Уборка: удалить `views/WeekSalary.vue` и ставшее мёртвым (`salaryFree`, `allocationRoom`, тексты карточки
   «разложить?» и т. п. — только без потребителей; список «было → удалено» — в Handoff). История (`HistorySquare`):
   записи `kind: 'breakdown'` — строками по статьям; старые записи — как были (Р-65).
5. Тексты — правило 12: заголовок карточки 1–3 слова, одна строка под ним.

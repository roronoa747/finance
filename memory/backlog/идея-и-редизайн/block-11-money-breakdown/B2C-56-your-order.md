# B2C-56 — «Ваш порядок» — первый разбор: порядок, пороги, суммы «Жизни» и «Трат» (фронт)

Блок 11 · MVP · Репо/каталог: `frontend/src/` · Зависит от: B2C-55 · Роли: member правит, viewer не видит

## Контекст (что уже есть)

- Макет — `pivot-3/money-breakdown.html`, вопрос 2, колонка «Первый раз · порядок»: заголовок «Ваш порядок»,
  строка «Сверху — что важнее (?)», список статей с номером, названием, короткой подписью и ручкой ⋮⋮, одна
  брендовая «Готово» в доке.
- Модель и стор — B2C-54 (`moneyArticles`, `moneySettings`, `setArticle`, `reorderArticles`, `setMoneySettings`,
  `setSpendArticle`); статусы и суммы — B2C-55 (`breakdownArticles`, `articleFact`).
- Кит: `kit/Card`, `kit/Hint`, `ui/Button`, лист снизу (`fx-sheet`, как листы «Денег» — `components/capital/*Sheet`),
  ввод денег — `parseMoney` (как `LivingWidget`); новых библиотек нет (перетаскивание — своими pointer-событиями).
- Правило 12 CLAUDE.md: заголовок 1–3 слова, одна строка под ним, пояснение — в `Hint`.

## Задача

1. Экран «Ваш порядок» (маршрут под «Неделей», не корень `AppShell`, «назад» — откуда пришли; имя и путь —
   на выбор исполнителя, записать в Handoff): статьи из `breakdownArticles` по `order`, пустые — тоже (порядок
   задаётся на будущее), с номером и короткой подписью (Р-56).
2. Перестановка: перетаскивание за ⋮⋮ (pointer-события, работает на iPhone; клавиатура — стрелки у фокуса);
   «Готово» — `reorderArticles`, `setMoneySettings({ orderedAt })`, возврат в разбор.
3. Нажатие на статью — лист с её настройками (одно поле — одно действие):
   - «Жизнь» / «Траты» — сумма в месяц; подсказка «по выпискам прошлого месяца N ₸» (`articleFact`) одним нажатием
     подставляет её; ниже — разделы статьи чипами (перенос раздела между «Жизнью» и «Тратами» —
     `setSpendArticle`);
   - «Запас» — месяцев (1–3), «Подушка» — месяцев (1–12), «Дорогие долги» — «дороже N %» (целые), у всех трёх —
     взнос в месяц; при активном плане «Сначала долги» — строка «по плану „Сначала долги“» без полей (Р-66);
   - «Обязательное» и «Мечты» — без полей: подпись, откуда берётся сумма («из платежей», «взносы целей»).
4. Первый вход: разбор без `orderedAt` открывает «Ваш порядок» первым (Р-55); дальше — из разбора тихой ссылкой
   «Изменить порядок».
5. Viewer сюда не попадает (маршрут — только member; прямой адрес — назад в разбор).

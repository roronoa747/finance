## Задача

1. Статусы в `finance.ts` (слова — данными рядом, как `weekTag`): «Доход» — нагрузка словом (низкая < 30 %, средняя
   30–50 %, высокая > 50 % — дефолт составителя, пороги в Handoff), «Траты» — раздел с наибольшим превышением
   ориентира («продукты выше нормы») или «в норме», без выписок — нет тега; «Платежи» — «N из M оплачено» за месяц
   (`monthDues` + отметки). Теги — в виджеты на место нынешних (цифры «нагрузка N %» уходят в подсказку виджета).
2. Нормы: `lib/statements/norms.ts` — доли разделов трат (`sc_*` → целые проценты) по **структуре потребительских
   расходов домохозяйств РК** (Бюро национальной статистики, последний доступный год); источник и год — в
   комментарии файла и в Handoff; разделов без строки в источнике нет в таблице (черты нет). Числа не выдумывать:
   источник недоступен — остановиться и спросить владельца.
3. `spendNorms(totals, spendCategories, uploads, key)` в `finance.ts`: после трёх полных месяцев с загрузками —
   своё среднее долей по этим месяцам, иначе таблица (Р-57); и `spendShares(...)` — доли разделов месяца от трат
   месяца (без `must`-разделов).
4. Лист «Траты за <месяц>» по нажатию на виджет «Траты»: строки по убыванию доли, полоса доли и черта ориентира
   (цвета — токены разделов), подпись «Черта — обычная доля» с `Hint` («по статистике РК» / «ваше среднее за 3
   месяца»). Правка плана в листе — суммы статей «Жизнь» и «Траты» (`setArticle`), не `d4`.

## Критерии приёмки

- На демо и стенде: у «Дохода», «Трат», «Платежей» по одной короткой строке; нажатие на «Траты» — лист с чертами;
  числа листа сходятся с «Историей» за месяц.
- `cd frontend && npm run build && npm test` зелёные.

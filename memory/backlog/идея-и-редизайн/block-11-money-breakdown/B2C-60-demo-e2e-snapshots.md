## Задача

1. Демо: план статей пройден (`orderedAt`), запись разбора прошлого месяца (для «как в сентябре»), зарплата
   Ильяса пришла сегодня и не разложена — на «Неделе» карточка «Пришла зарплата»; цель-копилка с частичным запасом;
   один дорогой долг; разделы для листа «Траты» и черт.
2. e2e `e2e/b2c-block11-money-breakdown.test.ts` частями: «Ваш порядок» при первом разборе; кольцо — статьи и
   «Остаётся» = ручной расчёт; выключение статьи; «Разложить» → взносы, досрочка, запись; партнёр докрывает; «как
   обычно» одним нажатием; редирект `/week/salary` (4 источника); viewer без кнопок; статусы виджетов и лист «Траты».
3. Сверка на настоящих выписках (машина владельца; иначе — синтетика с пометкой в Handoff): таблица «статья →
   нужно → дано → ручной расчёт» для одного месяца двух участников; расхождение хоть на тенге — баг, не отклонение.
4. Снимки «макет | стенд» 390 px в обеих темах — «Ваш порядок», кольцо (обычное, нехватка, выключенная,
   «Разложено», viewer), карточка «как обычно», «Деньги» со статусами, лист «Траты»; таблица «экран → расхождение →
   правка → совпадает» в Handoff.

# B2C-08 — Замер доли незнакомых названий на корпусе → решение по Блоку 6 (фронт, локально)

Блок 1 · MVP · Каталог: `frontend/src/lib/statements/` · Зависит от: B2C-07 · Роли: —

## Контекст (что уже есть)

- Р-12: ИИ для незнакомых названий — только после замера на корпусе; Р-29: «заметная доля» —
  более 15 % строк трат или более 25 % суммы трат месяца не узнаны после словаря и памяти
  (среднее по месяцам корпуса). Ниже порога — Блок 6 отменяется записью в §4.
- Корпус — `memory/secrets/statements/<банк>/` (вне git); парсеры и `categorize` — B2C-02…04;
  скрипт снятия строк — B2C-01 (`STATEMENTS_DIR`).
- Памяти семьи на корпусе нет — замер идёт по словарю; правила, которые владелец уже завёл в
  B2C-07 на проде/стенде, в замер не входят (честная оценка для чужой семьи).

## Задача

1. Тест-замер `lib/statements/corpus.test.ts`: пропускается (`describe.skipIf`) без переменной
   `STATEMENTS_DIR`; с ней — читает все файлы корпуса (Node-путь pdf.js / xlsx), разбирает,
   применяет `categorize` только со словарём и считает по каждому месяцу и банку: строк трат,
   незнакомых строк и их долю, сумму трат и долю незнакомой суммы; среднее по месяцам; топ-20
   незнакомых нормализованных названий по числу строк (без сумм и имён людей — `counterparty`
   не печатать). Вывод — в консоль и в файл по пути из `CORPUS_REPORT` (вне git). В CI не бежит.
2. Пополнить словарь `dictionary.ts` **общими** продавцами из топа (сети, сервисы, банки —
   не частные лица и не уникальные ИП), повторить замер, записать «до / после».
3. Итог — в Handoff (доли до и после, порог Р-29, вывод) и строка в §4 индекса под таблицей
   блоков: «Блок 6 открыт» или «Блок 6 отменён (замер B2C-08: N % строк, M % суммы)» — по Р-29;
   в шапку статуса — то же одной фразой.

## Тесты

- Сам тест-замер (п. 1) — с фикстурами вместо корпуса гоняется всегда: на фикстурах доля
  незнакомых считается и равна ожидаемой (эталон по фикстуре).
- Тесты словаря (B2C-02) — обновлены под новые записи.

## Критерии приёмки

- Замер проведён на полном корпусе, цифры в Handoff, §4 и шапка обновлены.
- `cd frontend && npm run build && npm test` зелёные; в CI тест-замер пропущен.

# B2C-93 — Вкладка «План»: `/week` и `/month`, переключатель, память выбора, редиректы, viewer (фронт)

Блок 15 · MVP · Репо/каталог: `frontend/src/router/`, `components/AppShell.vue`, `views/` · Зависит от: B2C-91 ·
Роли: member, viewer

## Контекст (что уже есть)

- `AppShell.vue` — `tabs` (Мечты `/`, Неделя `/week`, Деньги `/money`; `active` по префиксу пути), капсула `Tabs`.
- `router/index.ts`: `week` → `Statements.vue`; `money/:square(plan|history)?` → `Money.vue`; `toPlan` (→ `/money`) у
  `week/salary|order|breakdown` и `ritual`; `plan` → `/money/plan`; `statements` → `/week`; мета `memberOnly`,
  `viewerTo`. Гвард старых адресов — `router/legacy.test.ts`, общий — `router.test.ts`.
- Ссылки на месяц плана: «История» (`HistorySquare.vue` → `/money?month=`), карточка «Пришла зарплата»
  (`Statements.vue`, `MarkSheet.vue`) → `/money`. Хранилище устройства — `lib/storage.ts` (обёртки с try/catch).
- Решения: Р-89, Р-99, Р-103, Р-104; вид переключателя — макет `week-month.html` (B2C-91).

## Задача

1. Вкладка «План» (иконка — по макету) активна на `/week` и `/month`; нажатие ведёт на последний выбранный вид
   (ключ в `lib/storage.ts`; пусто — «Неделя»), viewer — всегда `/month`.
2. Маршрут `/month` → новый `views/Month.vue` (пока — оболочка с переключателем и тем, что сейчас наверху «Денег»:
   навигация месяца, `MonthPlan` / `MonthPast`, `?month=`; наполнение — B2C-94). `/week` — `Statements.vue` с
   переключателем сверху (наполнение — B2C-95).
3. Переключатель «Неделя | Месяц» — один компонент на обоих экранах (вид — макет), переход без перезагрузки данных,
   выбор сохраняется. Viewer: переключателя нет, `/week` → `/month` (`viewerTo`).
4. Редиректы (Р-103): `/money?month=…` → `/month?month=…`; `/money/plan` и `/plan` → `/money/debts` (квадрат появится в
   B2C-97 — до этого маршрут `debts` показывает тот же `PlanSquare`); `toPlan` → `/month` (с `month`, если был);
   ссылки «Истории» и карточек зарплаты — на `/month`.

## Тесты

- `router.test.ts` / `legacy.test.ts`: каждый старый адрес ведёт куда в Р-103 (с query); viewer на `/week` → `/month`;
  вкладка «План» активна на обоих путях.
- DOM: переключатель меняет маршрут и запоминает выбор; повторное открытие вкладки — последний вид; пустое
  хранилище (или исключение при чтении) — «Неделя».

## Критерии приёмки

- `npm run build && npm test` зелёные; стенд 390 px: вкладки «Мечты · План · Деньги», переключатель работает в обе
  стороны, закладки `/money?month=2026-09` и `/money/plan` открывают нужное.

## Вне скоупа

- Содержимое «Месяца» (B2C-94), «Недели» (B2C-95), «Денег» (B2C-97). Переименование квадрата в UI — B2C-97.

# B2C-96 — Загрузка «сразу готово» с «Отменить» и вопросы за «!» (фронт)

Блок 15 · MVP · Репо/каталог: `frontend/src/views/Statements.vue`, `stores/operations.ts`, `lib/finance.ts`
(`decisionQueue`) · Зависит от: B2C-95 · Роли: member

## Контекст (что уже есть)

- Загрузка: файл → `readStatementFiles` → `store.setDraft` (черновик) → сводка `draftSummary`, подсказки партнёра
  `partnerHints`, незнакомые пачкой → «Отправить» = `store.send()` (`pull`, `remember`, `writeTotals`, `autoMark`,
  очередь `pending`, `flush`; в демо — `demoUploads`). `cancelDraft()` — сброс черновика. **Удаления загрузки на
  сервере нет** (ручек DELETE в Go нет; бэкенд блок не трогает) — значит, «Отменить» работает до отправки.
- Очередь вопросов — `decisionQueue` (`finance.ts`): `match` («то же самое?», `acceptMatch`/`declineMatch`),
  `unknownBatch` (`UnknownBatch.vue`, пачкой), `keep` («оставить подписку?»), `allocate`/`salary` («Пришла
  зарплата»), `freed`, `monthEnd` («остались деньги?»); «Потом» — `deferred`; во время черновика — только
  `unknownBatch`.
- Эталон — `week-month.html` (кадры «Загрузил выписку», «Нажал „! 3“»). Решения: Р-97, правило 12.

## Задача

1. «Сразу готово» (Р-97): выбрал файл → без сводки и «Отправить» операции сохраняются, тост «Загружено N ·
   Отменить». Реализация — на клиенте: отправка откладывается, пока висит тост (рекомендация — ~6 с), «Отменить» =
   `cancelDraft`; закрытие тоста, уход с экрана или скрытие вкладки — отправка сразу. Цифры недели обновляются после
   отправки. Ответы на незнакомых продавцов черновика больше не спрашиваются до отправки — они уходят в «!».
2. Вопросы — в листе за «! N» (Р-97): по одному, «N из M», «Потом» откладывает; виды — `match`, `unknownBatch`
   (по операциям месяца, не черновика), `keep`, `monthEnd`. `allocate`, `salary`, `freed` из очереди «Недели»
   уходят (они на «Месяце», B2C-94) — функция отбора в `finance.ts`, не фильтр в шаблоне.
3. Нет вопросов — значка «!» нет. Ошибки чтения файла — тостом/листом по макету, без брендовой кнопки.

## Тесты

- Стор: «Отменить» до отправки — ни операций, ни итогов, ни `pending`; без отмены — то же, что прежний `send`;
  двойная загрузка подряд не теряет первую.
- DOM: после файла — тост и обновлённая неделя; «!» показывает число и открывает лист; «Потом» откладывает; зарплаты и
  «освободится» в листе нет.
- `finance.test.ts`: отбор вопросов «Недели» — состав и порядок.

## Критерии приёмки

- `npm run build && npm test` зелёные; стенд: загрузка синтетической выписки (и настоящей на машине владельца —
  `memory/secrets/statements/`) — тост, «Отменить» возвращает как было, повторная загрузка — дедуп как раньше;
  второй телефон видит итоги после отправки.

## Вне скоупа

- Отмена уже отправленной загрузки (нужна ручка Go — хвост §4, если владелец захочет). ИИ-разбор — нет (Р-29).

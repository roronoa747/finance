## Задача

1. **Секция «Счета»** в квадрате «Капитал» (`Money.vue` или дочерний компонент `CapitalLists`):
   подпись секции + итог (все живые счета в тенге, `fxToTenge` для валютных — как
   `totalAccountsAmount`); строки: `IconBox` по виду (карта, наличные, конверт, вклад — иконки из
   `Capital.vue`), название, мета «<вид> · <чей: имя | общий | личный>» (у вклада — «N % · общий»),
   сумма, ›. Нажатие — `AccountSheet` (и для вклада). Внизу — тихая строка «+ Добавить счёт» (member)
   → `AccountSheet` на новый счёт с выбором вида, включая вклад (как «Добавить счёт или накопления»
   сейчас). `?account=<id>` в адресе открывает лист этого счёта (цель редиректа `/money/capital/:id`).
2. **Вклад внутри листа счёта**: `AccountSheet` при `account.deposit` показывает секцию «Вклад» —
   поля из `Deposit.vue` (ставка, пополнение в месяц, срок, капитализация; `useSavedMark`) и
   свёрнутый блок «Расчёт вклада» (`<details>` как у цели: «будет на счёте через N мес.»,
   проценты, эффективная ставка, взносы, «заработал банк», «Реально ≈ N %» с `Hint`). Удалить —
   та же `DangerZone` листа (текст про вклад, как `removeWarning`). Viewer — цифры без полей.
   `Deposit.vue` после этого не нужен (удаление — B2C-45).
3. **Секция «Платежи»**: подпись + итог «N в месяц» = `duesTotal(monthDues(state, key))`. Один
   список, порядок по дню, оплаченное остаётся на месте: **кредиты** (название, мета «<день>-го ·
   оплачено» / «<день>-го»; у `rateUnknown` — «ставку уточните»; сумма — платёж месяца, у
   оплаченного тихим цветом; справа «Оплатил» (`PaidRow`) или тег ✓), **обязательства**
   (мета «<день>-го · <чьё>», «≈ оценка» у `estimate`, «раз в год · в <месяце>» у годового не в
   свой месяц — без «Оплатил», «сумма изменится» при `nextChange`), **группы подписок** («Подписки ·
   3 · <сумма группы в месяц> ›» → лист группы с подписками и их «Оплатил», как сейчас).
   Нажатие на название — `CreditSheet` / `ObligationSheet` (как сейчас, без изменений внутри);
   «Оплатил» — `MarkSheet` через `PaidRow`. Строка плана под кредитом («Досрочка по плану»,
   «Изменить режим», `PlanStepAction`) уходит в квадрат «План» (B2C-43) — в списке её нет.
   Ставка, доли платежа и переплата — только в листе кредита (`creditNote` в строке не печатать).
   Внизу — тихая строка «+ Добавить» (member) → лист выбора из трёх: «Подписка или услуга»,
   «Долг или рассрочка», «Группа подписок» → существующие листы.
4. Query-ключи `?add=payment|debt`, `?credit=`, `?obligation=`, `?income=1` (из листа «+» оболочки
   и ссылок) открывают соответствующие листы в `Money.vue` — перенести обработчик из
   `Capital.vue` (строки 505–515) как есть; viewer игнорирует.
5. «Чистый капитал» карточкой, «На счетах · Семья / Личный · Накоплено по мечтам», «Досрочками уже
   сэкономили» — на экране больше нет (Р-33/Р-34: «чистых» — в виджете «Долги», сэкономленное — в
   «Плане»).

## Критерии приёмки

- Браузер (стенд, два профиля, 390 px, обе темы): «Оплатил» из «Платежей» → ✓ у обоих, сводка «До
  зарплаты» уменьшает K; правка кредита, обязательства, счёта, вклада, досрочка — работают из
  листов; `/money/capital/<id вклада>` открывает лист вклада; viewer — без форм.
- Снимок «Капитал» целиком рядом с макетом (обе темы), листы счёта-вклада и кредита — в ряд.
- `cd frontend && npm run build && npm test` зелёные.

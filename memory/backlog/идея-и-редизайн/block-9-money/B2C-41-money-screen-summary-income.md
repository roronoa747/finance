## Задача

1. **Маршруты.** `/money` (квадрат «Капитал»), `/money/plan`, `/money/history` — все на
   `views/Money.vue` (ленивый чанк: `Money` уходит из главного чанка, `/money/*` — один `import()`);
   квадрат выбирается по маршруту, переключение — `router.replace`, чтобы «назад» вёл на прошлую
   вкладку, а не перебирал квадраты. Редиректы: `/money/budget` → `/money`, `/money/capital` →
   `/money` (с query: `?add=payment|debt`, `?income=1`, `?credit=`, `?obligation=`, `?advice=strategy`
   — те же ключи, что читал `Capital.vue`, строки 181 и 505–515, теперь читает `Money.vue`),
   `/money/capital/:id` → `/money?account=:id` (открывает лист счёта — B2C-42). Ссылки в коде на
   старые адреса (`AppShell.vue` 147–149, `GoalDetail.vue` 318/322, `StrategyCompare.vue` 325,
   `DebtPlan.vue` 246, `Budget.vue` 156/186, `Deposit.vue`) — на новые; `AppShell` заголовок
   «Деньги · <месяц> · <имена>» для всего `/money*`.
2. **Сводка «До зарплаты»** (первая карточка): заголовок «До зарплаты N дней» (0 — «Зарплата
   сегодня»; нет людей с окладом — карточки нет); тег `--ok` «хватает» / `--warn` «не хватает N ₸»
   при `knowsCash`; мета «K списаний · сумма ₸ · остаётся R ₸» (K и сумма — платежи до зарплаты из
   `untilPayday`, не месяца; если `untilPayday` их списком не отдаёт — добавить в его результат
   список `dues` той же выборкой, тест на сумму = `dueTotal`); без счетов — мета «Добавьте счёт —
   покажем, хватит ли». Нажатие — лист `Sheet` «До зарплаты»: те же строки с `PaidRow` («Оплатил»
   — member) и строка зарплаты (`SalaryRow`, как в «Впереди» сейчас). **Остаётся как сейчас** до
   разбора «Неделя» (Р-39): `SalaryRow` «Пришла зарплата» в сводке при `salaryAsk` и карточка
   «Освободится N ₸ → Распределить» при `freedChange` (одна брендовая кнопка на экране — правило
   12, порядок как в `Money.vue` сейчас).
3. **Квадраты** — компонент `MoneySquares` (три ссылки): «Капитал» + `netWorth` коротко (`plain`),
   «План» + подпись (`activePlan` → «сначала долги»; есть открытые кредиты → «что гасить первым»;
   нет долгов → «долгов нет»), «История» + «N операций» за месяц (свои операции `ops.all` текущего
   месяца; 0 → «отметки»). Активный — по маршруту.
4. **Виджет «Доход»**: сумма `budgetAmounts(...).income`; тег «нагрузка N %» = доля `d1 + d2` в
   доходе (формула «вместе с жильём» из `Budget.vue`); `Hint` (?) у подписи: «Нагрузка — кредиты и
   жильё: до 30 % по кредитам комфортно, до 50 % вместе с жильём — ориентир для пары. Зарплаты
   приходят в разные дни, месяц закрывается 1-го.»; полоса `StackBar` и легенда: обязательное
   (`d1 + d2`) · мечты (`d3` + `planExtra`, когда план) · еда и быт (`d4`) · свободно (`d5`, не
   меньше 0) — проценты от дохода, `pct`; при `d5 < 0` — заметка «План не сходится: расписано на
   N ₸ больше, чем приходит» (как в Бюджете). Строки участников: `Avatar`, имя, «<день>-го»
   (+ «с <месяца> — N» при `nextSalaryChange`), `salaryAt` ›; нажатие — `SalaryDialog` (перенести
   из `Budget.vue` как есть; viewer — строка без нажатия).
5. **Виджет «Еда и быт»**: факт — сумма трат месяца по выпискам обоих без разделов
   `plannedElsewhere` — **вынести из `freeByFact` общую функцию** (`monthSpentByFact(...)` или
   как назовёт исполнитель) и звать её и там, и здесь (дубля формулы нет); тег «по выпискам N %»
   (факт / план); план — `d4` база раздела: поле `NumFieldBlur` в листе по нажатию на «план
   300 000» (member; viewer — текст), запись в документ как в `Budget.vue`; полоса факт/план
   (`--ok`, при перерасходе — `--destructive`). Нет выписок за месяц — факт «—», тег не
   показывать. `Hint` «Откуда эти суммы» — переносится сюда.
6. **Виджет «Долги»**: остаток — сумма `principal` живых кредитов (как `totalDebts` в `Capital.vue`)
   со знаком минус, `--destructive`; тег «в <месяце> оплачено N из M» — платежи кредитов месяца из
   `monthDues(...).filter(kind === 'credit')`: оплачено / всего (нет кредитов — виджет «Долгов нет»
   с `--ok`); «чистых N ₸» = `netWorth` с `Hint` «всё, что есть, минус всё, что должны». Строка
   «из них проценты банку N в месяц» (`budgetInterest`) — в квадрат «План» (B2C-43), здесь нет.
7. Тексты — коротко, без «выписки» в заголовках (DESIGN.md §1.3); суммы — `money()`/`plain()`,
   класс `num`. На экране считается ничего: только вызовы `finance.ts`.

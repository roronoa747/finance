## Задача

1. **Квадрат «История»** (`/money/history`) — компонент `HistorySquare`:
   - **Чипы фильтра** (горизонтальная прокрутка, `Chip`): «Всё», «Операции», «Отметки», затем
     разделы трат, встречающиеся в своих операциях показанного периода, по убыванию суммы;
     «Не разобрано» — если есть. Выбор запоминается только в состоянии экрана.
   - **Строка «Наш <месяц> · итог месяца · поделиться ›»** первой: месяц — `summaryMonth()`, а в
     середине месяца — прошлый (`addMonths(key, -1)`); нажатие — `Sheet` с `MonthSummaryCard` за
     этот месяц (внутри — «Поделиться» сторис, как сейчас). Нет данных за месяц — строки нет.
   - **Лента по дням** (подпись `type-section` «24 сентября», карточка `flush` со строками),
     новые сверху: *операции* (`OpRow`: буква — первая буква продавца (у «ИП …» — «ИП»), цвет и
     имя раздела, сумма со знаком по `kind`; `internal` — тихим цветом, раздел «между своими · не
     трата», без знака; поступления `+` зелёным); *отметки* (`Row` с `Avatar` участника у зарплаты
     и `IconBox` у платежа: «<Цель> · оплачено · <кто> · из выписки» / «Зарплата <имя> · пришла»
     / «Досрочка в <кредит> · N ₸ не отдадим банку»; сумма со знаком); *моменты* (строки как в
     `History.vue`: «„Япония“: собрали половину», «Не отдадим банку N», «„Автокредит“ закрыт» со
     ссылкой на план или раскладку — member). День = `date` операции / день `at` отметки и
     момента по Алматы.
   - **Период**: текущий месяц; внизу тихая кнопка «Раньше» добавляет предыдущий месяц (пока есть
     что показывать); при сотнях строк — списки по дням, без виртуализации.
   - **Нажатие на операцию** (member, не `internal`): лист «куда отнести?» с чипами разделов
     (частые первыми, «Ещё N», «Кому → что», «Между своими» — тот же набор ответов, что у
     незнакомого продавца в `Statements.vue`; вынести общий компонент, не копировать) →
     `ops.recategorize(match, to)` — строка, итоги `spendTotals` и «Свободно» обновляются.
     Нажатие на отметку — `MarkSheet` (снять отметку, «Разложить»). Viewer: только чтение
     (операций у него нет вовсе — Р-5, он видит отметки, итоги и моменты).
   - **Пусто**: нет ни операций, ни отметок за период — `EmptyState` «Пока пусто» с тихой
     кнопкой «Загрузить выписку» (→ `/week?upload=1`, member) — одна фраза, без механики.
2. Подпись квадрата «История» (B2C-41) — число своих операций за текущий месяц.
3. «Разделы за месяц» на «Неделе» (`Statements.vue`, `<details>`) **не трогать** (Р-39: решается
   шагом «Неделя»); «Впереди» в «Деньгах» больше нет (сводка, B2C-41).
4. Правило 12: главного действия у «Истории» нет (просмотр); сложное — лист итога месяца и лист
   раздела — по нажатию.

## Критерии приёмки

- Браузер (стенд Go на моках + настоящие выписки владельца из `memory/secrets/statements/` или
  синтетика `scripts/statement-fixtures.mjs`, два профиля, 390 px, обе темы): после загрузки
  выписки «История» показывает свои операции по дням; партнёр на своём телефоне видит отметки
  и итог, но не операции первого; раздел задним числом из «Истории» меняет итоги недели на
  «Неделе» и «Свободно» на главном; «Оплатил» из «Платежей» появляется в «Истории» отметкой.
- Снимок «История» рядом с макетом (обе темы), лист «куда отнести?» и лист итога — в ряд.
- `cd frontend && npm run build && npm test` зелёные; экран с 600 операциями открывается без
  заметной задержки (настоящая Freedom-выписка владельца — 596 операций).

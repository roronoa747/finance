## Задача

1. **Мечта по центру** — новый вид героя (переделать `DreamHero` или новый `kit/DreamCenter.vue` — на
   выбор исполнителя, старый вариант не держать, если потребителей не остаётся): фото квадратом по
   макету, % крупно (`CountUp` из B2C-47), «<название> · <месяц года>» (`heroMonth`; нет срока — только
   название). Нажатие — `/goals/:id`. Нет фото у member — тихий «Добавить фото» (как сейчас, `PhotoPicker`).
2. **Строка «Свободно N ₸ · до зарплаты N дней»** — одна, по центру; сумма — `freeByFact().amount`
   (`--ok`, отрицательная — `--destructive`); нет людей с окладом — без «до зарплаты»; нет выписок —
   строки нет (или «до зарплаты N дней» одна — на выбор, записать в Handoff). Текст «по факту/по плану»
   и «уточнится, когда … загрузит» — уходит (в `Hint` при необходимости, правило 12).
3. **«Цели»** — все живые мечты, кроме главной, строками (`kit/GoalRow` или в экране): мини-фото (нет
   фото — цвет `hue` цели плашкой), название, полоса `ProgressBar` тонкая, `pct`; нажатие — `/goals/:id`.
   Заголовок секции «Цели» + «+ Новая» ссылкой (member; viewer — без). Нет других мечт — секция с одной
   строкой-приглашением или пустая с «+ Новая» (одна «добавить» на список).
4. **«Желания»** — первые 3 некупленных строками: мини-фото, название, «<сумма> · <чьё>» (имя `by` или
   «общие» для `list: 'all'`), тихая кнопка «Открыть» → лист желания (`/wishes` с открытым листом или
   `WishSheet` здесь — на выбор, путь ≤ 2 нажатий). Заголовок «Желания» + «Все N» → `/wishes` —
   **всегда**, и без главной мечты (хвост критика Б9). Пусто — одна строка «+ Желание» (member).
5. **Убрать с главного** (Р-42): картину недели (`WeekCard`, `weekPicture`, `weekTag`), `FreeCard`, карточку
   решения (`nextDecision`, `DecisionCard`, `answerRest`, `deferred`, `cancelling`, `readMonthEnd`),
   плитки `DreamTile`, пустые состояния «Картины недели пока нет» с «Загрузить выписку». Неиспользуемые
   после этого `kit/DreamTile.vue`, `kit/FreeCard.vue`, `kit/WeekCard.vue` (последний — нужен ли «Неделе»,
   решает B2C-50: удалить только то, у чего потребителей нет), импорт `nextDecision` — убрать.
   `nextDecision` в `finance.ts` не удалять здесь — его заменяет `decisionQueue` в B2C-49.
6. **Без главной мечты** — пустой герой «Выбрать мечту» (одна брендовая кнопка, member) и те же списки
   «Цели» / «Желания» (путь к «Желаниям» есть всегда).
7. **Viewer** — видит мечту, строку, списки; без «+ Новая», «Добавить фото», «Открыть» ведёт в просмотр.
8. Анимации B2C-47: бег %, полосы, строки по очереди, нажатие строк.
9. `DESIGN.md` §3 «что → где» — строка главного: состав по Р-42 (точечно, пометка «пивот 3»).

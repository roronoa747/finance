# B2C-51 — «Свободно» — одно слово, одно число (фронт)

Блок 10 · MVP · Каталог: `frontend/src/components/money/IncomeWidget.vue`, `components/money/PaydaySummary.vue`, `views/Dreams.vue` · Зависит от: B2C-48 · Роли: все

## Контекст (что уже есть)

- Хвост критика Б9 (§4): «Свободно» — три разных числа под похожими словами — сводка «Денег» «остаётся
  885 000» (на счетах минус платежи до зарплаты, `untilPayday().shortfall`), «Доход» — «свободно 35 %» (по
  плану, `incomeSplit(budgetAmounts(...))` доля `free`), главный — «Свободно до конца месяца 313 000» (по
  факту выписок, `freeByFact`). Решение Р-47: **«Свободно» — только число на «Мечтах»** (`freeByFact`, после
  B2C-48 — строка «Свободно N ₸ · до зарплаты N дней»); в «Доходе» доля подписана «по плану»; в сводке
  «Денег» — «останется на счетах». **Расчёты не меняются, меняются слова.**
- `components/money/IncomeWidget.vue` ~31–36: `LABEL` — `must` «обязательное», `dreams` «мечты», `living`
  «траты», `free` «свободно» (`--ok`); подсказка `Hint` у подписи виджета.
- `components/money/PaydaySummary.vue` ~51: мета сводки `${head} · остаётся ${plain(p.shortfall)} ₸`.
- Другие места со словом (проверить grep `вободн` по `frontend/src` без тестов): `MarkSheet.vue` ~223
  («премия целиком ляжет в свободное»), `HistorySquare.vue` (комментарий), лист плана «Трат»
  (`LivingWidget`), раскладка `/week/salary` (`WeekSalary.vue` — «свободно» в долях раскладки?),
  `storyCard.ts`.

## Задача

1. «Доход»: доля `free` — подпись без слова «свободно»: **«по плану»** вариантом по умолчанию —
   «остаток по плану» (легенда: «обязательное · мечты · траты · остаток по плану»); точный текст —
   показать владельцу на снимках приёмки, он вправе сократить.
2. Сводка «Денег»: «остаётся N ₸» → «останется на счетах N ₸».
3. Пройти grep: каждое пользовательское «свободно/свободное» вне строки «Мечт» — либо переименовать по
   смыслу (раскладка, лист отметки), либо оставить с записью в Handoff, почему это то же число, что на
   «Мечтах». Список «место → было → стало» — в Handoff.
4. `DESIGN.md` §6 (тексты) — строка о «Свободно» (точечно).

## Тесты

- `IncomeWidget` / `Money.test.ts` (SSR): легенда без «свободно», доля — прежний процент.
- `PaydaySummary` (SSR): «останется на счетах N ₸», N = `untilPayday().shortfall`.
- `grep`-проверка в тесте не нужна — список в Handoff, критик сверяет.

## Критерии приёмки

- На стенде слово «Свободно» с числом — только на «Мечтах»; числа в «Доходе» и сводке — прежние.
- `cd frontend && npm run build && npm test` зелёные.

## Вне скоупа

- Любые изменения расчётов (`freeByFact`, `incomeSplit`, `untilPayday`) — Р-50. Цвета полосы «Дохода»
  (хвост ревью Б9 Н-11) — решение владельца, не здесь.

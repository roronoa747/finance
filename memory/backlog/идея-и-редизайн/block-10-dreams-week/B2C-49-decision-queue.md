## Задача

1. **`decisionQueue(state, ctx) → Decision[]`** в `finance.ts` — один порядок (Р-43): сопоставления (по
   одному на каждое ждущее) → незнакомые продавцы (по одному на группу; окно — месяц, в разборе —
   черновик: группы передаются в `ctx`, функция их не ищет) → «оставить подписку?» → зарплата
   («разложить?» `salaryToAllocate`, затем «пришла?» `salaryAsk`) → «освободится N ₸» (`freedChange`) →
   «остались деньги?» (`monthEndAsk`). Шаг плана в очередь не входит (живёт в квадрате «План», Р-34).
   Отложенные («Потом») фильтрует экран, не функция. Это перестановка существующих проверок, **новых
   расчётов денег нет** (Р-50). `Decision` расширить вариантами `match`/`unknown`/`freed` с данными для
   ответа на месте. `nextDecision` — удалить вместе с её тестами, перенеся проверки порядка в тесты
   `decisionQueue`.
2. **«Неделя» — одно решение за раз:** экран берёт `decisionQueue(...)` минус отложенные; показывает
   первое; «N из M» — **M фиксируется на открытии экрана** (или на начале разбора) и не уменьшается при
   ответе, N растёт; новые решения, появившиеся после ответа (например, «разложить?» после «Да,
   зарплата»), — увеличивают M. Цепочка `computed` `match/unknownCard/allocate/salaryHere/keep/monthEnd` и
   `lead` заменяются одной очередью; главное действие экрана — первое решение, иначе загрузка (B2C-50).
3. Одна брендовая кнопка: у первого решения (у продавца ответ — чипы, брендовой нет); «Пропустить все» у
   продавцов — остаётся тихой.
4. «Освободится N ₸» — карточка в очереди с «Распределить» → `/week/salary` (как в «Деньгах»); в
   «Деньгах» карточка остаётся (Р-43).
5. Разбор (черновик): та же очередь, но только сопоставления и продавцы черновика; «Отправить» — как сейчас.

## Тесты

- `finance.test.ts`: `decisionQueue` — порядок на фикстуре со всеми видами; пустая очередь; viewer
  (`me` undefined или `canEdit` false) — пусто; каждое решение исчезает после соответствующей записи

  «освободится» — сумма = `freedChange().monthly` (как в «Деньгах»).

- Перенесённые проверки `nextDecision` — в Handoff списком «было → стало».

  как в Р-43; на главном решений нет.
- `grep -n "nextDecision" frontend/src` — пусто.

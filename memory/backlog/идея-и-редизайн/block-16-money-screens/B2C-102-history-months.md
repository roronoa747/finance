## Контекст (что уже есть)

- Квадрат «История» (`/money/history`) = `HistorySquare` (309: лента `historyFeed`, фильтры, «Отложено по плану» →

  Решения: Р-111, Р-35 (изменено).

## Задача

1. Список месяцев из `historyMonths`: «<Месяц>», «осталось N», зелёным «+отложили M», ›; нажатие → `/month?month=`.
2. Внизу тихое «Все записи ›» — нынешняя лента `HistorySquare` целиком (фильтры и переходы как есть), свёрнута по
   умолчанию.
3. Пусто (первый месяц) — одна строка «Здесь появятся прошлые месяцы», без кнопок.

## Тесты

- DOM: строки месяцев = `historyMonths`; нажатие ведёт на `/month?month=<key>`; «Все записи» свёрнуто, раскрытие —
  прежняя лента; пустое состояние.
- Регрессия: тесты `HistorySquare` проходят без изменения смысла.

## Критерии приёмки

- `npm run build && npm test` зелёные; стенд 390 px, обе темы — «История» рядом с `money-b16.html`.

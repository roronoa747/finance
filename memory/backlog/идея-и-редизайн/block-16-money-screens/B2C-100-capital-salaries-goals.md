# B2C-100 — «Капитал»: зарплаты для справки (общий лист зарплаты) и «Цели · N» в «Счетах» (фронт)

Блок 16 · MVP · Репо/каталог: `frontend/src/views/Money.vue`, `components/money/CapitalLists.vue`,
`components/money/MonthPlan.vue` · Зависит от: B2C-99 · Роли: member, viewer

## Контекст (что уже есть)

- `Money.vue` — квадраты, карточка «Капитал» (`netWorth`), `CapitalLists` (счета, кредиты, платежи; «Подписки · N» —
  свёрнутая группа, образец раскрытия на месте).
- Лист зарплаты — встроен в `MonthPlan.vue` (`salaryFor`, `salarySheet`, шаблон ~613: «Пришла», сумма, обмен).
- Эталон — `block-16-money-screens/money-b16.html` (экран «Капитал»). Решения: Р-108, Р-109, правило 12.

## Задача

1. Карточка «Зарплаты» под числом капитала (Р-108): строки из B2C-99 — кружок, имя, ✓ «пришла <дата>» / серая сумма и
   «ждём <дата>». Нажатие — лист зарплаты; **лист вынести из `MonthPlan.vue` в компонент**, «Месяц» и «Капитал»
   зовут один. Viewer — строки без нажатия.
2. «Цели · N · сумма» в «Счетах» (Р-109): свёрнутая строка по образцу «Подписки · N»; раскрытие — цели из
   `capitalGoals`; цель на счёте — «на <счёт>», серой суммой; нажатие цели — экран цели. Итог заголовка «Счета» =
   счета + `total` целей.
3. Брендовой кнопки на экране нет (правило 12); новые строки — на токенах `style.css`.

## Тесты

- DOM: «Счета» − «Кредиты» = число «Капитал» на экране; группа свёрнута по умолчанию, раскрытие показывает цели,
  цель на счёте — с пометкой и вне суммы; нажатие цели → её адрес.
- DOM: строка зарплаты открывает тот же лист, что в «Месяце» (общий компонент); «Пришла» из «Капитала» пишет ту же
  отметку; viewer — без листа.
- Регрессия: лист зарплаты в «Месяце» (`MonthPlan.dom.test.ts`) — без изменений.

## Критерии приёмки

- `npm run build && npm test` зелёные; стенд 390 px, обе темы — «Капитал» рядом с `money-b16.html`.

## Вне скоупа

- Перекладка между целями; правка суммы цели из «Капитала» (только переход на экран цели).

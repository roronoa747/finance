# B2C-101 — «Долги» по макету: сумма, «без долгов — к», кредиты с полосой, расчёт свёрнут, без «Шаг сделан» (фронт)

Блок 16 · MVP · Репо/каталог: `frontend/src/views/Money.vue`, `components/money/DebtsWidget.vue`,
`components/money/PlanSquare.vue` · Зависит от: B2C-99 · Роли: member, viewer

## Контекст (что уже есть)

- Квадрат «Долги» (`/money/debts`) = `DebtsWidget` (24 строки) + `PlanSquare` (352: «Самая дорогая ставка», «Сначала
  долги» с переключателем, шаг месяца с брендовым «Шаг сделан», прогноз, `StrategyCompare`, «Шаги по месяцам»).
- «Отложил» в долг — у строки долга в «Месяце» (Блок 15). Эталон — `money-b16.html` (экран «Долги»). Решения: Р-110,
  Р-34 (изменено), правило 12.

## Задача

1. Карточка: сумма остатков, «без долгов — к <месяц>» (`debtsOverview`).
2. Кредиты строками: имя, «платёж в месяц · ставка · до когда», остаток; полоса `paidShare` (нет — без полосы);
   нажатие — лист кредита, как сейчас.
3. «Как закрыть быстрее ›» — свёрнуто по умолчанию; внутри — нынешнее содержимое `PlanSquare` **без** «Шаг сделан»
   (кнопку и её обработчик убрать; шаг месяца записывает только «Отложил» в «Месяце»).
4. Тихое «+ Кредит» внизу; брендовых кнопок на экране нет.

## Тесты

- DOM: числа карточки и строк = `debtsOverview`; расчёт свёрнут, раскрытие показывает «Сначала долги»; «Шаг сделан»
  нет; viewer — без переключателей и «+ Кредит».
- Регрессия: план «Сначала долги» включается и выключается из свёрнутого блока; лист кредита открывается из строки.

## Критерии приёмки

- `npm run build && npm test` зелёные; стенд 390 px, обе темы — «Долги» рядом с `money-b16.html`.

## Вне скоупа

- Математика плана долгов и графиков (Р-34) не меняется; исходная сумма кредита не заводится.

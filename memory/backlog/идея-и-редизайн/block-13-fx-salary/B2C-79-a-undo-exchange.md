# B2C-79-а — Отменить обмен (фронт) · клинап Блока 13

Блок 13 · MVP · Репо/каталог: `frontend/src/` · Зависит от: B2C-79 · Роли: member (viewer — без отмены) · Делает: клинап, до деплоя

## Контекст (что уже есть)

- Владелец на приёмке Блока 13 (2026-10-04): хвост §4 «обмен нельзя отменить из интерфейса» — **сделать до деплоя**,
  блок принят.
- Стор: `undoExchange(id)` (`stores/finance.ts` ~1079) — надгробие `deletedAt`, протестирован (e2e Блока 13 часть 4);
  обмены месяца — `salaryExchange(payments, fxExchanges, personId, period)`, живые — `liveExchanges`.
- `components/SalaryExchange.vue`: строка «обменяно 800 € из 1 500 € · ≈ N ₸» + тихая «Обменял» (только своя
  зарплата, не viewer) → лист «Обменял» (сумма, курс, «= N ₸», счёт, одна брендовая «Записать»).
- Ревью frontend Н-6: «Снять отметку» у валютной зарплаты обмены месяца не трогает, а строка «обменяно …» без отметки
  пропадает — обмены считаются невидимо, пока зарплату не отметят снова.
- Решения: Р-73 (отмена — надгробие), правило 12 (одно действие, сложное — скрыто).

## Задача

1. Нажатие на строку «обменяно … из …» (у своей зарплаты, не viewer) открывает лист обменов месяца: по строке на
   живой обмен — «500 € по 515 → 257 500 ₸ · Kaspi Gold · 3 окт», у строки тихая «Отменить»; нажатие — подтверждение
   в том же листе («Отменить обмен 500 €?» — «Отменить» / «Нет»), затем `undoExchange`. Главной брендовой кнопки в листе
   нет; «Обменял» остаётся там же, где сейчас.
2. Остатки сходятся сразу: евро-счёт +500 €, тенговый счёт −257 500 ₸, тенге зарплаты месяца — по Р-74 без этого
   обмена (всё уже выводится из записей — проверить, а не досчитывать в компоненте).
3. Н-6: у месяца есть живые обмены, а отметки зарплаты нет (сняли) — строка обменов и лист с «Отменить» видны (без
   «Обменял»: приходить нечему). Снятие отметки обмены по-прежнему не трогает.
4. Viewer и партнёр: строку видят, лист открывают только для чтения — без «Отменить».

## Тесты

- DOM: лист обменов — строки двух обменов, «Отменить» → подтверждение → надгробие у одного, вторая строка на месте;
  viewer — без «Отменить»; партнёр — без «Отменить».
- e2e `b2c-block13-fx-salary` — часть 6: два обмена, отмена одного → остатки обоих счетов и `salaryTenge` до тенге,
  второй телефон после синка видит то же; снятая отметка + живой обмен → строка видна, отмена работает.
- Мутация: отмена без подтверждения или без надгробия — тест падает.

## Критерии приёмки

- `cd frontend && npm run build && npm test` зелёные.
- Стенд 390 px, обе темы: снимок листа обменов с «Отменить» и подтверждением — владельцу вместе со смоуком клинапа;
  после отмены «Капитал» и «Доход» сходятся до тенге.
- Правило 12 в «Итогах пост-приёмки»: главное действие листа, что скрыто.

## Вне скоупа

- Правка суммы или курса записанного обмена (отменить и записать заново). Отмена прихода валютной зарплаты — как
  было («Снять отметку»).

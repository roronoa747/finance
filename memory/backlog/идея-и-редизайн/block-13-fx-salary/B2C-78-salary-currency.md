# B2C-78 — Оклад в валюте: версии с валютой, форма «Доход», тенге по курсу (фронт)

Блок 13 · MVP · Репо/каталог: `frontend/src/` · Зависит от: B2C-77 · Роли: member (viewer видит)

## Контекст (что уже есть)

- `Person.salary` + `salaryVersions?: ObligationVersion[]` (`{ from: 'YYYY-MM', amount, reason? }`,
  `types/finance.ts` ~22/160). `salaryAt(p, key)` (`finance.ts` ~910) — сумма последней версии с `from ≤ key`, иначе
  `p.salary`; `nextSalaryChange`; `totalIncome(people, key)` ~927.
- Правка: стор `amendSalary(id, from, amount, reason?)` ~860 (версия с месяца), `correctSalary(id, amount)` ~877
  (исправить текущую); форма — `components/SalaryDialog.vue` (201 строка: «с какого месяца» `fromMonth`, `months`).
- Показ: `components/money/IncomeWidget.vue` ~85–88 (строка участника: день, `salaryAt`, «с <месяца> — N»).
- Книга курсов и `rateOn` — B2C-77. Р-70: валюта версии `currency?` (нет — KZT), `rate?` — курс на момент ввода,
  `amount` — целые единицы валюты; задним числом можно.

## Задача

1. `ObligationVersion` += `currency?: Currency`, `rate?: number` (общий тип с обязательствами — B2C-81 пользуется тем
   же). Старые версии без полей — KZT.
2. `finance.ts`: `salaryOf(p, key)` → `{ amount, currency }` (в валюте оклада) и **тенге оклада** с книгой:
   `salaryAt(p, key, book?)` — KZT как было; валюта — `fxToTenge(amount, rateOn(book, cur, день зарплаты месяца,
   version.rate))`, без книги — по `version.rate`. День зарплаты месяца — `payday` в этом месяце (обрезка по длине
   месяца — как в существующих расчётах). Вызовы, которым нужны тенге месяца, получают книгу параметром; полный
   переход потребителей на «тенге зарплаты месяца» (с обменами) — B2C-80, здесь — только оклад.
3. `SalaryDialog`: выбор валюты (KZT по умолчанию; чипы KZT · USD · EUR · RUB · CNY), сумма в валюте, «с какого
   месяца» — в том числе прошлые месяцы (до 24 назад). Под суммой — одна тихая строка «≈ N ₸ по курсу Нацбанка»
   (правило 12). Сохранение — версия с `currency` и `rate` (курс на сегодня из книги; нет — поле курса вручную, как у
   счёта).
4. `IncomeWidget`: строка участника с валютным окладом — «2 500 € · ≈ 1 265 000 ₸»; суммы дохода — тенге из п. 2.

## Тесты

- `salaryAt`/`salaryOf`: KZT без изменений (все старые тесты зелёные), EUR по книге на день зарплаты, выходной день
  зарплаты → пятница, без книги → `rate` версии, смена валюты между версиями (KZT до марта, EUR с апреля), задним
  числом — прошлый месяц пересчитан, текущий нет.
- Стор: `amendSalary` с валютой пишет `currency`/`rate`; слияние версий как прежде.
- DOM: `SalaryDialog` — выбор EUR, прошлый месяц, строка «≈ N ₸».

## Критерии приёмки

- `npm run build && npm test` зелёные.
- Стенд 390 px, обе темы: Ильяс задаёт оклад 1 500 € с октября 2025 → в «Доходе» «1 500 € · ≈ N ₸», N сходится с
  ручным `1 500 × курс Нацбанка на день зарплаты` до тенге (сверка в Handoff); партнёр видит то же; viewer — без
  правки.
- Правило 12 в Handoff: главное действие формы, что ушло в подсказку.

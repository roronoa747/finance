# B2C-82 — «Доход»: строка «курс за год» и лист с графиком и выбором месяца (фронт)

Блок 13 · MVP · Репо/каталог: `frontend/src/` · Зависит от: B2C-80 · Роли: member, viewer (смотрит)

## Задача

1. `finance.ts`: `fxYearDelta(p, key, book)` → `{ currency, rateNow, rateThen, perUnit, tenge } | null` — оклад
   месяца в валюте × (курс на день зарплаты этого месяца − курс того же дня год назад), каждая сторона через
   `fxToTenge`; `null` у KZT или без курса год назад. И `fxMonthDelta(p, key, otherKey, book)` — то же против любого
   месяца.
2. `IncomeWidget`: под строкой валютного участника одна строка «евро −134 ₸ за год · −201 000 ₸» (минус — `--destructive`,
   плюс — `--ok`); нажатие — лист.
3. Лист: заголовок 1–3 слова («Курс евро»), график курса за 12 месяцев (линия, отметки дней зарплаты), выбор месяца
   чипами/лентой — «в марте по 590 ₸ · было бы +126 000 ₸». Таблиц и абзацев нет.

## Тесты

- `fxYearDelta`: евро упал на 134 ₸ при окладе 1 500 € → −201 000 ₸; рост → плюс; нет курса год назад → `null`;
  KZT → `null`; выходной день зарплаты.
- DOM: строка видна только валютному участнику; лист открывается, выбор месяца меняет строку.

## Критерии приёмки

- `npm run build && npm test` зелёные.
- Стенд 390 px, обе темы: строка и лист; цифра года сходится с ручным расчётом по курсам Нацбанка до тенге (сверка
  двух дат в Handoff). Правило 12: главное — число, расчёт в листе.

## Вне скоупа

- Прогноз курса, советы «когда менять», курсы других банков — не делаем.

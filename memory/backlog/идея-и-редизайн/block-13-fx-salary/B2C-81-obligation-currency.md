# B2C-81 — Подписки и платежи в валюте (фронт)

Блок 13 · MVP · Репо/каталог: `frontend/src/` · Зависит от: B2C-77 (книга), тип версии — B2C-78 · Роли: member

## Контекст (что уже есть)

- `Obligation` (`types/finance.ts` ~167): `day`, `versions: ObligationVersion[]`, `every?: 'month' | 'year'`, `month?`,
  `group?`/`parentId` (группы подписок), `who?`. `ObligationVersion` после B2C-78 несёт `currency?`, `rate?`.
- `amountAt(o, key)` (`finance.ts` ~776) — сумма версии месяца; `monthlyAmount` (годовые / 12); 8 вызовов
  `amountAt` в `finance.ts` (`monthDues` ~1428, `duesTotals`, бюджет), компоненты — `ObligationSheet.vue`,
  `PaymentLine.vue`, `Money.vue` (`freedChange`).
- Отметка «Оплатил» — `markPaid` пишет тенге в `payments` (`amount`); счёт — только тенговый (`payableAccounts`).
- Форма обязательства — `components/capital/ObligationSheet.vue` (347 строк).
- Решение: Р-75 (валюта у версии, тенге по курсу дня списания, наценки нет; кредиты и траты — тенге).

## Задача

1. `finance.ts`: `amountAt(o, key, book?)` → тенге: KZT как было; валюта — `fxToTenge(amount, rateOn(book, cur, день
   списания месяца, version.rate))`; без книги — по `rate` версии. `amountIn(o, key)` → `{ amount, currency }` для
   подписей. Годовые — та же логика на месяц списания.
2. Потребители, считающие деньги месяца (платежи месяца, бюджет, «до зарплаты», «освободится»), получают книгу
   параметром; итоги «Платежей» — в тенге.
3. `ObligationSheet`: валюта суммы (чипы, KZT по умолчанию), строка «≈ N ₸ по курсу» под суммой; новая версия при
   смене суммы или валюты — с месяца (как сейчас). В списке «Платежей» — «Netflix · $15 · ≈ 7 700 ₸».
4. «Оплатил» по валютной подписке — тенге по курсу дня списания (правится руками, как сейчас).

## Тесты

- `amountAt`: KZT без изменений (старые тесты), USD по курсу дня списания, выходной → пятница, годовая в валюте,
  смена валюты версией.
- `monthDues`/`duesTotals` с валютной подпиской — итог до тенге.
- DOM: форма — выбор USD, строка «≈ N ₸»; список — подпись в валюте.

## Критерии приёмки

- `npm run build && npm test` зелёные.
- Стенд: подписка $15 на 10-е → в «Платежах» тенге по курсу 10-го (сверка с Нацбанком в Handoff), отметка
  «Оплатил» пишет эту сумму.

## Вне скоупа

- Валюта у кредитов и трат, наценка банка — не делаем (Р-75).

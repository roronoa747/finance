## Задача

1. В перечисленных местах заменить `plain(x)` на `money(x)` (тенге) — суммы строк, итоги разделов, «На карте», мета заметки,
   строки листа «План трат», строка платежа, история месяца, все списки `CapitalLists` и `PaymentLine`, `SectionSheet`.
   У валютного счёта сумма справа остаётся тенге (`money(a.amount)`), валютная сумма — в подписи, как сейчас.
2. Составные строки — валюта один раз в конце: «осталось 133 500 / 175 000 ₸» (`data-week-rest`), «сверх плана 12 000 ₸»;
   «N из M оплачено / отложено» — без валюты (счётчики). Тренд «26к» (`data-trend-bars`) не трогать.
3. Снять комментарии о правиле «без ₸» (`CapitalLists.vue:52`, `PaymentLine.vue:16, :27`, `Money.vue:25`) — заменить одной
   строкой со ссылкой на Р-12 бэклога «Figma».
4. Проверить grep-ом `plain(` по `views/`, `components/money/`, `components/week/`, `components/capital/`, `components/goals/`:
   каждое оставшееся использование — либо счётчик/день/«к», либо составная строка из п. 2. Остальное — `money`.
5. Ширина: колонка сумм в списках «Денег» и «Месяца» на 390 и 375 px не переносится и не наезжает на название (`truncate` у
   названия есть) — проверить на стенде на демо-семье.

## Критерии приёмки

- На демо-семье в Chrome 390 и 375, обе темы: «Неделя» (строки, «На карте», полоса плана, заметка), «Месяц» (разделы, лист
  «План трат», раскрытые «Платежи»), «Деньги → Капитал» (счета, цели, кредиты, подписки) — у каждой суммы «₸» или валюта
  счёта; нигде нет двух валют в одной строке, кроме подписи валютного счёта.
- `cd frontend && npm run build && npx vitest run` зелёные.

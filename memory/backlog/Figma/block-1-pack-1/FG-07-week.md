## Задача

1. **Шапка (К-1).** Стрелки — `size-9` (36 px), иконки `:size="20"`, цвет `text-ink-2` (не `ink-3`), `disabled:opacity-30`
   остаётся; подпись недели — `text-[15px] font-semibold text-ink` обычным регистром вместо `type-section` (капс читается как
   заголовок раздела и шумит), `data-week-label` и aria-label не менять. **Свайп (вариант составителя, Р-9):** горизонтальный
   свайп по `data-week-head` листает неделю (`touchstart`/`touchend`: |dx| ≥ 48 px и |dx| > 2·|dy| → `turn(dx < 0 ? 1 : -1)`,
   с теми же `canBack`/`canForward`); без новых зависимостей; десктоп — только стрелки. Ничего из шапки не убирать (полоса
   загрузок, «На карте», полоса плана — решения прошлых блоков). В Handoff — «вариант составителя, утром показать владельцу».
2. **Значок заметки (К-2).** `PhClock` → `PhNote :size="16"` в карточке заметки; в листе `NoteSheet` ничего не добавлять.
3. **«Не разобрано» последним (К-3), вариант составителя.** В `myWeek()` после сортировки строка `UNKNOWN_CATEGORY`
   переставляется в конец (`rows.sort(...)` → затем стабильный перенос «Не разобрано» последней). Вид строки (кнопка
   `data-bang` с «N вопросов» / обычная строка) не меняется; строка «Вопросы» без «Не разобрано» — как была. Идею владельца
   «последняя из видимых, при прокрутке меняется местами» не делаем: строки, прыгающие при прокрутке, ломают «нажатие ведёт
   туда, куда ждёшь» (правило 12), а список недели почти всегда помещается в экран; зов издалека остаётся — подпись «N
   вопросов» и пузырь. В Handoff — пометка для владельца с этой причиной.
4. **«История» (К-5, Р-14).** Текст строки `data-week-feed` — «История», без счётчика; `PhCaretRight` остаётся. Счётчик
   переезжает в лист: заголовок листа «История», под ним одна строка «16 операций» (`plural`). `feed.count === 0` → строки нет,
   как сейчас.
5. **«Статистика» (К-6, Р-14).** Текст раскрывашки `data-week-trend` — «Статистика»; содержимое (8 столбиков) не меняется.

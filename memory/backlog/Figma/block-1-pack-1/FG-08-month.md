## Задача

1. **Подписи разделов (К-7, Р-14).** `spend.meta`: `потрачено ${plain(x)}` → `${plain(x)} потрачено` (как на макете `18:153`;
   валюта в подписи — нет, как у владельца; суммы справа — с «₸» из FG-06). «по плану» и «K из M …» не трогать.
2. **Зарплата чёрным (К-8).** :1094 — всегда `text-ink`; «≈ » у плавающей остаётся; подсветка пришедшей не меняется.
3. **Точка вместо призыва (К-12), вариант составителя (Р-9).**
   - Новая анимация в `style.css`: `@keyframes fx-pulse` — кольцо `box-shadow: 0 0 0 0 color-mix(in srgb, var(--brand) 55%,
     transparent)` → `0 0 0 9px transparent`, `1.6s var(--ease-out) infinite`; утилита `fx-pulse`. Под
     `prefers-reduced-motion` гасится общим правилом (точка остаётся обычной) — ничего дописывать не надо.
   - Точка раздела :765 получает `fx-pulse` и `data-section-call`, когда есть зов: `s.dot || sectionMarked[s.key]` (для `dues`
     `dot` теперь ещё и `foundMeta` — «нашли в выписке» тоже зов). Текст зова остаётся читалке (`sr-only` у кнопки уже есть) и
     `title` точки.
   - Подпись под названием всегда нейтральная `s.meta` (`text-ink-2`): для `dues` при `foundMeta` — «платежей нет» (число
     найденных — в раскрытом разделе, где список `data-found-list`), иначе «K из N оплачено». Брендовый текст `data-section-call`
     в подписи больше не рендерится; `data-section-found` остаётся на подписи (значение — `found.length`).
   - ✦ после названия (`data-section-mark`) остаётся как есть — точка пульсирует и для совета ИИ, ✦ показывает, что именно совет.
   - Предмет зова внутри раскрытого раздела должен быть виден (список найденных, `data-freed`, `data-spend-dot`, очередь) —
     если для какого-то случая предмета нет, добавить тихую строку `data-section-call-line` с текстом `s.call` первой в
     раскрытом разделе, не больше.
4. **Без подписи при кнопке; «Установить план» (К-14, Р-14).** При `planFact` подпись под «Траты» не рендерится (строка —
   название + кнопка + сумма), текст кнопки `data-plan-fact` — «Установить план», размер `xs` как сейчас (на макете чип 10 px —
   не повторять, крупнее читается); в листе кнопка `data-plan-fact-save` — «Установить», заголовок «План трат» и строка
   «обычно в месяц» в листе остаются.
5. **«ещё 6» (К-15).** Текст кнопки `data-plan-fact-more` — «ещё N» без слова «разделов», класс `text-brand font-semibold`
   + `PhCaretDown :size="14"` сразу после текста; сумма скрытых справа остаётся (`money`, FG-06). После раскрытия кнопки нет.
6. В Handoff по экрану «Месяц»: главное действие и предмет, что ушло в раскрытый раздел (тексты зовов), пометка «вариант
   составителя, утром показать владельцу» у точки.

## Критерии приёмки

- Демо в Chrome 390, обе темы: подписи трёх разделов — «N из M оплачено · N потрачено · N из M отложено»; сумма
  непришедшей зарплаты — чёрным (`--ink`), пришедшая — подсвечена; у раздела с зовом точка пульсирует, брендового текста под
  названием нет, при раскрытии предмет зова виден; с «Уменьшить движение» точка статична; при «Установить план» под «Траты»
  одна строка; в листе «План трат» — «ещё 6 ▾» брендом, по нажатию все строки.
- `npm run build && npx vitest run` зелёные.

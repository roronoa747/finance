## Задача

1. **Полоса одной ширины.** Процент в `#end` — колонка фиксированной ширины, выровнен вправо: `inline-block w-[52px] text-right`
   (`font-num` табличный; измерить на стенде, чтобы «100 %» влезало в 390 и 375 без переноса — при нужде 56 px). Полоса `flex-1`
   получает одинаковую ширину во всех строках. Проверить строки «Сбылось» в листе (`#end` — галочка, ширину не трогать) и `WishRow`
   («Желания» — другой компонент, не трогать).
2. **Без строки сдвига.** Убрать `rowNotes`, `shiftOf`, `snap` и разметку `data-row-note` из `Dreams.vue` целиком — вместе с
   «на паузе» (пауза уже видна приглушением `opacity-60`, слово — на экране цели; строка цели = фото, имя, полоса, % — вариант
   составителя по формуле владельца, `/ux` проверит). Неиспользуемые импорты и функции (`dreamShift`, `shiftShort`, `termOf`, если
   больше не нужен) — убрать; расчёт `dreamShift` на «Мечтах» больше не гоняется (план месяца на каждую отрисовку — дешевле).
   Комментарий у `shiftOf` «у строк целей — как была» → удалить. Для viewer — то же (строки одинаковые).
3. Экран цели (`GoalDetail` `data-goal-shift`, `termShort`), `lib/finance.ts` (`dreamShift`, `shiftShort` — живые для экрана цели и
   ИИ), ИИ-тексты — **без изменений**.
4. `DESIGN.md` — строка про строки целей на «Мечтах» (фото 48, имя, полоса `ink` 5, процент фиксированной колонкой; сдвиг — только
   на экране цели) — точечно grep-ом по «Мечты».

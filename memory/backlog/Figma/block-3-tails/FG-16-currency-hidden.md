## Задача

1. `StrategyCompare.vue`: `:275` → `{{ money(g.monthly) }}/мес` («25 000 ₸/мес»); `:199` → `{{ money(inputs.saving) }}` (текст
   подсказки тот же).
2. `ScheduleTable.vue`: ячейки `:27-30` и `r.extra` `:32` → `money(...)`. **Ширина:** на стенде в Chrome 390 и 375 раскрыть
   «График платежей» у кредита с остатком ≥ 10 000 000 ₸ (ипотека, срок 240 мес.) — таблица не должна выходить за карточку
   листа (нет горизонтальной обрезки, колонки не наезжают; `NBSP` переносов не даст — сетка либо помещается, либо вылезает).
   Если при 8-значных суммах не помещается — **вариант Б** (составитель, Р-9: в Handoff пометка «вариант составителя, показать
   владельцу»): «₸» один раз в заголовках колонок («Платёж ₸ · В долг ₸ · Банку ₸ · Остаток ₸»), ячейки — `plain`, строка
   досрочки — `money(r.extra)`. Решение и замер (ширина карточки / таблицы в px) — в Handoff.
3. `SalaryRow.vue:59`: тенговая ветка → `money(shown)` («+245 000 ₸»); валютная — как была.
4. `SalaryDialog.vue:205`: `moneyIn(weekHint.amount, current.currency)` («≈ 161 538 ₸ за неделю»; валютный оклад — своя валюта).
5. Grep-контроль: `plain(` по `components/*.vue` (без подкаталогов) — каждое оставшееся использование попадает в список «не
   трогать» из Контекста; новое — либо туда же по правилу, либо `money`. Список оставшихся — в Handoff одной строкой.

## Критерии приёмки

- Стенд (Chrome 390 и 375, обе темы): лист кредита → «График платежей» — суммы с «₸» (или заголовки с «₸» по варианту Б), таблица
  в карточке без обрезки при ипотеке ≥ 10 000 000 ₸; экран плана → «Копить или гасить?» → строки целей «N ₸/мес»; «Месяц» →
  карточка зарплат — «+N ₸»; лист зарплаты → смена ритма → подсказка «≈ N ₸ за неделю». Ни одной суммы без валюты в
  `components/*.vue` вне правил Контекста.
- `cd frontend && npm run build && npx vitest run` зелёные (e2e `pv-block1-calculator`, `pv-block2-money-edit` — в наборе).

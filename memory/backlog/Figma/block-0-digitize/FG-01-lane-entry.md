   пересекаясь); внутри — ряд фреймов 390 px с шагом 470 px по x, имена «NN · <Экран>» и «NN.m · <Экран> → <Лист>» (лист —

   «01 · Лэндинг — страница 04».
2. **Экраны этой задачи:** 01 Лэндинг (мобильный, если его нет на «04») · 02 Вход (`Access`: Google, код, «Попробовать») ·
   03 Кто вы (`Who`) · 04 Первый запуск · вступление (`intro`, первый образ, точки) · 05 Первый запуск · мечта (`dream`, сетка
   плиток) · 06 Первый запуск · «Тратьте как обычно» — **переместить сюда `19:156`** (`node.parent` → новая секция, `x/y` по
   сетке; id не меняется) · 07 Первый запуск · партнёр (`invite`).
3. Каждый макет — по снимку стенда и шаблону компонента: структура слоёв как в Блоке 5, тексты демо, Inter, цвета только
   переменными, редактируемые слои (без растров, кроме фото мечты — прямоугольник с заливкой `--surface-3` и подписью
   «фото»). Иконки — векторы Phosphor (путь `d` из `node_modules/@phosphor-icons/vue` соответствующего компонента; `createNodeFromSvg`,
   если доступен в `use_figma`) или простой примитив с именем «Иконка · <имя>».
4. Handoff (в `SESSION.md`): число вызовов MCP на задачу, список фреймов с id, на чём остановились, что упрощено.

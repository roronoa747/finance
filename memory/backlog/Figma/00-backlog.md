## 1. Цель

Всё приложение лежит в Figma одной лентой по пути пользователя, владелец правит его картинкой и комментариями, и каждая
пачка правок одного экрана быстро доходит до прода. Первая пачка — 15 комментариев владельца на макетах Блока 5 «Фидбека»
(2026-10-24) и хвосты «Фидбек-2» F2-Х2..Х4; отдельно — честная цифра «На карте» (F2-Х1). Успех: все экраны и листы в Figma;
после каждой пачки прод совпадает с макетом (стенд Chrome 390, обе темы), тест на правило + e2e, смоук прода; инициатива
закрыта, когда владелец говорит «правок больше нет» → бриф iOS.

Режим: пачки вида — **S** (исполнитель → критик → приёмка; правило 12 проверяет критик явным пунктом); пачка, трогающая счёт
денег или данные, и Блок 2 (F2-Х1) — **M**; Блок 0 (оцифровка) — без кода, приёмка — владелец глазами.

## 2. Зафиксированные решения

- **Р-1. Оцифровка — экраны + листы**: ≈ 40–50 макетов 390 px, светлая тема, редактируемые слои (владелец правит руками),
  шрифт Inter (SF Pro в среде MCP нет), цвета — переменные коллекции «Тема · Светлая» (`VariableCollectionId:12:2`), данные —
  демо-семья (без данных семьи). *(владелец, р.1; шрифт, токены, демо — дефолт по памяти проекта)*
- **Р-2. Раскладка — одной лентой** по пути пользователя: лэндинг и вход → первый запуск → «Мечты» (желания, цель) → «План»
  («Неделя», «Месяц») → «Деньги» (капитал, долги, история) → «Настройки»; листы — в ленте сразу за своим экраном. Шесть
  готовых макетов секции «Блок 5 · Вид» `18:2` **переезжают** в ленту на свои места (узлы те же — комментарии и правки пачки 1
  не теряются); пустая секция `18:2` убирается. *(владелец, р.2; переезд вместо перерисовки — дефолт составителя: экономит
  лимит MCP)*
- **Р-3. Цикл правок:** владелец правит макет / комментирует → «посмотри Figma» → составитель вносит в макет сразу,
  исполненные комментарии удаляет → правки одного экрана = пачка → код → прод. *(владелец, р.1)* Ночью 2026-10-25 макеты
  пачки 1 правит исполнитель Блока 1 (FG-13), комментарии удаляет приёмка после «принято». *(решение ночи)*
- **Р-4. Пачка вида — блок режима S** (исполнитель → критик → приёмка), эталон — макет Figma, правило 12 проверяет критик;
  пачка трогает счёт денег или данные — режим M. *(владелец, р.2)*
- **Р-5. Каждая пачка — на прод отдельно:** «да» владельца с перечнем, откат — promote прошлого Production. *(владелец, р.1)*
- **Р-6. Старт параллельно:** пачка 1 (15 комментариев + F2-Х2, F2-Х3, F2-Х4) идёт в код сразу; оцифровка — тем временем.
  *(владелец, р.2)*
- **Р-7. F2-Х1 — отдельный блок M сразу**, не ждёт Figma (честная цифра «На карте»). *(владелец, р.2)*
- **Р-8. F2-Х2 меняет Р-2 «Фидбек-2»** («Месяц» не меняется) → «Оплатил» небольшой кнопкой и ✓ прямо в строке платежа
  «Месяца», как на «Долгах»; запись — `memory/decisions/figma-pack-1.md`. *(бриф; владелец 2026-10-25)*
- **Р-9. Правка с новым поведением** (не вид: мигающая точка, анимации, свайп) — вариант в Figma и один вопрос владельцу;
  крупная — своей пачкой. *(дефолт составителя)* **Ночью 2026-10-25** исполнитель делает такие правки по рекомендованному
  варианту из ТЗ (каждый назван в ТЗ явно), в Handoff — пометка «вариант составителя, утром показать владельцу». *(владелец,
  решение ночи)*
- **Р-10. Данные — без миграций БД по умолчанию;** всё в документе семьи / личном документе. Правке нужна миграция — режим M,
  миграцию на прод запускает владелец. *(дефолт составителя)*
- **Р-11. Бэклог растёт пачками:** составитель дописывает блок по каждой готовой пачке владельца (Блоки 3…N); оцифровка —
  блок без кода (приёмка — владелец глазами, критика и приёмки агентами нет). *(дефолт составителя)*
- **Р-12. Валюта у каждой суммы.** Все суммы на экранах и в листах — с «₸» (`money`) или своей валютой (`moneyIn`); голое
  число (`plain`) остаётся только внутри составной строки, где валюта стоит один раз в конце («осталось 133 500 / 175 000 ₸»),
  и у счётчиков («1 из 9»). Отменяет правило «суммы списков без ₸» (FB-20 / Р-34 «Фидбека», `DESIGN.md` §2 и §5 п. 34).
  *(владелец — комментарии К-4, К-9, К-13 от 2026-10-24)*
- **Р-13. Подсказки-пузыри (`kit/Tip`) — один раз на устройство:** показанная или закрытая подсказка не возвращается после
  выхода, смены семьи и демо (ключ переживает `clearLocal`). Отменяет «выход стирает увиденное» (бэклог «первый», Р-7).
  Общий список по человеку (личный документ) — не сейчас (Р-10). *(владелец, F2-Х3; механика — дефолт составителя)*
- **Р-14. Тексты по макетам владельца:** «8 недель» → «Статистика», «Траты недели · N» → «История» (счётчик — в лист),
  «Поставить план» → «Установить план» (кнопка и лист), подписи разделов «Месяца» — «N из M оплачено · N потрачено · N из M
  отложено». *(владелец — К-5, К-6, К-7, К-14)*
- **Р-15. Ночной прогон 2026-10-25→26:** роли — фоновые субагенты подряд; Блок 0 параллельно с кодовыми блоками; кодовые
  блоки — последовательно, каждый в своей ветке от `main`; деплоя ночью нет (принятый блок ждёт в ветке, утром «да» владельца
  → мёрж → смоук); ветки блоков пушить в `origin` ради CI можно, `main` — нет. Бюджет Figma на ночь — ≤ 150 вызовов MCP
  суммарно: Блок 0 ≈ 130, Блок 1 ≈ 20; 50 остаются на утро. Каждая сессия считает свои вызовы и пишет число в Handoff.
  *(владелец, 2026-10-25)*
- **Р-16. Шапка цели — без имени, кнопки-значки шапки — «белый 60 %».** На `/goals/:id` шапка оболочки без заголовка (имя — на обложке
  и в листе «···», как в макетах `78:50`, `78:104`); фон «‹», «Поделиться», «···» — токен `--surface-glass` (светлая `rgb(255 255 255 /
  0.6)`, тёмная — `--surface` тёмной на 60 %), не чистый `--surface` (на бежевом резко; макет `104:21`). *(владелец: «ок» на п. 6
  страницы `/ux` 2026-10-27; вариант C — 2026-10-27; один стиль «‹» на всех экранах с шапкой — дефолт составителя)*
- **Р-17. iPhone: контент под строкой статуса, отступы — `safe-area`.** `viewport-fit=cover` + `apple-mobile-web-app-status-bar-style:
  black-translucent`; обложка «Мечт» уходит под строку статуса, шапка на фото — ниже выреза (`env(safe-area-inset-top)`), капсула
  вкладок и листы — над полосой жеста (`env(safe-area-inset-bottom)`); с нулевым вырезом раскладка не меняется. Закрывает FG-Х1.
  *(владелец — скрин iPhone 2026-10-27, решение через оркестратора; цвет текста строки статуса — проверяет смоук владельца, FG-31 п. 5)*
- **Р-18. Строка цели на «Мечтах» = фото, имя, полоса, %.** Процент — колонка фиксированной ширины (полосы одной длины); строки
  «• +N недели» нет — сдвиг срока только внутри цели (правило 12 «нет шумных цифр»: число переезжает в предмет). *(владелец,
  2026-10-27; «на паузе» в строке → приглушение, слово — на экране цели: дефолт составителя)*

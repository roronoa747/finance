# Бриф «iOS»

## Контекст

Family Finance — семейные финансы (Go + Vue 3, PWA на `family-finance-ff.vercel.app`). На iPhone сайт уже ставится
иконкой; FG-31 сделал вырез и safe-area. Старый план — Блок 8 `идея-и-редизайн` (B2C-37…39: Capacitor iOS на Mac
владельца, Sign in with Apple, TestFlight/App Store) — опирался на Блок 7 Android (Capacitor, нативный вход Google, FCM),
который не делался: Google Play владелец пропустил 2026-10-25 (`plan-after-tails`).

**Разведка 2026-11-01 (что уже есть):** вход Google в вебе на проде (`internal/googleauth`, `GOOGLE_CLIENT_IDS`,
`VITE_GOOGLE_CLIENT_ID`); удаление аккаунта (`auth.deleteAccount`) и политика `/privacy` RU/EN — обязательные пункты
ревью Apple; траты касанием и пуши банков через «Быстрые команды» (`internal/applepay`, миграции `000008`/`000009`);
демо «Попробовать» без входа. **Нет:** Capacitor (`frontend/ios/` нет), пушей приложения (ни Web Push — VAPID не задан, ни
нативных), Sign in with Apple, токенов устройств.

## Что хочется получить и зачем

Бриф владельца (2026-11-01): «iOS — приложение в App Store; план заранее, без Mac». FG-Х1 (вырез) уже закрыт FG-31.

## Резюме бриф-интервью

- **Цель одной строкой:** приложение в App Store (Казахстан), которое ставят незнакомые семьи, — то же приложение,
  что сайт, плюс то, чего сайт не умеет: вход Apple, пуши, «Поделиться выпиской» из банка.
- **Скоуп (1.0):** оболочка Capacitor iOS (iPhone only); вход Apple + Google в приложении; пуши «Платёж завтра» и
  «Партнёр сделал»; «Поделиться выпиской» из Kaspi / Freedom / Halyk → в приложение; живое обновление веб-части;
  облачная сборка в TestFlight; листинг, App Privacy, ревью, выпуск в App Store КЗ.
  **Не-скоуп:** Android и Google Play; iPad; пуши на сайте (Web Push); вход Apple на сайте; FinanceKit; казахский язык и
  другие страны в 1.0. **После 1.0 (в этом бэклоге, последним блоком):** виджет (версия 1.1).
- **Решения (кандидаты в Р-*):**
  - Р-1 **Публичный релиз в App Store** — успех = прошли ревью и приложение в магазине. *(ответ владельца, раунд 1)*
  - Р-2 **Аккаунт Apple Developer — на владельца как физлицо** (99 $/год, продавец — его имя; перенос на компанию —
    позже). *(раунд 1)*
  - Р-3 **Mac — MacBook Neo владельца** (A18 Pro, 8 ГБ): на нём сессии нативной части («Поделиться», виджет, первая
    настройка подписи). **Перед покупкой — проверить, что свежий Xcode ставится** (официально Xcode пишет «M1 или новее»,
    Neo в списке не назван). Claude Code на этих сессиях запускается на Mac (клон репо, хук). *(раунды 1–3; заменяет
    Р-18 «iOS на Mac» по смыслу — Mac теперь не для каждой сборки)*
  - Р-4 **Сборки — облаком** (GitHub Actions macOS или Codemagic — выбор исполнителя по бесплатным минутам), подпись —
    ключ App Store Connect API (секрет — `memory/secrets/ios/`), выход — TestFlight. Проверка — на iPhone владельца и
    партнёра через TestFlight (симулятор — только на Neo). *(раунд 1, дефолт)*
  - Р-5 **Нативное в 1.0:** вход Apple (обязателен по 4.8 рядом с Google), пуши, «Поделиться выпиской» (Share Extension).
    **Виджет — версией 1.1** после выпуска. *(раунды 1–2)*
  - Р-6 **Пуши 1.0 — два вида:** «Платёж завтра» (по плану платежей «Месяца», накануне, утром по Алматы) и «Партнёр
    сделал» (взнос в цель, «Оплатил» — второму участнику семьи). **С суммой** в тексте («Завтра: кредит · 45 000 ₸»);
    скрыть — настройкой iPhone. Суммы в тексте пуша считает `finance.ts`/сервер по тем же правилам, что экран, — без
    дробей. *(раунды 2–3)*
  - Р-7 **Обновления — живые:** веб-часть внутри приложения + обновление с нашего сервера при запуске (без ревью на
    каждую пачку Figma); новая версия в App Store — только когда меняется нативное. *(раунд 3)*
  - Р-8 **Магазин — только Казахстан**, описание по-русски; другие страны — «потом посмотрим». **Имя** — «Family Finance»,
    скорее всего, занято: составитель/исполнитель предложит 3–5 имён с проверкой занятости, выбирает владелец (в задаче
    листинга). *(раунд 2: «в начале КЗ, потом посмотрим»)*
  - Р-9 **Порядок — после пачек Figma** (план 2026-10-25 в силе): бэклог iOS стартует, когда пачки Figma закончены.
    *(раунд 3)*
  - **Дефолты составителя (владелец — поправить при подтверждении):**
    - Р-10 Пуши — **APNs напрямую из Go** (ключ `.p8`, без Firebase): Android нет, Firebase лишний (меняет Р-26
      `идея-и-редизайн`). Токены устройств — новая таблица (миграция), по пользователю; viewer пушей не получает;
      каждый вид — переключатель в «Настройках», разрешение спрашиваем после первого полезного действия, не на старте.
    - Р-11 Вход Apple — **только в приложении** (на сайте — Google, как сейчас); привязка по почте, кроме relay-адреса
      Apple (как в B2C-38); удаление аккаунта уже есть — в приложении то же.
    - Р-12 «Поделиться выпиской» — файл из банка открывает приложение сразу на загрузке выписки «Недели» (тот же разбор,
      что `<input type=file>`); выбор из «Файлов» остаётся.
    - Р-13 Демо «Попробовать» — остаётся в приложении (вход для ревьюера Apple без аккаунта) + тестовый аккаунт в
      заметках ревью.
    - Р-14 «Быстрые команды» (траты касанием, пуши банков) — работают как сейчас, в 1.0 не трогаем.
- **Эскиз блоков:**
  0. **До старта (владелец):** Apple Developer на себя, MacBook Neo (проверка Xcode), выбор имени.
  1. **Оболочка** — Capacitor iOS, облачная сборка → TestFlight, живое обновление, safe-area/клавиатура/файлы/фото,
     нативный вход Google. *(без Mac — облако; первая подпись — на Neo)*
  2. **Вход Apple** — Go (`oidc` общий с Google, `appleauth`, миграция `apple_sub`) + кнопка в приложении.
  3. **Пуши** — Go: токены, APNs, рассылка «Платёж завтра» (cron) и «Партнёр сделал» (по событию); приложение:
     разрешение, переключатели, нажатие пуша открывает свой экран.
  4. **«Поделиться выпиской»** — Share Extension (Swift, на Neo).
  5. **Магазин** — имя, тексты, скриншоты, App Privacy, заметки ревью, ревью → выпуск 1.0 КЗ (отправка — по «да»).
  6. **Виджет 1.1** — после выпуска 1.0.
  Зависимости: 1 → (2 ∥ 3 ∥ 4) → 5 → 6. Серверные части 2 и 3 можно делать без Mac.
- **Режим процесса:** **L** — 2 (секрет, внешний API, миграция, вход), 3 (секрет APNs, внешний API, миграция, данные
  семьи наружу — суммы в пушах), 5 (релиз во внешний магазин); **M** — 1, 4, 6.
- **Отложено владельцем:** другие страны и имя — «потом посмотрим» (имя — выбор в Блоке 5); пуши «неделя / загрузите
  выписку» и «зарплата пришла» — не в 1.0 (кандидаты после выпуска).

**Подтверждение владельца:** 2026-11-01 — «Подтверждаю» (вместе с пятью дефолтами Р-10…Р-14). Дальше — `/backlog iOS` (по Р-9 — после пачек Figma).

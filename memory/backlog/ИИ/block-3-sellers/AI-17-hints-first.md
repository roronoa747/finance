## Задача

1. Порядок показа в `UnknownBatch`: группы с подсказкой (`hintOf(g)`) — первыми, между собой в пришедшем порядке (по
   сумме); остальные — после, в прежнем порядке. Нет подсказок (без ИИ, «Не надо», viewer, демо, «думает», лимит, ошибка,
   0 подсказок) — порядок как был. `unknownGroups` и `decisionQueue` не трогать — меняется только вид пачки.
2. «Ещё K · сумма» и «Выбрать все» — по новому порядку (хвост — всё, что не в первых шести).
3. Пришёл ответ — строки переставляются плавно: `move` у `TransitionGroup` (transform ~200 мс); `prefers-reduced-motion`
   — без анимации. Отметки (`picked`) — по ключу, перестановка их не сбрасывает.

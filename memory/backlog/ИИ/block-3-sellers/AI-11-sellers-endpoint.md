## Задача

1. `POST /api/ai/sellers` (`family`-группа, через гейт): тело `{names: string[] (1…50, каждое ≤ 80 символов,
   без дублей), categories: [{id, name}] (1…40)}` ≤ 16 КБ. Название с 6+ цифрами подряд → 400 (гвард на сервере
   повторяет фильтр телефона).
2. В модель — только список названий и список разделов + фиксированная инструкция: казахстанские продавцы и сервисы
   (Kaspi, Freedom); для каждого названия — id раздела **из присланного списка** или `null`, если не уверен; не
   придумывать разделы. Схема ответа `{items: [{name, categoryId: string|null}]}`.
3. Ответ 200 `{items: [{name, categoryId|null}]}` в порядке присланных `names`; `categoryId` вне присланного списка →
   `null`; название, которого не было во входе, — выбрасывается; отсутствующее — `null`.

## Тесты

- Фейковый Claude (`httptest`): тело исходящего запроса содержит только названия, названия/id разделов и инструкцию
  (нет id семьи, почты, сумм, дат); чужой id → `null`; лишнее название в ответе выброшено; порядок как во входе.
- Гвард: 6+ цифр → 400; > 50 названий → 400; пустой список → 400; > 16 КБ → 413.
- Гейт: viewer → 403, без флага → 503, лимит → 429; успех — `requests +1`; 502 модели — без списания.

  время ответа — в Handoff.

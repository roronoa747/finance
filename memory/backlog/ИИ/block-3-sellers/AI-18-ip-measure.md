## Задача

1. **Привычка по каждому ИП** (код, на телефонных данных): сколько покупок и средний чек (целые тенге, округлить до 100).
2. **Способ А — Claude без имени:** в запрос — только `[{id: "ip-1", count, avg}]` и разделы семьи `{id, name}`; без
   имени, города, дат, отдельных сумм. Инструкция: раздел по привычке или `null`, «лучше null, чем догадка». Haiku и
   для сравнения Opus, по 3 прогона. Код замера — временный (живой тест / программа в scratchpad), в прод-путь не
   вливать.
3. **Способ Б — правило кодом:** частота и средний чек → раздел (например, часто и по мелочи → «Продукты»), иначе без
   догадки; пороги записать.
4. **Эталон — владелец:** по каждому ИП — догадки А и Б рядом, владелец отмечает «верно / неверно / не знаю» (или свой
   раздел). Где отмечать — приватный артефакт без сумм и дат (имена ИП — только там и в `memory/secrets/`, не в git).
5. **Итог владельцу** (артефакт, без имён и сумм): по каждому способу — у скольких ИП есть догадка, сколько верных,
   сколько неверных (неверная хуже «не знаю»: человек может принять ✓ не глядя), время и ≈ $; рекомендация. Дальше —
   решение владельца: способ А (тогда Р-5 «без сумм» меняется, слова согласия — «Названия продавцов и средний чек»), Б
   или ничего; реализация — следующей задачей этого блока по его ответу.

## Задача

1. Гейт `aiGate` в `handlers/ai.go` (используют AI-11, AI-14): клиент есть и семья `Enabled` → иначе 503 `ai_off`;
   роль `member` → иначе 403; `LimitReached(Used(месяц), limit)` → 429 `ai_limit`. После успешного вызова —
   `AddUsage(семья, месяц, 1, in, out, CostMicros)`; ошибки модели → 502 `ai_failed` без списания.
2. `POST /api/ai/review` (`family`-группа): тело `{summary: object}` ≤ 32 КБ, в модель уходит **только** `summary` (как
   JSON-текст) + фиксированная системная инструкция (роль — семейный финансовый помощник; тон «мы», по-русски, коротко;
   без упрёков и сравнения участников; **не вычислять, не вводить новых чисел — только числа из сводки, как в ней
   записаны**; шаги — ссылкой на экран из списка). Схема ответа: `{good: string, risk: string, steps: [{text: string,
   screen: string|null}] (2–3)}`.
3. Проверка чисел `ai.CheckNumbers(answer, summary) (bad []string)`: из текстов ответа извлечь числа с учётом русского
   формата (пробелы/NBSP-разделители тысяч «220 000», «₸», «%», дробь через запятую «1,5», «тыс.»/«млн» → множитель);
   каждое должно встретиться среди чисел сводки (все целые и проценты, рекурсивно). **Не считаются**: 1–3 как счёт
   («2 шага», «первый»), номера месяцев/годы в датах, если месяц/год есть во входе. Допуск — точное совпадение после
   нормализации (никаких «±»). Брак → повтор с добавкой «в прошлом ответе были числа, которых нет во входе: …; используй
   только числа входа»; снова брак → 502 `ai_failed`.
4. Ответ 200: `{good, risk, steps: [{text, screen|null}]}`; экран вне белого списка → `null` (текст шага остаётся).
5. Ничего из тела и ответа не логируется; к телу модели сервер ничего не добавляет (ни id, ни почты, ни даты сервера).

## Тесты

- `CheckNumbers` (таблица): «220 000 ₸», «220000», «220 000» с NBSP, «33%», «1,5%», «1,2 млн» (при 1 200 000 во
  входе), «2 шага» — принимаются; «215 000» при отсутствии во входе — брак; дата «октябрь 2026» при `month: 2026-10` —
  не брак.
- Хендлер на фейковом Claude (`httptest`): тело исходящего запроса = инструкция + присланная сводка и **ничего сверх**;
  ответ с выдуманным числом → повтор (второй запрос содержит строгую добавку) → второй чистый → 200; два брака → 502 и
  `ai_usage` не изменился; успех → `requests +1`, токены обеих попыток; viewer → 403; семья без флага / без ключа → 503;
  лимит исчерпан → 429; тело > 32 КБ → 413; экран вне списка → `null`.

## Задача

1. Модель: `SyncDoc.aiReviews?: AiReview[]` — `{id, month, at (ISO), by (slot), good, risk, steps[{text, screen|null}],
   sent (сводка, ушедшая в модель), updatedAt, deletedAt?}`; слияние `mergeList(…, x => x.id)`; для месяца
   показывается последний по `at`. Хранить не больше 12 последних (старые — `deletedAt`).
2. Клиент `apiClient.aiReview(summary)`; ошибки → состояния: `ai_limit` — «ИИ вернётся 1-го»; `ai_failed` / сеть —
   «Не вышло. Попробуйте позже»; `ai_off` — обновить `me` (кнопка исчезнет).
3. Кнопка у остатка: рядом с «Хватит?» тихая `ghost sm` «Разобрать» (иконка + слово; финальное слово — `/ux`); для
   текущего месяца; видна, если `stores/ai.available` **или** (есть разбор месяца и `authStore.ai`) — viewer видит
   кнопку «Разбор», открывающую сохранённый, только если он есть. Точка на кнопке, если разбор есть и не открывался на
   этом устройстве (ключ устройства в `lib/storage`; добавить в `LOCAL_KEYS`, `stores/finance.ts:147`, — выход стирает).
4. Нажатие: разбор месяца есть → лист с ним, без запроса; нет → `ensureConsent()` → (да) запрос → сохранить в
   документ (`mutateHouseholdDoc`) → лист. Во время запроса — состояние «Думаю…» в листе (без блокировки экрана).
5. `components/ai/AiReviewSheet.vue` (`Sheet`): три блока — «Хорошо», «Риск», «Шаги» (шаг с `screen` — ссылка
   `router-link`, лист закрывается); внизу тихо: «Подсказка ИИ по цифрам приложения · что ушло» (раскрывает `sent`
   читаемым списком, не JSON) и «Обновить» (только member с `available`, только если последний разбор старше суток —
   иначе кнопки нет).
6. Viewer: только чтение; без `ensureConsent`, без «Обновить».

## Тесты

- `merge.test.ts`: разборы с двух телефонов по id; показывается последний по `at`; лишние сверх 12 → удалены.
- DOM `MonthPlan` / `AiReviewSheet` (фейковый клиент со счётчиком): без `ai` — кнопки нет; есть разбор — открывает
  без запроса (счётчик 0); нет разбора — согласие → запрос → разбор в `householdDoc.aiReviews`; «Не надо» — запроса
  нет; «Обновить» скрыто, если разбору < 24 ч; viewer — видит сохранённый, нет «Обновить» и запуска; 429 → «ИИ
  вернётся 1-го»; шаг со `screen` — ссылка, без — текст; «что ушло» показывает разделы сводки.
- Исходящий запрос (фейковый клиент): тело = `{summary}` из `buildMonthSummary`, без имён (поиск подстрок имён
  семьи).

## Критерии приёмки

- `cd frontend && npm run build && npx vitest run` зелёные.
- Браузер (стенд с ключом и Go с БД): 390 px обе темы — кнопка у остатка не ломает кольцо и «Хватит?» (одна высота,
  ровно); разбор по кнопке → партнёр (второй телефон) после синка видит тот же текст без запроса (Network); viewer —
  только чтение; повторного запроса при открытии нет; ссылки шагов ведут на экраны.
- Handoff по правилу 12: главное действие («Разобрать») — у остатка; что в подсказке; что скрыто («что ушло»).

# Бриф «ИИ»

## Контекст

Семейные финансы (Go + Vue 3, прод `family-finance-ff.vercel.app`, регион `icn1` — Сеул). Бэклог «первый запуск» закрыт
2026-10-15; по порядку `memory/decisions/order-2026-10-12-launch.md` дальше шёл Google Play (Блок 7 Android
`идея-и-редизайн`). Владелец 2026-10-15: **«Давай сначала сделаем ИИ»**.

Что уже есть и решено раньше:

- Владелец 2026-10-08 (бриф «мелочи»): ИИ — отдельным брифом, шире разбора ИП (в том числе **анализ бюджета**); тариф
  **платный, без обучения на данных**; **по умолчанию выключен** — включает владелец из админки (подписки нет).
- Образцы, не план: архив `развитие-приложения` RP-26…28 (Р-25…Р-28 — разбор бюджета кнопкой «Разобрать», модель получает
  цифры `finance.ts` и сама не считает, число в ответе, которого нет во входе, — брак; имена → «участник 1/2», заметки и
  личный документ не уходят; разбор сохраняется в общий документ, тон «мы»); `идея-и-редизайн` Блок 6 (B2C-31/32 —
  Gemini бесплатно, «спросить ИИ» про незнакомых продавцов, отменён 2026-10-03), RP-18/19 (желание со скриншота).
- Приватность выписок (Р-4, Р-5 `идея-и-редизайн`): выписка разбирается на телефоне, операции личные (партнёр их не
  видит), в общий документ идут итоги по разделам (`spendTotals`).
- Админка `/admin` (B2C-28): только общие цифры по `ADMIN_EMAILS`, списка семей и флагов нет; `/auth/me` отдаёт `admin`.
  События — 5 видов (`CHECK kind`, миграция `000006`). Политика (`Privacy.vue`) упоминает Gemini — «сейчас выключено».
- Ключа ни одного ИИ-провайдера нет; секреты — `memory/secrets/` и env (инвариант 11).

## Что хочется получить и зачем

ИИ, который помогает дойти до мечты: разбирает месяц семьи и говорит, что хорошо, где риск и что сделать; снимает ручной
разбор незнакомых продавцов; превращает скриншот товара в желание с фото и ценой.

## Резюме бриф-интервью

3 раунда, 2026-10-15.

- **Цель одной строкой:** включённым владельцем семьям ИИ (Claude) разбирает месяц, предлагает разделы незнакомым
  продавцам и делает желание из скриншота — данные уходят минимальные и с одним понятным согласием.
- **Скоуп:** фундамент (Go-клиент Claude, флаг ИИ у семьи, лимит, расход, админка со списком семей); разбор месяца;
  предложения разделов для незнакомых продавцов; желание из скриншота; согласие; политика; демо-пример.
  **Не-скоуп:** чат и свободные вопросы («Можно купить?»); автоприменение предложений; подписка и оплата; ИИ у семей без
  флага. **После MVP:** вопрос «Можно купить?» текстом; «Поделиться» скриншотом из галереи (Android, после Блока 7);
  разбор «сам раз в месяц»; лимит на каждую семью в админке.
- **Решения (кандидаты в Р-*):**
  - Р-1. **Три функции в MVP:** разбор месяца, незнакомые продавцы, желание со скриншота. *(ответ владельца, раунд 1)*
  - Р-2. **Провайдер — Claude (Anthropic API), платный тариф** (не обучается на данных); вызов только из Go, ключ —
    env `ANTHROPIC_API_KEY` (значение — `memory/secrets/`), модель — переменная env по функции (лёгкая модель для продавцов,
    сильная — для разбора и скриншота; конкретные id — в бэклоге по актуальной документации). Без ключа ИИ выключен
    везде. Доступность API из `icn1` и лимит времени функции Vercel проверить в первом блоке, не по памяти. *(ответ
    владельца, раунд 1; env, модели и проверка — дефолт)*
  - Р-3. **Разбору месяца уходит сводка + траты по разделам:** цифры месяца, посчитанные `finance.ts` (доход, платежи,
    остаток, долги со ставками, цели с прогрессом и сроками), итоги трат по разделам; имена → «участник 1/2»; без
    заметок, без операций и продавцов, без личного документа. Модель денег не считает; число в ответе, которого нет во
    входе, — брак ответа (проверка в Go). *(ответ владельца, раунд 1; запрет счёта и проверка — дефолт по Р-25 RP)*
  - Р-4. **Разбор месяца — небольшой кнопкой на «Месяце» у остатка** (рядом с «Хватит?», правило 12) → лист: что
    хорошо, где риск, 2–3 шага со ссылками на экраны, тон «мы», без упрёков и сравнения участников. Ответ сохраняется в
    общий документ — партнёр видит тот же текст; «Обновить» — не чаще раза в день. *(ответ владельца, раунд 2; содержание
    и тон — дефолт по Р-25/Р-27 RP)*
  - Р-5. **Незнакомые продавцы — ИИ сам предлагает:** после загрузки выписки в пачке «Без раздела» у каждого продавца
    стоит предложение раздела; человек принимает одним нажатием или меняет; автоматически ничего не применяется.
    Уходят только названия продавцов и названия разделов (без сумм, дат, ФИО; название с 6+ цифрами не уходит). Принятое
    — то же правило «продавец → раздел» в личном документе, как ручной ответ. *(ответ владельца, раунд 3; состав
    запроса — дефолт по B2C-31)*
  - Р-6. **Желание из скриншота:** «+» → «Желание» → тихая кнопка «Из скриншота» → картинка из фото уходит в Claude через
    Go (на сервере не хранится) → предзаполнены название, цена и фото товара (вырез по рамке, которую вернула модель;
    не вышло — весь скриншот) → человек проверяет и сохраняет. *(ответ владельца, раунд 2; вырез и хранение — дефолт)*
  - Р-7. **ИИ включается семье** в админке: список семей (почты участников, включён ли ИИ, запросов и ≈ $ за месяц) с
    переключателем; флаг — в базе (миграция). Участники семьи с флагом — все функции; viewer видит сохранённый разбор,
    кнопок ИИ нет. *(ответ владельца, раунд 2; viewer — дефолт)*
  - Р-8. **Лимит — один на все семьи, env** (старт 30 запросов в месяц: разборы + пачки продавцов + скриншоты), счётчик
    на сервере; кончился — спокойное «ИИ вернётся 1-го». Расход по семьям — в админке; общий потолок — владелец ставит в
    консоли Anthropic. *(ответ владельца, раунды 2–3; 30 и месяц по Алматы — дефолт)*
  - Р-9. **Согласие — один раз на человека:** при первом использовании лист «что уходит» (цифры месяца без имён,
    названия продавцов, скриншот), куда (Anthropic), «не обучается на ваших данных» → «Включить» / «Не надо»; выключить —
    в настройках; у разбора — ссылка «что ушло». Согласие хранится в личном документе (общее для устройств человека).
    *(ответ владельца, раунд 3; хранение — дефолт)*
  - Р-10. **Без флага — ИИ не видно совсем; демо — пример:** в демо «Разобрать» показывает заранее написанный разбор
    демо-семьи без запроса; предложения продавцов и скриншот в демо — нет. *(ответ владельца, раунд 3; демо только для
    разбора — дефолт)*
  - Р-11. **Политика конфиденциальности** — строка про Gemini заменяется на Claude (Anthropic): что уходит, при каком
    условии, без обучения. *(дефолт)*
  - Р-12. **Запуск в Google Play — после ИИ, без спешки** (владелец, раунд 1); `order-2026-10-12-launch.md` дополняется
    записью: ИИ → Android (Блок 7) → дальше по порядку. *(ответ владельца, раунд 1)*
- **Эскиз блоков:**
  1. **Фундамент** — Go-клиент Claude (проверка региона и времени функции), миграция: флаг семьи и счётчик запросов;
     `/auth/me` → `ai`; админка: список семей, переключатель, расход; лимит; согласие и настройки; политика.
  2. **Разбор месяца** — сводка (рядом с `finance.ts`, сама не считает), ручка, проверка чисел, лист на «Месяце»,
     сохранение в общий документ, демо-пример. Зависит от 1.
  3. **Незнакомые продавцы** — ручка пачкой, предложения в «Без раздела», принять / сменить. Зависит от 1.
  4. **Желание из скриншота** — ручка с картинкой, вырез на телефоне, форма желания. Зависит от 1.
  Порядок 1 → 2 → 3 → 4, на прод после каждого блока; затем Блок 7 Android `идея-и-редизайн`.
- **Режим процесса:** **L** — Блок 1 (секрет, внешняя интеграция, миграция, данные уходят третьей стороне; ревью —
  `backend`, `frontend`); **M с `/ux`** — Блоки 2, 3, 4 (Блок 2 — по решению составителя может стать L: финансовые
  данные уходят наружу). Миграцию на прод запускает владелец по готовой команде (память агента).
- **Критерии готовности:** у семьи владельца ИИ включён из админки; разбор настоящего месяца — по делу, все числа текста
  совпадают с экраном (проверка), партнёр видит тот же разбор; на настоящей выписке предложения у продавцов «Без раздела»,
  принятие — одно нажатие; скриншот товара → желание с фото и ценой; семья без флага ИИ не видит; в админке видны запросы
  и ≈ $; согласие спрошено один раз.
- **Отложено владельцем:** — (всё ясно; «после MVP» — выше).

**Подтверждение владельца:** 2026-10-15, «подтверждаю» (без правок).

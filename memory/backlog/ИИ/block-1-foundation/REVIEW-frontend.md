## Проверено независимо (не по Handoff-у)

- **Один лист в оболочке:** grep `AiConsentSheet|ensureConsent|sheetMounted` — лист монтируется только в
  `AppShell.vue:202`; вне оболочки (`/start`, `/who`, `/privacy` — соседи `/` в `router/index.ts:63-88`) `ensureConsent`
  → `false` (`sheetMounted`). Пачка «Без раздела» (Блок 3) живёт только на «Неделе» (`Week.vue:464`, внутри оболочки) —
  то, что первый запуск вне оболочки, продавцам ИИ не мешает. Выход размонтирует оболочку → `onUnmounted` отвечает
  ждущему «нет» (`AiConsentSheet.vue:21-24`); при пересоздании оболочки Vue зовёт `unmounted` старой раньше `mounted`
  новой — флаг не падает.
- **Слияние `aiConsent`** (`lib/merge.ts:250-262`): `newerObject` по полю `at` — коммутативно (тест в обе стороны); ключ
  исключён из `mergeUnknownKeys`, даже когда согласия нет ни с одной стороны (`{ ...known, aiConsent: null }`), — «не
  спрошено» не превращается в `null`. Мимо `mergePrivateDocs` личный документ не пишется: pull / 409 / досылка —
  `stores/finance.ts:663, 713`, сброс при смене семьи — `:374`.
- **Контракт с Go:** `AiCheck.reason` = `no_key | failed | rate_limited | refused` — ровно то, что отдаёт `checkReason`
  (`backend/internal/handlers/admin_ai.go:110, 133-142`); `CHECK_REASONS` — `Record` по этому объединению: новая причина
  без строки на фронте не соберётся. Поля `AdminFamily` — как в ответе ручки.
- **Кит и токены:** админка — `Card`, `Hint`, `Toggle`, `Toast` + `useFlash` (тот же паттерн, что `TripCard`, `Week`),
  `Button ghost sm`; цвета — `text-warn` / `text-ink-2` / `bg-surface-2` / `text-brand` / `border-line`, у `--warn` есть
  тёмная пара (`style.css:42, 107`); сырых цветов в диффе нет. Тумблеры брендовые — на обоих экранах брендовой главной
  кнопки нет, правило `tone="ok"` (`Toggle.vue`) не нарушено.
- **Дубли с прошлыми блоками:** второго «листа-обещания» (`Promise` из листа) в коде нет — `ensureConsent` первый такой;
  `useFlash` переиспользован, а не скопирован; e2e — на общих `fakePrivate` / `privateFor` / `phone` / `screen`
  (`e2e/support/family.ts`). Локальные `mount` / `settle` в двух новых DOM-тестах — как в остальных 12 DOM-тестах

- **Деньги:** `usdFromMicros` — целые микродоллары → центы целочисленно (`Math.floor((micros + 9_999) / 10_000)`), float

## Находки

### Н-1 · средняя · Политика не говорит, сколько Anthropic хранит запросы и что они уходят из «Сеула»

`frontend/src/views/Privacy.vue:49-63, 82-88`. Блок заменил строку про Gemini (Р-11 выполнен как записан): что уходит,
при каком условии, «не обучается». Рядом осталось неполным: (1) «Где хранится» — «оба размещены в регионе Сеул», а цифры
месяца, продавцы и скриншоты будут обрабатываться у Anthropic; (2) Anthropic по умолчанию хранит данные API **30 дней**
(источник — Handoff AI-01, privacy.claude.com) — в политике об этом ни слова; (3) «Что храним» не называет новое на
нашем сервере — согласие человека (со временем ответа) и счётчики ИИ семьи (запросы, ≈ $). Лист согласия ведёт сюда
ссылкой «Подробнее» — это и есть место, где человек узнаёт, на что соглашается. В Блоке 1 наружу уходит только «Связь
есть?» админа; первые данные семьи — разбор Блока 2.

**Рекомендация.** Одно-два предложения в «Кому передаём» и в английской сводке: Anthropic хранит запросы до 30 дней и
удаляет; где обрабатывает — сверить по живой документации Anthropic при правке, не по памяти. В «Что храним» — пункт
«Согласие на ИИ-помощника и число его запросов в месяц». Слова — владельцу артефактом «до | после».

**Вердикт: хвост §4** — новые слова юридического текста утверждает владелец, это не правка кода. Предложение судьбы:
Блок 2, в AI-10 (доки) — до деплоя первого разбора; у AI-16 «сверка `Privacy.vue`» уже есть, у AI-10 — нет.

### Н-4 · низкая · Новый телефон до первого синка — лист согласия спросит второй раз

`frontend/src/stores/ai.ts:19-22, 38-46`. `consent` читает личный документ как есть: на новом телефоне (или офлайн) до
первого `pullPrivateDoc` там пусто → `'unknown'` → лист, хотя человек уже ответил на другом телефоне; «Не надо» с поздним
`at` перепишет его «да» на всех телефонах. Критерий брифа — «согласие спрошено один раз». Окно узкое: движок тянет
личный документ на старте и при фокусе (`stores/syncEngine.ts:45-48`), а без сети ИИ не работает. Сейчас `ensureConsent`
никто не зовёт — проявится с первой кнопкой (AI-09 п. 4: «нет разбора → `ensureConsent()` → запрос», про сеть и синк —
ни слова).

**Рекомендация.** Одно место на Блоки 2–4 — `ensureConsent`: при `'unknown'` сначала `await finance.pullPrivateDoc()`
(при сети, не в демо) и перепроверить, лист — только если и после этого «не спрошено»; без сети — `false` без листа.
e2e: согласие на телефоне 1, телефон 2 без синка → `ensureConsent` → `true`, листа нет.

**Вердикт: хвост §4** — без вызывающего проверить нечем (кнопки ИИ появятся в AI-09), а асинхронная правка
`pending` / `answer` — не мелочь клинапа. Предложение судьбы: Блок 2, в AI-09 (первый вызов `ensureConsent`), рядом с
хвостом «флаг ИИ при старте».

### Н-5 · низкая · `usdFromMicros` — в модуле «целых тенге без центов», ветка «$0» после `/ux` недостижима

`frontend/src/lib/money.ts:1-7, 53-61`, `views/Admin.vue:86-90`. Шапка модуля — «суммы… целые единицы валюты, без
центов (Р-70)», а функция печатает центы; единственный вызывающий (`spent`) после `/ux` сам обрабатывает ноль («0
запросов» / «≈ —»), так что `micros <= 0 → '$0'` срабатывает только в юнит-тесте. Логика «≈» поделена между двумя
файлами.

**Рекомендация.** Нет.

**Вердикт: не делаем** — комментарий функции прямо говорит, что это цена запросов для владельца, не деньги семьи; ветка
нуля — дешёвая защита и покрыта тестом; перенос в `Admin.vue` — перестановка без выигрыша.

- Р-7: список семей (почты, ИИ вкл/выкл, запросов и ≈ $ за месяц) с переключателем. Р-8: лимит — одно значение на
  все семьи: показать один раз (подсказка шапки), у семьи — только число запросов.
- `views/Admin.vue` (маршрут `admin`, `router/index.ts:125`): зовёт `apiClient.adminMetrics()` → `GET
  /api/admin/metrics` (`api/client.ts:163`, тип `AdminMetrics` :311-320); 404 → «Нет такой страницы»; показывает
  удержание, итоги, воронку 28 дней, таблицу недель; только чтение. Ошибки — локальный `state`/`error` + строка
  `role="alert"` (`Admin.vue:14-21`). Вход — ссылка «Цифры» в настройках при `authStore.admin` (`Settings.vue:139-141`).
- Ручки AI-03: `GET /api/admin/families` → `{families: [...], limit, key}` (поля строки — `id, created_at, emails,
  ai, month, requests, cost_micros`), `PUT /api/admin/families/{id}/ai` `{on}`, `POST /api/admin/ai-check`.
- Кит (§6): `kit/Toggle.vue`, `kit/Hint.vue`, кнопки `ui/Button.vue`. Правило 12 CLAUDE.md: одно главное действие,
  текста минимум, нет шумных цифр, сложное свёрнуто.

## Задача

1. Клиент: методы `adminFamilies()`, `setFamilyAi(id, on)`, `aiCheck()` + типы в `types/api.ts`.
2. `lib/money.ts`: `usdFromMicros(micros: number): string` — «≈ $0.42» (2 знака, округление вверх до цента, 0 →
   «$0»). Это форматирование расхода сервиса, не деньги семьи (`finance.ts` не трогаем).
3. `Admin.vue` — раздел «Семьи» **над** метриками: строка семьи — почты (через « · », длинные обрезаются), справа
   `Toggle` ИИ; под почтами одной тихой строкой — «N запросов · ≈ $X» только у семей с ИИ или с расходом за месяц.
   Переключение — сразу `PUT`, на время запроса тумблер неактивен, ошибка — тумблер возвращается + строка `alert`.
   Шапка раздела: «Семьи» + `Hint` (лимит `limit` запросов в месяц на семью; потолок денег — в консоли Anthropic).
   Нет ключа (`key: false`) — одна строка-предупреждение «Ключ не задан — ИИ выключен везде».
4. Тихая кнопка «Проверить связь» (`ghost sm`) в шапке раздела → `aiCheck()` → тост «Связь есть · N мс» /
   «Нет связи» (причина в `Hint`, не в тексте).
5. Метрики ниже — как были (не переделывать).

## Тесты

- DOM (`Admin.dom.test.ts`, фейковый `apiClient`): список рисует почты и тумблеры; включённая семья сверху как пришла;
  клик по тумблеру зовёт `setFamilyAi(id, true)`, ошибка возвращает тумблер и показывает `alert`; `key:false` —
  предупреждение; «Проверить связь» → тост; 404 → «Нет такой страницы» (как было).
- `usdFromMicros`: 0 → «$0», 1 → «≈ $0.01», 420 000 → «≈ $0.42», 6 000 000 → «≈ $6.00».

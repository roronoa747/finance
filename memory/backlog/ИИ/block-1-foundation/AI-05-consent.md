## Задача

1. Ключ личного документа `aiConsent: {on: boolean, at: string /* ISO */}`; правило слияния — `newerObject` по `at`
   в известных ключах личного документа (`merge.ts`). Нет ключа = не спрошено.
2. Модуль `stores/ai.ts` (Pinia, маленький): `available` = `authStore.ai && !authStore.isViewer && !authStore.isDemo`;
   `consent` (`'unknown' | 'on' | 'off'` из `privateDoc.aiConsent`); `setConsent(on)` — пишет в личный документ;
   `ensureConsent(): Promise<boolean>` — `on` → `true`; `off` → `false` без листа; `unknown` → открывает лист и ждёт
   ответа. Лист монтируется один раз в оболочке (`AppShell`) и управляется стором.
3. `components/ai/AiConsentSheet.vue`: заголовок «ИИ-помощник» (финальные слова — владелец на `/ux`), три короткие
   строки с иконками: «Цифры месяца — без имён» · «Названия продавцов» · «Скриншот товара»; строка «Уходит в Anthropic
   (Claude). Не обучается на ваших данных» + ссылка «Подробнее» → `/privacy`; кнопки «Включить» (главная) и «Не надо»
   (`ghost`). Закрытие свайпом = «Не надо» на этот раз (согласие остаётся `unknown`).
4. Настройки: карточка «ИИ» после «Разбора трат» — только при `available`; `Toggle` «Помощник» ↔ `aiConsent.on`
   (включение из настроек — без листа: человек уже здесь видит, что уходит, — одна строка под тумблером «Без имён ·
   Anthropic» + `Hint` с тремя пунктами листа).
5. `Privacy.vue`: строка про Gemini → «ИИ-помощник (Claude, Anthropic) — только если его включили семье и вы дали
   согласие: уходят цифры месяца без имён и заметок, названия продавцов без сумм, скриншот товара; на ваших данных не
   обучается.»; английская сводка — одной строкой то же; `UPDATED` — дата коммита. Текст — в тоне соседних строк.

## Тесты

- `merge.test.ts`: `aiConsent` с двух устройств — побеждает более позднее `at`.
- `stores/ai`: `available` ложно для viewer, демо и без `ai`; `ensureConsent` при `on` не открывает лист, при `off`
  → `false` без листа, при `unknown` открывает и резолвится по кнопке («Включить» → `true` + запись `on`; «Не надо» →
  `false` + запись `off`; свайп → `false` без записи).
- DOM: карточка «ИИ» в настройках только при `available`; тумблер пишет `aiConsent`; лист — три пункта и ссылка на
  `/privacy`.
- `Privacy.test.ts`: нет «Gemini», есть «Anthropic» и «не обучается».

## Критерии приёмки

- `cd frontend && npm run build && npx vitest run` зелёные.
- Браузер (стенд, член семьи с ИИ): настройки — карточка и тумблер (перезагрузка держит; второй телефон того же
  человека после синка видит то же); семья без ИИ и viewer — карточки нет; лист согласия вызывается из консоли
  стенда (`ensureConsent`) — 390 px обе темы.
- Handoff по правилу 12 (лист и карточка: главное действие, подсказка, скрытое).

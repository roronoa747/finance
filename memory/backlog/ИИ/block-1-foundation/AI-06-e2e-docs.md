## Задача

1. `e2e/ai-block1-foundation.test.ts` (фейковый `/auth/me` с `ai`, фейковые ручки админки):
   - семья без `ai` — нигде нет ни карточки «ИИ», ни листа согласия;
   - член семьи с `ai` включает тумблер на телефоне 1 → после синка личного документа телефон 2 **того же человека**
     видит «вкл»; партнёр (другой человек) — своё согласие `unknown`;
   - viewer семьи с `ai` — карточки нет;
   - админ: список семей → включить ИИ семье → `PUT` ушёл с `{on:true}`.
2. Доки: DESIGN.md — строки карты экранов `/settings` (карточка «ИИ») и `/admin` (раздел «Семьи»), §6 — тексты листа
   согласия и карточки (как утвердит `/ux`); `backend/README.md` — раздел «ИИ»: ручки админки, таблица `ai_usage`,
   что не логируется (Р-15), гонка лимита (AI-02).
3. Шаги владельцу (в Handoff и промпт клинапа): ключ в `memory/secrets/anthropic.md` и в env Vercel
   (`ANTHROPIC_API_KEY`, Production), потолок расхода в консоли Anthropic, прод-миграция `000007` (команда — клинап).

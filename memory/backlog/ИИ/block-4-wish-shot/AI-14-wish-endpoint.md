# AI-14 — Ручка скриншота товара (бэкенд, зрение)

Блок 4 · MVP · Каталог: `backend/internal/handlers/ai.go`, `backend/server/server.go` · Зависит от: Блок 3 🏁 · Роли: member

## Контекст (что уже есть)

- Р-6: картинка из фото уходит в Claude через Go, **на сервере не хранится**; ответ — название, цена и рамка товара
  (вырез делает телефон). Р-13: модель `Config.AIModelWish` (`claude-opus-5-5`, зрение), effort `low`. Р-14: один
  скриншот = один запрос лимита. Р-15: ни картинка, ни ответ не логируются. Деньги — целые тенге; модель цену **не
  пересчитывает** (не тенге → `null`).
- Гейт `aiGate` — `handlers/ai.go` (AI-08); клиент умеет одну картинку base64 + media type (AI-01). Изображение:
  блок `image`, `source.type: base64`; длинная сторона до 2576 px (телефон присылает ≤ 1568 px — дешевле).
- Ближайший образец «JSON с картинкой, member, ничего не хранить» — `POST /api/photos/preview`
  (`handlers/preview.go:36-55`, ответ с base64). Проверка типа по магическим байтам — `handlers/photos.go:33-40`
  (там webp/jpeg). Потолок тела Vercel ≈ 4.5 МБ.

## Задача

1. `POST /api/ai/wish` (`family`-группа, через гейт): тело `{image: string (base64), type: 'image/jpeg'|'image/webp'|
   'image/png'}` ≤ 3 МБ; base64 декодируется, тип сверяется по магическим байтам (+ png), иначе 400; картинку не
   сохранять никуда.
2. В модель — картинка + фиксированная инструкция: это скриншот карточки товара из магазина (Kaspi, Wildberries,
   Ozon…); найти один главный товар; название — коротко, по-русски, без бренда-мусора и артикулов; цена — **только если
   она в тенге** (₸, тг, KZT), целым числом как написано (без пересчёта, без копеек), иначе `null`; рамка фото товара в
   **долях** картинки `{x, y, w, h}` (0…1) или `null`. Схема ответа `{title: string|null, price: integer|null,
   box: {x, y, w, h}|null}`.
3. Ответ 200 `{title, price, box}`; рамка проверяется (числа в 0…1, `w, h ≥ 0.1`, не выходит за край — иначе `null`);
   `price` ≤ 0 или > 1 000 000 000 → `null`; `title` обрезается до 80 символов.

## Тесты

- Фейковый Claude (`httptest`): исходящий запрос — инструкция + один блок `image` с присланным base64 и типом, больше
  ничего; ответ разобран; рамка вне 0…1 → `null`; цена 0 → `null`; длинное название обрезано.
- Гвард: не картинка (магические байты) → 400; тип вне списка → 400; > 3 МБ → 413; пустое → 400.
- Гейт: viewer → 403, без флага → 503, лимит → 429; 502 модели — без списания; успех — `requests +1`.

## Критерии приёмки

- `cd backend && go build ./... && go vet ./... && go test ./...` + корень `go test ./api/...` зелёные; CI.
- Живой вызов с ключом на 3 скриншотах (Kaspi с ценой в ₸, маркетплейс в ₽, картинка без цены): название, цена / `null`,
  разумная рамка; время ответа — в Handoff.

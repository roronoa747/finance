## Задача

1. «+» → «Покупка в список желаний» ведёт на `/wishes?new=1` — лист «Новое желание» открывается сразу
   (`useQuerySheet('new')`; закрытие убирает параметр). Остальные входы — как были.
2. `lib/photos/crop.ts`: `cropToBox(blob, box): Promise<Blob>` — `createImageBitmap` → холст под-прямоугольника (доли →
   пиксели, округление внутрь) → blob; итог меньше `bigEnough` → вернуть исходный скриншот. `downscaleForAi(blob):
   Promise<{base64, type}>` — длинная сторона ≤ 1568 px, jpeg ~0.85 (на базе `fitSize` из `compress.ts`, без
   дублирования).
3. В листе «Новое желание» (только `stores/ai.available`): тихая кнопка «Из скриншота» (`ghost sm`, рядом с
   `PhotoSlot`) → выбор картинки → `ensureConsent()` → `downscaleForAi` → `apiClient.aiWish(...)` → предзаполнить:
   «Что покупаем» (если пусто или автозаполнено), «Цена» (если пусто), фото = `cropToBox(исходник, box)` или весь
   скриншот (`box: null`) — как `wishFile` (превью в `PhotoSlot`, сохранение — прежний `createWish`). На время запроса
   — «Смотрю…» на кнопке; ошибка — тост «Не разобрал. Заполните сами» (скриншот всё равно ставится фото); `ai_limit` —
   «ИИ вернётся 1-го». Ничего не сохраняется без «Сохранить».
4. Viewer и демо — кнопки нет.

## Тесты

- `cropToBox` (happy-dom/канвас-заглушка как в тестах `compress.ts`): доли → пиксели; рамка у края не выходит за
  картинку; маленький вырез → исходник. `downscaleForAi`: 3000×2000 → 1568×1045.
- DOM `Wishes` (фейковый клиент): `/wishes?new=1` открывает лист; без `ai` / viewer / демо — кнопки нет; ответ с
  названием и ценой заполняет пустые поля, не трогает введённое руками; `box` → фото-вырез, `null` → весь скриншот;
  502 → тост, фото = скриншот; «Не надо» в согласии — запроса нет; сохранение идёт прежним `createWish` (цена —
  целое через `parseMoney`).

## Критерии приёмки

- `cd frontend && npm run build && npx vitest run` зелёные.
- Браузер (стенд с ключом): «+» → «Покупка в список желаний» → форма сразу; «Из скриншота» на 3 настоящих скриншотах
  (Kaspi ₸, маркетплейс ₽ — цена пустая, без цены) → название, цена, вырез товара → «Сохранить» → желание с фото и ценой

## Задача

1. **Даты и бюджет:** `GoalNew.vue` для `template.type === 'travel'` (включая направления) — в шаге `form` ниже суммы
   два поля «Когда» (`from`, `to`; необязательные) и «Бюджет поездки, ₸» (`Hint` «Сколько планируете потратить в
   поездке; пусто — как сумма мечты»); `create()` → `setTripDates` после `addGoal`. `GoalSheet.vue` — те же поля у
   цели-путешествия или у любой с датами. Проверка формы: `to ≥ from`.
2. **До поездки** (`before`/`none`): экран как обычно; у цели с датами в «Подробнее» строка «Поездка {from}–{to}»
   (`dayWeekdayLabel`/`weekRangeLabel` из `lib/dates.ts`).
3. **В поездке и после** (`during`/`after`): `GoalDetail` — под героем карточка `data-trip` : заголовок «Потрачено
   {total} из {budget}» (`during`) / «За поездку — {total} из {budget}» (`after`), `ProgressBar` (`warn`, если
   `total > budget`), строка `--ink-2` «{Вы} {amount} · {Партнёр} {amount}» (`tripSpent.byPerson`, только у кого > 0);
   ниже свёрнутое «Операции · N» (`aria-expanded`) → свои `tripOps` строками `OpRow` (дата, продавец, сумма); у
   строки тихое «Убрать» (`data-trip-exclude`) → `excludeFromTrip`, строка уходит в свёрнутое «Убрано · N» внизу с
   «Вернуть». Партнёр видит свою сумму и общий итог, чужих строк нет (Р-5). Viewer — карточку и итог без действий.
   Карточка срока и «Пополнить» в поездке остаются (копить можно); «Сбылось» (Блок 4) — как у любой мечты.
4. «Мечты»: герой-поездка в `during` — строка под процентом «потрачено N из M» вместо «ближе на N дней» (одна строка).
5. `DESIGN.md` — экран цели: абзац «Поездка».

## Критерии приёмки

- Критерий брифа: поездка показывает «потрачено N из M» по выписке; лишнее убирается нажатием. `cd frontend && npm
  run build && npx vitest run` зелёные; стенд с Go и выпиской (фикстуры `lib/statements/fixtures` или
  `secrets/statements`): операции за даты поездки, «Убрать», второй телефон — общий итог.

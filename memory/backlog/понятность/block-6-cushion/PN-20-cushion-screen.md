## Задача

1. `GoalDetail.vue` для `fundKind === 'cushion'`: карточка срока → заголовок «Хватит на {months} {месяца}»
   (`data-cushion-cover`; `months` null → «Пока не на что считать» — нет платежей и трат плана); строка под ним
   «нужно {monthsNeeded} {месяца} · {money(need)}» (`--ink-2`); «Пополнить» как есть; при `have ≥ need` — заголовок
   «Хватит на {months} {месяца} ✓» (`--ok`), строки «Собрано» нет (число говорит само). Герой — строка «{have} из
   {need}» как есть. «Соберём в …» для подушки больше не показывается (срок — в «Подробнее» строкой `leftLine`).
   Viewer видит то же.
2. «Подробнее» подушки: поле «Месяцев трат» остаётся (поправимо), подпись-подсказка `Hint` «Нужно = месяцы × (платежи +
   траты по плану)»; «Чтобы успеть за год» и «дорожает» у фонда не показывать (уже так — проверить).
3. `MonthPlan.vue` строка фонда «Подушка» в «Цели и фонды»: подпись `--ink-2` «хватит на {months} мес.» вместо
   процента/суммы, если место позволяет (та же функция); нет — оставить как есть и записать в Handoff для `/ux`.
4. `DESIGN.md` — экран цели: абзац «Подушка».

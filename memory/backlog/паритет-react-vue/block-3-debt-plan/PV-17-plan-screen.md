## Задача

1. **«План и факт по месяцам»** — таблица `planMonths`: месяц · план · факт (сумма досрочек с
   `planId`) · долг-цель; текущий месяц выделен; пропуски без упрёка.
2. **«Что не ушло в цели»** — по каждой цели на паузе: «{name}: {money(monthly × месяцев паузы)}
   не внесено, дата сдвинулась на {N} мес.» (N = месяцев паузы; расчёт — `finance.ts`
   `pauseShift(plan, goal, key)`); подушка — «взносы продолжаются».
3. **«Выигрыш»** — три строки: «При выборе ожидали: не отдадим банку {forecast.savedInterest},
   без процентных долгов через {debtFreeMonth}» · «Сейчас (от факта): …» (`planForecast`) ·
   «Уже сэкономили: {planFact.savedInterest}».
4. **«График платежей»** долга-цели — `creditSchedule` с `extra` = будущие шаги плана
   (месяц → сумма шага, пока долг не закроется; строится `planSchedule(plan, state, key)` в
   `finance.ts`); свёрнут по умолчанию.
5. **«История планов»** — завершённые и отменённые (`status !== 'active'`): «{monthTitle
   старта} — {monthTitle конца}: сэкономили {result.savedInterest} ₸ процентов» / «отменён,
   сэкономили N». Активного нет и история есть — экран показывает историю + ссылку на
   калькулятор.
6. Завершение (Р-5): `settlePlan` из PV-14 переводит в `done`; экран показывает Callout
   «Долги с процентами закрыты — цели возобновились. Сэкономили N ₸ процентов.» пока план
   последний в истории и закрыт в текущем месяце.
7. Viewer — без «Отменить план».

## Тесты

- `lib/finance.test.ts`: `pauseShift` — цель на паузе 3 месяца → 3; `planSchedule` — шаги до
  закрытия, Σ `extra` + платежи закрывают долг; после закрытия цели — следующий долг.
- `views/DebtPlan.test.ts` (SSR): фикстура с планом, двумя досрочками и одной паузой: таблица
  месяцев с фактом, «не внесено» = `monthly × 2`, три строки выигрыша (числа = функции),
  график с «по плану»; план `done` — Callout завершения и строка истории; viewer — без кнопки.
- e2e (файл блока): досрочка на весь остаток последнего долга → у обоих план `done`, цели без
  тега паузы, история с итогом.

## Критерии приёмки

- Браузер, два профиля: экран плана показывает месяцы, паузы, выигрыш и график; закрыть
  единственный долг досрочкой → план в истории с «сэкономили», цели возобновились у обоих;
  отмена — история осталась.
- `cd frontend && npm run build && npm test` зелёные.

## Задача

1. **Выбор в `StrategyCompare`** (нет активного плана, `redirected > 0`): блок «Выбрать этот
   план»: «Подушка — какая цель?» (радио по живым целям + «без подушки»; целей нет → Callout
   «Заведите цель-подушку — план начнёт с неё» со ссылкой на `/goals`), кнопка «Выбрать этот
   план» (только member) → `choosePlan({ keptGoalIds: kept, cushionGoalId, months, lump: useSaved
   ? lump : 0 }, by)` → переход на `/plan`. Пояснение под кнопкой: что встанет на паузу (имена
   целей и Σ), какой долг первый, шаг месяца.
2. **Активный план в `StrategyCompare`**: вместо блока выбора — карточка «План выбран
   {monthTitle} · шаг этого месяца N ₸ → Открыть план» (ссылка `/plan`).
3. **Пауза целей:** `Goals.vue` — у цели на паузе вместо «N/мес» — `Tag` «На паузе ради плана»;
   `GoalDetail.vue` — Callout «На паузе ради плана»: «Взнос {money(monthly)} идёт в досрочку
   самого дорогого долга — так семья отдаст банку меньше. Цель возобновится сама, когда долги с
   процентами закроются, или когда вы отмените план.» + ссылка «Открыть план»; крупная цифра
   «Цель закроется в …» получает подпись «после плана»; ползунок остаётся (правка `monthly`
   вступает после плана). Подушка — Callout «Подушка плана: взносы продолжаются».
4. **Бюджет и Обзор:** `budgetAmounts` с `plans`; строка «Досрочно по плану» (`planExtra`) в
   «Куда уходит» и в легенде/сегментах Обзора (цвет — токен d2), «Взносы в цели» без пауз;
   «Свободно» не меняется от выбора плана.
5. **Маршрут `/plan`** → `views/DebtPlan.vue` (минимум для этой задачи; PV-17 наполнит):
   заголовок «План «Сначала долги»», дата выбора, цели на паузе, кнопка «Отменить план»
   (member; подтверждение «Цели возобновятся, история плана останется») → `cancelPlan()`.
   Заголовок в `AppShell` — «План». Без активного плана — текст «Плана нет» + ссылка на
   калькулятор.
6. Viewer: ни кнопки выбора, ни отмены; всё остальное видно.

- `views/Goals.test.ts` (SSR): цель на паузе — «На паузе ради плана», подушка — без тега;
  `GoalDetail` на паузе — Callout с суммой; `monthly` в документе не изменился.
- `views/Budget.test.ts`, `views/Overview.test.ts`: с планом — «Досрочно по плану» = Σ

- `views/DebtPlan.test.ts` (SSR): без плана — «Плана нет»; с планом — цели на паузе; viewer —
  без «Отменить план».
- e2e (файл блока): A выбирает план → у B после синка цель с тегом паузы и строка «Досрочно по
  плану»; A отменяет → у B тег исчез.

## Критерии приёмки

- Браузер, два профиля: выбор плана в калькуляторе (с подушкой) → `/plan` → у партнёра цели
  на паузе, Бюджет и Обзор со строкой «Досрочно по плану», «Свободно» прежнее; отмена → всё
  вернулось; viewer не видит кнопок.
- `cd frontend && npm run build && npm test` зелёные.

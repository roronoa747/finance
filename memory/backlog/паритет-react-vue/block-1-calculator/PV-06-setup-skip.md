## Задача

1. `Setup.vue`: флаги `skipHousing`, `skipCredit`, `skipGoal`. «Пропустить» / «Пока без цели»
   ставят флаг и зовут `next()`; «Дальше» своего шага сбрасывает флаг (человек мог вернуться
   назад). `finish()` не сохраняет шаг с поднятым флагом (жильё: ни обязательств, ни
   `setCategoryAmount('d1')`; кредит; цель и `d3`). Введённое в полях остаётся.
2. `joining` считает только живые записи (`liveObligations` / `liveGoals` из `lib/finance.ts`)
   — паритет с React.
3. Решение «что сохранять» вынести в чистую функцию `setupPlan(form, skips)` (`lib/setup.ts`
   или рядом в `Setup.vue` с экспортом) → `{ housing?, credit?, goal? }`; `finish()` применяет
   её результат. Без этого кнопки не протестировать в Node.

## Находки

### Н-1 · средняя · Деньги в `Capital.vue` считаются в шаблоне; строка кредита пишет «Infinity платежей» и «переплата ∞»

Хвосты §4 «округление в Капитале» и «Infinity в строке кредита» владелец отдал клинапу
через это ревью. Полный список арифметики над деньгами (grep `Math\.` по `Capital.vue`):

| Место | Сейчас | В `finance.ts` |
|---|---|---|
| `Capital.vue:143-146` `paymentsLeft` | `Math.ceil(annuityMonths(…))` → «Infinity платежей» | `creditOutlook(c).months` |
| `Capital.vue:903-907` `sub` строки кредита | `Math.round(annuityTotal − principal)` → «переплата ∞» | `creditOutlook(c).overpay` при `closes` |
| `Capital.vue:442-447`, `:1012`, `:1016`, `:1025`, `:1034` «Что гасить первым» | `debtCost` + `Math.round(monthlyInterest)`, `Math.round(interestShare × 100)` ×2, `Math.round(overpay)` | `creditOutlook` + поля `monthlyInterest` и `sharePct` (целые) |
| `Capital.vue:1049` «минус N мес. и экономия» | `Math.round(monthsSaved)`, `Math.round(saved)` | `prepayOutcome` (ниже) |
| `Capital.vue:735-743`, `:1857`, `:1862`, `:1865-1867` результат калькулятора | `Math.round`/`ceil`/`max(0, …)` над `prepayment`/`lumpSum` | `prepayOutcome(credit, extra, 'monthly' \| 'once')` → `{ finite, monthsNow, monthsAfter, monthsSaved, saved }`, всё целое |
| `Capital.vue:722-734` чипы | `Math.round(pay / 2 / 1000) * 1000`, `Math.round(pay / 1000) * 1000` | `payoffChips(credit)` (`halfOverpayExtra` внутри) |
| `Capital.vue:745-756`, `:1984-1985` лесенка | `Math.round(pay × k / 1000) * 1000`, `Math.round(monthsSaved)`, `Math.max(0, Math.round(saved))` | `payoffLadder(credit)` на `prepayOutcome` |

Одна и та же «экономия» обрезается нулём в калькуляторе и лесенке (`:1862`, `:1985`), а в
«Что гасить первым» (`:1049`) — нет. С одной функцией это расхождение уйдёт само.

**Ловушка.** `creditOutlook` отдаёт `closes: false` в двух случаях: у закрытого долга
(`debtCost.closes` требует `months > 0`, а у остатка 0 месяцев 0) и при платеже ≤ процентов.
Строка «`!closes` → «долг не закрывается»» напишет это и у закрытого кредита. Критик уже ловил
ту же ошибку в калькуляторе (правка 4). Сейчас закрытый кредит в строке — «0 платежей», как в
React `Capital.tsx:152`.

**Рекомендация.**
- Строка кредита: остаток 0 → «долг закрыт», как уже пишут `PaidRow.vue:174` и калькулятор
  `:1819`; `!closes` → «долг не закрывается», как модалка `:1391` и калькулятор `:1818`;
  иначе — `${months} ${plural(…)}`. `sub` — только при `closes && overpay > 0`.
- Остальные места — на функции из таблицы. После правки в `Capital.vue` не должно остаться ни
  одного `Math.` над деньгами: разрешены только обрезки дня и месяца. Импорты
  `annuityMonths`, `annuityTotal`, `debtCost`, `prepayment`, `lumpSum` из Капитала уходят.
- Не трогать: суммы `:119-123` (сумма целых — целое, это не округление) и `rateText` `:530`
  (это ставка, не деньги).
- Тесты. В `finance.test.ts`: новые поля `creditOutlook`; `prepayOutcome` — конечный и
  бесконечный случаи, взнос больше остатка (экономия ≥ 0, месяцы целые); `payoffChips` —
  уникальные, по возрастанию, с половиной переплаты; `payoffLadder` — без бесконечных. SSR
  `Capital.test.ts`, строка кредита в трёх случаях: закрытый → «долг закрыт»; платёж ≤
  процентов → «долг не закрывается», без «Infinity» и «∞»; обычный → «N платежей · переплата
  M». Числа калькулятора и лесенки в существующих тестах и e2e не меняются — переделка не
  должна сдвинуть ни одного вывода.

**Вердикт: клинап.**

### Н-5 · низкая · «Сохранено» всегда сидит в заголовке окна, а озвучка его не произносит

`kit/SavedMark.vue:10-20`, `kit/Sheet.vue:129-132` (вопрос от приёмки). Текст «Сохранено»
всегда в DOM внутри `<h3>`, гасится только `opacity-0`. Итог двойной:
- для чтения с экрана заголовок окна — всегда «Кредит Kaspi Сохранено» (навигация по

`<Transition>` с `v-if="on"` (затухание — классами перехода). В `Sheet` слот `mark` вынести
рядом с `<h3>`, а не внутрь. SSR-тест: при `on=false` текста «Сохранено» нет, контейнер с
`aria-live` есть. Тесты, которые ждут «Сохранено» в выключенном состоянии, не нашлись

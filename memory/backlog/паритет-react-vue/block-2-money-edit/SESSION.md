# Блок 2 — Правка денег · сессии

**Цель блока:** вернуть семье право исправлять деньги без удаления — кредит, обязательство,
валютный счёт, форму платежа с разделом и оценкой, удаление с честным предупреждением — на
едином ките окон, и показать по каждому платежу по кредиту, сколько ушло в долг, а сколько
банку.

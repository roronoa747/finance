## Задача

1. `lib/finance.ts` (все целые):
   - `paymentSplit(record | null, credit, due)` → `{ body, interest }` по правилу выше (одно
     место для `PaidRow` и модалок);
   - `creditTotals(payments, creditId)` → `{ body, interest, count }` по учтённым живым
     записям `credit` + `prepay` (у досрочки всё тело);
   - `budgetInterest(credits)` → Σ `creditSplit(...).interest` по открытым кредитам (месяц);
   - `creditSchedule(credit, payments, { from = monthKey(), extra?: { period, amount }[] })` →
     строки `{ period, day, amount, body, interest, left, paid: boolean }` до закрытия (кап 600
     мес.); прошедшие периоды с отметками — по записям; `extra` — досрочки будущих месяцев
     (PV-17 передаст план), сейчас — применённые досрочки текущего месяца.
2. `PaidRow` (кредит): под суммой «в долг X · банку Y» (строка и лист «оплачено»); в модалке
   кредита — «За всё время: в долг X, банку Y (N платежей)» и та же строка у каждой досрочки в
   списке применённых.
3. Строка кредита в Капитале: `note` дополняется следующим платежом «платёж N ₸: в долг X,
   банку Y» (текущий период через `nextCreditDue`).
4. Бюджет: под строкой «Кредиты» — «из них проценты банку N ₸ в месяц» (`budgetInterest` по
   производным кредитам).
5. Модалка кредита: раздел «График платежей» (свёрнут по умолчанию; строка = месяц · платёж ·
   в долг · банку · остаток; оплаченные помечены) на `creditSchedule`.

## Критерии приёмки

- Браузер: у живого кредита в строке, в модалке и в «Оплатил» разбивка сходится (тело + банку
  = платёж, Σ тела по графику = остаток — сверить скриптом); после отметки «За всё время»
  выросло на тело и проценты записи; Бюджет показывает проценты месяца; второй профиль видит
  то же.
- `cd frontend && npm run build && npm test` зелёные.

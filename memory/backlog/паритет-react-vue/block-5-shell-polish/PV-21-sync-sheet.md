## Задача

1. `SyncBadge.vue` на `Sheet`; «Последний обмен» — дата и время (`toLocaleString('ru-RU')`).
2. «В бюджете»: список из `people` документа (имена; свой отмечен «это вы»; у себя при
   `isViewer` — «только просмотр»). *(дефолт составителя: роль партнёра без ручки Go недоступна
   — показывается только своя; хвост §4 — владелец согласился 2026-09-25)*
3. «Пригласить второго» при `people.length < 2` с текстом React и «Создать код» (общая логика с
   `Overview.makeInvite` — вынести в стор/композабл, ошибка через `authErrorText`); viewer не видит.
4. Пояснение про офлайн — дословно.
5. «Начать бюджет заново» (member): `DangerZone`-подтверждение с текстом React → `resetAll()` →
   `syncHousehold()` → закрыть шторку; демо — тоже (локально).
6. «Выйти» остаётся в «Оформлении» (не дублировать) — ссылка «Выйти — в Оформлении» не нужна.

- Браузер, два профиля: шторка показывает дату обмена, обоих участников, пояснение; «Начать

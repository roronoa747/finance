## Задача

1. Стор: `addWish({name, price, by, url?})` (id, `addedOn` — ISO даты, новая в начало),
   `updateWish(id, patch)` (с `unchanged`), `removeWish(id)` (надгробие), `toggleBought(id)`
   (`boughtOn` ISO / `null`); `Goals.vue` перестаёт мутировать документ напрямую.
   *(дефолт составителя: даты — ISO, не «сегодня» как в React; показ через `atLabel`; старые
   строки `dd.mm.yyyy` показываются как есть — владелец проверит утром)*
2. `Goals.vue`: строка покупки — правка по нажатию (диалог `WishDialog` на `Sheet` с
   автосохранением по blur, `SavedMark`, «Готово», `DangerZone` с текстом React); тексты
   диалога создания как React («Что покупаем», «Цена, ₸», «Ссылка на товар», placeholder’ы,
   «Кто добавил» всегда при ≥ 2 людях — как сейчас, «Добавить в список»); «Список пуст»;
   карточка после покупки с «Это N-я покупка в дом…».
3. «Уже купили»: всегда виден, итог `money(boughtSum)` в заголовке, «Пока ничего», строка с
   зачёркнутым названием, «{nameOf} · куплено {дата}», кнопка «Вернуть в список».
4. Viewer: кнопок нет (диалог не открывается), список и итог видны.

## Тесты

## Критерии приёмки

- Браузер, два профиля: поправить название и цену покупки, удалить покупку, вернуть купленное
  в список — всё видно партнёру; итог «Уже купили» сходится с суммой цен.
- `cd frontend && npm run build && npm test` зелёные.

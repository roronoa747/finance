## Задача

1. Стор `updateGoal`: правило React для `have` (`seed = max(0, have − Σ)`, `have =
   goalHave(seed, movements)`), `unchanged`-защита; остальные поля как сейчас.
2. Диалог правки цели на `Sheet`, автосохранение по blur каждого поля (название — только
   непустое и изменённое; «Сколько нужно» `> 0`; «Уже накоплено» `>= 0`; «Откладывать в месяц»
   `> 0` — поле остаётся, оно есть во Vue); цвет — сразу; `SavedMark`; кнопка «Готово» только
   закрывает; закрытие фоном/крестиком ничего не теряет. Пояснение про взносы — дословно.
   Текст `DangerZone` — React.
3. Viewer: диалог не открывается.
4. **Хвост Н-8 ревью frontend Блока 3** (владелец, 2026-09-25 → PV-19): у цели на паузе
   (`financeStore.pausedGoalIds`) дата «Цель закроется в …» считается так, будто взносы идут с
   этого месяца, с подписью «после плана». Дата — от конца плана: месяц без процентных долгов из
   `planForecast` (`debtFreeMonth`) плюс месяцы цели, функцией в `finance.ts`; долги не
   закрываются (`debtFreeMonth` null) — только «после плана», без месяца. Если дата от конца
   плана окажется шумной — «через N мес. после плана» (выбор записать в Handoff). Тест: SSR
   `GoalDetail` у цели на паузе на `planFamilyDoc` — месяц позже `debtFreeMonth`.

  `have = Σ`; повторный патч без изменений — no-op.

- e2e (файл блока): правка «Уже накоплено» на A → у B `have` и кольцо обновились, история
  взносов на месте.

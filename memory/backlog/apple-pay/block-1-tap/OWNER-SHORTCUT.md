# Команда «Траты сами» — инструкция владельцу (AP-07)

Утром, ~10 минут, на своём iPhone. Ключей и ссылок-значений в этом файле нет: ключ — личный (из приложения),
ссылки iCloud живут в env Vercel.

**Что получится:** оплатили телефоном в магазине → через секунды трата в «Неделе». Команда шлёт строки транзакции на
сервер, сервер сам находит сумму, валюту, банк и магазин.

## 0. Команда уже собрана (ночью 2026-10-16) — проверьте пять мест

Откройте «Быстрые команды» → свою команду → проверьте по порядку:

1. Первое действие — **«Текст»**: в нём будет ключ. Нажмите **ⓘ** внизу → **«Настройка»** → **«Добавить вопрос»** →
   выберите поле действия «Текст» → вопрос: «Вставьте ключ из приложения». Так у каждого, кто добавит команду по
   ссылке, iPhone спросит его ключ.
2. Действие **«Получить содержимое URL»**: адрес `https://family-finance-ff.vercel.app/api/wallet/tap`.
3. Там же **«Показать больше»** → **Метод: POST**.
4. **Заголовки** → «Добавить новый заголовок»: `Authorization` = `Bearer ` (с пробелом) + переменная «Текст» из шага 1;
   второй: `Content-Type` = `application/json`.
5. **Текст запроса: JSON** → поля типа «Текст»: `merchant`, `amount`, `card`, `name` ← «Продавец», «Сумма», «Карта»,
   «Название» триггера. **Если iOS не даёт выбрать эти свойства** (так было ночью) — оставьте как есть: всё в одном
   поле `merchant` целиком, сервер найдёт сумму в тексте сам.

## 1. Команда A — для iOS 27 (триггер внутри команды)

1. В редакторе команды нажмите **ⓘ** → **«Триггер»** (на iOS 27 — пункт в сведениях команды) → **«Транзакция»**.
2. Карты — **все**; **«Запускать сразу»** — включено; **«Уведомлять при запуске»** — выключено.
3. Внизу → **«Поделиться»** → **«Скопировать ссылку iCloud»**.

У человека, который добавит команду по ссылке, триггер придёт выключенным — лист в приложении говорит «Включите
автоматизацию тумблером».

## 2. Команда B — для iOS 17–26 (без триггера)

1. Нажмите на команду A и удерживайте → **«Дублировать»** → назовите **«Траты сами»** (лист приложения ссылается на это
   имя).
2. В сведениях (**ⓘ**) уберите триггер; там же **«Получать»** → **«Любой ввод»**.
3. В теле JSON вместо свойств триггера — **«Входные данные команды»** (целиком в `merchant`, если свойства не
   выбираются).
4. **«Поделиться»** → **«Скопировать ссылку iCloud»**.

**Как проверить B на iOS 27:** вкладка **«Автоматизация»** → **«+»** → **«Транзакция»** → карты, **«Запускать сразу»**
→ **«Далее»** → **«Новая пустая автоматизация»** → действие **«Запустить команду»** → «Траты сами», вход —
«Входные данные быстрой команды».

**Запасной путь** (если поля транзакции не проходят через «Запустить команду» — живьём не проверено): действия
«Текст» и «Получить содержимое URL» кладутся прямо в автоматизацию, без команды B. Тогда
`APPLEPAY_SHORTCUT_URL_LEGACY` не задаётся (у iOS 17–26 карточки не будет), а лист для них — хвост §4, не утро.

## 3. Ссылки — в приложение

Пришлите обе ссылки агенту (или впишите сами в Vercel → Settings → Environment Variables, **Production**):
`APPLEPAY_SHORTCUT_URL` — команда A, `APPLEPAY_SHORTCUT_URL_LEGACY` — команда B. Ссылки не секрет, но в git их не
кладём. Принимаются только ссылки вида `https://www.icloud.com/shortcuts/…`.

## 4. Свой ключ и первая оплата

1. После деплоя: приложение → **Настройки** → **Apple Pay** → **«Подключить»** → **«Скопировать ключ»**.
2. Вставьте ключ в действие «Текст» своей команды (шаг 0.1) — или откройте команду по ссылке из листа и ответьте на
   вопрос.
3. Оплатите что-нибудь телефоном → откройте приложение → «Неделя».

## 5. Утренний смоук (критерии брифа)

- [ ] До первой оплаты карточка «Apple Pay» — «Ждём первую оплату» и «Подключить» (ключ делает только «Скопировать
      ключ»); после оплаты — «Последняя трата <день>» и «Подключить снова» (владелец 2026-10-19).
- [ ] Kaspi в магазине → трата в «Неделе» за секунды; незнакомый магазин — в «Не разобрано».
- [ ] Freedom в магазине → трата с банком Freedom.
- [ ] Повтор того же срабатывания (та же сумма ≤ 2 минут) — одна трата.
- [ ] Выписка за этот период → трата с телефона заменена строкой выписки, дублей нет.
- [ ] Партнёр видит только итог раздела, саму трату — нет.
- [ ] **«Отключить»** в настройках → следующая оплата не приходит (сервер отвечает 401, в «Неделе» ничего).

## 6. Если трата не пришла

Ответ сервера команда может показать действием «Показать результат» в конце (на время проверки):

- `{"status":"skipped","reason":"amount"}` или `"currency"` — сервер не понял сумму. Откройте **/admin** →
  **«Последнее касание»**: там тело последнего касания, как его прислала команда (только ваше, хранится сутки).
  Пришлите скриншот этого блока — агент поправит разбор. Блок виден и когда трата пришла — по нему видно, как iPhone
  записал транзакцию текстом.
- `{"error":"unauthorized"}` — ключ не тот или отключён: «Подключить» заново и вставьте новый ключ.
- `{"error":"limit"}` — больше 200 трат с телефона за сутки (защита от зациклившейся автоматизации).

## Для агента: проверка контракта `curl`-ом

Стенд: Go `:8141` с env-заглушками ссылок (`APPLEPAY_SHORTCUT_URL=https://www.icloud.com/shortcuts/stub-ios27`,
`APPLEPAY_SHORTCUT_URL_LEGACY=https://www.icloud.com/shortcuts/stub-legacy`). На Windows тело с `₸` — **только из
файла** (`--data-binary @file`): аргумент командной строки теряет символ, ответ — `skipped/currency`.

```bash
B=http://localhost:8141/api
# TOKEN — JWT member-а стенда (POST $B/auth/register или /auth/login).
KEY=$(curl -s -X POST $B/wallet/connect -H "Authorization: Bearer $TOKEN" | sed -n 's/.*"key":"\([^"]*\)".*/\1/p')
curl -s $B/wallet -H "Authorization: Bearer $TOKEN"                        # connected: true, phones: 1
tap() { printf '%s' "$1" > tap.json; curl -s -w ' %{http_code}\n' -X POST $B/wallet/tap \
  -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' --data-binary @tap.json; }
tap '{"merchant":"Magnum","amount":"1 234,50 ₸","card":"Kaspi Gold"}'    # saved 200
tap '{"merchant":"Magnum","amount":"1 234,50 ₸","card":"Kaspi Gold"}'    # duplicate 200
tap '{"merchant":"Apple Store","amount":"$6.22","card":"Freedom"}'       # saved 200 (fx_* USD 622)
tap '{"merchant":"SMALL 5 000 ₸ Halyk Bonus"}'                           # saved 200 (вся транзакция текстом)
tap '{"merchant":"X","amount":"6.22"}'                                   # skipped currency 200
curl -s $B/operations -H "Authorization: Bearer $TOKEN"                   # source: "tap", amount −1234 …
curl -s -o /dev/null -w '%{http_code}\n' -X DELETE $B/wallet -H "Authorization: Bearer $TOKEN"   # 204
tap '{"merchant":"Magnum","amount":"100 ₸"}'                             # unauthorized 401
```

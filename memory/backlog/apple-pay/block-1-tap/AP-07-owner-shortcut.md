# AP-07 — Инструкция владельцу: сборка команды и ссылки; заглушка стенда

Блок 1 · MVP · Каталог: `memory/backlog/apple-pay/block-1-tap/` (+ стенд) · Зависит от: AP-03, AP-06 · Роли: владелец

## Контекст (что уже есть)

- Р-4: команду «Быстрых команд» и ссылку iCloud может сделать только iPhone — **владелец утром** (~5–10 минут) по этой
  инструкции; ссылки становятся env бэкенда (Р-17: `APPLEPAY_SHORTCUT_URL` — iOS 27, `APPLEPAY_SHORTCUT_URL_LEGACY` —
  iOS 17–26). Р-18: ключ — «вопросом при импорте». Р-3: на iOS 27 триггер — внутри команды (у получателя команда
  приходит выключенной, включается тумблером); на iOS 17–26 — команда без триггера + автоматизация руками.
- Контракт ручки — §6 индекса и AP-03: `POST https://family-finance-ff.vercel.app/api/applepay/tap`, заголовки
  `Authorization: Bearer <ключ>` и `Content-Type: application/json`, тело `{"merchant": …, "amount": …, "card": …,
  "name": …}` — строки из триггера «Транзакция». Прод-домен — `family-finance-ff.vercel.app` (не `family-finance`).
- Память владельца: инструкции — полной фразой «Нажмите на…, чтобы…», коротко, без механики там, где можно; владелец
  обсуждает визуально — схемы лучше абзацев.

## Задача

1. Файл `memory/backlog/apple-pay/block-1-tap/OWNER-SHORTCUT.md` (в git, **без ключей и ссылок-значений**):
   - **Команда A «Траты сами» (iOS 27)** — по шагам с русскими названиями пунктов iOS: новая команда → триггер
     «Транзакция» (все карты, «Запускать сразу», без уведомления) → действие «Текст» с ключом, отмеченное **«Вопрос при
     импорте»** («Вставьте ключ из приложения») → «Получить содержимое URL»: URL ручки, метод POST, заголовки
     `Authorization` = «Bearer » + переменная текста, `Content-Type` = `application/json`, тело JSON: `merchant` ←
     «Продавец», `amount` ← «Сумма», `card` ← «Карта», `name` ← «Название» (магические переменные триггера) →
     «Поделиться» → «Скопировать ссылку iCloud». Проверка до раздачи: оплатить что-нибудь Apple Pay → трата появилась
     (ключ — свой, полученный в приложении на стенде/проде).
   - **Команда B «Траты сами» (iOS 17–26)** — та же без триггера; «Получать: Транзакции / любой ввод»; поля — из «Ввод
     команды». Как проверить на iOS 27: ручная автоматизация «Транзакция» → «Запустить команду» → B.
   - **Запасной путь**, если поля транзакции не проходят через «Запустить команду» (не подтверждено живьём): действия
     прямо в автоматизации (без команды B); тогда `APPLEPAY_SHORTCUT_URL_LEGACY` не задаётся, а лист iOS 17–26 — задача
     хвоста (записать в §4, не делать ночью).
   - Что сделать со ссылками: прислать агенту (или вписать в env Vercel `APPLEPAY_SHORTCUT_URL`,
     `APPLEPAY_SHORTCUT_URL_LEGACY` — Production) — ссылки iCloud не секрет, но в git не кладутся (живут в env).
   - Чек-лист утреннего смоука (критерии брифа для касания): Kaspi и Freedom в магазине → трата за секунды; повтор не
     дублирует; «Отключить» → следующая оплата не приходит (ответ 401, в «Неделе» ничего); выписка за период — без
     дублей; партнёр видит только итог.
   - Что делать, если сумма в тенге не разбирается (статус `skipped`, причина `currency`/`amount`): прислать вид строки
     «Сумма» (скриншот поля, без остального) — правка таблицы `ParseAmount`.
2. Заглушка стенда: env `APPLEPAY_SHORTCUT_URL=https://www.icloud.com/shortcuts/stub-ios27` и
   `…_LEGACY=…/stub-legacy` для `cmd/server` стенда (в Handoff — как поднимать; в `backend/README.md` — строка, что на
   стенде это заглушки).
3. Скрипт-проверка контракта `curl`-ом (в инструкции, раздел «для агента»): connect → tap тенге → tap валюта → повтор →
   отключение → 401. Прогнать на стенде (Go :8141), результат — в Handoff.

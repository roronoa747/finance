## Задача

1. Типы: `BankId` += `'halyk' | 'card'`; `Operation` += `source?: 'tap' | 'push'` (нет — выписка), `at?: string`
   (ISO момента), `fx?: { currency: Currency; amount: number }` (минорные, целое); `OperationWire` += `source?`,
   `occurred_at?`, `fx_currency?`, `fx_amount?`, `deleted?`. `fromWire` / `toWire` — поля туда и обратно (`toWire`
   `source`/`fx`/`at` не шлёт — сервер их игнорирует; шлёт `deleted`, когда надо, — AP-05).
2. Курс — функция в `lib/finance.ts` (правило 6): `phoneOpTenge(op, book): number | null` — `null`, пока нет курса дня;
   иначе `-fxToTenge(fx.amount / 100, rate)` (целое, минус — списание).
3. `pull`: (а) надгробие → `delete ops.value[id]` (и из `pending`, если там есть), период — в пересчёт; (б) полученные
   операции с телефона (`source` есть) + все свои с `fx` и `amount === 0` (повтор после офлайна) → курс
   (`ensureRates` для их валют и дат, затем `phoneOpTenge`; нет курса — оставить как есть) → `reapply` (раздел и
   `internal` по правилам; выписочные операции `pull` по-прежнему не трогает) → `remember`; изменённые (`categoryId`,
   `amount`) — в `pending` и `flush`; (в) `writeTotals(periodsOf(…))` для периодов операций с телефона и надгробий.
   Только member и не демо — как сейчас.
4. Подтягивание при возврате в приложение (видимость `visible`) — member, не демо, не чаще раза в 30 с (константа в
   сторе); без нового движка — рядом с существующим `sync` в `syncEngine.ts`.
5. Операции с телефона не участвуют в `autoMark` (отметки платежей ставит выписка, Р-2 «выписка — истина»); вопросы
   сопоставления (`pendingMatches`) — как для любых операций, без изменений.

## Тесты

- `lib/finance`: `phoneOpTenge` — USD 6.22 по курсу 480.5 → −2989; нет курса → null; KZT-операция без `fx` не
  трогается.
- `stores/operations` (Vitest, фейк клиента): `pull` с операцией `source: 'tap'`, продавец с правилом → раздел из
  правила, `pending` с этой операцией, итог недели в `householdDoc.spendTotals` вырос; незнакомый продавец → `categoryId`
  null и операция в `unknownGroups`; надгробие → операции нет, итог периода уменьшился (обнулился); валюта без курса →
  `amount` 0, в итогах нет; курс пришёл на следующем `pull` → пересчитана и отправлена; выписочные операции из `pull`
  без изменений (регрессия: `pull` не шлёт их назад).
- `fromWire`/`toWire` — круг без потерь для новых полей.

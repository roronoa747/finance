## Задача

1. Стор `stores/applepay.ts`: `status` (ответ GET, кэш в памяти на сессию), `load()`, `connect()` → ключ (держится
   **только в памяти листа**, не в localStorage), `disconnect()`; `isIPhone` (`/iPhone/` в UA), `iosMajor` (`Version/NN`
   → число или null), `path` (`'ios27' | 'legacy'`, переключаемый тихой ссылкой), `link` (ссылка для пути или пусто),
   `available` = member && !демо && ссылка для пути есть. Демо и viewer — без запросов.
2. Настройки — карточка «Apple Pay» (после «Разбор трат», только `available`): не подключено — строка «Траты появятся
   сами после оплаты» и кнопка «Подключить» (на экране настроек брендовой кнопки нет — эта может быть основной;
   решает `/ux`); подключено — «Подключено · последняя трата <дата>» (`last_used_at`, нет — «ждём первую оплату») и тихая
   «Отключить» (подтверждение в один шаг: «Отключить? Траты перестанут приходить сами»).
3. Лист подключения (`Sheet`, адрес `?applepay=1`): шаги **по одному на экран** («1 из N», «Дальше»), картинка-схема
   шага (простой SVG/CSS-макет экрана iPhone на токенах, не скриншот), подпись одной строкой:
   - iOS 27: «Скопировать ключ» (кнопка; ключ создаётся `connect()` при входе на шаг, показывается замаскированным
     `ffk_…xxxx`) → «Открыть команду» (ссылка iCloud, новая вкладка) → «Нажмите „Добавить“ и вставьте ключ» → «Включите
     автоматизацию тумблером» → «Готово — оплатите что-нибудь телефоном».
   - iOS 17–26: «Скопировать ключ» → «Открыть команду» → «Добавить, вставить ключ» → «Автоматизация → + → Транзакция» →
     «Выберите карты, „Запускать сразу“» → «Действие „Запустить команду“ → „Траты сами“» → «Готово».
   - Закрыть лист до конца — ключ уже создан: статус `connected` (после `load()`); повторное «Подключить» — новый ключ.
   - Точные названия пунктов iOS — из инструкции AP-07 (одно место правды); видео владельца позже заменит схемы
     (после MVP).
4. «Неделя»: под шапкой (рядом с «Загрузить») — тихая строка-ссылка «Траты сами с Apple Pay» → `/settings?applepay=1`;
   только `available` && `isIPhone` && !`connected`; `load()` статуса — в `onMounted` рядом с `pull`.
5. Политика (`Privacy.vue`): строка «Apple Pay (если подключите): название магазина, сумма, банк и время оплаты — без
   номера карты и остатка. Подключение отключается в настройках» — **черновик**: финальные слова — владельцу
   артефактом «до | после» (роль `/ux`). Про хранение ключа — без механики («хеш» в тексте не нужен).
6. Handoff по правилу 12: главное действие и у какого предмета, что ушло в подсказку, что скрыто.

## Тесты

- `stores/applepay`: `iosMajor` для UA iOS 27 Safari, iOS 26, iOS 17, standalone PWA без `Version/` → null; путь и
  ссылка; без ссылки — `available` false; viewer/демо — `load` не зовёт клиента; ключ не попадает в `localStorage`
  (проверка всех ключей хранилища после `connect`).
- DOM (`Settings.applepay.dom.test.ts`): карточка скрыта у viewer, в демо, без ссылки; «Подключить» → лист, шаг 1,
  копирование ключа; подключено — «Отключить» → подтверждение → `disconnect`; брендовая кнопка на экране одна.
- DOM «Неделя»: строка есть на iPhone и не подключено; нет — на Android UA, у подключённого, у viewer.

## Критерии приёмки

- `npm run build && npx vitest run` — зелёные.

  карточка → лист → все шаги обоих путей → подключено; «Отключить»; строка на «Неделе» появляется и исчезает; viewer —
  ничего. Скриншоты — в Handoff ссылками на файлы вне git.

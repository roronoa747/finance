## Задача

1. Точка «Пришла?»: вычисление в сторе/`lib` (кандидаты зарплаты среди операций с `source === 'push'`, своя
   неотмеченная зарплата периода) → у строки зарплаты точка (токен `--brand` или существующий стиль «ждёт действия» —
   выбрать по ките), в листе зарплаты — строка «Пришло N ₸ в <банк> <дата>?» у «Пришла» (сумма и дата — подсказкой, не
   на строке). Отметка — существующим «Пришла» (предзаполнить сумму прихода, если лист это умеет). Viewer — точки нет.
2. Лист подключения (подключено, iOS 27, ссылка пушей есть): тихая строка «Ещё — пуши банков» → шаги второй команды
   (по одному на экран): «Скопировать ключ»¹ → «Открыть команду» → «Добавить, вставить ключ» → «Выберите приложения
   банков» → «Включите тумблер». ¹ ключ тот же — показан один раз; если листа уже нет — «Подключить заново» выдаёт новый
   и **обе команды** надо обновить: в шаге — предупреждение одной строкой. Альтернатива — решение `/ux`.
3. «Цифры» (админ): строка «Пуши за 7 дней: разобрано N · не разобрано M» по банкам, детали — под «подробнее».

## Тесты

- Вычисление точки: приход из пуша ≈ ожидаемой зарплате в окне → точка; уже отмечено → нет; приход из выписки — точка
  не нужна (вопрос сопоставления как раньше); чужая зарплата — нет; сумма вне допуска — нет.
- DOM: точка у строки зарплаты на «Месяце»; лист — строка прихода; «Пришла» ставит отметку, точка исчезает.
- DOM листа: строка «Ещё — пуши банков» только при `push_shortcut_url` и iOS 27; шаги.
- DOM «Цифр»: строка пушей у админа.

## Критерии приёмки

- `npm run build && npx vitest run` — зелёные.
- Браузер (стенд Блока 2, Vite :5251 → Go :8151; 390 px, обе темы): `curl` пуша зарплаты → точка у зарплаты → «Пришла»
  → отметка; лист с шагами второй команды; «Цифры».

## Вне скоупа

- Автоотметка зарплаты без человека — нет (Р-8). Команда пушей для iOS ≤ 26 — нет (триггера нет).

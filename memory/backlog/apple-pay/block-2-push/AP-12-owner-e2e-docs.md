## Контекст (что уже есть)

- Р-4: команду собирает владелец утром. Триггер «Уведомление» (iOS 27): выбранное приложение, отдаёт заголовок, текст,
  дату (и, вероятно, название приложения — проверить на iPhone). Контракт — `POST /api/wallet/push`, `Authorization:
  Bearer <ключ>`, тело `{"app": …, "title": …, "body": …}` (AP-10).
- Инструкция Блока 1 — `block-1-tap/OWNER-SHORTCUT.md` (формат, «вопрос при импорте», раздел «для агента»).
- e2e Блока 1 — `frontend/e2e/ap-block1-tap.test.ts` и хелперы фейка (`serverTap`); имя этого — `ap-block2-push.test.ts`.

## Задача

1. `block-2-push/OWNER-PUSH-SHORTCUT.md`: команда «Пуши банков» (iOS 27): триггер «Уведомление» → приложения Kaspi.kz,
   Freedom, Halyk (Homebank) → «Запускать сразу» → «Текст» с ключом («Вопрос при импорте») → «Получить содержимое URL»
   (POST, заголовки, JSON `app` / `title` / `body` из триггера) → ссылка iCloud → env `APPLEPAY_PUSH_SHORTCUT_URL`.
   Чек-лист смоука (критерии брифа): Kaspi QR и перевод → трата; перевод себе Kaspi → Freedom — не трата; входящая
   зарплата → точка «Пришла?»; касание + пуш одной покупки — одна; «не разобрано» в «Цифрах» → прислать вид пуша
   (скриншот без суммы остатка) для таблицы форматов. Раздел «для агента» — `curl`-проверка на стенде.
2. e2e `ap-block2-push.test.ts`: пуш покупки → трата; касание + пуш → одна; пара своих → не трата, итог недели не
   вырос; приход зарплаты → точка, «Пришла» → отметка; выписка с покупкой из пуша → без дубля.
3. Доки: `backend/README.md` (env, ручка пуша, счётчик), DESIGN.md (лист подключения — вторая команда; точка у
   зарплаты), §6 индекса — «После Блока 2» пишет критик.

## Тесты

# Команда «Пуши банков» — инструкция владельцу (AP-12)

Утром, ~10 минут, на своём iPhone с **iOS 27** (триггера «Уведомление» раньше нет). Ключей и ссылок-значений в этом
файле нет: ключ — личный (из приложения), ссылка iCloud живёт в env Vercel.

**Что получится:** пришёл пуш Kaspi / Freedom / Halyk о покупке, переводе или пополнении → через секунды операция в
«Неделе». Перевод себе (из одного своего банка в другой, та же сумма, ≤ 10 минут) — не трата. Зарплата → точка у
«Пришла» в «Месяце». Касание Apple Pay и пуш одной покупки — одна трата.

**Чего не будет:** Kaspi **не шлёт пуш** на оплату Kaspi QR, «Платежи», Магазин и переводы клиентам Kaspi (справка
Kaspi) — эти траты придут только с выпиской. Остаток «Доступно» сервер не хранит; текст пуша — тоже.

## 1. Собрать команду

Проще всего — от команды «Траты сами» (AP-07): там уже есть ключ, адрес и заголовки.

1. «Быстрые команды» → удерживайте «Траты сами» → **«Дублировать»** → назовите **«Пуши банков»** (лист приложения
   ссылается на это имя).
2. Первое действие — **«Текст»** с ключом; вопрос при импорте уже настроен (AP-07 §0.1) — проверьте, что он остался:
   **ⓘ** → **«Настройка»** → вопрос «Вставьте ключ из приложения».
3. Действие **«Получить содержимое URL»**: адрес — тот же, но в конце **`/api/wallet/push`** вместо `/api/wallet/tap`:
   `https://family-finance-ff.vercel.app/api/wallet/push`. Метод **POST**, заголовки те же: `Authorization` =
   `Bearer ` + «Текст», `Content-Type` = `application/json`.
4. **Текст запроса: JSON** — три поля типа «Текст»: `app` ← «Приложение» (название приложения уведомления), `title` ←
   «Заголовок», `body` ← «Текст» (тело) — свойства триггера «Уведомление». **Если iOS не даёт выбрать свойства** —
   положите уведомление целиком в одно поле `body`: сервер сам найдёт банк, вид и сумму в тексте.
5. **ⓘ** → **«Триггер»** → **«Уведомление»** → приложения **Kaspi.kz**, **Freedom** (Freedom SuperApp), **Halyk**
   (Homebank) → **«Запускать сразу»** — включено; **«Уведомлять при запуске»** — выключено.
6. Внизу → **«Поделиться»** → **«Скопировать ссылку iCloud»**.

У человека, который добавит команду по ссылке, триггер придёт выключенным — лист в приложении говорит «Выберите
Kaspi, Freedom и Halyk» и «Включите автоматизацию тумблером».

## 2. Ссылка — в приложение

Пришлите ссылку агенту (или впишите сами в Vercel → Settings → Environment Variables, **Production**):
`APPLEPAY_PUSH_SHORTCUT_URL`. Только ссылки вида `https://www.icloud.com/shortcuts/…`. Без неё в листе подключения нет
шага «Ещё — пуши банков» и кнопки «Пуши банков» в карточке; сама ручка работает и без ссылки.

## 3. Свой ключ

- Если «Траты сами» подключаете сейчас: лист **Apple Pay** → шаги касания → на последнем шаге тихая **«Ещё — пуши
  банков»** → «Скопировать ключ» (тот же ключ) → «Открыть команду» → «Добавить» и вставить.
- Если «Траты сами» уже работает: **Настройки → Apple Pay → «Пуши банков»** — лист выдаст новый ключ этого iPhone.
  Прежний ключ (в «Траты сами») продолжает работать: ключей на человека до пяти, вытесняется тот, что дольше всех не
  работал. Обновлять первую команду не нужно.

## 4. Утренний смоук (критерии брифа)

- [ ] Покупка картой Kaspi в магазине → **одна** трата (касание + пуш склеены: магазин — из касания, банк — Kaspi).
- [ ] Перевод человеку из Freedom или Halyk → трата «Перевод Имя Ф.» в «Без раздела».
- [ ] Перевод себе: Kaspi → Freedom (или наоборот) той же суммой → обе операции не траты, итог недели не вырос.
- [ ] Входящая зарплата → в «Месяце» точка у «Пришла» своей зарплаты; в листе зарплаты — «Пришло? N ₸ в <банк>»;
      «Пришла» → отмечено этой суммой, точка ушла.
- [ ] Выписка за этот период → траты из пушей заменены строками выписки, дублей нет.
- [ ] **/admin** → «Пуши за 7 дней»: «не разобрано» > 0 → откройте «Последнее касание или пуш» и пришлите скриншот
      (сумму остатка закройте) — агент добавит форму в таблицу разбора.
- [ ] Kaspi QR — пуша нет, трата придёт с выпиской (это нормально).

## 5. Если операция не пришла

Ответ сервера покажет действие «Показать результат» в конце команды (на время проверки):

- `{"status":"skipped","reason":"format"}` — сервер не понял текст пуша (или это не операция: код, отказ, возврат,
  реклама, курсовая разница). У админа тело непонятого пуша — в **/admin** → «Последнее касание или пуш», сутки.
- `{"status":"skipped","reason":"currency"}` — валюта, которой нет в приложении, или приход в валюте.
- `{"status":"duplicate"}` — повтор того же пуша за 2 минуты или касание той же покупки уже записано.
- `{"error":"unauthorized"}` — ключ не тот или отключён: «Пуши банков» в карточке → новый ключ.
- `{"error":"limit"}` — больше 200 операций с телефона за сутки (касания и пуши вместе).

## Для агента: проверка контракта на стенде

Стенд Блока 2: Go `:8151` с `APPLEPAY_PUSH_SHORTCUT_URL=https://www.icloud.com/shortcuts/stub-push` (и двумя
заглушками Блока 1), Postgres `:54461`, `ADMIN_EMAILS` — почта админа стенда. На Windows тело с `₸` — **только из
файла** (`--data-binary @file`) или `node` (`fetch`): аргумент командной строки теряет символ. Суммы — синтетические.

```bash
B=http://localhost:8151/api
# TOKEN — JWT member-а стенда (POST $B/auth/register); KEY — POST $B/wallet/connect.
push() { printf '%s' "$1" > push.json; curl -s -w ' %{http_code}\n' -X POST $B/wallet/push \
  -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' --data-binary @push.json; }
push '{"app":"Kaspi.kz","title":"Kaspi Gold","body":"Покупка: 5 000 ₸\nMAGNUM\nДоступно: 12 345,67 ₸"}'  # saved
push '{"app":"Kaspi.kz","title":"Kaspi Gold","body":"Перевод: 7 000 ₸\nАйгерим С."}'                    # saved (transfer-out «Перевод Айгерим С.»)
# касание и пуш одной покупки (≤ 10 мин) → второй ответ duplicate, одна операция с банком пуша
curl ... /wallet/tap '{"merchant":"Small","amount":"2 500 ₸"}'; push '{"app":"Kaspi.kz","title":"Kaspi Gold","body":"Покупка: 2 500 ₸\nSMALL"}'
# перевод себе: Kaspi «Перевод … На карту другого банка» + Freedom «+20 000 ₸» через ≤ 10 мин → обе internal
push '{"app":"Freedom SuperApp","title":"Зачисление зарплаты","body":"+450 000 ₸"}'                   # saved (income)
push '{"app":"Kaspi.kz","title":"Kaspi Gold","body":"Что-то произошло 5 000 ₸"}'                     # skipped format
curl -s $B/operations -H "Authorization: Bearer $TOKEN"     # source: "push", kind, amount, internal
curl -s $B/admin/metrics -H "Authorization: Bearer $ADMIN"  # push_stats: kaspi parsed / unknown …
```

пуши, склейка, пара, метрики, «Отключить» → 401.

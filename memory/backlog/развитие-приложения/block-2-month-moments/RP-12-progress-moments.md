# RP-12 — Моменты прогресса на «Обзоре» (фронт)

Блок 2 · MVP · Каталог: `frontend/` · Зависит от: Блок 1 · Роли: все

## Контекст (что уже есть)

- Р-21: моменты прогресса — закрытый долг, половина цели, сэкономленное досрочкой — одна
  спокойная строка в истории семьи на «Обзоре»; закрытый долг ведёт в `/ritual`
  («освободилось N ₸»). Без конфетти, значков и серий. Правило заказчика 7: геймификация не
  детская. Отвергнуто владельцем: значки, серии дней, сравнение участников.
- Данные для моментов уже есть: записи `payments` (RP-06: платежи и досрочки с датами,
  сэкономленные проценты — RP-08), производный остаток кредита (закрыт = 0), взносы целей
  `Goal.movements` (дата, сумма, `by`), `Goal.need`, `seed`.
- На Обзоре сейчас **нет** ленты/истории событий (`views/Overview.vue`).
- `views/Ritual.vue` принимает источник суммы (RP-10); сейчас его источник по умолчанию —
  освободившийся платёж обязательства.

## Задача

1. `finance.ts`: чистая функция «моменты прогресса» из документа — выводит события из уже
   записанного (ничего нового в документ не пишет): кредит закрыт (дата последней записи,
   обнулившей остаток; освободившийся платёж), цель прошла половину (дата взноса, на котором
   `have` пересёк `need / 2`), досрочка сэкономила N ₸. Последние события — сверху.
2. На Обзоре — «История семьи»: несколько последних строк, одна строка на момент, тон «мы»,
   без имён-сравнений (кто внёс — не показывать как соревнование).
3. Строка закрытого долга ведёт в `/ritual` с источником «освободился платёж кредита» и
   суммой платежа.
4. Снятие отметки, которая закрыла долг, убирает момент (он вычисляемый).

## Тесты

- `lib/finance.test.ts`: закрытие кредита последней отметкой → момент с верной суммой
  освободившегося платежа; снятие отметки → момента нет; половина цели — ровно на
  пересекающем взносе; снятие взноса (отрицательный) не создаёт повторный момент при
  повторном пересечении (или создаёт один — зафиксировать правило в тесте).
- SSR Обзора: строки истории, без значков/конфетти.

## Критерии приёмки

- Браузер: закрытие долга (последний платёж на маленьком тестовом кредите) даёт строку
  прогресса; нажатие ведёт в раскладку «освободилось N ₸».
- `cd frontend && npm run build && npm test` зелёные.

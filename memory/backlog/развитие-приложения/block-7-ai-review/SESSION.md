  добавляет; содержимое не логируется ни на фронте, ни в Go.
- Верификация: `cd backend && go build ./... && go vet ./... && go test ./...` + корень `api/`;
  `cd frontend && npm run build && npm test`; живой вызов — локально с ключом.

## Промпт критика — уровень review · Opus 5 · effort xhigh (ultracode)

```
/critic развитие-приложения 7 ultracode
```

Блок-специфика:

- Приватность: перебрать все текстовые поля документа (`name`, `note`, `reason`, `url`,
  личный документ) — ни одно не попадает в сводку; тест поиском строк.
- Проверка чисел: попытаться обмануть валидатор (число прописью, другое форматирование,
  проценты, даты) — решить, что допустимо, зафиксировать тестом.
- Тон ответа: инструкция модели требует «мы», без упрёков и сравнения участников.
- Следующего блока нет → вместо актуализации его промпта проверить готовность бэклога к
  закрытию (DoD: хвосты §4 с судьбой, живые доки, e2e, CI).

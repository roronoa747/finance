# RP-08 — Применить досрочку и счётчик сэкономленного (фронт)

Блок 1 · MVP · Каталог: `frontend/` · Зависит от: RP-06 · Роли: member

## Контекст (что уже есть)

- Р-6: досрочку можно применить (сейчас только калькулятор): выбор «сократить срок» /
  «снизить платёж», видно, сколько процентов не отдадим банку; счётчик «сэкономлено на
  процентах» по всем досрочкам. Р-5: досрочка списывает со счёта (по умолчанию — прошлый
  счёт этого кредита). Р-7: запись с id, снять можно.
- Калькулятор: `views/Capital.vue` модалка `?payoff=<id>` (`:449-508`, шаблон `:1209-1305`):
  обзор через `debtCost`; `Segmented monthly|once` — `monthly` → `prepayment(p, r, pay, v)`
  (платёж + extra каждый месяц), `once` → `lumpSum(p, r, pay, v)` (разовый взнос, платёж
  тот же = «сократить срок»); чипы из `halfOverpayExtra`; «лесенка» из `prepayment`.
- `finance.ts`: `prepayment` — только режим «сократить срок» (комментарий: второй режим «добавим
  позже»); `lumpSum` (`:221`); `annuityPayment(principal, rate, months)`, `annuityMonths`.
  Режима «снизить платёж» нет.
- Записи — `SyncDoc.payments` (RP-06): у кредита производный остаток = база − тело по записям;
  досрочка — запись того же списка с `kind` досрочки.
- Досрочка обычно разовая (так работают банки); «платёж + extra ежемесячно» остаётся
  калькулятором.

## Задача

1. `finance.ts`: режим «снизить платёж» для разового взноса — новый платёж при том же
   оставшемся сроке, и сэкономленные проценты для обоих режимов. Всё в целых тенге на
   выходе. Обновить комментарий у `prepayment`.
2. В калькуляторе (режим «разово») — «Применить»: выбор режима «сократить срок» / «снизить
   платёж», сумма, счёт списания (по умолчанию — прошлый для этого кредита; «не
   списывать»). Перед подтверждением видно: новый остаток, новый срок или новый платёж и
   «не отдадим банку N ₸» — спокойно, как победа.
3. Применение = запись досрочки (тело = сумма, сэкономленные проценты — снимок расчёта на
   момент применения). «Снизить платёж» дополнительно меняет `Credit.payment` (запись хранит
   прежний платёж, чтобы снятие вернуло его).
4. Снятие досрочки (с подтверждением) — надгробие, остаток и счёт возвращаются, платёж — тоже.
5. Счётчик «сэкономлено на процентах» — сумма по живым досрочкам всех кредитов, на экране
   Капитала рядом с кредитами (спокойной строкой).

## Тесты

- `lib/finance.test.ts`: «снизить платёж» — новый платёж = аннуитет на остаток и прежний
  срок; сэкономлено ≥ 0 и меньше, чем у «сократить срок» при той же сумме; целые числа.
  Сверка на числах из живого случая (кредит 33% годовых — любые реалистичные цифры,
  записать в тест).
- Стор: применение → остаток и срок изменились, счёт уменьшился; снятие → всё вернулось
  (включая платёж в режиме «снизить платёж»); счётчик — сумма по живым.
- e2e Блока 1: досрочка «сократить срок» меняет остаток и срок и показывает сэкономленное —
  сверено с `finance.ts` до тенге.

## Критерии приёмки

- Браузер: досрочка «сократить срок» меняет остаток и срок, показывает сэкономленные
  проценты; второй профиль видит то же после синка; счётчик растёт.
- `cd frontend && npm run build && npm test` зелёные.

# RP-25 — Экран «А если…» (фронт)

Блок 6 · MVP · Каталог: `frontend/` · Зависит от: RP-24 · Роли: все

## Контекст (что уже есть)

- Р-23: «продержимся N месяцев, вот что поставить на паузу» — сценарием, а не допросом.
  Р-29: паттерны Vue, токены, телефон, тон «мы» без упрёков. Отвергнуто: сравнение
  участников.
- Функция сценария — RP-24 (имя и вход — в его Handoff).
- Роутер `router/index.ts`: дети `AppShell` — `''`, `budget`, `goals`, `goals/:id`, `capital`,
  `capital/:id`, `ritual` (+ маршруты, добавленные блоками 3–5). Обзор
  `views/Overview.vue` — место входа (например, рядом с «До зарплаты»).
- Кит: `components/kit/Segmented.vue`, `NumField.vue`, `Card`, `Section`, `Row`, `Callout`.

## Задача

1. Экран «А если…» (новый маршрут): выбрать сценарий — «без дохода <участник>» или «доход
   <участник> станет X», с какого месяца; ответ крупно — «продержимся N месяцев»; ниже —
   список «что поставить на паузу» с эффектом каждого пункта; можно отметить пункты и
   увидеть новое N (ничего не сохраняется в документ).
2. Вход с Обзора — спокойная строка «Запас прочности: N месяцев» (текущий `cushionMonths`
   или сценарий по умолчанию — выбрать и описать) → экран.
3. Формулировки — про семью, не про человека («если доход участника пропадёт», не «если
   <имя> потеряет работу»); декрет не упоминать как допрос.

## Тесты

- SSR: экран со сценарием по умолчанию — число месяцев из `finance.ts`; отмеченные паузы
  меняют число.
- Роутер: маршрут доступен из Обзора.

## Критерии приёмки

- Браузер, телефонная ширина: «А если» без одного дохода даёт число месяцев, совпадающее с
  RP-24 на живых числах; паузы пересчитывают; документ не меняется (статус синка остаётся
  «синхронизировано»).
- `cd frontend && npm run build && npm test` зелёные.

## Вне скоупа

- Сохранение сценариев.
- ИИ-объяснение сценария (Блок 7 разбирает бюджет, не сценарии).

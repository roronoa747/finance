# RP-20 — «Можно ли это купить?» (фронт)

Блок 4 · MVP · Каталог: `frontend/` · Зависит от: Блок 3 · Роли: все (добавить в желания — member)

## Контекст (что уже есть)

- Р-15: ввести цену → ответ по данным приложения («до зарплаты хватает» / «отодвинет <цель>
  на N дней»), считает `finance.ts`; из ответа одной кнопкой — в желания. Трат не вводит и
  не хранит. Правило заказчика 1: никакого ежедневного ввода трат.
- `finance.ts`: `untilPayday(state)` (после Блока 1 — по производным остаткам, оплаченное не
  входит): `onAccounts`, `dueTotal`, `shortfall`, `inDays`, `who`; `goalMonths(remaining,
  monthly)`; `budgetAmounts(state).d5` — свободно в месяце; `liveGoals`.
- Лист быстрых действий «+» — `components/AppShell.vue:189-244` (пункты с маршрутами:
  «Внеплановый доход» → `/capital?income=1`, «Покупка в дом» → `/goals?tab=wish` и др.).
- Добавление желания — действие стора (RP-16), списки по людям (RP-17).
- Время — по Алматы (RP-06).

## Задача

1. `finance.ts`: ответ на «можно ли купить за X» — хватает ли до зарплаты с учётом платежей до
   неё (и сколько останется); если нет или остаток ниже честного порога — какую цель и на
   сколько дней это отодвинет (правило выбора цели и расчёт дней — описать в комментарии;
   например, ближайшая по сроку активная цель с `monthly > 0`, дни через `goalMonths` до и
   после). Целые тенге и целые дни.
2. Вход — пункт «Можно ли купить?» в листе «+»: поле цены (и необязательное название) →
   ответ одной-двумя фразами спокойным тоном → кнопка «В желания» (цена и название
   переносятся, желание — в свой список).
3. Ничего не сохраняется, пока не нажато «В желания» (Р-15).

## Тесты

- `lib/finance.test.ts`: хватает до зарплаты; не хватает — выбранная цель и дни совпадают с
  расчётом вручную на тестовых числах; нет целей — честный ответ без «отодвинет»; цена 0 /
  пусто — без ответа.
- SSR/стор: «В желания» создаёт желание с ценой; без нажатия документ не меняется.

## Критерии приёмки

- Браузер: «Можно ли купить?» отвечает с цифрами, совпадающими с `finance.ts`; «В желания»
  добавляет желание в свой список.
- `cd frontend && npm run build && npm test` зелёные.

## Вне скоупа

- Учёт трат / списание покупки со счёта (правило заказчика 1).
- ИИ в этом ответе (считает только `finance.ts`).

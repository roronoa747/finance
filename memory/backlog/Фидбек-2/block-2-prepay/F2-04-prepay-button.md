# F2-04 — «Внёс досрочно» в листе кредита (фронт)

Блок 2 · MVP · Репо/каталог: `frontend/` · Зависит от: Блок 1 🏁 · Роли: участник (кнопка), viewer (нет кнопки)

## Контекст (что уже есть)

- Тестер досрочно погасил и правил «Остаток долга» руками: путь к досрочке не нашёл. Сейчас: лист кредита
  (`components/capital/CreditSheet.vue`) → тихая `ghost` «Посчитать досрочно» :291-293 (эмит `payoff`) → калькулятор
  `components/capital/PayoffSheet.vue` → режим «Разово» → блок «Применить к кредиту» :212-253 (режим «Сократить срок /
  Снизить платёж», `AccountChoice` «Откуда списать», `form.submit(applyPrepay)` :126-135) → строка «Досрочка применена: не
  отдадим банку N» :255-264. Решение — Р-3.
- Кнопка показывается сейчас только у кредита со ставкой (`!rateUnknown`), не у долга человеку — те же условия остаются:
  `applyPrepayment` считает экономию по ставке (`lumpPlan`), без ставки она врёт (B2C-19).
- Счёт по умолчанию — прошлой оплаты кредита (`lastAccountFor`, PayoffSheet.vue:105); счета списания —
  `payableAccounts(accounts)` (тенговые); `AccountChoice` — `undefined` не выбран / `null` «только отметить» / id.
- Подключение листов — `DebtsWidget.vue:194-195`, `CapitalLists.vue` (см. §6 бэклога); `CreditSheet` эмитит `payoff`,
  родитель открывает `PayoffSheet`.
- Паттерн «небольшая кнопка у предмета» — «Отдал» у долга человеку (`DebtsWidget.vue:132-141`, `variant="soft" size="sm"`).

## Задача

1. В листе кредита (участник, кредит со ставкой, остаток > 0) — небольшая кнопка **«Внёс досрочно»** у остатка долга
   (предмет действия — остаток; правило 12), вместо тихой «Посчитать досрочно» внизу. «Готово» внизу остаётся единственной
   крупной.
2. «Внёс досрочно» открывает лист ввода (новый `components/capital/PrepaySheet.vue` поверх листа кредита): сумма
   (`NumField`), «Сократить срок / Снизить платёж» (по умолчанию — срок), «Откуда списать» (`AccountChoice`, счёт прошлой
   оплаты), одна главная — подтвердить → `financeStore.applyPrepayment` (действующий, без правок стора). Предпросмотр
   (`lumpPlan`) — не больше одной строки; подробности — в калькуляторе.
3. Калькулятор — за «подробнее»: тихая ссылка в `PrepaySheet` открывает существующий `PayoffSheet` (как сейчас эмит
   `payoff`). Блок «Применить к кредиту» в `PayoffSheet` убрать — вносят из одного места; в калькуляторе в режиме «Разово»
   с суммой — тихая «Внёс досрочно» открывает `PrepaySheet` с этой суммой. «Применённые досрочки» со «Снять» остаются в
   `PayoffSheet`.
4. После подтверждения — лист показывает результат (F2-05 наполняет его «было → стало»; в этой задаче — существующая
   строка «не отдадим банку N»). `PlanSquare` (план «Сначала долги») — без изменений поведения.

## Тесты

- DOM `CreditSheet`: участник, кредит со ставкой — «Внёс досрочно» есть (`data-credit-prepay`), «Посчитать досрочно» нет;
  без ставки, долг человеку, остаток 0, viewer — кнопки нет.
- DOM `PrepaySheet`: сумма + счёт → `applyPrepayment` с `{ amount, mode, accountId }`; без счёта — ошибка формы, записи
  нет; «Снизить платёж» меняет платёж кредита; сумма больше остатка — долг закрыт (остаток 0).
- DOM `PayoffSheet`: блока «Применить к кредиту» нет; «Внёс досрочно» из калькулятора открывает лист с суммой.
- e2e `e2e/f2-block2-prepay.test.ts`: «Долги» → кредит → «Внёс досрочно» → сумма → подтвердить → остаток в строке «Долгов»
  уменьшился на сумму, досрочка в «Применённых».

## Критерии приёмки

- Досрочка вносится за два нажатия от листа кредита («Внёс досрочно» → подтвердить), долг пересчитан сам, остаток руками
  не правится.
- Build, весь vitest; стенд Chrome 390, обе темы; Handoff — правило 12 по листу кредита и `PrepaySheet`.

## Вне скоупа

- «Было → стало» крупно — F2-05. Поздравление при ручной правке остатка (не делаем, §4). Изменения `applyPrepayment`,
  плана «Сначала долги», «Как закрыть быстрее».

# F2-05 — «Было → стало» после досрочки (фронт, finance.ts)

Блок 2 · MVP · Репо/каталог: `frontend/` · Зависит от: F2-04 · Роли: участник

## Контекст (что уже есть)

- Тестер: «было 92 млн — стало 90,5 млн, смотри какой ты молодец». Решение — Р-4: крупно остаток **всех** долгов «было →
  стало» и «не отдадите банку N», числа — `finance.ts`, показ — в листе после «Внёс досрочно».
- Остаток всех долгов — `openDebt(credits)` (`lib/finance.ts:791`), та же крупная цифра карточки «Долгов»
  (`debtsOverview().total`, `DebtsWidget.vue:100`). Кредиты стора — производные: после `applyPrepayment` остаток уже меньше
  на `record.principal` (досрочка вся в тело).
- Запись досрочки (`Payment`, `kind: 'prepay'`) несёт `amount`, `principal`, `saved` (проценты, которые не отдадим),
  `prevPayment/newPayment` при «снизить платёж».
- Правила владельца: крупная цифра ≤ 34 px (`font-num text-[34px]` — образец `DebtsWidget.vue:100`), подписи `--ink-2`,
  одна крупная цифра у предмета, остальное — мелко или в предмете; текст — заголовок 1–3 слова + одна строка.

## Задача

1. `lib/finance.ts`: чистая функция `prepayBeforeAfter(credits, record)` → `{ before, after, saved }` — остаток всех
   открытых долгов до и после досрочки и экономия, целые тенге. До — посчитать из состояния **после** записи (`after +
   record.principal`), чтобы лист не держал снимок до нажатия; закрывший кредит взнос — тоже верно (кредит выпал из
   открытых).
2. `PrepaySheet` после подтверждения: вместо формы — результат: крупно «было → стало» (одна крупная цифра — «стало»,
   «было» — зачёркнутым или мелко рядом; решает исполнитель, `/ux` проверит), строка «не отдадите банку N» (если `saved`
   > 0), короткая похвала 1–3 слова; одна главная — «Готово» (закрыть). Долг закрыт целиком — «Долг закрыт» вместо
   «стало 0».
3. Слова — без механики («досрочка применена» → не нужно); числа — только из `prepayBeforeAfter`.

## Тесты

- Юнит `prepayBeforeAfter`: один кредит; два кредита (до/после — сумма обоих); взнос закрыл кредит; «снизить платёж»
  (остаток тот же, что «сократить срок»); `saved` = `record.saved`; деньги — целые.
- DOM `PrepaySheet`: после подтверждения — `data-prepay-before` / `data-prepay-after` с числами функции, «не отдадите
  банку» при `saved > 0` и без строки при 0.
- e2e (дописать `e2e/f2-block2-prepay.test.ts`): «было» = крупная цифра «Долгов» до, «стало» = после.

## Критерии приёмки

- После «Внёс досрочно» человек видит, как уменьшились все долги, и сколько не отдаст банку; цифры совпадают с «Долгами».
- Build, весь vitest; стенд Chrome 390, обе темы, крупная цифра ≤ 34 px; Handoff — правило 12 по листу результата.

## Вне скоупа

- Анимация, конфетти; «Это приближает: мечта» (`closerWish`) из старого блока — не переносить без решения `/ux`;
  поздравления на других экранах.

## Задача

1. `types/finance.ts`: у `Account` поле `spendBy?: PersonId | 'both' | null` — хозяин счёта для трат; `null` — отметку
   сняли явно (единственная карта больше не «сама»). Старые счета без поля — как раньше.
2. `lib/finance.ts`: `spendAccountOf(accounts, person)` → счёт для трат человека или `null`; `spendOwners(account,
   accounts)` → кто тратит с него (`PersonId[]`). Правила: явная отметка (`spendBy` = человек или `'both'`); нет явных
   отметок ни у одного счёта и ровно одна живая тенговая карта (`kind: 'card'`, без валюты) — она, хозяин «оба». Вклады,
   конверты, валютные — никогда. У человека один счёт для трат.
3. Стор: `setSpendAccount(accountId, owner)` — пишет `spendBy`; если человек был хозяином другого счёта — снимает его
   оттуда (`'both'` → остаётся партнёр; свой → `null`) одной правкой документа.
4. `AccountSheet` (участник, счёт `card`/`cash` в тенге): строка «Траты отсюда» — переключатель; включена и в семье двое —
   выбор хозяина «Я / <имя партнёра> / Оба» (`Segmented`). Семья из одного — только переключатель. Подсказка `Hint` (?) —
   одной полной фразой, что траты уменьшают остаток (без механики выписок). Viewer — строка без кнопок (кто тратит).

## Тесты

- Юнит `spendAccountOf` / `spendOwners`: явная отметка; `'both'`; единственная карта без отметок — «оба»; две карты без
  отметок — `null`; вклад/конверт/валютная — никогда; явный `null` у единственной карты — `null`; удалённый счёт — нет.
- Юнит стора `setSpendAccount`: перенос с одного счёта на другой; `'both'` → у старого остаётся партнёр; одна запись
  документа.
- DOM `AccountSheet`: участник — переключатель и выбор хозяина (двое) / без выбора (один); вклад — строки нет; viewer —
  без кнопок.

## Критерии приёмки

- В листе карты можно отметить «Траты отсюда» и выбрать хозяина за ≤ 2 нажатия; единственная карта отмечена сама.
- Build, весь vitest; стенд Chrome 390, обе темы; Handoff — правило 12 по листу счёта.

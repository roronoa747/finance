# F2-08 — Баланс на «Счетах» и «Неделе» (фронт)

Блок 3 · MVP · Репо/каталог: `frontend/` · Зависит от: F2-07 · Роли: участник, viewer (только «Счета»)

## Контекст (что уже есть)

- Решение — Р-7: баланс — в строке счёта «Капитал → Счета» и тихой строкой на «Неделе» («На карте 245 000»), без второй
  крупной цифры.
- «Счета» — `components/money/CapitalLists.vue:208-227`: `Row` с `:value="plain(a.amount)"` и подписью `accountMeta(a)`
  :81-85 (вид · валюта · «личный/общий»). После F2-07 `a.amount` уже тает тратами — число в строке меняется само.
- «Неделя» — `views/Week.vue` (697 строк); тихая строка-образец — `components/applepay/ApplePayWeekLine.vue` (Week.vue:522).
  Лист счёта открывается адресом `/money?account=<id>` (`CapitalLists.vue:175`).
- Правила владельца: одна крупная цифра у предмета; подписи `--ink-2`; цвета — только токены `style.css`; текст минимум.

## Задача

1. «Счета»: у счёта для трат подпись строки говорит, чей он для трат («траты · оба» / «траты · <имя>» — коротко, вместо
   «общий»); число — уже тающий остаток (ничего не пересчитывать на экране).
2. «Неделя»: тихая строка «На карте N» (у наличных — «Наличные N»; `N` — `financeStore.accounts` остаток счёта
   `spendAccountOf(…, я)`), нажатие — лист счёта (сверить остаток). Счёта для трат нет — строки нет. Место — рядом с
   прочими тихими строками «Недели», не крупно; `/ux` проверит.
3. Viewer: на «Неделе» строки нет (своего счёта для трат нет); на «Счетах» видит остаток и подпись.

## Тесты

- DOM `CapitalLists`: счёт для трат — подпись с хозяином; остаток — тающий (`accountBalance` с `spent`).
- DOM `Week`: есть счёт для трат — `data-week-balance` с остатком; нажатие ведёт на лист счёта; нет счёта — строки нет;
  viewer — строки нет.
- e2e (дописать `e2e/f2-block3-spend-balance.test.ts`): ручная трата на «Неделе» → строка «На карте» уменьшилась на её
  сумму; у партнёра — то же число на «Счетах».

## Критерии приёмки

- «Сколько денег у меня сейчас» видно на «Неделе» одной тихой строкой и в «Счетах»; числа совпадают.
- Build, весь vitest; стенд Chrome 390, обе темы, ошибок консоли нет; Handoff — правило 12 по «Неделе» и «Счетам».

## Вне скоупа

- Крупная цифра баланса, график, история баланса; показ на «Месяце» (не меняется).

## 1. Цель

Тестер без подсказок вводит кредит и досрочку, видит, как уменьшился долг («было → стало»), отмечает платёж у самого
кредита на «Долгах» и знает, сколько денег на карте сейчас — траты сами уменьшают баланс счёта для трат. Числовые поля
не прячут нижнюю кнопку клавиатурой. Заодно закрыт бэклог «Хвосты». Успех — по каждому пункту тест на правило + e2e,
Chrome 390 в обеих темах, смоук прода после каждого блока; тестер повторяет свои сценарии.

Режим: Блок 1 — **S** (без `/ux`; правило 12 проверяет критик явным пунктом), Блоки 2 и 3 — **M с `/ux`**.

## 2. Зафиксированные решения

- **Р-1. Клавиатура — везде**: во всех числовых полях клавиша «Готово» прячет клавиатуру; лист поднимается над ней —
  нижняя кнопка видна. *(бриф, р.1)*
- **Р-2. «Оплатил» у строки кредита на «Долгах»** — небольшой кнопкой, как «Отдал» у долга человеку; оплачено в этом
  месяце — ✓ у суммы; та же отметка, что в «Месяце» и листе кредита. «Месяц» не меняется. *(бриф, р.1)*
- **Р-3. «Внёс досрочно»** — небольшая кнопка в листе кредита вместо тихой «Посчитать досрочно»: сумма → долг пересчитан
  сам (действующий `applyPrepayment`); калькулятор — за «подробнее» (правило 12). *(бриф, р.1)*
- **Р-4. «Было → стало»** после досрочки: крупно остаток всех долгов «было → стало» и «не отдадите банку N»; числа считает
  `finance.ts`; показ — в листе после «Внёс досрочно». *(бриф, р.1; место — дефолт)*
- **Р-5. Счёт для трат** — один на человека или общий: в листе счёта отметка «Траты отсюда» с выбором хозяина (я / партнёр /
  оба); единственная карта — счёт для трат сама. Депозиты и конверты не тают. *(бриф, р.2)* Хозяин единственной карты без
  отметки — «оба». *(дефолт составителя)*
- **Р-6. Что тает баланс** — все траты после сверки (`amountSetAt`): ручные, Apple Pay, выписка; трата, уже отмеченная
  платежом, и одна покупка из двух источников — один раз. Приходы (возвраты, переводы себе) — плюсом; зарплата — как
  сейчас, по «Пришла», выписочная зарплата второй раз не прибавляется. *(бриф, р.2; приходы — дефолт)* Перевод себе **со**
  счёта (на депозит, в конверт) — минусом, зеркало прихода. *(дефолт составителя — сверить на `/ux` Блока 3)*
- **Р-7. Где баланс** — в строке счёта «Капитал → Счета» и тихой строкой на «Неделе» («На карте 245 000»), без второй
  крупной цифры. *(бриф, р.2)*
- **Р-8. Данные** — без миграций БД, всё в документе семьи; суммы трат партнёра — итогами, без его операций. Viewer видит
  баланс и ✓, кнопок нет. *(бриф, дефолт)* Уточнение: хозяин — поле счёта; «потрачено с последней сверки» каждый телефон
  пишет **своей записью** документа семьи (по образцу `spendTotals`, id `<счёт>:<человек>`) — одно поле счёта на двоих
  слияние по `updatedAt` затёрло бы. *(дефолт составителя, `lib/merge.ts` правило 2)*
- **Р-9. Хвосты «Хвостов»** — Х-24, Х-25, Х-27 — принятый долг; ветка `fb-hf1-review-waits` удаляется (локально и на
  `origin`); бэклог «Хвосты» → архив — первой задачей бэклога. *(бриф, р.3)*
- **Р-10. Порядок и прод** — мелкое сначала; каждый блок на прод отдельно, с откатом promote прошлого Production.
  *(бриф, р.3)*

## 6. Технический контекст

**Кредиты и отметки** (F2-03, F2-04, F2-05).
- Кредиты в сторе — производные: `financeStore.credits` = `derivedCredits(doc.credits, payments)` (stores/finance.ts:299),
  `principal` — остаток на сейчас с учётом отметок и досрочек. Сумма открытых — `openDebt(credits)`
  (`lib/finance.ts:791`; `debtsOverview` :2935).
- Отметка платежа: `financeStore.markPaid('credit', id, by, { period, amount?, accountId })` (stores/finance.ts:1511): сумма
  по умолчанию — `c.payment`, месяц уже отмечен — вернёт ту же запись. Оплачено ли — `paidFor(payments, 'credit', id,
  period)` (lib/finance.ts:1577). Счёт прошлой оплаты — `lastAccountFor(payments, id, accounts)` (:1947): `undefined` —
  спросить счёт листом `MarkSheet` (`first-time`), `null` — «только отметить».
- Досрочка: `financeStore.applyPrepayment(creditId, by, { amount, mode: 'term'|'payment', accountId })` (stores/finance.ts:1707)
  → запись `Payment` `kind: 'prepay'` с `saved` (не отдадим банку), `prevPayment/newPayment` при «снизить платёж»;
  `removePrepayment(id)` :1769. Предпросмотр — `lumpPlan(principal, rate, payment, amount, mode)` (lib/finance.ts:479).
- Листы: `components/capital/CreditSheet.vue` (лист кредита; эмит `payoff` → калькулятор), `components/capital/PayoffSheet.vue`
  (калькулятор + «Применить досрочку» в режиме «Разово» :212-253, «Применённые досрочки» со «Снять» :266-309). Оба

  `components/money/PlanSquare.vue`.
- Кредит без ставки (`rateUnknown`) калькулятор не открывает (PayoffSheet.vue:46); долг человеку (`person`) — без
  банковских полей и досрочки.

**Счета** (F2-06, F2-07, F2-08).
- `Account` — `types/finance.ts:449` (`amount` — база ручной сверки, `amountSetAt` — якорь, `kind: card|cash|deposit|envelope`,
  `currency`). Видимый остаток — `accountBalance(a, payments, ctx)` (lib/finance.ts:1623); стор отдаёт счета уже с ним
  (`withBalance`, `balanceCtx()` stores/finance.ts:286-294) — экраны берут `financeStore.accounts[].amount`. Тот же `ctx`
  идёт в `shiftedBase` (`shiftAccountAmount` :1404) и сравнение «не изменилось» в `updateAccount` :1372 — новый вклад в
  баланс обязан пройти через `balanceCtx()`, иначе сдвиг и сверка разъедутся с экраном.
- Счета создаются общими (`NewAccountSheet` → `addAccount(…)` без `isPrivate`); личные (`privateDoc.accounts`) стор
  читает, UI их не создаёт. Список — `components/money/CapitalLists.vue:208-227` (строка `Row`, подпись `accountMeta`),
  лист — `components/capital/AccountSheet.vue`.
- Операции — личные, в сторе `stores/operations.ts`: `all` :180 (свои с правками; ручные траты, Apple Pay `source:
  'tap'|'push'`, выписка), `shown` :395. Дубли телефон ↔ выписка стор уже снимает (`draftReplaced` → надгробия при
  `send`). Трата — `isSpend(op)` / `spendOf(op)` (`lib/statements/model.ts:404/411`, учитывает `refund`, `internal` — не
  трата); отмеченные платежом — `totalMarks(ops).marked` (operations.ts:605, `markedOps` в `lib/statements/matching.ts:180`).
- Итоги в документ семьи пишет `writeTotals` (operations.ts:437) — образец «своя запись по id, ноль явно, без лишних
  записей» (`sameTotal`). Слияние: `lib/merge.ts` — списки с `id` сливаются по id, поля сущности — по `updatedAt`.

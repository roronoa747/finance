## Задача

1. `POST /api/ai/dream` (`family`, через гейт): тело `{phrase (1…200 символов), themes: [{id, name}] (≤ 40), photos:
   [{id, theme, name}] (≤ 150)}` ≤ 32 КБ, строго. Фраза с 6+ цифрами подряд → 400 (гвард как у продавцов).
2. Инструкция: по фразе — короткое название мечты (2–4 слова, без цифр), тема из присланных и 3 фото из присланных
   (лучше всего подходящие, разные); не уверен с фото — меньше. Схема `{name, theme, photos: string[]}`, `theme` и
   `photos` — `enum` из присланных id.
3. Ответ 200 `{name, theme, photos (0…3, только из присланных, без дублей)}`; пустое `name` → брак → 502.

## Тесты

- Фейковый Claude: исходящее тело — инструкция, фраза как есть, темы и фото — больше ничего; чужие id выброшены; > 3 фото
  — обрезаны; 6+ цифр → 400; > 200 символов → 400; гейт (viewer 403, без флага 503, лимит 429).
- Живой (`AI_LIVE=1`): «море с детьми летом», «машина для семьи», «квартира в Астане» — разумные темы и фото; время —
  в Handoff.

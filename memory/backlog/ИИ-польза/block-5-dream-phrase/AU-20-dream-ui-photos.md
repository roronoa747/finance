## Задача

1. **Новые фото:** темы, которых не хватает для фраз («море», «горы», «отдых с детьми», …) — по 5 фото по правилам шапки
   `goalTemplates.ts`; вариантами существующих тем или направлениями путешествий (в сетку плиток новые плитки не
   добавлять — решение `/ux`). Список новых — в Handoff (id, место, автор).
2. **«Словами»:** на шаге `pick` (не в первом запуске, только `ai.available` и согласие не «Не надо») — тихая `ghost`
   «Словами» → лист с полем фразы (до 200 символов) и «Найти» → `ensureConsent` → запрос → на шаге `pick` название
   подставлено, 3 фото рядом — выбор одного (как вариант темы) → «Дальше» → прежняя форма (сумма и срок — человек).
   Ошибка / лимит — тост, форма как без ИИ.
3. Уходит: фраза как есть, список тем (`id`, `name`) и фото (`id`, `type`, `name`/`place`) — без данных семьи.

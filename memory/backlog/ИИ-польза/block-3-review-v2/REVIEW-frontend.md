## Находки

### Н-1 · средняя · Сборка разбора v1 — мёртвый код вместе с тестами

`frontend/src/lib/aiSummary.ts:61`, `:106–171`, `:174–179`. Ручка v2 на `{summary}` отвечает 400 (AU-12), стор шлёт только
`buildReviewFacts` (`stores/ai.ts:138`), демо — тоже (`demo.ts:34`). `buildMonthSummary`, `summaryNumbers`, `SummaryEnv`
больше никто не зовёт: grep по `src/` и `e2e/` находит их только в `aiSummary.test.ts`. Живы лишь `maskNames` (берёт
`aiFacts.ts:37`) и тип `MonthSummaryAI` (рисует «что ушло» сохранённых разборов v1 — до 12 в документе,
`AiReviewSheet.vue:123`). Мёртвый код держит 7 тестов из 9 в `aiSummary.test.ts`, и они проверяют то, что в модель уже не
уходит; следующий читатель решит, что сводка v1 ещё в деле (комментарий `:102` так и говорит).

**Рекомендация.** Удалить `buildMonthSummary`, `summaryNumbers`, `SummaryEnv` и ставшие лишними импорты (`who` нужен
`maskNames` — оставить); в `aiSummary.test.ts`
оставить только тесты `maskNames` (`:106`, `:128`). Тип `MonthSummaryAI` — с комментарием «только чтение разборов v1,
сохранённых до v2». Файл можно оставить с этим именем — переносить `maskNames` в `aiFacts.ts` необязательно.

**Вердикт: клинап** — недоснесённое этим блоком: v2 заменил v1 целиком, удаление не меняет поведения.

### Н-2 · средняя · «✓ Сделано» у шага — по одной цели сдвига, без источника

`frontend/src/components/ai/AiReviewSheet.vue:80–85`. `done` — «в этом месяце есть сдвиг в ту же цель»
(`sameTo(s.to, c.shift.to)`); `from` не сравнивается. В ту же мечту пишет и «Вернуть срок» (`GoalDetail.vue:722` →
`DoSheet` → `addPlanShift`, кандидат `return:<goalId>` — тоже `to: {goalId}`). Случай: разбор советует «из плана «Кафе» в
мечту «Япония»», человек на экране мечты нажал «Вернуть срок» (сдвиг из остатка) → у шага разбора «✓ Сделано», «Сделать»
пропала (`fresh` при `done` — null), а план «Кафе» не урезан. Обратное тоже: перенос вернётся после отмены «Вернуть срок».
Проверено чтением: условие явное, тест (`AiReview.dom.test.ts:392`) смотрит только счастливый путь. Сравнение «та же цель»
уже есть в `finance.ts:3429` (`addOf`) — в листе вторая копия.

**Рекомендация.** В `finance.ts` — `shiftMade(shifts, shift)`: живой сдвиг того же `period`, той же цели (`to`) и того же
источника (`'rest'` или тот же `spend` + `categoryId`); лист зовёт его вместо своего `sameTo`. Тест: «Вернуть срок» в ту же
мечту из остатка → у шага `move` разбора «Сделать» остаётся; свой «Сделать» → «✓».

**Вердикт: клинап** — неверный «✓» прячет действие (правило 12: «сделано — ✓ у суммы»); правка — одно условие и тест.

### Н-3 · низкая · Вход плана для фактов собирается третий раз

**Рекомендация.** `buildReviewFacts(doc, input, reason)` с `input = finance.planInput(key)`: стор и `demo.ts` передают

**Вердикт: клинап** — три вызова и один помощник тестов; без него вход разъедется при первом новом поле.

### Н-4 · низкая · «Мои отметки зарплаты месяца» — два одинаковых фильтра

**Вердикт: клинап** — две копии одного правила повода; разъедутся — повод «зарплата» начнёт срабатывать не там.

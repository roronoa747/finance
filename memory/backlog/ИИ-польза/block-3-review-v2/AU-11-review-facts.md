## Задача

1. `buildReviewFacts(doc, key, now, env)` → `ReviewPayload { facts: ReviewFact[], candidates: ReviewCandidate[] }` и
   локально `byId: Map<string, StepCandidate>`. Факты (id `f1…`, не больше 30), только то, что есть:
   - доход месяца и разница с прошлым месяцем; платежи месяца и новые платежи (названием); остаток или нехватка;
   - мечты очереди (до 3, первая — главная): срок, сдвиг месяца с причиной (`dreamShift`), сколько осталось;
   - подушка — на сколько месяцев хватит; долги — дата «без долгов», первый долг и ставка;
   - 1–2 главных раздела трат (`over` первыми, иначе крупнейший сверх плана): факт, обычно, план, % дохода;
   - главный образ месяца (крупнейший из `habitImages` и `interestImage`): привычка, сумма в месяц, во что складывается
     (`value` — строка образа, `raw` — числа образа);
   - для повода `month` — итог закрытого прошлого месяца (траты против плана), если выписки его покрывают.
2. Кандидаты (`c1…`, до 3) — из `stepCandidates`: `{ id, kind, about (без цифр: «из плана «Кафе» в мечту «Море»»),
   value (сумма), effect (строкой: «на 2 недели раньше») }`.
3. Все `about` — через `maskNames` (имена участников) и без цифр; названия статей, целей, разделов — как есть (согласие
   «без ваших имён»). Никакой своей арифметики над деньгами — только вызовы `finance.ts`.
4. `factsLines(payload)` — читаемый список для «что ушло» (about: value), не JSON.

## Тесты

- `aiFacts.test.ts` на `planFamilyDoc` с тремя месяцами итогов и снимком: каждый вид факта; `about` не содержит цифр

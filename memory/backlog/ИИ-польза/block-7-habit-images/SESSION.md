# Блок 7 — Образы трат · сессии

**Цель блока:** привычку, которую семья чувствует, но не считает (такси, кофе навынос, доставка, обеды, мелкие покупки,
проценты банку), приложение показывает одной строкой-образом у её раздела — во что она складывается — и даёт одно
действие: «Сделать мечтой», «В желания», «Перенести в мечту». Всё — код, у всех семей. Идёт после Блока 2, до Блока 3.

Сессии: исполнитель ⬜ · критик ⬜ · ux ⬜ · приёмка ⬜

## Промпт критика — уровень review · Opus 5.5 · effort xhigh

```
/critic ИИ-польза 7
```

Блок-специфика:

- Честность (Р-30): образ только у привычки 3 месяца подряд; «окупится» не дольше 12 месяцев; машина — без кредита;
  числа образа = расчёт `finance.ts` (сверить вручную два образа). «Как посчитали» (Р-31): у каждой цены источник и
  дата, арифметика сходится с образом; устаревшие цены справочника (тур 2023) — заменены свежими или помечены.
- Граница данных: в общий документ — только счётчик и сумма привычки, без продавцов и дат.
- «Перенести в мечту» каждый месяц: «Отменить» возвращает и план, и взнос; два телефона не затирают друг друга.
- Актуализировать промпт исполнителя Блока 3 (AU-11 — факт «главный образ месяца»: функции и форма); §6 — «После
  Блока 7».

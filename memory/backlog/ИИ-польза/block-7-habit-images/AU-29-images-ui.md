## Задача

1. Лист раздела: под строками сравнения — строка-образ (`--ink`, 15 px, без новой крупной цифры) и справа небольшая
   `secondary sm` с действием образа; viewer — строка без кнопки.
2. Действия:
   - «Сделать мечтой» → `addGoal` (название и цена из образа, `monthly` = сумма привычки) → переход на экран новой цели;
   - «В желания» → `addWish` (название, цена) → тост «В желаниях»;
   - «Перенести в мечту» → лист подтверждения с готовыми цифрами («−N из плана «Кафе» каждый месяц · +N в «Японию» ·
     на 3 месяца раньше»), брендовая «Перенести»: план раздела участника с бо́льшим планом −N (плана нет — только
     взнос), `setGoalMonthly(мечта, monthly + N)`; тост «Отменить» возвращает оба значения;
   - «Как закрыть быстрее» → `/money/debts/faster`.
3. «Долги»: строка процентов под строкой первого долга («За год банку уходит новый iPhone») с «Как закрыть быстрее»,
   только при `interestImage`.
4. Демо — работает локально.

## Тесты

- DOM `SpendCategorySheet`: образ раздела (один, крупнейший); viewer — без кнопки; нет образа — строки нет; «Перенести в
  мечту» → план −N и взнос +N в документе → «Отменить» → прежние значения; «Сделать мечтой» → цель с ценой и взносом;
  «В желания» → желание.
- DOM `DebtsWidget`: строка процентов с кредитами под ставку; без них — нет.

## Критерии приёмки

- `cd frontend && npm run build && npx vitest run` зелёные.
- Браузер (390 px, обе темы, member / viewer / демо): лист «Транспорт» с образом такси, «Кафе» — кофе или доставка;
  «Перенести» → «Месяц» показывает новый план и взнос; партнёр после синка видит то же.
- Handoff по правилу 12: действие — у строки-образа в листе раздела; на экране новых точек и строк нет.

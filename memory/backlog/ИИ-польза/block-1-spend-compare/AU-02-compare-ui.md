## Задача

1. **Раскрытая «Траты» — разделы семьи.** Вместо блоков по участникам — строки `spendCompare().rows`: название, одна
   цифра (факт месяца; выписок нет — план с подписью «план»), тонкая полоса факт/план, если план есть; точка `--brand`
   у строки с `over`. Нажатие строки — лист раздела. Внизу раздела — тихая «+ Раздел» (лист «Траты на месяц» как
   сейчас; участник — свой, в семье из двух — выбор участника в листе). Участник без плана и трат — без отдельной строки.
2. **Заголовок «Траты»:** `dot = rows.some(r => r.over)` — зовёт издалека (правило 12), мета-строка прежняя.
3. **Лист раздела** `SpendCategorySheet.vue` (`Sheet`, заголовок — название раздела): крупно — факт месяца; под ним
   строками (`--ink-2`, коротко): «N % дохода» · «обычно у вас N» (нет — «обычно — когда будет 2 месяца выписок») ·
   «план N» (нет — «плана нет»); рекомендация «до плана: +N в «<мечта>» · на <earlierLabel> раньше» — только при
   `advice`; справка РК одной мелкой строкой «у вас X % · в Алматы Y %» с `Hint` («Доля <группы> в тратах семей Алматы,
   stat.gov.kz, II кв. 2025») — только у раздела с группой. План по участникам — строками «<имя> · N» с «Изменить» →
   прежний лист «Сколько в месяц» (member); viewer — без «Изменить». Брендовой кнопки в листе нет (действия плана —
   тихие, правило 12).
4. Лист по адресу не нужен (открывается только с «Месяца»); закрытие — как у прочих листов `MonthPlan`.
5. Демо — на своих данных (сервер не зовётся); семья без выписок — строки по плану, точек нет.

## Тесты

- DOM `MonthPlan` (обновить затронутые тесты раскрытой «Траты»): строки разделов семьи вместо блоков участников;
  точка у строки и у заголовка при `over`; без выписок — план без точек; viewer — строки и лист без «Изменить» и «+
  Раздел»; «+ Раздел» — лист «Траты на месяц».
- DOM `SpendCategorySheet`: все строки при полных данных (% дохода, обычно, план, рекомендация, справка; `Hint` —
  сначала открыть); «обычно» нет — подпись; рекомендации нет при `usual ≤ plan`; свой раздел — без справки РК;
  «Изменить» у участника открывает «Сколько в месяц» с его суммой.

## Критерии приёмки

- `cd frontend && npm run build && npx vitest run` зелёные.
- Браузер (стенд, 390 px, обе темы, member и viewer): раскрытая «Траты» — разделы семьи, точки ровно у разделов выше
  обычного, лист раздела по нажатию; числа листа = `spendCompare` (сверить 2 раздела вручную); кольцо и остаток не
  сдвинулись.
- Handoff по правилу 12: главное действие экрана не изменилось; действие у раздела — лист; что ушло в подсказку
  (справка РК); что скрыто (план по участникам — в листе).

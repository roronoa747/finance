Блок 2 · MVP · Каталог: `frontend/src/views/Dreams.vue`, `views/GoalDetail.vue`, `components/kit/DreamCenter.vue`, новый `components/plan/DoSheet.vue` · Зависит от: AU-05 · Роли: member (действия), viewer (только метка), демо

  «Вернуть срок» у мечты — то же действие. Правило 12: действие живёт у своего предмета небольшой кнопкой; крупная
  кнопка во всю ширину — только подтверждение в листе; одна крупная цифра у предмета.

  `actions`), строки целей — `kit/ThumbRow` :170 (подпись `whenOf` :71 — сейчас только «на паузе»); `termOf` :66.

## Задача

1. **Метка.** Герой «Мечт» — строка под названием (`DreamCenter`: новый необязательный проп `note`, `--ink-2`, 13 px;
   сдвиг дальше — с `--warn`-точкой, ближе — `--ok`); строки целей — метка вместо пустой подписи (`whenOf`); экран цели —
   строкой под `doneTitle`. Метка не спорит с процентом героя (одна крупная цифра).
2. **«Вернуть срок».** На экране цели, у метки «дальше» — тихая `secondary sm` «Вернуть срок» (member; есть
   `returnTermShift`); на «Мечтах» кнопки нет — нажатие героя ведёт на экран цели, как сейчас.
3. **`DoSheet.vue`** (`Sheet`) — один лист для любого кандидата (его же откроет шаг разбора в Блоке 3): заголовок по виду
   («Перенести в мечту», «Внести досрочно», «Отложить в подушку»; из «Вернуть срок» — «Вернуть срок», кнопка
   «Вернуть»); крупно — N; строками — откуда → куда («из плана
   «Кафе» этого месяца» / «из остатка месяца»), эффект («на 2 недели раньше» / «на 3 месяца раньше · −N процентов» /
   «подушки хватит на 2,1 мес.»), «Только этот месяц». Подтверждение — брендовая во всю ширину («Перенести» /
   «Внести» / «Отложить»), под ней тихая «Не сейчас». Подтвердил → `addPlanShift`, лист закрыт, тост «<Мечта> ближе на
   N дней» с действием «Отменить» (`undoPlanShift`). Viewer лист не открывает (кнопок нет).
4. **Видно в «Месяце»:** после сдвига «Месяц» показывает новый план (раздел −N, строка мечты +N — прежняя разметка);
   ничего не дорисовывать.
5. Демо — работает локально (документ демо), без сервера.

## Тесты

- DOM `Dreams`/`DreamCenter`: метка у героя и у строки при сдвиге ≥ 7 дней; нет снимка — метки нет; viewer — метка есть.
- DOM `GoalDetail`: «Вернуть срок» у метки «дальше» (member) → `DoSheet` с N и эффектом → «Вернуть» → сдвиг в
  документе, метка ушла (сдвиг ≤ 0), тост «Отменить» → сдвиг надгробием, метка вернулась; viewer — кнопки нет; денег нет
  (`returnTermShift` → null) — кнопки нет.
- DOM `DoSheet`: три вида — заголовок, строки, кнопка; «Не сейчас» ничего не пишет.

## Критерии приёмки

- `cd frontend && npm run build && npx vitest run` зелёные.
- Браузер (390 px, обе темы, member / viewer / демо): метка на герое и экране цели; «Вернуть срок» → лист → подтвердить →
  на «Месяце» план раздела меньше, взнос мечты больше; партнёр после синка видит тот же план.
- Handoff по правилу 12: главное действие («Вернуть срок») — у метки срока на экране цели; что в подсказке; что скрыто.

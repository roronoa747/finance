## Задача

1. `affordWhy(state, amount, now)` → `{ kind: 'short' | 'tight', from: { day, key }, to: { day, key }, name } | null`:
   только при `knowsCash`; баланс = `onAccounts − amount`, платежи окна по порядку (`when`, `day`); первый платёж, после
   которого баланс < 0 → `short`, окно — от его дня до дня перед зарплатой, `name` — его название; иначе, если остаток
   после всех платежей окна < `LOW_REST_SHARE × income` → `tight`, окно — от дня самого крупного платежа окна до дня
   перед зарплатой; иначе `null`. Строка — `affordWhyText` рядом: «тесно 20–24-го — <платёж>» (окно через месяц —
   «тесно с 28-го до 5-го»).
2. Лист «Хватит?»: строка под вердиктом (`--ink-2`, одна строка), только когда `affordWhy` не `null`.
3. `firstDebt(state, key)` → `{ name, rate } | null`: первый из `costliestCredits` (без `rateUnknown`), только если
   открытых долгов с процентами ≥ 2 (при одном «первый» не нужен). «Долги»: строка под «без долгов — к …» — «первым —
   <название>: ставка <N> % — самая высокая» (финал слов — `/ux`); без `freeMonth` — строка всё равно.
4. Числа — `finance.ts`; ничего не пишется.

## Тесты

- `finance`: `affordWhy` — `short` (баланс уходит в минус на платеже автокредита 20-го, зарплата 25-го → 20–24),
  `tight` (остаток < 15 % дохода, крупнейший платёж), `null` (запас есть; без счетов); окно через границу месяца.
- `firstDebt`: два долга — дороже первым; ставка неизвестна — пропуск; один долг — `null`.
- DOM `AffordSheet`: строка у «Нет» и у «Да, тесно»; нет — без строки. DOM `DebtsWidget`: строка при двух долгах; viewer
  видит.

  строка первого долга.

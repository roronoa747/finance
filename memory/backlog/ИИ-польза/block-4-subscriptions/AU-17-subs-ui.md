# AU-17 — Метки, «Добавить» и имена в подписках «Денег» (фронт)

Блок 4 · MVP · Каталог: `frontend/src/components/money/CapitalLists.vue`, `components/capital/ObligationSheet.vue`, `components/capital/NewObligationSheet.vue`, `stores/ai.ts`, `api/client.ts` · Зависит от: AU-16 · Роли: member (действия, свои находки), viewer (метки), семья без ИИ (код без имён)

## Контекст (что уже есть)

- Р-8: живёт в платежах-подписках на «Деньгах», издалека зовёт точкой; «Добавить» рядом с найденной; имя от ИИ человек
  принимает. Р-13: имена — только семьи с ИИ и после согласия v2 (пункт «Названия продавцов и подписок» уже в списке,
  AU-10); «подорожала» и «нашли новую» — у всех; демо — без имён. Правило 12: действие у предмета; точка — на строке
  «Подписки · N».
- «Деньги»: строка «Подписки · N» — `CapitalLists.vue:282` (`data-subs`, раскрытие по людям `subsByWho` :97, :291);
  лист подписки — `ObligationSheet` (:366, правка суммы — новая версия), новый платёж — `NewObligationSheet` (:375; вид
  «Подписка»).
- Расчёты — AU-15 (`subscriptionRise`, `subscriptionsFound`, `subsDismissed`); ручка — AU-16 (`titles: true`); согласие —
  `ensureConsent`, `available` (`stores/ai.ts`).

## Задача

1. Строка «Подписки · N»: точка, если есть «подорожала» или найденные (свои). В раскрытом списке: у подорожавшей —
   подпись «подорожала: 2 990 → 3 490» (`--warn`), нажатие — лист подписки (правка суммы — как сейчас); ниже —
   «Нашли · K»: строки найденных (название, сумма, день) с «Добавить» (→ `NewObligationSheet`, заполнено: имя, сумма,
   день, вид «Подписка») и тихим «Не подписка».
2. Имена (ИИ): у найденных и у подписок с «сырым» названием (заглавные, `.COM`, `/BILL` — правило константой) — один
   запрос пачкой `titles: true` при раскрытии (после `ensureConsent`, кэш на устройстве с чисткой, ключ в `LOCAL_KEYS`);
   имя-подсказка чипом «Apple iCloud?» с ✓ → «Добавить» берёт его, у заведённой — переименование одним нажатием.
   Без ИИ / «Не надо» / ошибка — без чипов, как раньше.
3. Viewer — метки видны, действий нет. Демо — код работает, имён нет.

## Тесты

- DOM `CapitalLists`: точка при подорожании и находках; «Добавить» → лист с заполненными полями; «Не подписка» →
  находка исчезла и на втором телефоне человека (личный документ); viewer — без кнопок.
- Имена (фейковый клиент со счётчиком): один запрос на раскрытие, повтор — 0 (кэш); ✓ — переименование; без ИИ — 0
  запросов.

## Критерии приёмки

- `cd frontend && npm run build && npx vitest run` зелёные.
- Браузер (стенд с ключом, 390 px, обе темы): на копии настоящей выписки — понятные имена, «подорожала», «нашли новую» →
  «Добавить».
- Handoff по правилу 12: главное действие («Добавить») — у найденной строки; звать — точкой на «Подписки · N».

## Задача

1. Необязательное поле тела `titles: true` → у каждого элемента ответа `title: string | null` — короткое человеческое
   имя сервиса («Apple iCloud», «Яндекс Плюс»); не уверен — `null`. Без поля — ответ как раньше (контракт Блока 3 «ИИ»
   не ломается). Инструкция — одна строка про имена подписок; в модель уходят те же только названия.
2. `title` ≤ 40 символов, без цифр 6+; иначе `null`.

## Тесты

- Фейковый Claude: с `titles` — схема с `title`, без — прежняя; длинный/с цифрами `title` → `null`; исходящее тело —
  только названия и разделы; гейт — как у ручки продавцов.
- Живой (`AI_LIVE=1`): 10 обезличенных продавцов подписок — имена разумные; время — в Handoff.

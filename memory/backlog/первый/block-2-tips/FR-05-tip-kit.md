# FR-05 — Пузырь у предмета и «видел» (фронт)

Блок 2 · MVP · Репо/каталог: `frontend/src/components/kit/`, `frontend/src/lib/storage.ts` · Зависит от: Блок 1 🏁
(выкладка) · Роли: все (member, партнёр, viewer, демо)

## Контекст (что уже есть)

- `kit/Hint.vue` (85 строк) — знак «?» с окном по нажатию: окно `position: fixed` под знаком, прижато к краям
  (`kit/hintPosition.ts`), закрывается нажатием мимо, Escape и прокруткой. Тесты — `Hint.test.ts`, `Hint.dom.test.ts`.
  Это «подсказка по запросу»; пузырь обучения показывается сам и закрывается только «Понятно».
- Хранение на устройстве — `lib/storage.ts` (`readStorage`/`writeStorage`, без исключений). Ключи, которые выход
  стирает, — `LOCAL_KEYS` в `stores/finance.ts:147` (туда же `START_ANSWERED_KEY` — «другой пользователь на этом
  телефоне — свои вопросы»).
- Цвет — только токены `style.css` (пара для тёмной темы); кнопки — `ui/Button.vue`.

## Задача

1. Ключ `TIPS_SEEN_KEY = 'ff_tips_seen'` в `lib/storage.ts` — список id увиденных подсказок; функции «видел ли» и
   «отметить» рядом с ключом. Ключ — в `LOCAL_KEYS` (Р-7: как ответы первого запуска; выход стирает — следующий вход на
   этом телефоне видит подсказки снова, это допустимо).
2. Компонент кита `kit/Tip.vue` — пузырь у предмета: обёртка над предметом (слот) + пузырь со стрелкой к нему, 1–2
   короткие строки и кнопка «Понятно» (`ghost sm` или `secondary sm` — не брендовая: главное действие экрана остаётся
   одно). Пропсы — `id` и текст; показывается, если `id` не в «видел»; «Понятно» — отметка и скрытие навсегда. Без
   затемнения и без блокировки экрана (тур — не-скоуп, Р-7); нажатие самого предмета работает как обычно и тоже
   закрывает пузырь с отметкой.
3. **Одна за раз** (Р-7): одновременно на экране — не больше одного пузыря (простой общий флаг/реестр в модуле
   компонента: первый смонтированный показывается, остальные ждут); пузырь не показывается поверх открытого листа
   (`Sheet`) — ждёт его закрытия.
4. Положение — над или под предметом, прижато к краям экрана на 390 px (переиспользовать `hintPosition`, если
   подходит); при прокрутке едет с предметом (не `fixed`, в отличие от `Hint`).

## Тесты

- `storage.test.ts`: «видел» пуст → отметка → «видел»; мусор в ключе — пустой список; ключ в `LOCAL_KEYS`.
- `Tip.dom.test.ts`: показан при новом id; «Понятно» — скрыт и отмечен, после перемонтирования не показан; нажатие
  предмета — то же; два `Tip` на экране — виден один, после «Понятно» первого — второй; открыт лист — пузыря нет.

## Критерии приёмки

- Пузырь читается в обеих темах (токены, контраст подписей — `--ink-2`, не бледнее), не вылезает за край на 375 px.
- `cd frontend && npm run build && npx vitest run` зелёные.

## Вне скоупа

- Расстановка по вкладкам и тексты (FR-06); тур с затемнением; «видел» в документе/на сервере (после MVP).

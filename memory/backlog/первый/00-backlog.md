## 1. Цель

Новый человек за минуту понимает, что даёт приложение, доходит до своей мечты без выписки и на главных экранах знает,
куда нажать. Для первых чужих семей перед запуском в магазинах. Успех — путь Google → «Мечты» без выписки:
вступление + 2 шага (мечта, зарплата) + партнёр; выписка нигде не выглядит обязательной; «Пропустить» видно без
прокрутки; подсказки показываются один раз. Режим процесса — **M** (оба блока, с экранами). Только `frontend`;
Go и миграций нет.

## 2. Зафиксированные решения

- **Р-1. Вступление — 3 экрана-образа** после «С кем ведём?» и до настройки: картинка + 1–3 слова («Мечта» ·
  «Свободно» · «Утечки»), листаются, внизу «Дальше», вверху справа тихое «Пропустить». Видно один раз (шаг первого
  запуска). Картинки — снимки лэндинга `public/landing/{dream,free,leaks}-{light,dark}.webp` в теме экрана.
  *(интервью р. 1; картинки — дефолт)*
- **Р-2. Порядок: мечта → зарплата.** Первый шаг — «На что копим?», второй — зарплата и день руками (поля и ритм как
  сейчас в «Введу вручную»). Выписка — тихая кнопка «Есть PDF из банка» на шаге зарплаты, не обязательна (можно
  позже, в «Неделе»). *(интервью р. 1)*
- **Р-3. Выписку загрузили — зарплата из неё и те же вопросы по одному** (кредиты, подписки; код вопросов
  сохраняется). Экран «Ваш <месяц>» из первого запуска **убираем** — та же картина есть в «Деньгах». *(интервью р. 2)*
- **Р-4. «Пропустить» — тихой кнопкой в шапке справа, рядом с «n из k»** на каждом необязательном шаге (вступление,
  мечта, вопросы по выписке вместо «Потом», партнёр вместо «Позже»). Внизу — только главная кнопка. *(интервью р. 1)*
  - Зарплата обязательна: без неё нет ни «Свободно», ни срока мечты — «Пропустить» на этом шаге нет. *(дефолт)*
  - Мечту пропустили — дальше зарплата, «Мечты» встречают пустым экраном «Новая мечта», как сейчас. *(дефолт)*
- **Р-5. Шаг «Пригласите партнёра» остаётся для всех** в конце первого запуска. *(интервью р. 2)*
- **Р-6. Партнёр по коду:** вступление → зарплата (с тихим «Есть PDF из банка» и вопросами) → «Мечты». Мечта общая —
  шага «На что копим?» у него нет, шага партнёра тоже. *(дефолт)*
- **Р-7. Обучение — подсказка у предмета:** при первом заходе на главную вкладку («Мечты», «Неделя» / «Месяц»,
  «Деньги») — один короткий пузырь у главного предмета вкладки, одна за раз, «Понятно» закрывает навсегда. Без
  затемнения экрана (тур — не-скоуп). *(интервью р. 1)*
  - **Показываются всем один раз**, в том числе нынешним семьям и в демо. *(интервью р. 2)*
  - «Видел» хранится на устройстве (как ответы первого запуска, `lib/storage`); новое устройство — подсказки ещё раз,
    это допустимо. Viewer видит подсказки без кнопок действия. *(дефолт)*
- **Р-8. Данные:** схема и сервер не меняются; `onboardedAt` / `finishSetup` — как сейчас. Пройденный первый запуск у
  нынешних семей не перезапускается. *(дефолт)*
- **Р-9. Тексты** вступления и подсказок — коротко, без механики («выписка», «PDF» не в заголовках); финальные слова
  владелец утверждает по артефакту «до | после» на `/ux`. *(дефолт)*
- **Р-10. События — без новых:** `first_run_goal` и `first_run_done` сохраняются; `intro_done` / `intro_skip` **не
  заводим** — сервер принимает только 5 видов (`CHECK kind` в `backend/migrations/000006_events.sql`, `EventKinds` в
  `events_repo.go`), новые потребовали бы миграции вопреки Р-8. Воронку вступления видно косвенно — по
  `first_run_goal` / `first_run_done` в админке. *(бриф — дефолт; уточнено владельцем 2026-10-12 при составлении
  бэклога: «без новых событий»)*

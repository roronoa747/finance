# FR-01 — Порядок «мечта → зарплата», выписка опцией, без «Ваш месяц» (фронт)

Блок 1 · MVP · Репо/каталог: `frontend/` · Зависит от: — · Роли: новая семья (member), партнёр по коду; viewer мимо

## Контекст (что уже есть)

- `src/views/Start.vue` (номера — §6 бэклога): шаги `['upload', 'questions', 'month', 'dream', 'invite']`, партнёру
  `['upload', 'questions']`. Шаг `upload` — главная «Выбрать файл» + тихое «Введу вручную» (переключает `manual` на
  форму зарплаты с `PayRhythmFields`, «Дальше» → `manualNext` → `dream`, партнёру — `finish`). После выписки —
  `questions` (вопрос дохода, повторы); `advance()` ведёт дальше только при известной зарплате, иначе — короткая форма
  «дохода не нашли» (`manualAfterQuestions`). `month` — `WeekCard` + `FreeCard` (`spendRows`, `budgetAmounts`).
- Форма зарплаты сейчас написана дважды (:426-443 и :476-492) — один и тот же блок полей.
- `GoalNew.vue` в первом запуске (`props.next`): «Дальше» по плитке → форма → «Готово — к мечте» → `land()` →
  `router.push(next)`; «Пока без мечты» → `skip()` → `next`. Форма показывает «при остатке ≈ N · реально» от
  `budgetAmounts(...).d5` — до зарплаты это 0 и «реально» не загорается никогда.
- Гард роутера и `landingPath` уже держат пользователя на `/start`, пока нет `onboardedAt` (§6) — цель до зарплаты
  безопасна.

## Задача

1. **Новые шаги** (Р-2, Р-5, Р-6): новая семья — `['dream', 'salary', 'questions', 'invite']`, партнёр по коду —
   `['salary', 'questions']`. Шаг `questions` входит в путь, только если на шаге зарплаты загрузили выписку (иначе
   `salary` → `invite` / `finish`). Шаг `month` и его разметка/вычисления удаляются (Р-3) — вместе с ненужными
   импортами (`WeekCard`, `FreeCard`, `spendRows`, `budgetAmounts`, если больше не нужны).
2. **Шаг `salary`** — экран «Зарплата» (заголовок 1–3 слова; Р-9 — финальные слова на `/ux`): поля зарплаты, дня и ритма
   — тот же блок, что «Введу вручную» сейчас (вынести дважды написанную разметку в один кусок шаблона/компонент, без
   новых абстракций сверх этого), главная «Дальше» (партнёру — «Готово»). Под ней — **тихая** кнопка «Есть PDF из
   банка» (`ghost`): раскрывает на этом же шаге прежний выбор файла (банки с подсказкой пути, «Файл остаётся на
   телефоне», ошибки чтения) с главной «Выбрать файл» и тихим «Назад» к полям. Выписку прочитали → `questions`.
   Заголовки и подписи без «выписки»/«PDF» (Р-9) — механика только на тихой кнопке и внутри раскрытия.
3. **Вопросы** — код вопросов не меняется (Р-3): доход из выписки подтверждается «Да, это зарплата»; дохода в выписке
   нет и зарплата ещё не введена — прежняя короткая форма. Если зарплату уже ввели руками до выписки — вопрос дохода
   остаётся (выписка точнее), «Да» перезаписывает оклад, как сейчас. После вопросов — `invite` (партнёру — `finish`).
4. **Мечта первой** (`dream`): `GoalNew next="/start/salary"`; в первом запуске форма мечты **не показывает** строку
   «при остатке ≈ N» и тег «реально» (свободного ещё нет) — только «По N в месяц · будет вашей в …». «Пока без мечты»
   пока остаётся — его заменит «Пропустить» в шапке (FR-03).
5. **Старые адреса** (перезагрузка у тех, кто посреди старого потока на проде): `/start/upload` → `salary`,
   `/start/month` → `invite`; чужой шаг — первый шаг своего пути (как сейчас).
6. Заголовки шагов (`titles`) — под новые шаги; `Stepper` считает «n из k» по видимым шагам (вступление FR-02 в счёт не
   входит; `questions` — подшаг зарплаты, «n» на нём не растёт: новая семья видит «1 из 3» · «2 из 3» · «3 из 3»).
7. Комментарий-шапка `Start.vue` — под новый поток.

## Критерии приёмки

- Новая семья: Google → «С кем» → мечта → зарплата → партнёр → «Мечты»; ни одного экрана, где выписка — главная кнопка.
- С выпиской: те же вопросы по одному, документ тот же, что раньше (оклад, кредит, обязательства, правила, отметки).
- Партнёр по коду: зарплата (+ выписка опцией) → «Мечты», шагов мечты и партнёра нет.
- Экрана «Ваш <месяц>» нет; `first_run_goal` / `first_run_done` пишутся как раньше.
- `cd frontend && npm run build && npx vitest run` зелёные; стенд 390 px, обе темы: оба пути (без выписки и с
  фикстурой) + партнёр.

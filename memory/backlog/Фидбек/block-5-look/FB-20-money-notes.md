## Задача

1. **Сегмент «Денег»** — `MoneySquares.vue` → группа кнопок как `PlanSwitch` (три: Капитал · Долги · История; `aria-current`,
   `router.replace`, `role="group"`), без рамок-коробок. Подсказка `Tip id="tab-money"` — как была.
2. **Зарплаты с экрана убрать**: удалить `CapitalSalaries.vue` и его тест; из `Money.vue` — импорт и вставку; тесты
   `Money.b16.dom.test.ts` про зарплаты и e2e с `data-capital-salaries` — переписать на «Месяц» (там тот же лист и отметка).
3. **Строки «Капитала» ровно** (`CapitalLists.vue`, Figma `19:21`, `19:73`): у **каждой** строки слот 32 px слева
   (`rounded-[10px] bg-surface-3`): счета — значок вида (как сейчас), «Цели · N» — `PhTarget`, кредиты — `PhCreditCard`,
   платежи — **аватар плательщика 32** в слоте (в `PaymentLine` добавить проп `slot` / режим «аватар слева, у суммы нет»;
   «Месяц» (`DueRow`) не трогать), «Подписки · N» — ↻ в слоте 32, группы — `PhFolderSimple`, «Закрытые · N» — тихой строкой
   без слота как была. Суммы в списках — `plain()` **без «₸»** одной колонкой (`font-num 15 px`), «₸» остаётся только у
   крупной суммы капитала. Строки «Добавить счёт» и «Добавить» — обычными строками списка со слотом «+» (`PhPlus`), тем же
   `border-t`, что у строк, — **одна черта** (убрать обёртку `div.border-t` вокруг `Button ghost`). Заголовки секций
   `Section` — как были («Счета», «Кредиты», «Платежи» с «В календарь»). Секция «Кредиты» (остаток) остаётся — в Figma её нет,
   данные не убираем без решения (Р-34, владельцу посмотреть на `/ux`).
4. **Модель заметки** (Р-33): `types/finance.ts` → `Note = Tracked & { id: string; text: string; date: string (YYYY-MM-DD);

## Критерии приёмки

- «Деньги» на 390 px в обеих темах — как Figma `19:2`: сегмент, слот у каждой строки, суммы колонкой без «₸», одна черта
  перед «Добавить», зарплат нет; капитал, долги, история — цифры те же.
- Заметка: «+ → Заметка» → лист → карточка на своей неделе с ✓; видна только автору; переживает синк и второй телефон того же
  человека (личный документ); нигде не прибавляется к тратам.
- `cd frontend && npm run build && npx vitest run` — зелёные; стенд Chrome 390: демо и семья из двух (партнёр заметку не видит).

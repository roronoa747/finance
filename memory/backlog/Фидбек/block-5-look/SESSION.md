## Handoff — исследование (FB-18)

- **Артефакт:** https://claude.ai/artifact/AvUr9PagMTq3Lv1CBBcM7c (приватный; 5 пар «до | после» 390 px, светлая/тёмная по
  теме зрителя, токены `style.css`; «до» — снимки стенда `main` на демо, данных семьи нет). **Решение владельца:** ⬜ (→
  `memory/decisions/fb-look.md`).
- **Рекомендации (по экранам):**
  - «Неделя» — **А «одна шапка»**: 4 яруса (заголовок, сегмент, кружки, карточка суммы) → 2: ‹неделя› и сумма слева,
    кружки выписок + «+» мелко справа; полосы «осталось» у строк — в лист раздела. Только вид. Вариант Б — под суммой «план
    недели · осталось» (пометка владельца «заполнить траты, потом посмотреть, сколько вышло») — нужен расчёт плана недели.
  - «Месяц» — **А «полоса»**: кольцо 236 px (два слоя) → «Остаётся» крупно + одна полоса долей дохода (платежи · траты ·
    цели · остаток), строки разделов — её подпись; «Хватит?» / «✦ Разбор» — строкой под числом. Б — малое кольцо 112 px
    рядом с суммой. Обе — только вид (`parts` те же).
  - «Деньги» — «криво» названо: (1) «Капитал · Долги · История» — коробки с рамкой, а на «Плане» тот же выбор сегментом;
    (2) значки только у «Счетов», у «Целей», «Кредитов», «Платежей» нет — текст строк с разного места; (3) двойная черта
    перед «Добавить счёт», «Подписки» одни со значком; (4) зарплаты повторяют «Месяц». После — сегмент, слот значка/«чей»
    слева у каждой строки, суммы одной колонкой, одна черта, зарплаты убрать. Только вид (уборка зарплат — решение).
  - Заметки — (б) заметка у траты уже есть (`OpSheet`, «Что это было», Р-3) — снимок «до»; (а) заметка себе: А «у месяца»
    (общая, переходит в следующий месяц до ✓) / Б «с датой» (личная, всплывает на своей неделе). **Вопрос владельцу**: имел
    в виду (б) или (а); если (а) — рекомендую А. Обе — новое хранение заметок в документе.
  - Первый запуск — сейчас «сначала план» (образы → мечта → зарплата → партнёр). После — **мечта первой, затем «тратьте как
    обычно»** (день 1: фото мечты + «Загрузить выписку» / «Позже»), через 2 недели — точка на «Месяце» и кнопка «План по
    факту» в строке «Траты» → лист плана по разделам. Нужен расчёт «обычно» по 2–4 неделям (`usualSpend` — по полным месяцам).
- **Оценка режима:** M с `/ux` (вид — «Неделя» А, «Месяц», «Деньги»; данные — заметки, «обычно» по неделям для первого
  запуска). FB-19 — «Неделя» + «Месяц», FB-20 — «Деньги» + заметки, FB-21 — первый запуск + e2e/доки (как в заглушках).
- **Отклонения:** порты стенда 5291/8191 заняты старыми стендами других сессий (`fb1-ux` preview, `ffserver.exe`) — не
  трогал, стенд на 5294/8194. Первый запуск снят через `/api/auth/register` моков + токен в `localStorage` (вход в UI — только
  Google). Код продукта не менялся, ветки нет (как FB-14).
- **Грабли среды:** скрипт playwright без `try/finally b.close()` висит после ошибки локатора — ставить `setDefaultTimeout`
  и закрывать браузер в `finally`; подсказки `Tip` гасятся `ff_tips_seen` (JSON-массив id).

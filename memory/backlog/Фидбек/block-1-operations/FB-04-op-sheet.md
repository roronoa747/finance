## Задача

1. `OpCategorySheet.vue` → `components/OpSheet.vue` (один лист операции): заголовок — продавец коротко (`shortMerchant`) или
   получатель; строкой — день · сумма (с возвратом — «5 000 · вернули 5 000» / «вернули 2 000»); **заметка** — `Input`
   «Что это было» (≤ 60, сохраняется по blur/закрытию через `editOp(id, {memo})`, пустая — снимает); **чипы «куда
   отнести?»** — `CategoryChips` с «+ Раздел» (FB-03), текущий раздел — `on`; под ними ряд тихих чипов: **«Мне вернули»**
   (`on`, когда есть `refund`). Подпись «Ответ запомним…» — убрать (понятно без неё) или в `Hint` у чипов (решает `/ux`).
   Главной кнопки нет.
2. «Мне вернули» (Р-12): нажатие → внутри листа строка выбора: приходы `refundCandidates` (до 5: «Перевод от Имя Ф. ·
   12 окт · 30 000»), чип «Наличными» → `NumField` суммы (по умолчанию вся трата) + «Готово». Выбор прихода →
   `editOp(id, {refund: {amount: min, opId}})`; наличными → `{refund: {amount}}`; чип `on` → повторное нажатие снимает
   (`refund` undefined). Сумма возврата > траты — срезается до траты; 0 — снимает.
3. Входы: `WeekFeedSheet` (как было, `OpSheet` поверх, `z` 60); `SectionSheet` «Недели» — строки выписки и телефона становятся
   кнопками (стрелка-шеврон `--ink-3` у суммы, как карандаш у ручной) → событие `open(id)` → `Week.vue` открывает `OpSheet`
   поверх листа раздела (`z` 60); `HistorySquare` — как было. Ручная трата везде → «Трата» (`HandSpendSheet`). Строки
   `internal` (переводы между своими) остаются не кнопками, как сейчас.
4. Подписи сумм с возвратом в ленте (`WeekFeedOp` + `refund?: number`) и листе раздела (`sectionWeek` + `refund`): сумма —
   `spendOf`, мелко «вернули N» (`type-meta`); полный возврат — сумма 0, строка остаётся (видно, что было и вернули).
5. Р-14 часть «Недели» — здесь (строки листа раздела нажимаются); лист раздела «Месяца» — FB-05.

## Критерии приёмки

- Из ленты, листа раздела «Недели» и «Истории» своя операция открывается одним нажатием; в листе — заметка, чипы раздела с
  «+ Раздел», «Мне вернули» (приход или наличными); всё помнится (FB-02).
- Правило 12: главной кнопки нет, ответ — чипом; «Мне вернули» — тихий чип у предмета; подписи 1–3 слова; крупная цифра
  одна (сумма) ≤ 34 px; цвета — токены; обе темы; без горизонтального скролла на 390.
- `cd frontend && npm run build && npx vitest run` зелёные; стенд: выписка владельца → возврат переводом → сумма недели и
  «Месяц» сходятся на тенге.

## Задача

1. **План недели — `finance.ts`** (Р-31). `MyWeek` получает `plan: number | null` и `rest: number | null`: `plan` = сумма моих
   строк плана месяца недели (`planned`, уже есть в `myWeek`) × 7 / `daysInMonth(month)`, целое (`Math.round`); нет строк —
   `null`. `rest = plan − total` (может быть < 0). `MyWeekRow.plan/spent/rest/low` остаются (лист раздела). Тест в `week.test.ts`.
2. **«Неделя» — шапка в два яруса** (Figma `18:11`): одна карточка `data-week-head` (`Card tight`): слева колонка — строка
   ‹ `data-week-label` › (как сейчас, `type-section`) и под ней сумма `data-week-total` 34 px; справа `data-week-strip` —
   аватары 26 px внахлёст (−8 px; свой — кнопка `data-my-uploads` → `UploadsSheet`, партнёр — span; загрузил за неделю —
   полный цвет, нет — `opacity-35`; ✓-бейдж убрать) и рядом загрузка: своей выписки за неделю нет — брендовая `Button size="xs"`
   «Загрузить» `data-upload="lead"`; есть — кружок 26 px с «+» `data-upload="quiet"`. Скрытый `input file`, `pick`, фокус из
   «+» (`?upload=1`), `ApplePayWeekLine` под шапкой — как были. Карточку `data-week-sum` и кнопку `data-to-plan` убрать
   (призыв к плану — FB-21, точка на «Месяце»).
3. **Полоса плана недели** `data-week-plan` под шапкой (Figma `18:29`), только при `mine.plan !== null`: полоса 8 px
   `bg-track`, заполнение `min(100, total / plan)` цветом `--brand`; `rest < 0` — заполнение `--warn`. Под полосой одна подпись
   справа 12.5 px: «осталось **48 500** / 175 000» (`data-week-rest`; слово `--ink-2`, числа `num`), при `rest < 0` — «сверх плана
   **N** / 175 000» (`text-warn`). Без плана — ни полосы, ни подписи.
4. **Строки разделов «Недели»** (Figma `18:47`): значок 32 px, имя, сумма `data-amount` — без полос и `data-rest`, без «вне
   плана» (остаток раздела — в листе раздела, он там уже есть). Строка **«Не разобрано» при вопросах — сама кнопка** `data-bang`

   `data-questions-row` целиком кнопка `data-bang`, без чипа. Остальные строки — как были (`sectionFor`). `Tip` над разделами
   остаётся (нажатие строки закрывает).

  `rest` отрицательный при перерасходе; неделя на стыке месяцев — месяц по последнему дню не позже сегодня (как `month`).
- `Week.dom.test.ts` / `Week.screen.dom.test.ts` (адаптация + новое): шапка — аватары 26, без ✓-бейджа; «Загрузить» `xs`

  нет плана — нет `data-week-plan` и нет `data-to-plan`; строка «Не разобрано» — кнопка `data-bang`, чипа нет; `data-rest` в
  строках нет; лист раздела по-прежнему пишет «осталось N из M».
- `MonthPlan.dom.test.ts` (адаптация + новое): `MonthRing` без внешних дуг (`circle` только частей), `size` 112; «Остаётся» и
  число справа от кольца; «Хватит?» и «✦ Разбор» — чипами в карточке; строки разделов — одна точка, `data-section-dot` нет,
  призыв — `data-section-call` в подписи (освободившийся платёж, «больше обычного», ждут «Отложил»); зарплата пришла —
  `data-came` на строке с `bg-ok-soft`, «✓» и `data-came-count` нет; ждущая — `text-ink-2`; карточка зарплат — после разделов.

- e2e из «Контекста» — обновить селекторы и ожидания; **сценарии не удалять** (проверяемые факты те же: суммы, отметка,
  вопросы).
- Мутанты (откат копией файла): формула плана недели (`× 7` → `× 1`), условие `rest < 0` → `--warn`, подсветка `came` — красные.

- Экраны на 390 px в обеих темах повторяют Figma `18:3` и `18:105` по структуре: шапка «Недели» в два яруса, полоса плана

  той же карточке с одной точкой, зарплаты ниже, «пришла» — подсветка `--ok-soft` без ✓ и «0 из 2 пришли».
- Ничего не потеряно: остаток раздела — в листе раздела, части зарплаты — в листе зарплаты, призыв раздела — подписью.
- Цифры те же, что до блока (`myWeek.total`, `plan.rest`, суммы разделов, строки зарплат): считает `finance.ts`, экраны не
  считают (правило 6).
- `cd frontend && npm run build && npx vitest run` — зелёные; стенд Chrome 390: демо-семья и семья без плана трат.

## Задача

1. e2e `fb-block1-operations.test.ts`: два телефона одного человека + партнёр. Сценарии: (а) пуш «Перевод Имя Ф.» и затем
   строка выписки о нём — вопрос один, ответ держится после синка и повторной загрузки; «Потом» → переоткрытие — нет; (б)
   «Мне вернули» переводом — сумма недели и «Месяц» уменьшились у обоих телефонов, партнёр видит только итог раздела, его
   документ без `opEdits`; (в) заметка видна на втором телефоне; (г) «+ Раздел» из листа → партнёр видит раздел; (д) лист
   раздела «Месяца» — операции, «Ещё N».
2. DESIGN.md: лист операции (`OpSheet`) — состав и входы; строки листов раздела; «+ Раздел» в чипах; одна строка про
   приватность правок. `00-backlog.md` §6 — критик пишет «После Блока 1» (имена функций по факту).
3. `README`/политика конфиденциальности (`views/Privacy.vue`): правки операций — личные, на сервер не уходят — одна строка,
   если там перечислено, что хранится у семьи (проверить grep «операции»).

  действие и предмет, что в подсказке, что скрыто).

## Задача

1. `sectionMonth(ops, {month, categoryId, limit?})` в `finance.ts` — как `sectionWeek`, но за месяц (`op.date.slice(0,7)`),
   без топа продавцов (в месяце он уже есть у находок) — или с `tops` 3, решает исполнитель по месту на экране; строки
   `{id, date, name, amount (spendOf), hand, refund?}`; «Ещё N · сумма».
2. `SpendCategorySheet`: новый проп `ops?: SectionMonth | null`; под цифрами и «до плана», над справкой РК и «План
   каждого» — заголовок-строка «Мои операции · N» (`type-section`) и дни со строками (первые 5, «Ещё N»); нажатие строки
   → событие `open(id)` (выписка/телефон) или `edit(id)` (ручная). Нет своих операций — блок не показывается (у партнёра
   этот раздел может быть только из его итогов).
3. `MonthPlan.vue`: передать `ops` (`sectionMonth(store.shown, {month: monthKey, categoryId: catFor})`), обработать `open` →
   `OpSheet` поверх листа раздела (`z` 60), `edit` → `HandSpendSheet` с `op-id` (есть ли он на «Месяце»? нет — открыть
   через адрес `/week?spend=1&edit=<id>`? **Проще:** на «Месяце» смонтировать `HandSpendSheet` тоже — компонент
   самодостаточный, `saved` → ничего). `MonthPast.vue` — `ops` за тот месяц, `open` → `OpSheet` (правка заметки/возврата
   прошлого месяца допустима), `edit` → «Трата».
4. Лист из отчёта ИИ (`/month?cat=`) получает операции автоматически (тот же лист).

## Критерии приёмки

- Лист раздела «Месяца» показывает свои операции этого раздела за месяц, строка открывает лист операции (заметка, раздел,
  «Мне вернули»); сумма строк (все, через «Ещё») = своя часть факта раздела.
- Правило 12: крупная цифра одна; операции — списком под цифрами, без новых кнопок; «Ещё N» — тихая строка.
- `cd frontend && npm run build && npx vitest run` зелёные; стенд 390 px, обе темы, member и viewer.

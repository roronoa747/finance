## Задача

1. **Стянуть вниз** (только лист снизу, не окно `sm:`): pointer/touch на карточке; жест вниз начинается, только когда
   `card.scrollTop === 0` (иначе прокручивается содержимое); лист едет за пальцем (`transform: translateY`), затемнение
   светлеет; отпустил при сдвиге больше порога (~30 % высоты листа или ~120 px) или быстром смахивании вниз — `close()`;
   иначе — пружиной назад. Жест вверх и горизонтальный — не трогает. Не ломать: ввод в полях, прокрутку длинных листов,
   нажатия кнопок внутри, выделение текста, лист поверх листа (тянется только верхний). `prefers-reduced-motion` — без
   анимации доезда. Без новых зависимостей.
2. **Ручка-полоска** сверху каждого листа на телефоне (цвет — токеном, пара для тёмной темы; на `sm:` не показывать);
   заголовок, крестик и отступы — как были. Комментарий :142-143 переписать.
3. Тесты: `Sheet.dom.test.ts` — свайп вниз за порог закрывает (через `close`: фокус из поля ушёл до `close`), недотянул —
   открыт, при `scrollTop > 0` не закрывает, верхний из двух; мутации «без проверки scrollTop» и «порог 0» — красные.
   e2e `frontend/e2e/pn-block5a-sheet-swipe.test.ts`: лист с правкой в поле (`NumFieldBlur`) стянут — правка записана.
4. Доки: `DESIGN.md` §5 (лист: ручка, стянуть вниз), §6 бэклога «После Блока 5а», SESSION.md.

## Критерии приёмки

- На стенде 390 px (настоящие touch-жесты Playwright, обе темы): несколько разных листов («+», «Хватит?», длинная форма
  с прокруткой, лист поверх окна Капитала) закрываются стягиванием; длинный лист сначала прокручивается; правка поля не
  теряется. Весь накопленный e2e зелёный. Смоук владельца на iPhone (PWA): листы стягиваются вниз.

## Вне скоупа

- Высоты-«ступени» листа (наполовину / во весь экран), свайп вверх — нет. Окна на широком экране — без изменений.

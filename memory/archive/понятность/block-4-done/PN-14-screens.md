## Задача

1. **Вопрос «Купили?»** (`GoalDetail`, мечта не фонд, `!doneAt`, `remaining ≤ 0`): карточка срока → заголовок
   «Накоплено!», строка «Купили?», брендовая «Сбылось» (`data-goal-done`), тихая «Ещё нет» (`data-goal-not-yet` —
   прячет вопрос до следующего открытия экрана, `ref`); «Пополнить» в этом состоянии нет. Viewer — заголовок
   «Накоплено» без кнопок.
2. **Меню «···»** — пункт «Сбылось» у мечты всегда (не у фонда), над «Поставить на паузу». Оба входа →
   `markGoalDone(id, { by })` → момент.
3. **Момент** — новый `components/goals/DoneSheet.vue` (`goalId`): фото (`usePhoto`, иначе CDN шаблона), «Сбылось!»,
   имя, «за N месяцев» (`doneTerm`), «Поделиться» → `StorySheet kind="goal"` с `percent: 100` и строкой «сбылось за N
   месяцев» (расширить `StoryData` полем `doneTerm?` → `storyText`: «<имя> · сбылось за N месяцев»), «Готово» →
   закрыть; экран цели под листом уже в состоянии «сбылось».
4. **Экран сбывшейся мечты** (`doneAt`): герой 100 % с фото; вместо карточки срока — «Сбылось в <monthIn> · за N
   месяцев» (`data-goal-done-at`); «Пополнить», «Подробнее», взнос полем, фонд — нет; история взносов остаётся; шапка
   — карандаш и «···» с пунктами «Вернуть в мечты» (`undoGoalDone`) и «Удалить» (как сейчас в `GoalSheet` —
   проверить, где живёт удаление; если только в листе правки — пункт ведёт туда). Кнопка истории (`data-goal-share`)
   остаётся — карточка с «сбылось».
5. **Альбом на «Мечтах»**: между «Целями» и «Желаниями» — свёрнутая строка «Сбылось · N ›» (`data-done-album`,
   `aria-expanded`), раскрыта — `ThumbRow` на каждую (`doneGoals`): фото, имя, «<monthShort(doneAt)> · за N мес.»;
   нажатие — `/goals/:id`. N = 0 — строки нет. Закрыто при каждом заходе. Viewer видит.
6. Тост после «Сбылось» не нужен — есть момент. «Ближе на N дней» (PN-09) у сбывшейся не считается.
7. `DESIGN.md` — «Мечты» / экран цели: абзац «Сбылось».

## Тесты

- `GoalDetail.test.ts`/DOM: 100 % → «Купили?» с «Сбылось» и «Ещё нет», «Пополнить» нет; фонд на 100 % — прежняя
  строка «Собрано», без вопроса; «Сбылось» → `doneAt`, `DoneSheet` открыт с «за N месяцев»; сбывшаяся — заголовок с
  месяцем, нет «Пополнить»/«Подробнее», меню с «Вернуть в мечты»; viewer — без кнопок. Мутация «вопрос у фонда» — красная.

## Задача

1. Модалка кредита на `Sheet`: поля и правила React (п. А-2), `NumFieldBlur` для чисел, имя и
   примечание — `Input` с blur (только если изменилось); ставка — `kind="rate"`, ноль законен;
   день 1..28. `updateCredit` получает `unchanged()`-защиту (RP-01: коммит только изменённого),
   правка `principal` — только через явное поле «Остаток долга» (ставит якорь).
2. Выводы «Платежей осталось / Переплата до конца» или текст «долг не закрывается» — числа
   через `finance.ts` (`creditOutlook(c)` → `{ closes, months, overpay }` на базе `debtCost`).
3. `PaidRow` в модалке пересчитывает `creditDue` после правки дня/платежа/ставки (снимок
   обновлять при изменении полей кредита, не только id).
4. `SavedMark` через `useSavedMark`. Текст удаления — React (Б-21, часть «кредит»).
5. Калькулятор досрочки (Б-17): сброс суммы и режима при смене кредита; «долг не закрывается»
   вместо «—»; placeholder `chips[0] ?? 5000`; чип «половина переплаты»; тексты «Впишите
   сумму…» и «Половину переплаты снимает уже…»; заголовок «Отдача падает».
6. Viewer: полей и кнопок нет, цифры видны (SSR-тест под viewer).

## Тесты

- `stores/finance.test.ts`: `updateCredit({day})` / `{annualRate}` / `{payment}` не двигают
  `principalSetAt`; `{principal}` — двигает и отметки до якоря больше не вычитаются;
  повторный патч с теми же значениями — документ не меняется (`updatedAt` прежний).
- `lib/finance.test.ts`: `creditOutlook` — платёж ≤ процентов → `closes false`; иначе
  `months`/`overpay` = React-формулы.
- `views/Capital.test.ts` (SSR): модалка кредита — поля «Остаток долга, ₸», «Ставка (ГЭСВ), %
  годовых», «Платежей осталось», «Переплата до конца»; для кредита с платежом ≤ процентов —
  текст «долг не закрывается»; под viewer полей нет. Калькулятор: «Переплата, если не трогать»
  → «долг не закрывается»; тексты лесенки.
- e2e (`pv-block2-money-edit.test.ts` — файл блока): правка ставки у кредита с отметками не
  меняет производный остаток; правка остатка ставит якорь; второй клиент видит новые день и
  ставку.

## Критерии приёмки

- Браузер: поправить день, ставку, платёж и название у живого кредита — строка Капитала,
  Бюджет и «Оплатил» обновились, остаток из отметок не изменился; правка остатка — сверка
  (якорь); «Сохранено» загорается и гаснет; удаление с текстом React; калькулятор: открыть
  кредит А с суммой, затем кредит Б — поле пустое; тексты лесенки на месте.
- `cd frontend && npm run build && npm test` зелёные.

## Вне скоупа

- Разбивка «в долг / проценты» и график — PV-13.
- «Снизить платёж» по LWW — хвост §4 RP, не трогать.
- Слияние правок кредита с двух устройств — `mergeList` LWW, как было.

# Бриф «первый запуск»

## Контекст

B2C-приложение «Реально.» (Family Finance), прод — family-finance-ff.vercel.app. Решение владельца о порядке до запуска
в магазинах — `memory/decisions/order-2026-10-12-launch.md`: этот бриф первым, ≈ 20.10 — Google Play и App Store.

Что есть сейчас (разведка кода, 2026-10-12): Лэндинг (`Landing.vue`) → вход Google (`Access.vue`) → «С кем ведём?»
(`Who.vue`: один / семья с кодом / по коду) → `/start/*` (`Start.vue`): **«Ваш банк»** (главная кнопка «Выбрать файл»,
«Введу вручную» — тихая) → вопросы по выписке по одному → «Ваш <месяц>» (полоса трат + «Свободно») → «На что копим?»
(`GoalNew` + лист `PhotoPicker`, «Пропустить» — в самом низу листа под липкой «Выбрать это») → «Пригласите партнёра»
→ «Мечты». Партнёр по коду — только «Ваш банк» и вопросы. Ни вступления, ни подсказок на главных экранах нет.

## Что хочется получить и зачем

Слова владельца (2026-10-12): вступление и обучение кривые — нет объяснений, «Пропустить» слишком низко, люди
путаются; выписка выглядит обязательной (хвост «понятности», Р-22 там).

## Резюме бриф-интервью

- **Цель одной строкой:** новый человек за минуту понимает, что даёт приложение, доходит до своей мечты без выписки
  и на главных экранах знает, куда нажать.
- **Скоуп:** вступление из 3 экранов-образов; новый порядок первого запуска «мечта → зарплата», выписка —
  необязательная; «Пропустить» — вверху на каждом необязательном шаге; подсказки у предмета на главных вкладках.
- **Не-скоуп:** лэндинг, вход Google и «С кем ведём?» (`Who.vue`) — без изменений; новые расчёты в `finance.ts`;
  тур с затемнением; изменения в разборе выписки.
- **После MVP / не в этой инициативе:** Apple Wallet (следующий по порядку), магазины (Блоки 7–8 `идея-и-редизайн`),
  казахский и валюты.

### Решения (кандидаты в Р-*)

- **Р-1. Вступление — 3 экрана-образа** после «С кем ведём?» и до настройки: картинка + 1–3 слова
  («Мечта» · «Свободно» · «Утечки»), листаются, внизу «Дальше», вверху справа тихое «Пропустить». Видно один раз.
  *(ответ владельца, раунд 1)*
  - Картинки — готовые снимки экранов лэндинга `public/landing/{dream,free,leaks}-{light,dark}.webp` в теме
    экрана. *(дефолт)*
- **Р-2. Порядок: мечта → зарплата.** Первый шаг — «На что копим?», второй — зарплата и день руками (поля и ритм
  как сейчас в «Введу вручную»). Выписка — тихая кнопка «Есть PDF из банка» на шаге зарплаты, не обязательна
  (можно позже, в «Неделе»). *(ответ владельца, раунд 1)*
- **Р-3. Выписку загрузили — зарплата из неё и те же вопросы по одному** (кредиты, подписки; код вопросов
  сохраняется). Экран «Ваш <месяц>» из первого запуска **убираем** — та же картина есть в «Деньгах».
  *(ответ владельца, раунд 2)*
- **Р-4. «Пропустить» — тихой кнопкой в шапке справа, рядом с «шаг n/k»** на каждом необязательном шаге
  (вступление, фото мечты / мечта, вопросы по выписке вместо «Потом», партнёр вместо «Позже»). Внизу — только
  главная кнопка. *(ответ владельца, раунд 1)*
  - Зарплата обязательна: без неё нет ни «Свободно», ни срока мечты — «Пропустить» на этом шаге нет. *(дефолт)*
  - Мечту пропустили — дальше зарплата, «Мечты» встречают пустым экраном «Новая мечта», как сейчас. *(дефолт)*
- **Р-5. Шаг «Пригласите партнёра» остаётся для всех** в конце первого запуска. *(ответ владельца, раунд 2)*
- **Р-6. Партнёр по коду:** вступление → зарплата (с тихим «Есть PDF из банка» и вопросами) → «Мечты». Мечта
  общая — шага «На что копим?» у него нет, шага партнёра тоже. *(дефолт)*
- **Р-7. Обучение — подсказка у предмета:** при первом заходе на главную вкладку («Мечты», «Неделя»/«Месяц»,
  «Деньги») — один короткий пузырь у главного предмета вкладки (например, у «Отложил»), одна за раз, «Понятно»
  закрывает навсегда. *(ответ владельца, раунд 1)*
  - **Показываются всем один раз**, в том числе нынешним семьям и в демо. *(ответ владельца, раунд 2)*
  - «Видел» хранится на устройстве (как ответы первого запуска, `lib/storage`); новое устройство — подсказки
    ещё раз, это допустимо. Viewer видит подсказки без кнопок действия. *(дефолт)*
- **Р-8. Данные:** схема и сервер не меняются; `onboardedAt` / `finishSetup` — как сейчас. Пройденный первый
  запуск у нынешних семей не перезапускается. *(дефолт)*
- **Р-9. Тексты** вступления и подсказок — коротко, без механики («выписка», «PDF» не в заголовках); финальные
  слова владелец утверждает по артефакту «до | после» на `/ux`. *(дефолт)*
- **Р-10. События:** `intro_done` / `intro_skip`, прежние `first_run_goal` и `first_run_done` сохраняются.
  *(дефолт)*

### Эскиз блоков

1. **Блок 1 «Настройка»** — вступление (Р-1), порядок «мечта → зарплата» и выписка опцией (Р-2, Р-3), «Пропустить»
   в шапке (Р-4), партнёр (Р-5, Р-6), события (Р-10). → прод первым.
2. **Блок 2 «Подсказки»** (зависит от Блока 1 только по выкладке) — подсказки у предмета на главных вкладках (Р-7)
   для всех, включая демо. → прод вторым.

- **Срок:** оба блока до ≈ 20.10; если Блок 2 не успевает — магазины уходят с Блоком 1. Apple Wallet — после.
  *(ответ владельца, раунд 2)*
- **Режим процесса:** M для обоих (исполнитель → критик → `/ux` → приёмка → «да» владельца → прод). Блоков для L нет.
- **Критерии готовности:** путь Google → «Мечты» без выписки — вступление + 2 шага (мечта, зарплата) + партнёр;
  ни на одном экране выписка не выглядит обязательной; «Пропустить» видно без прокрутки на 390 px в обеих темах;
  партнёр по коду проходит без шага мечты; каждая подсказка показывается один раз и не возвращается после «Понятно»;
  билд, vitest, Go, e2e первого запуска зелёные; смоук прода.

# FR-03 — «Пропустить» в шапке (фронт)

Блок 1 · MVP · Репо/каталог: `frontend/` · Зависит от: FR-02 · Роли: новая семья, партнёр по коду

## Контекст (что уже есть)

- После FR-01/02 шапка `Start.vue` — `Stepper` («n из k», `kit/Stepper.vue`, 16 строк: `ProgressBar` + `n из k`) и
  заголовок шага; вступление — точки страниц и «Пропустить» вверху справа (FR-02).
- Нижние «пропуски» сейчас: мечта — «Пока без мечты» (`GoalNew.vue` :239, под сеткой 18 плиток — на 390 px за
  прокруткой; `skip()` → `nextPath()`); вопросы — «Потом» третьей кнопкой `DecisionCard` (`ghost`, → `skipRest`);
  партнёр — «Позже» внизу (`ghost` до кода, → `finish`) + строка «Один человек — тоже семья…».
- `GoalNew` используется и вне первого запуска (`/goals/new` из «+») — там «Пока без мечты» ведёт на `/` и остаётся.

## Задача

1. Шапка шага: справа в строке `Stepper` (рядом с «n из k») — тихая кнопка «Пропустить» (`ghost sm`) на необязательных
   шагах (Р-4): вступление (уже из FR-02 — привести к одному месту и виду), `dream`, `questions`, `invite`. На `salary`
   — нет (Р-4). Расширить `Stepper` слотом справа или поставить кнопку рядом — без новой абстракции сверх слота.
2. Действия «Пропустить»: `dream` → `salary` (цели нет; «Мечты» потом — пустой экран «Новая мечта», как сейчас);
   `questions` → то же, что `skipRest` (остальные вопросы закрыты без записи; без зарплаты — короткая форма, как сейчас);
   `invite` → `finish()`.
3. Убрать нижние дубли: «Пока без мечты» — **только в первом запуске** (`props.next`); «Потом» у `DecisionCard` в
   первом запуске; «Позже» и строку под ним на шаге партнёра — внизу остаётся одна главная кнопка (до кода — «Создать
   код» брендовая, после — «Готово»). Подсказку «Код есть и в настройках» — в `Hint`, если она нужна (правило 12).
4. «Пропустить» на мечте видно без прокрутки: шапка не прокручивается вместе с сеткой плиток (липкая шапка шага или
   шапка вне прокручиваемой области — на выбор исполнителя, как проще в текущей вёрстке).

## Тесты

- `Start` (DOM): «Пропустить» есть на `intro`, `dream`, `questions`, `invite`, нет на `salary`; каждое ведёт по п. 2;
  на `questions` без зарплаты — короткая форма; на `invite` — `onboardedAt` и `first_run_done`.
- `GoalNew` (DOM): в первом запуске нет «Пока без мечты», вне его — есть; `DecisionCard` в первом запуске без «Потом».

## Критерии приёмки

- На каждом необязательном шаге «Пропустить» — вверху справа, видно без прокрутки на 390 × 844 и 375 × 667, обе темы;
  внизу — одна главная кнопка.
- Мечту пропустили → зарплата → партнёр → «Мечты» с пустым «Новая мечта».
- `npm run build && npx vitest run` зелёные; стенд — касания, обе темы, новая семья и партнёр.

## Вне скоупа

- «Пропустить» в `PhotoPicker` (лист у «Мечт»/экрана цели — не первый запуск).
- «Пропустить» на шаге зарплаты (Р-4); изменения `DecisionCard` вне первого запуска.

## Задача

1. Новый файл `e2e/fr-block1-setup.test.ts` — критерии брифа сценариями:
   (а) новая семья без выписки: вступление (3 экрана) → мечта из шаблона → зарплата руками → «Пропустить» партнёра →
   документ: цель главная, оклад и день, `setupDoneAt`, `onboardedAt`; события `first_run_goal`, `first_run_done`;
   (б) «Пропустить» на вступлении и на мечте → зарплата → «Мечты» без целей;
   (в) с выпиской (фикстура Kaspi из части 4): зарплата → «Есть PDF из банка» → вопросы → документ тот же, что в части 4;
   (г) партнёр по коду: вступление → зарплата → «Мечты», шагов мечты и партнёра нет, `finishSetup` не зовётся;
   (д) перезагрузка посреди: `/start/salary` после мечты — цель на месте, вступление не повторяется; старые
   `/start/upload`, `/start/month` → новые шаги.
2. DESIGN.md — только затронутые секции: §2 строки `/start/*` (новые шаги, «Пропустить» в шапке, «Ваш месяц» убран),
   §5 `Stepper` (слот «Пропустить», точки вступления), §6 тексты первого запуска — как утвердит `/ux` (исполнитель пишет
   черновик).
3. §6 бэклога — «После Блока 1»: шаги и их адреса, где форма зарплаты, что убрано (факты для Блока 2 и критика).
4. Снимки стенда «до | после» (390 px, обе темы) — артефактом для `/ux` (до — `main`, после — ветка), ссылка в Handoff.

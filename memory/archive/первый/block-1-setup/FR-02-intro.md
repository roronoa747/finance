# FR-02 — Вступление: 3 экрана-образа (фронт)

Блок 1 · MVP · Репо/каталог: `frontend/` · Зависит от: FR-01 · Роли: новая семья, партнёр по коду

## Контекст (что уже есть)

- После FR-01 первый запуск — `Start.vue`, шаги в адресе `/start/:step`; новая семья `dream → salary → (questions) →
  invite`, партнёр `salary → (questions)`. Первый заход после «С кем» — `/start` без шага = первый шаг пути.
- Картинки — снимки демо для лэндинга, по одной на тему: `public/landing/{dream,free,leaks}-{light,dark}.webp`
  (≤ 72 КБ). Лэндинг выбирает тему так: `computed(() => (isDark.value ? 'dark' : 'light'))`, `isDark` из
  `lib/theme.ts` (`Landing.vue:21-22`). Подписи лэндинга — «Мечта» / «Свобода» / «Утечки» с длинными строками
  (`Landing.vue:24-28`) — во вступление их строки не переносить.
- Правило 12: заголовок 1–3 слова, одна строка под ним; одна главная кнопка (`--brand`), второстепенные тихие.

## Задача

1. Шаг `intro` — **первым** в пути и новой семьи, и партнёра по коду (Р-1, Р-6). Не входит в счёт `Stepper`
   («n из k» на нём не показывается — вместо полосы точки страниц 1·2·3).
2. Три экрана: картинка в теме экрана + заголовок 1–3 слова — «Мечта» · «Свободно» · «Утечки» (Р-1) + не больше одной
   короткой строки под ним (черновик — исполнитель; финальные слова — владелец на `/ux`, Р-9; без «выписки», «PDF»).
3. Листаются свайпом влево/вправо и кнопкой «Дальше» внизу (главная, во всю ширину — форма первого шага); на третьем
   экране «Дальше» ведёт на первый настоящий шаг (`dream` / `salary`). Тихое «Пропустить» вверху справа — сразу на
   первый настоящий шаг (размещение — общее с FR-03; здесь — только для вступления).
4. Номер экрана вступления — в адресе или в состоянии так, чтобы перезагрузка не возвращала к вступлению после
   пройденных шагов: пройденное вступление = любой следующий шаг в адресе; на `/start/intro` после перезагрузки —
   снова с первого экрана (допустимо).
5. Картинки грузятся с `loading` по умолчанию у первой и `lazy` у остальных; размер — по ширине экрана 390 px без
   прокрутки страницы (картинка + заголовок + «Дальше» видны целиком на 390 × 844 и 375 × 667).
6. Событий не заводить (Р-10).

## Тесты

- `Start` (DOM): путь новой семьи начинается с `intro`; три экрана, «Дальше» × 3 → `dream`; «Пропустить» → `dream`;
  партнёр: `intro` → `salary`; картинка — `-dark.webp` при `isDark`, `-light.webp` иначе; «n из k» на вступлении нет.
- Свайп — тест на обработчик (смена экрана по направлению жеста), если жест написан своим кодом.

## Критерии приёмки

- После «С кем ведём?» — три экрана-образа, листаются пальцем и «Дальше», «Пропустить» видно без прокрутки на 390 px
  в обеих темах; картинки — в теме экрана.
- Вступление видно один раз: после него — шаги, назад к нему поток не возвращает.
- `npm run build && npx vitest run` зелёные; стенд 390 px и 375 px, обе темы, касания (свайп), новая семья и партнёр.

## Вне скоупа

- Новые картинки или съёмка (берём снимки лэндинга); анимации сверх смены экрана.
- Вступление для нынешних семей (их первый запуск пройден — Р-8) и в демо.
- «Пропустить» на других шагах (FR-03); события (Р-10).

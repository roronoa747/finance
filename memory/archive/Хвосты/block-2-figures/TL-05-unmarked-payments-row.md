## Задача

1. `spendCompare` возвращает сумму неотмеченных строк разделов платежей за месяц (поле, например `unmarkedPayments`; та же
   величина, что входит в `PlanSpend.fact` через `spentOf`). Строки + «Не разобрано» + «Разовые» + «Платежи без отметки» =
   «потрачено». Комментарий :4311 — правдив.
2. В `MonthPlan.vue` под «Разовые» — тихая строка «Платежи без отметки» с суммой, тот же вид и права, что «Не разобрано»;
   при нуле строки нет.
3. Нажатие — лист (как у «Не разобрано»): крупная сумма, список неотмеченных строк разделов платежей (`sectionMonth` по
   каждому разделу платежей с `marked`/`categories`). У строки — её действие (правило 12, небольшой кнопкой в строке):
   есть кандидат в `pendingMatches` → «Да» (`acceptMatch`) и тихое «Нет» (`declineMatch`), текст вопроса — «это платёж по
   <имя>?»; кандидата нет, но `recurringFor(op)` есть → «В платежи». Нажатие на строку — `OpSheet`. После ответа строка уходит
   из листа, сумма пересчитывается.
4. Числа — только из `lib/finance.ts`, цвета — токены.

## Критерии приёмки

- На демо и новой семье сумма всех строк «Трат» = «потрачено» в шапке.
- Из листа «Платежи без отметки» можно ответить на вопрос или завести платёж одним нажатием у строки.
- `npm run build && npx vitest run` зелёные; стенд Chrome 390, обе темы. Handoff — правило 12 по экрану.

## Вне скоупа

- Перенос вопроса «это платёж по …?» в другие экраны — не делаем.
- Изменение состава «потрачено» (факт без неотмеченных платежей) — отклонено брифом.

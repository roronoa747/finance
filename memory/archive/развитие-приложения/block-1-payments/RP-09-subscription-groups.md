# RP-09 — Группы подписок и «оставить?» (фронт)

Блок 1 · MVP · Каталог: `frontend/` · Зависит от: RP-06 · Роли: member

## Контекст (что уже есть)

- Р-20: подписки группируются свободными группами через существующий `parentId` (названия
  любые, без хардкода). У группы флаг «рабочие — не спрашивать». Для остальных — «оставить?»:
  у годовых перед каждым продлением, у ежемесячных — не чаще раза в квартал. «Отменить» —
  надгробие подписки. Р-30: квартал и «перед продлением» — по Алматы. Правило заказчика:
  без хардкода справочников.
- `Obligation.parentId?: string` есть в типе, но **нигде не проставляется** (ни во Vue, ни в
  React) — живых групп нет. Единственное использование: `views/Capital.vue:636-649`
  показывает только `!x.parentId` (дети просто скрыты). `views/Budget.vue` `parentId` не знает.
- Добавление: `Capital.vue` «Подписка или услуга» (`:283-313`, модалка `:1046-1112`) —
  категория жёстко `'d4'`, `estimate=false`, `every` month|year; у годовых `month` берётся
  текущим (выбора месяца в форме нет — `obMonth` не в шаблоне). Модалка обязательства
  (`:1115-1206`): «Сумма сейчас» (`correctObligation`), «Запланировать изменение»
  (`amendObligation`), удалить (`removeObligation`, надгробие).
- Подпись суммы годовых в списке Капитала ошибочно «в месяц» (`:636-649`).
- `budgetAmounts` / `dueIn` / события Бюджета считают каждое обязательство платежом.
- **Что считается подпиской** (толкование составителя, в брифе не уточнено): обязательство
  категории `d4` без `estimate` — ровно то, что создаёт форма «Подписка или услуга». Аренда
  (`d1`), кредиты и оценочные (коммуналка) «оставить?» не спрашиваются.

## Задача

1. Группа = обязательство-родитель, помеченное как группа (новое поле), без собственной
   суммы и не являющееся платежом: итог группы — сумма детей (считает `finance.ts`); в
   `budgetAmounts`, `dueIn`, событиях Бюджета, `untilPayday` и отметках (RP-06/07) группа
   не участвует, дети — как обычные платежи.
2. UI: создать группу со свободным названием; положить подписку в группу / вынуть; список
   Капитала показывает группы с детьми и итогом (дети больше не пропадают). Флаг группы
   «рабочие — не спрашивать».
3. «Оставить?»: для подписок вне группы с флагом — у годовых перед продлением (окно до месяца
   списания — выбрать разумное, например 14 дней, и записать в комментарий), у ежемесячных —
   если последний ответ «оставить» был до начала текущего квартала (Алматы). Ответ хранится
   в документе (партнёр не получает тот же вопрос повторно). Показ — одна спокойная карточка
   (например, на Обзоре), не больше одной-двух за раз.
4. «Отменить» — с подтверждением → надгробие (`removeObligation`).
5. Попутно по месту: у годовой в форме добавления — выбор месяца списания; подпись суммы
   годовой — «в год».

## Тесты

- `lib/finance.test.ts`: итог группы; группа не входит в `budgetAmounts`/`dueIn`/
  `untilPayday`; дети входят.
- Чистая функция «кого спросить сейчас» (в `finance.ts` или рядом): рабочая группа — не
  спрашивает; годовая досуговая за 14 дней до продления — спрашивает, после ответа — нет до
  следующего года; ежемесячная — раз в квартал; граница квартала по Алматы.
- SSR-рендер Капитала: группа с детьми и итогом.

## Критерии приёмки

- Браузер: подписка из рабочей группы не спрашивает «оставить?», досуговая годовая —
  спрашивает (подвинуть месяц списания для проверки); «отменить» — подписка ушла у обоих.
- Бюджет месяца не изменился от того, что подписки сложили в группу.
- `cd frontend && npm run build && npm test` зелёные.

## Вне скоупа

- Вложенные долги (группы кредитов) — Р-1, не-скоуп.
- Валюта подписок — Р-1, не-скоуп.
- Push-напоминания о продлении — Р-1, не-скоуп.

# RP-11 — Вопрос в конце месяца об остатке (фронт)

Блок 2 · MVP · Каталог: `frontend/` · Зависит от: RP-10 · Роли: member

## Контекст (что уже есть)

- Р-19: второй вход в `/ritual` в последние дни месяца — спросить, остались ли деньги, и
  предложить распределить, «чтобы остаток не висел, который потратили» (NEXT.md
  «Ближайшее» п.4). Тон без упрёка. Р-30: «последние дни месяца» — по Алматы.
- После RP-10 `views/Ritual.vue` принимает источник суммы (освободившийся платёж, зарплата).
- `views/Overview.vue` — секции сверху вниз: баннер приглашения, «Свободно в <месяц>»,
  карточка освободившихся денег → `/ritual`, Callout-ы, «До зарплаты», «Впереди», цели.
- Хелперы дат по Алматы — из RP-06 (`lib/dates.ts`).

## Задача

1. В последние дни месяца (окно выбрать, например последние 3 дня, — в комментарий) на
   Обзоре — спокойная карточка: «Остались деньги с <месяца>?» → ввести сумму (или «нет,
   всё ушло») → `/ritual` с источником «остаток месяца» и этой суммой.
2. Ответ запоминается на месяц: карточка не возвращается после ответа или «не сейчас». Где
   хранить — на выбор исполнителя (достаточно устройства; если в документе — партнёр тоже
   не увидит повторно); записать выбор.
3. Тексты — без упрёка («потратили» не звучит как обвинение).

## Тесты

- Чистая функция «показывать ли вопрос» (дата по Алматы, ответ в этом месяце): последние
  дни — да; середина — нет; после ответа — нет; новый месяц — снова да в его конце.
- SSR Обзора: карточка есть в окне, нет вне окна.

## Критерии приёмки

- Браузер (подставить дату — мок времени в тесте или системное время): в конце месяца есть
  вход в `/ritual`, раскладка с введённой суммой; после ответа карточка ушла.
- `cd frontend && npm run build && npm test` зелёные.

## Вне скоупа

- Push-напоминание (Р-1, не-скоуп).
- Итог месяца — RP-13 (может жить рядом на Обзоре, но это другая карточка).

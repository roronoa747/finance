# Блок 4 — Быстрый вход желаний · сессии

**Цель блока:** желание попадает в приложение за секунды в момент, когда человек его увидел —
«Поделиться» с Android, скриншот на iOS с ИИ-подсказкой названия и цены, — а у витрины
приложение за секунду отвечает «можно ли это купить».

Сессии: исполнитель ⬜ · критик ⬜ · приёмка ⬜ · ревью backend ⬜ · ревью frontend ⬜ · клинап ⬜

---

## Промпт исполнителя — уровень build · Opus 5 · effort high (ultrathink)

```
/worker развитие-приложения 4 ultrathink
```

Блок-специфика:

- Ветка `rp-block-4-quick-wish` от `main` (после деплоя Блока 3). Push — с согласия
  владельца; `main` и env Vercel не трогать (это клинап).
- Задачи по порядку: `RP-18` → `RP-19` → `RP-20`. **RP-18 начинается с проверки доступности
  Gemini из `icn1` по актуальным источникам** — при «недоступно» стоп и вопрос владельцу
  (Р-17), RP-19 тогда делается без кнопки «Разобрать», RP-20 — как есть.
- Секрет: ключ Gemini создаёт владелец; значение — `memory/secrets/gemini.md` (попросить
  владельца положить), в коде и доках — только `GEMINI_API_KEY`. Pre-commit-хук не обходить.
- Данные уходят третьей стороне (L): на разбор — только картинка, без токена/имён/данных
  семьи; экран «что уйдёт» — до отправки, текст по Р-17/Р-28.
- Share Target с картинками требует обработчика в SW — не ломать `/sw.js`, scope и прекэш
  (`e2e/pwa-build.test.ts`).
- Верификация: `cd backend && go build ./... && go vet ./... && go test ./...` + корень `api/`;
  `cd frontend && npm run build && npm test`; живой вызов Gemini — локально с ключом.

## Промпт критика — уровень review · Opus 5 · effort xhigh (ultracode)

```
/critic развитие-приложения 4 ultracode
```

Блок-специфика:

- Секрет: ключа нет в диффе, логах, URL запросов (если API позволяет заголовок); ИИ без
  ключа выключен, а не падает; `ValidateProduction` не требует ключ.
- Что уходит в Google: только картинка; экран согласия перед каждой отправкой; тексты Р-28.
- Таймауты и лимиты: 429 бесплатного тарифа, размер ответа, таймаут ниже лимита функции.
- SW: обработчик share target не перехватывает `/api` и навигацию сверх нужного.
- «Можно ли купить?» — ничего не пишет в документ до «В желания»; расчёт в `finance.ts`.
- Промпт Блока 5 актуализировать по факту.

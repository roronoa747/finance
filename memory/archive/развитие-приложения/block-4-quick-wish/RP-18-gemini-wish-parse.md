## Задача

1. **Проверка доступности (до кода, результат — в Handoff с источниками и датой):**
   актуальный список регионов Gemini API и условия бесплатного тарифа (включая «используется
   для обучения / видят разметчики»); есть ли Южная Корея (исходящий запрос из `icn1`);
   актуальная модель бесплатного тарифа с поддержкой картинок и структурного JSON-ответа.
   **Не по памяти.** Если Корея недоступна — остановиться, записать и спросить владельца
   (Р-17); без его решения дальше не идти.
2. Ключ: владелец создаёт ключ (Google AI Studio) — значение в `memory/secrets/gemini.md`,
   в env — `GEMINI_API_KEY`; модель — `GEMINI_MODEL` с дефолтом из п.1. **Ключ не
   обязателен** для старта (не в `ValidateProduction`): без ключа ИИ выключен, остальное
   работает.
3. Общий клиент Gemini (пакет вроде `internal/ai`): запрос с картинкой и/или текстом,
   структурный ответ (схема JSON), таймаут, ограничение размера ответа, понятные ошибки
   (нет ключа, 429 лимит бесплатного тарифа, 5xx). Ни картинка, ни ответ, ни ключ не
   пишутся в логи.
4. Ручка разбора скриншота (под `/api`, защищённая, `member`): тело — картинка (как фото),
   ответ `{name, price}` — `price` целые тенге или `null`, если цена не в тенге/не найдена;
   ИИ выключен → 503 с понятным текстом; лимит → 429 с текстом «попробуйте позже».
5. Признак «ИИ включён» доступен фронту (например, поле в `/api/auth/me` или отдельная
   лёгкая ручка) — чтобы не показывать кнопку, когда ключа нет.
6. `backend/README.md` — env `GEMINI_API_KEY`, `GEMINI_MODEL`, ручка.

## Тесты

- Клиент на `httptest`: верный запрос (картинка inline, схема ответа, ключ в заголовке, не в
  URL — если API позволяет), разбор ответа, 429 → своя ошибка, таймаут.
- Хендлер: viewer → 403; нет ключа → 503; неверный тип файла → 400; успешный разбор → `{name,
  price}`; цена не в тенге → `price: null`.
- `config_test.go`: без `GEMINI_API_KEY` прод-конфиг валиден.

## Критерии приёмки

- `cd backend && go build ./... && go vet ./... && go test ./...` + корень `api/` зелёные;
  CI `ci-backend` зелёный.
- Handoff содержит: источники и дату проверки регионов/тарифа/модели; вывод «доступно из
  `icn1`» или решение владельца.
- Живой вызов с ключом — локально (`go run ./cmd/server` с `GEMINI_API_KEY` из секретов) на
  одном скриншоте; из `icn1` — смоук клинапа.

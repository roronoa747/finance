# RP-26 — Сводка для модели и экран «что уйдёт» (фронт)

Блок 7 · MVP · Каталог: `frontend/` · Зависит от: Блоки 2, 4 · Роли: member

## Контекст (что уже есть)

- Р-25: модель получает цифры, посчитанные `finance.ts`, и сама денег не считает. Р-26: в
  Gemini уходит только сводка — цифры `finance.ts` и названия статей; имена людей заменены на
  «участник 1/2», заметки и всё из `private_docs` не уходят; перед отправкой видно, что именно
  уйдёт. Р-28: в экране «что уйдёт» прямо сказано про бесплатный тариф (обучение,
  разметчики).
- Источники чисел (имена — из Handoff блоков): итог месяца (RP-13), `budgetAmounts`,
  `untilPayday`, производные остатки и кредиты (RP-06), сэкономлено досрочками (RP-08),
  цели и части (RP-21), жилищный вклад (RP-22), запас прочности (RP-24), моменты прогресса
  (RP-12).
- Поля с текстом людей, которые **не уходят**: `Person.name`, `*.note`, `ObligationVersion.
  reason`, `GoalMovement.note`, `WishItem` целиком (личное; решить — желания не нужны для
  разбора бюджета), `url`; весь `privateDoc` (личные счета, скрытые желания).
- Экран согласия для картинки уже есть (RP-19) — единый стиль «что уйдёт».

## Задача

1. Чистая функция сборки сводки (рядом с `finance.ts`, но **не** считает деньги сама —
   только вызывает функции `finance.ts` и раскладывает результаты): месяц, доходы по
   «участник 1/2», обязательные платежи по статьям (названия статей/обязательств/целей/
   кредитов — да, заметки — нет), остатки, долги со ставками, цели с прогрессом и датами,
   итог месяца, запас прочности. Только общий документ.
2. Сводка — стабильный JSON-объект (без лишнего), он же показывается человеку.
3. Экран «что уйдёт»: читаемый вид этой сводки (не сырой JSON — но всё, что в ней, видно),
   строки Р-26/Р-28 (имён и заметок нет; личное не уходит; бесплатный тариф: Google может
   использовать для обучения и показывать разметчикам) → «Отправить» / «Не надо». Отправка —
   RP-27/RP-28.

## Тесты

- Сводка на документе с именами, заметками, причинами версий, личным документом → в JSON
  нет ни одного имени участника, ни одной заметки, ничего из `privateDoc` (проверка
  поиском строк по сериализованной сводке).
- Все числа сводки равны результатам соответствующих функций `finance.ts`.
- SSR экрана «что уйдёт»: содержит строки Р-28 и все разделы сводки.

## Критерии приёмки

- `cd frontend && npm run build && npm test` зелёные.
- Сводка на живых данных (локальная копия документа) просмотрена глазами: имён и заметок нет.

- ИИ-чат со свободными вопросами (Р-1, после MVP).

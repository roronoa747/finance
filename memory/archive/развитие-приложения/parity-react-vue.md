## А. Считает неверно или действие невозможно

1. ✔ **«Копить или гасить» урезан.**
   - React: `src/screens/Capital.tsx:1542-1727`; Vue: `frontend/src/views/Capital.vue:912-944`.
   - Нет горизонта «год/два/три»: всегда 36 мес.
   - Нет «Что не останавливать» (цели-страховки): `keep: 0`.
   - Нет переключателя «Сначала подушка» и «Вложить уже накопленное» (`lump: 0`).
   - Нет «без процентных долгов через N мес.».
   - **Всегда выделено «Сначала гасить», а когда копить выгоднее, вывода нет.**
   - ТЗ RP-23 («что уже есть: `keep` — декретный депозит») описывает React-версию, а не
     фактический код.
2. ✔ **Кредит нельзя поправить.**
   - React: `Capital.tsx:879-967` — название, остаток, платёж, ставка, день, примечание,
     «Платежей осталось / Переплата», «долг не закрывается».
   - Vue: `Capital.vue:1179-1192` — три числа только для чтения; `updateCredit` из UI не
     вызывается.
   - Ошибку ставки, дня или платежа исправить можно только удалением, а вместе с кредитом
     уходит история отметок.
   - Связь с Блоком 1: правка остатка ставит якорь (`updateCredit`), день двигает график
     «Оплатил», платёж влияет на снятие «снизить платёж».
3. ✔ **Новый платёж в Капитале — всегда «Еда и быт» и без «оценки».**
   - React: `Capital.tsx:1247, 1343-1372`; Vue: `Capital.vue:329-330` — `obCategory = 'd4'`,
     `obEstimate = false`, элементов выбора нет.
   - Суммы разделов Бюджета искажаются.
   - Связь с Блоком 1: всё заведённое так — «подписка» для RP-09 (`isSubscription` = d4 без
     оценки), и оно раз в квартал спрашивает «Оставить?». Коммуналку нельзя отметить
     оценкой — `PaidRow` отметит её одним нажатием, без вопроса о сумме.
4. ✔ **Долг «по сроку» может молча сохраниться под 0%.**
   - Ставка не показывается. Если `rateFromSchedule` не находит решения, сохраняется
     `derivedRate ?? 0`, без предупреждения «не хватает N ₸, похоже платежей M».
   - Поле называется «Срок в месяцах» вместо «Сколько платежей осталось».
   - React: `Capital.tsx:802-830`, Setup `src/screens/Setup.tsx:381-386`; Vue:
     `Capital.vue:1146-1148`, `Setup.vue:349-357`.
5. ✔ **Покупки нельзя исправить и удалить; купленное нельзя вернуть в список.**
   - React: `src/screens/Goals.tsx:230, 264-270, 317-388` (`WishDialog`, `updateWish`,
     `removeWish`).
   - Vue: ничего из этого нет, в сторе нет методов.
   - Раздел «Уже купили» беднее: нет итога, дат, автора. Новая покупка встаёт в конец.
6. ✔ **Цель: накопленное уходит в минус; поле «Уже накоплено» пропало.**
   - Vue `stores/finance.ts:1126` — без `Math.max(0, …)`, а слияние (`merge.ts`, `mergeGoal`)

   - React: `src/store/useStore.ts:245-256` правил `seed`, сохраняя историю взносов; Vue:
     `GoalDetail.vue:365-373` — поля нет.
   - Правка цели во Vue сохраняется только кнопкой; закрытие окна теряет правки.
7. ✔ **Вклад: инфляция зашита 8% вместо настройки (10,2%).**

   - «Настоящая» доходность завышена примерно на 2 п.п.

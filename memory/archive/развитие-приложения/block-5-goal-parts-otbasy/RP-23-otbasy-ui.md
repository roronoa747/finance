## Задача

1. Экран жилищного вклада (`Deposit.vue` для вклада с признаком Отбасы): параметры (с
   дефолтами RP-22, правятся), три строки «свои / проценты банка / премия государства»,
   прогноз.
2. Цель, накапливаемая на жилищном вкладе (или его часть — RP-21): прогноз и дата с премией.
3. Подсказка конца года: в последние недели года (окно выбрать и описать), если предел
   премии не выбран, — спокойная карточка «добрать N ₸ до предела — это +M ₸ премии»; после
   добора или нового года — исчезает.
4. «Копить или гасить»: пополнения жилищного вклада учитываются как доходное накопление с
   премией (например, через `keep` и/или доходность в симуляции — решить и описать); совет
   не предлагает останавливать их, если расчёт не показывает выгоды явно. Цель на
   жилищном вкладе по умолчанию отмечена в «Что не останавливать» (`StrategyCompare`
   `kept`) — так она и в плане не встаёт на паузу (Р-18 паритета).

## Тесты

- Чистая функция «показывать ли подсказку года»: окно, выбранный предел, новый год.
- `lib/finance.test.ts`: стратегия с жилищным вкладом — пополнения не «съедаются» стратегией
  «сначала долги» без явной выгоды.
- SSR: экран вклада — три строки; цель — дата с премией.

## Критерии приёмки

- Браузер: вклад Отбасы показывает премию отдельной строкой по сверенным правилам; цель
  «Квартира» учитывает премию в дате; подсказка конца года появляется при подставленной дате.
- `cd frontend && npm run build && npm test` зелёные.

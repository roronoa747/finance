# RP-17 — Списки желаний по людям, скрытые подарки, «это приближает» (фронт)

Блок 3 · MVP · Каталог: `frontend/` · Зависит от: RP-15, RP-16 · Роли: member, viewer (только видит)

## Контекст (что уже есть)

- Р-10: у каждого участника свой список желаний; вход — нажатием на никнейм или аватар в
  шапке. Желание связано с деньгами: досрочка и освободившиеся деньги показывают «это
  приближает вот это». Р-9: скрытые желания-подарки — в `private_docs`, партнёр не видит ни
  записи, ни фото; остальные общие. Не-скоуп: чат в обзоре семьи.
- `components/AppShell.vue` шапка (`:61-109`): кружки-аватары участников (`var(--p${p.id})`,
  первая буква имени, `title=p.name`), без действия по нажатию.
- Вишлист сейчас общий: `views/Goals.vue` вкладка `wish`, у желания `by` — «кто добавил»
  (выбор показывается при >1 участника, по умолчанию `'a'`); после RP-16 — действия стора и
  фото.
- Личный документ сливается (RP-15); фото скрытого выдаётся только автору (RP-14).
- Деньги: досрочка (RP-08, «не отдадим банку»), освободившиеся деньги — `views/Ritual.vue`

  дети `AppShell`: `''`, `budget`, `goals`, `goals/:id`, `capital`, `capital/:id`, `ritual`.

## Задача

1. Экран участника (маршрут вида `/people/:slot` — имя на выбор): его желания (фото, цена,
   ссылка), вход — нажатием на аватар/никнейм в шапке. Желание принадлежит списку участника
   `by` (существующее поле — теперь «чей список»; при добавлении по умолчанию — свой).
2. Скрытый подарок: в чужом списке «добавить подарок-сюрприз» → запись в **своём** личном
   документе (с полем «для кого»), фото — со скрытым признаком. Автор видит его в списке
   адресата с пометкой «видишь только ты»; адресат — нет (ни записи, ни фото).
3. «Это приближает»: `finance.ts` — какое желание (некупленное, из списка, с ценой)
   становится ближе от суммы (разовой или ежемесячной) и на сколько (месяцев/дней).
   Показ — одной строкой в результате досрочки (RP-08) и на экране раскладки `/ritual`.
4. Вкладка желаний в Целях остаётся общим видом (все общие желания) — не дублировать логику
   с экраном участника (общий компонент списка).
5. Viewer видит списки, но не добавляет.

## Тесты

- `lib/finance.test.ts`: «это приближает» — выбор желания и срок; купленные и без цены не
  участвуют.
- Стор + SSR: скрытое желание есть в рендере автора и отсутствует в рендере партнёра
  (документы двух клиентов); общий — у обоих.
- e2e Блока 3: желание с фото видно партнёру; скрытое — нет (документ партнёра не содержит
  записи; запрос фото от имени партнёра → 404 на фейковом бэкенде).

## Критерии приёмки

- Браузер, два профиля: желание с фото, добавленное с телефона, видно партнёру; скрытое не
  видно ни записью, ни фото (DevTools: запрос фото от партнёра → 404).
- Нажатие на аватар в шапке открывает список участника.
- `cd frontend && npm run build && npm test` зелёные.

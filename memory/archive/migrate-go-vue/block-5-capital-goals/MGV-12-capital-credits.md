# MGV-12 — Экран Capital.vue (счета, кредиты, досрочка) (фронт)

Блок 5 · MVP · Каталог: `frontend/` · Зависит от: MGV-11 · Роли: все

## Контекст (что уже есть)
- Завершены Блоки 1–4. Все экраны базовой навигации, бюджет и ритуал готовы.
- Хранилище `useFinanceStore`: `accounts`, `credits`, `obligations`, `mutateHouseholdDoc`, `mutatePrivateDoc`.
- Финансовая математика `frontend/src/lib/finance.ts`: `netWorth`, `prepayment`, `amortization`, `liquidCash`.
- Эталонная реализация экрана: `src/screens/Capital.tsx`.
- Текущий маршрут `/capital` в роутере использует `PlaceholderView.vue`.

## Задача
1. Создать компонент `Capital.vue` (`frontend/src/views/Capital.vue`):
   - Карточка общего капитала (Net Worth): сумма счетов минус кредиты, изменение за месяц.
   - Раздел счетов (общие домохозяйства и приватные счета авторизованного пользователя):
     - Добавление, редактирование баланса, удаление счета.
     - Разделение на общие (`household_docs`) и личные (`private_docs`).
   - Раздел кредитов:
     - Список кредитов (остаток, процентная ставка, ежемесячный платёж).
     - Модальное окно или детальный просмотр с симулятором досрочного погашения (`prepayment`).
     - Расчёт экономии на процентах и сокращения срока выплат при дополнительных платежах.
   - Раздел регулярных обязательств:
     - Список обязательств с возможностью добавления новой версии платежа.
2. Подключить `Capital.vue` к маршруту `/capital` в `frontend/src/router/index.ts`.

## Тесты
- Юнит-тесты расчёта капитала (`netWorth`) с комбинацией общих и приватных счетов.
- Юнит-тесты досрочного погашения (`prepayment`).
- Компонентный тест рендеринга `Capital.vue`.

## Критерии приёмки
- Экран `Capital.vue` доступен по вкладке «Капитал» в нижней навигации `AppShell.vue`.
- Приватные счета сохраняются изолированно в `private_docs`.
- Симулятор досрочного погашения корректно рассчитывает экономию.
- `npm test && npm run build` проходит чисто (0 ошибок).

## Вне скоупа

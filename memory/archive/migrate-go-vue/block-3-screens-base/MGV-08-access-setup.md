# MGV-08 — Экраны Access.vue (вход/инвайт) и Setup.vue (мастер настройки) (фронт)

Блок 3 · MVP · Каталог: `frontend/` · Зависит от: MGV-07 · Роли: все

## Контекст (что уже есть)
- Хранилища Pinia: `useAuthStore` (`frontend/src/stores/auth.ts`) и `useFinanceStore` (`frontend/src/stores/finance.ts`).
- Клиент Go API: `frontend/src/api/client.ts` (`/api/auth/*`, `/api/household/*`, `/api/sync/*`).
- Эталонная верстка и логика:
  - `src/screens/Access.tsx` — авторизация, регистрация домохозяйства, присоединение по инвайту.
  - `src/screens/Setup.tsx` — пошаговый мастер настройки (участники, доходы, обязательные категории).
- Дизайн-токены и CSS: `frontend/src/style.css` (цвета, переменные, тёмная тема).
- Иконки: `@phosphor-icons/vue`.

## Задача
1. Установить и настроить `vue-router` в `frontend/`. Настроить базовую структуру маршрутов:
   - `/access` — экран входа/регистрации/инвайта.
   - `/setup` — экран мастера настройки.
   - `/` — главная (`Overview.vue`).
   - Навигационный гвард (`navigation guard`): перенаправление на `/access`, если пользователь не авторизован; перенаправление на `/setup`, если `setupDone` false и нет локального бюджета.
2. Реализовать компонент `Access.vue` (`frontend/src/views/Access.vue`):
   - Вкладка «Вход»: email, пароль, вызов `authStore.login()`.
   - Вкладка «Создать семью»: имя пользователя, название домохозяйства, email, пароль, вызов `authStore.register()`.
   - Вкладка «Присоединиться»: код инвайта (из URL `?code=...` или ручной ввод), отображаемое имя, вызов `authStore.joinHousehold()`.
   - Отображение ошибок валидации и сетевых ошибок.
3. Реализовать компонент `Setup.vue` (`frontend/src/views/Setup.vue`):
   - Шаг 1: Состав семьи и участники (Имя партнёра А, имя партнёра Б).
   - Шаг 2: Доходы и дни зарплаты (целые числа в тенге, день месяца 1–31).
   - Шаг 3: Обязательные базовые категории (жильё, еда, транспорт и т.д.).
   - Завершение настройки: сохранение в `financeStore`, отметка `setupDoneAt`, запуск фоновой синхронизации `syncHousehold()`, переход на `/`.
4. Базовый компонент `AppShell.vue` (`frontend/src/components/AppShell.vue`):
   - Шапка приложения с отображением семьи, индикатором синхронизации (`SyncBadge.vue`) и кнопкой темы/выхода.
   - Нижняя навигационная панель (Вкладки: Сводка, Бюджет, Цели, Капитал).

## Тесты
- Юнит-тесты роутера и навигационных гардов.
- Компонентные тесты для `Access.vue` (успешный вход, регистрация, обработка ошибок).
- Тест перехода на `Setup.vue` при отсутствии `setupDoneAt`.

## Критерии приёмки
- При неавторизованном входе приложение показывает `Access.vue`.
- Вход существующим пользователем перенаправляет в приложение.
- При отсутствии завершённой настройки запускается `Setup.vue`, прохождение сохраняет данные казны и переводит на главный экран.
- `cd frontend && npm test && npm run build` проходит чисто (0 ошибок).

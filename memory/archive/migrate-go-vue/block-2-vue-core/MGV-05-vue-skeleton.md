# MGV-05 — Скелет Vue 3 + Vite + Tailwind + Pinia (фронт)

Блок 2 · MVP · Каталог: `frontend/` · Зависит от: MGV-04 · Роли: все

## Контекст (что уже есть)
- Завершён Блок 1 (Go backend): REST API готов на `http://localhost:8080`.
- В `src/` находится текущая рабочая версия на React 19 + Tailwind 4.
- Используемые цвета и токены зафиксированы в `src/index.css`.

## Задача
1. Инициализировать проект в `frontend/`: Vue 3, Vite, TypeScript.
2. Подключить и настроить Tailwind CSS 4 с цветовой палитрой и токенами проекта.
3. Установить и настроить Pinia для управления состоянием.
4. Настроить базовую структуру каталогов: `src/stores`, `src/lib`, `src/api`, `src/components`, `src/views`.
5. Настроить конфигурацию прокси в `vite.config.ts` для перенаправления `/api` на `http://localhost:8080`.

## Тесты
- Тест сборки: `npm run build` завершается без ошибок.
- Тест линтинга/проверки типов: `vue-tsc --noEmit` проходит успешно.

## Критерии приёмки
- Приложение запускается через `npm run dev` и отображает стартовую страницу.
- Стили и токены соответствуют эталону проекта.
- Запросы к `/api/health` корректно проксируются к бэкенду.

## Вне скоупа
- Перенос бизнес-логики и математики (задача MGV-06).
- Хранилище синхронизации документов (задача MGV-07).

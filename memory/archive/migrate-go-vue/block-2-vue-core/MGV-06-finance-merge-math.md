# MGV-06 — Портирование финансовой математики и слияния (фронт)

Блок 2 · MVP · Каталог: `frontend/` · Зависит от: MGV-05 · Роли: все

## Контекст (что уже есть)
- Эталонная финансовая математика: `src/lib/finance.ts`.
- Тесты математики: `src/lib/finance.test.ts`.
- Алгоритм 3-стороннего слияния документов казны: `src/lib/merge.ts` (и тесты `src/lib/merge.test.ts`).
- Доменный инвариант: деньги — только целые числа; расчёты производит только `finance.ts`.

## Задача
1. Скопировать и адаптировать `src/lib/finance.ts` в `frontend/src/lib/finance.ts`.
2. Скопировать и адаптировать `src/lib/merge.ts` в `frontend/src/lib/merge.ts`.
3. Перенести типы моделей данных из `src/store/types.ts` в `frontend/src/types/finance.ts`.
4. Перенести все тесты Vitest: `finance.test.ts` и `merge.test.ts`.

## Тесты
- Полный прогон тестов финансовой математики: все тест-кейсы из `src/lib/finance.test.ts` должны выполняться без изменений и быть зелёными.
- Тесты слияния документов: все сценарии `src/lib/merge.test.ts` (одновременное добавление транзакций, счетов, категорий) должны проходить.

## Критерии приёмки
- `cd frontend && npm test` успешно проходит со 100% зелёными тестами.
- Отсутствуют вычисления с плавающей точкой в состоянии.

## Вне скоупа
- Подключение хранилища Pinia (задача MGV-07).

## Находки

### Н-1 · высокая · Vue не загружает шрифты Onest / Golos Text

`frontend/index.html:3-9`, `frontend/src/style.css:165-166`. Токены `--font-display`/`--font-sans` ссылаются
на Onest и Golos Text, но ни `index.html`, ни CSS, ни зависимости их не загружают (`grep fonts.googleapis
dist/index.html` → 0; `@font-face`/`fontsource` нет). React грузит оба в корневом `index.html:10-15`. После
cutover телефоны покажут system-ui (SF / Roboto), Windows — Segoe UI: вид «не как было» на каждом экране.
Блок 6 доводил `index.html` до паритета с React (MGV-17) и шрифты пропустил; репетиция на экранах этого
не поймала.

**Рекомендация.** Перенести из корневого `index.html` три тега — два `preconnect` и stylesheet
`family=Onest:wght@400;500;600;700&family=Golos+Text:wght@400;500;600;700&display=swap` — в
`frontend/index.html`. В `e2e/pwa-build.test.ts` добавить проверку, что `dist/index.html` содержит
`fonts.googleapis.com/css2?family=Onest`. Глазами — один экран на preview.

**Вердикт: клинап** (до переключения — иначе регрессия видна в день cutover).

### Н-2 · средняя · Курс формы счёта не меняется при смене валюты

`frontend/src/views/Capital.vue:190-193` (унаследовано 1:1 от `src/screens/Capital.tsx:240-243`). Курс
подставляется только в пустое поле: выбрал EUR → 508,71, переключил на USD — остаётся 508,71, и
`accountInTenge` (`Capital.vue:169-172`) сохранит счёт в USD по курсу евро. Сумма в тенге неверна —
это деньги, а не косметика. Находка приёмки, вердикт передан сюда.

**Рекомендация.** Флаг `rateTouched` (ставится на `@input` поля курса, сбрасывается при открытии формы);
watch `[rateInfo, newAccountCurrency]` подставляет `info.rates[cur]`, если `!rateTouched`, — т.е. при
смене валюты перезаписывает авто-курс, но не курс, вписанный руками. Тест на форму: EUR → USD меняет
курс; ручной курс → смена валюты его не трогает.

**Вердикт: клинап** (3–5 строк + тест; до cutover — счета в валюте заводятся именно в новой форме).

### Н-3 · низкая · Магическая строка `'demo-token'` в двух местах

`frontend/src/stores/syncEngine.ts:5`, `frontend/src/views/Access.vue:101`. Признак демо-режима
определён константой в движке и литералом во вьюхе; переименование в одном месте молча включит синк
демо-сессии с сервером (401 → «не сошлось»).

**Рекомендация.** Экспортировать `DEMO_TOKEN` и геттер `isDemo` из `stores/auth.ts`; `Access.vue` и
`syncEngine.ts` — через них.

**Вердикт: клинап.**

### Н-4 · низкая · Лишнее в прекэше: `icons.svg` и двойной `favicon.svg`

`frontend/public/icons.svg` (шаблон Блока 2, ссылок нет — подтверждаю находку критика) попадает в прекэш
каждого клиента. `frontend/vite.config.ts:17` — `includeAssets: ['favicon.svg']` дублирует
`globPatterns` (`svg` уже там): в `dist/sw.js` две записи `favicon.svg` с одной ревизией — Workbox это
терпит, но это шум.

**Рекомендация.** Удалить `public/icons.svg` и строку `includeAssets`. `pwa-build.test.ts` остаётся
зелёным (иконка и манифест не меняются).

**Вердикт: клинап.**

### Н-5 · низкая · `pwa-build.test.ts` привязан к корневому `public/` React

`frontend/e2e/pwa-build.test.ts:88`. Тест сравнивает иконку с `../../public/favicon.svg` — после удаления
React (`public/` уйдёт) тест упадёт с ENOENT.

**Рекомендация.** При уборке React заменить сравнение на проверку содержимого (`fill="#0A6B57"` и
`viewBox="0 0 64 64"`) — у Vue своя копия иконки, эталон больше не нужен.

**Вердикт: хвост §4** — приписать к существующему хвосту «Уборка старого»; сейчас тест верен и полезен
(ловит расхождение иконок до cutover).

### Н-6 · низкая · `pullHousehold` после повторного входа затирает неотправленное при `error`

`frontend/src/stores/finance.ts:205-210`, вызов — `Access.vue:49,76`. Сливает только при `dirty`; при
`error`/`offline`/`conflict` без новых правок кладёт серверную копию поверх локальной. Путь: правка →
синк падает (истёкший вход) → `error`, правка только в `localStorage` → вход заново в той же вкладке →
`pullHousehold` → правка потеряна. Логика до блока 6 (Блок 2); блок сделал путь чуть достижимее
(pull-сбой теперь тоже ставит `error`). Прямая правка «сливать при любом не-`idle`» небезопасна, пока
`logout` не сбрасывает документ стора (вход другим человеком в той же вкладке смешает документы) —
это решение крупнее клинапа.

**Рекомендация.** Отдельной задачей: `logout` сбрасывает `finance` (документ, ревизию, статус), после
этого `pullHousehold` сливает при любом статусе, кроме `idle`; тест «истёкший вход → вход → правка цела».

**Вердикт: хвост §4** (не регрессия блока; узкий сценарий; требует решения про logout).

### Н-7 · низкая · Демо-режим всё равно ходит на сервер через `scheduleSync`

`frontend/src/stores/finance.ts:96-102,255-260`. Движок демо-сессию пропускает, но любая правка в демо
вызывает `scheduleSync` → `syncHousehold` с `Bearer demo-token` → ожидаемо 401 → бейдж «не сошлось».
Код до блока 6 (Блок 3); в браузере не проверял — вывод по коду.

**Рекомендация.** Проверить на preview; если подтвердится — ранний выход `syncHousehold` при `isDemo`
(вместе с Н-3 это одна строка).

**Вердикт: хвост §4** (если клинап делает Н-3 и проверка подтвердит — можно закрыть там же, решение
клинапа).

### Н-8 · не делаем · `fx.ts` ходит `fetch('/api/fx-rate')` мимо `ApiClient`

`frontend/src/lib/fx.ts:13-21`. Базовый путь продублирован, а не взят из `ApiClient`. ТЗ MGV-17 п.3
явно разрешает `fetch` с тем же базовым путём; `baseUrl` нигде не переопределяется; ручка публичная,
токен ей не нужен. Переделка = новый метод клиента ради одной строки.

**Вердикт: не делаем** — ТЗ допускает, расхождения путей нет.

### Н-9 · не делаем · SPA-rewrite отдаёт `index.html` на пропавший `/assets/*.js`

`vercel.json:10`. Подтверждаю находку критика: `"/(.*)"` → `index.html` 200 и на несуществующий чанк.
Ленивых чанков нет (один `index-*.js`), старые клиенты получают ассеты из прекэша SW.

**Вердикт: не делаем** — безвредно; вернуться, если появится `defineAsyncComponent`/ленивые маршруты
(тогда исключить `assets/` из rewrite).

### Н-10 · не делаем · Полный синк на каждом старте поднимает ревизию

`frontend/src/stores/syncEngine.ts:50`. Каждое открытие приложения с сессией делает GET + push → `rev`
растёт на 1. Цена осознанная (комментарий `:48-49`): статус не хранится, и без полного круга
неотправленная перед закрытием правка выглядела бы как `idle`.

**Вердикт: не делаем** — корректность важнее счётчика ревизий.

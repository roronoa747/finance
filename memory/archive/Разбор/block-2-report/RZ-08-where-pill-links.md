## Задача

1. `components/ai/WhereBars.vue` (проп `rows: WhereRow[]`, `canOpen`): строка на раздел — название (`--ink`), справа
   сумма месяца (`money`, одна цифра), под ними полоса высотой 10 px: заливка цветом раздела на `share` факта; риска
   «обычно» (тонкая вертикальная черта `--ink-3`) и риска плана (`--brand`), если есть; выше обычного — полоса `--warn`
   (токен). Легенда одной строкой под полосами: «| обычно · | план» (мелко, `--ink-2`). Нажатие строки (member и viewer)
   → `openPath({kind: 'cat', id, name})` — лист раздела (п. 3). Анимация роста полосы — как у `StackBar` (`useGrow`),
   без своей.
2. Карточка «Куда ушло» в `AiReport.vue`: заголовок «Куда ушло», `WhereBars`, под ними строка `where` модели (`--ink`,
   одна-две строки). Нет строк (выписок месяца нет) — карточка показывает одну строку «Выписок за месяц ещё нет» и
   `where`.
3. Адреса «Открыть» (Р-18):
   - `MonthPlan.vue`: `?cat=<categoryId>` открывает лист раздела (`catFor = id`, если раздел есть в `compare.rows`);
     закрытие листа снимает параметр (расширить `useQuerySheet` параметром «значение», не копировать логику: `open`
     становится `ref<string | boolean>` или добавить `useQueryValue(key)` рядом — одно решение, без дублей).
   - `HistorySquare.vue`: `?cat=<categoryId>` → `filter = id` при монтировании / смене адреса (чип раздела подсвечен);
     чип «Всё» снимает параметр.
   - `/goals/<id>`, `/money/debts?credit=<id>`, `/money?obligation=<id>` — уже работают; проверить переход из отчёта
     (закрыт, параметр `review` снят, целевой лист открыт).
4. Пилюля «✦ Разбор» (Р-22): `Button secondary sm` с `PhSparkle` 14 и словом «Разбор», `data-review-open`, точка
   `data-review-dot` на правом верхнем углу, `aria-label` как сейчас; размеры и место — пробой в кольце 390 и 375
   (снимки в Handoff); не влезает — вариант «под кольцом» из Р-22. `reviewShown` без изменений.

## Критерии приёмки

- `cd frontend && npm run build && npx vitest run` зелёные.
- Браузер 390 / 375, обе темы: «Куда ушло» читается без текста (видно, какой раздел выше обычного и плана), одна цифра
  на строку; пилюля «✦ Разбор» заметна в кольце (или под ним), точка на ней; «Открыть» у совета про раздел открывает лист
  раздела на «Месяце», про продавца — историю с чипом раздела, про подписку — лист обязательства, про долг — лист
  кредита, про мечту — экран цели; кнопки ровные, горизонтальной прокрутки нет.

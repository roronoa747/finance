# RZ-13 — Лист раздела того месяца, что на картинке (`?month=&cat=`), с названием месяца (фронт)

Блок 3 · MVP · Каталог: `frontend/src/lib/aiFacts.ts` (`openPath`), `components/ai/WhereBars.vue`, `components/ai/AiReport.vue`,
`components/money/MonthPlan.vue`, `components/money/MonthPast.vue`, `components/money/SpendCategorySheet.vue` · Зависит от:
RZ-12 · Роли: member, viewer, партнёр, демо

Источник: хвост **Х-9** (критик Блока 2), вопрос 1 артефакта `/ux` Блока 2 — **владелец 2026-10-19 «А»**
(`memory/decisions/rz-ux2-owner.md`, Р-18 уточнено).

## Контекст (что уже есть)

- «Куда ушло» (`WhereBars.vue`) и «Открыть» совета `cat` (`AiReport.vue` → `openPath(target)`, `lib/aiFacts.ts`) ведут на
  `/month?cat=<id>`. Полосы считает `whereRows(state, ctx)` за **месяц находок** `findMonth(ctx)` (`finance.ts`: пока ничья
  выписка не дошла до 7-го — прошлый месяц); подпись карточки — «в <месяце>» (`whereMonth`).
- `/month?month=YYYY-MM` — `views/Month.vue` показывает тот месяц: текущий / прошлый с неотложенной своей зарплатой —
  `MonthPlan` (`:key="shown"`), иначе прошлый — сводкой `MonthPast` (листа раздела в ней нет).
- Лист раздела — `MonthPlan.vue` `useQueryValue('cat')` → `catRow` из `spendCompare(state, ctx)` месяца `monthKey` →
  `SpendCategorySheet` (пропы `row, rk, plans, canEdit, image`; «Изменить» плана участника — `canEdit`). План раздела
  (`setSpendPlan`) — общий, не по месяцам.
- Х-10 (`/ux` Блока 2): «Назад» после «Открыть» / строки «Куда ушло» возвращает отчёт на первую карточку. Промпт
  оркестратора: «если дёшево и в тему RZ-13 — сделай и отметь».

## Задача

1. `openPath(target, month?)`: раздел `cat` — `/month?cat=<id>` и `&month=<month>`, когда `month` задан и не текущий месяц;
   остальные виды — как были.
2. `AiReport` передаёт месяц картинки (`findMonth(input.ctx)`) в `WhereBars` (проп `month`) и в `openPath` советов `cat` —
   «того же месяца, что на картинке».
3. Лист раздела того месяца: `MonthPlan` (месяц плана) и `MonthPast` (сводка прошлого месяца — свой `useQueryValue('cat')`,
   строка `spendCompare` того месяца, планы участников) открывают `SpendCategorySheet` по `?cat=`.
4. `SpendCategorySheet` — название месяца над крупной цифрой (проп `month`, «сентябрь»); у закрытого месяца (раньше
   текущего) — без «Изменить» и без кнопки образа (правка плана из прошлого месяца сбила бы будущий план).
5. Х-10 (если дёшево): уходя из отчёта по ссылке (совет «Открыть», строка «Куда ушло»), запомнить карточку в состоянии
   записи истории; «Назад» → отчёт на той же карточке.

## Тесты

- `openPath`: `cat` с прошлым месяцем — `&month=`, с текущим и без месяца — как было.
- DOM: выписок нет (месяц находок — прошлый) — строка «Куда ушло» и «Открыть» совета ведут на `?cat=&month=<прошлый>`;
  по адресу — лист раздела прошлого месяца (сводка `MonthPast`) с названием месяца, суммой того месяца, без «Изменить»;
  текущий месяц — «Изменить» есть. Х-10: «Открыть» → «Назад» — отчёт на карточке того совета.

## Критерии приёмки

- `cd frontend && npm run build && npx vitest run` зелёные.
- Браузер 390, обе темы: стенд «пока выписка не дошла до 7-го» — строка «Куда ушло» открывает лист раздела прошлого
  месяца с его названием и той же цифрой, что в строке; «Назад» — отчёт.

## Вне скоупа

- История продавца (`seller` → `/money/history?cat=`) — без месяца (лента всех записей). Касание строки «Куда ушло» по
  правой трети (Х-10, вторая часть) — не трогаем.

# F2-02 — «Готово» на клавиатуре чисел, лист над клавиатурой (фронт)

Блок 1 · MVP · Репо/каталог: `frontend/` · Зависит от: — · Роли: все

## Контекст (что уже есть)

- Слова тестера (Android): у цифровой клавиатуры нет «Готово» / галочки, клавиатура закрывает нижнюю кнопку листа —
  приходится тыкать в пустое место. Решение — Р-1 («везде»).
- Все числовые поля — `components/kit/NumField.vue` (89 строк): `<input type="text" :inputmode="numeric|decimal">`,
  `enterkeyhint` нет, Enter не обрабатывается; атрибуты пробрасываются на `input` (`inheritAttrs: false`, `v-bind="$attrs"`).
  `NumFieldBlur.vue` — обёртка над ним, пишет значение по `blur` (`@commit`) — «Готово» через blur её тоже сохраняет.
  Используется в 24 файлах — правка в одном компоненте покрывает все.
- Образец `enterkeyhint="done"` уже есть: `views/MyCircle.vue:109` (текстовое поле).
- `components/kit/Sheet.vue` (298 строк): обёртка `fixed inset-0 flex items-end` (:249), панель `max-h-[88dvh]
  overflow-y-auto pb-9` (:265), слот `footer` (:292). Мета viewport — `frontend/index.html:6` (`width=device-width,
  initial-scale=1.0`, без `interactive-widget`). В Chrome Android по умолчанию клавиатура меняет только визуальный
  viewport — `fixed`-лист остаётся под ней. `visualViewport` в коде не используется.

## Задача

1. `NumField`: `enterkeyhint="done"`; Enter (`keydown`) — `preventDefault` и `blur()` поля (клавиатура уходит, `NumFieldBlur`
   пишет значение). Поле внутри формы не отправляет её по Enter.
2. Лист над клавиатурой: открытая клавиатура не закрывает низ листа — панель листа ограничена видимой высотой, поле в фокусе
   и нижняя кнопка докручиваются в видимую часть. Рекомендация — `interactive-widget=resizes-content` в мета viewport
   (Chrome Android: `dvh` и `fixed inset-0` сжимаются сами) **плюс** в `Sheet` подстраховка по `window.visualViewport`
   (`resize` → нижний отступ/максимальная высота панели = высота клавиатуры; iOS Safari мету не знает). Без
   `visualViewport` (старый браузер, SSR) — как сейчас. Подписка снимается при закрытии листа.
3. Проверить, что прочие `fixed`-слои (нижняя навигация, тосты) от смены мета не прыгают на открытой клавиатуре; прыгают —
   минимальная правка + запись в Handoff.

## Тесты

- `NumField` (DOM): у `input` `enterkeyhint="done"`; Enter снимает фокус и даёт `blur`; Enter внутри `<form>` не шлёт
  `submit`; `NumFieldBlur` по Enter эмитит `commit`.
- `Sheet` (DOM, мок `window.visualViewport` с `resize`): высота визуального viewport меньше окна — у панели появляется
  нижний отступ / ограничение высоты; вернулась — снят; закрытый лист слушатель снимает.
- e2e `e2e/f2-block1-keyboard.test.ts`: лист кредита — фокус в «Остаток долга», Enter → фокуса нет, значение записано
  (виртуальной клавиатуры в headless нет — сжатие визуального viewport проверяет DOM-тест).

## Критерии приёмки

- Все числовые поля: на Android-клавиатуре клавиша «Готово» (✓) прячет её, значение сохраняется.
- Лист кредита в Chrome 390 при эмуляции сжатого визуального viewport: нижняя кнопка и поле в фокусе видны.
- `cd frontend && npm run build && npx vitest run` зелёные; стенд Chrome 390, обе темы, ошибок консоли нет. Финальная
  проверка на телефоне — смоук прода (Android владельца или тестера), записать в шаги смоука приёмки.

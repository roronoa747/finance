## Задача

1. В `memory/backlog/Хвосты/00-backlog.md` §4: судьба Х-24, Х-25, Х-27 — «принятый долг (владелец 2026-10-25, бриф

2. Удалить ветку `fb-hf1-review-waits`: `git branch -D` и `git push origin --delete` (решение владельца Р-9 — подтверждать
   ещё раз не нужно). Перед удалением — убедиться, что её код не нужен: `git log origin/main..origin/fb-hf1-review-waits
   --oneline` записать в Handoff (хеши — для восстановления при нужде).
3. `git mv memory/backlog/Хвосты memory/archive/Хвосты`.
4. `memory/STATE.md`: строка в «Закрытые» («Хвосты» (TL) — 4 блока на проде, хвосты Х-24/25/27 — принятый долг); строка
   «Следующее» — бэклог «Фидбек-2» (F2), 3 блока; ссылки на `memory/backlog/Хвосты/` → `memory/archive/Хвосты/` (grep).
5. Grep по `memory/` и `.claude/` на `memory/backlog/Хвосты` — живые ссылки поправить на архив (в архивах других
   бэклогов не трогать).

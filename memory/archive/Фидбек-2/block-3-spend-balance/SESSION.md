### Возврат приёмки (2026-10-25, исполнитель)

- **Коммит:** `7bb91ab7` F2-07. Отклонение «ручная трата в день сверки считается» (выше) **снято**.
- **Починка:** у ручной траты теперь есть момент внесения — `saveHand` ставит новой `at` = сейчас, правка держит прежний
  (правка после сверки трату не «переносит» за сверку); `at` только на этом телефоне — `toWire` его не шлёт, а `pullOnce`
  при серверной копии без времени оставляет локальный. `spentSince`: есть `at` — `at > якоря`; нет — день позже дня сверки
  (для ручной траты — старой, до обновления, или внесённой на другом устройстве того же человека — как у выписки, по ТЗ).
  `Operation.at` — комментарий типа дополнен. Миграций и Go нет (Р-8).
- **Цена:** ручная трата без момента (внесена до этой сборки или на втором устройстве), внесённая после сверки в тот же
  день, до завтра не тает — редкий случай, ошибка в безопасную сторону (не двойное списание).
- **Попутно:** список трат (`finance.ts` сортировка по `date`, затем `at`) ставит ручные одного дня по времени внесения —
  новые выше; тесты порядка не тронуты, весь vitest зелёный.
- **Тесты:** e2e `f2-block3-accept.test.ts` (3) `it.fails` → `it`; юнит `spendBalance` — граница: ручная с `at` до/после

  введённой сумме, трата после — тает; новый: правка после сверки держит `at`, `pull` серверной копией без времени его не
  стирает. Мутанты (откат копией): `pull` без сохранения `at` — 1 красный; `saveHand` без `at` — 3 красных.
- **Верификация:** `npm run build` ✓; `npx vitest run` — **315 файлов, 3118 passed** (1 skipped). Стенд: `vite preview`

1. Для каждого из шести пунктов — воспроизвести исходный сценарий хвоста на стенде (демо или «новая семья», 390 px).
   Подтвердилось «закрыто» → в §4 `идея-и-редизайн` в колонке «Судьба» строки хвоста: «**устарел** — <чем закрыт:
   блок/коммит/файл:строка> (мелочи ML-01)».
2. Хвост жив → чинить минимально в этой же задаче (для 960 — по рекомендации хвоста: строка «Еда и быт» с полем всегда,
   раздел пишется только при вводе суммы) и закрыть «сделано `<хеш>` (мелочи ML-01)».
3. `pwa-build.test.ts` — подписи describe/it без слова «React» (поведение теста не меняется).

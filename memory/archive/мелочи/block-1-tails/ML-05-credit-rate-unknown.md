# ML-05 — Кредит без ставки: остаток и план честные (фронт)

Блок 1 · MVP · Репо/каталог: `frontend/src/stores/finance.ts`, `frontend/src/lib/finance.ts`, `frontend/src/components/money/PlanSquare.vue` · Зависит от: ML-04 · Роли: member

## Контекст (что уже есть)

Хвост §4 `идея-и-редизайн` **958** (жив, сверено 2026-10-08):

- Первый запуск создаёт кредиты из выписки с `annualRate: 0, rateUnknown: true` (`views/Start.vue:238`).
- `markPaid` (`stores/finance.ts:1305`, сплит :1327) зовёт `creditSplit(principal, c.annualRate, amount)`
  (`lib/finance.ts:1290`) — при 0 % весь платёж идёт в тело `principal` → остаток (`creditBalance`, :1468) занижается
  (~36 000/мес при 36 %), после ввода ставки не пересчитывается.
- `costliestCredits` (:758-763) берёт только `annualRate > 0` → `settlePlans` (:2733) закрывает план, `PlanSquare.vue:172`
  пишет «Долги с процентами закрыты — цели возобновились», :202 — «Долгов с процентами нет» (:203-204 — подсказка
  «Ставку … уточните»), пока долг без ставки открыт. Защиты от `rateUnknown` уже есть: `MarkSheet.vue:103`,
  finance.ts:714-715, :1538.
- Якорь остатка — `principalSetAt` (`types/finance.ts:275-297`).

## Задача

1. `markPaid` для `rateUnknown`: тело не пишется (`principal` отметки не задаётся) — остаток держится до ввода ставки.
2. При вводе ставки в листе кредита — подсказка «Сверьте остаток с банком» (поле остатка; сохранение обновляет
   `principalSetAt`), без пересплита старых отметок.
3. План «Сначала долги» не закрывается и не пишет «закрыты»/«нет», пока открыт долг с `rateUnknown`: `settlePlans` /
   `justDone` и тексты `PlanSquare` учитывают его как «ставка неизвестна».

## Тесты

- `finance.test.ts`/store-тест: отметка по кредиту без ставки не меняет остаток; после ввода ставки следующая отметка
  делит на тело и проценты; план с открытым `rateUnknown` не «закрыт».
- DOM: `PlanSquare` с долгом без ставки — нет «закрыты».

## Критерии приёмки

- На стенде (первый запуск с кредитом из выписки): «Оплатил» не меняет остаток; ввод ставки → подсказка сверки.
- `npm run build && npx vitest run` зелёные.

## Вне скоупа

- Пересплит прошлых отметок задним числом — нет (решение хвоста: якорь `principalSetAt`).

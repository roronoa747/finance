# ML-03 — Плановый раздел — только строке с отметкой (фронт)

Блок 1 · MVP · Репо/каталог: `frontend/src/lib/statements`, `frontend/src/stores/operations.ts`, `frontend/src/lib/finance.ts` · Зависит от: ML-02 · Роли: member

## Контекст (что уже есть)

Хвосты §4 `идея-и-редизайн` **952** и **967** (живы, сверено 2026-10-08; владелец ранее: 967 — «в хвост
`plannedElsewhere`»):

- `monthSpentByFact` (`lib/finance.ts:4163-4170`) выбрасывает целиком итоги разделов с `plannedElsewhere(categoryId,
  live)` (`lib/statements/dictionary.ts:35`) — кредиты, аренда, связь, подписки. Тот же фильтр — finance.ts:3108, 3696,
  3872. Незаведённая рассрочка Kaspi 80 000 выпадает из «Свободно».
- Итоги — по разделам (`SpendTotal`), не по операциям: исключить «только строки с отметкой» из итогов нельзя — нужна
  сумма строк раздела **без живой отметки** `Payment.opId`.
- `paymentFits(state)` (`lib/statements/matching.ts:112-115`) → `ruleHit` (:83-104, знак и допуск, без окна дат);
  `applyRules` → `fromRule(rule, op, fits)` (`lib/statements/model.ts:144-150`, :208-213) даёт плановый раздел каждой
  подходящей строке; `taken` в `matchCandidates` (:156, :173, :226) — одна отметка на kind:target:period. Две строки
  продавца по 15 000 в месяц → обе плановые, отмечена одна → «Свободно» завышено на вторую.
- `reapply` — `stores/operations.ts:155`.

## Задача

1. Строка с плановым разделом, **не связанная с живой отметкой** (`Payment.opId`), считается тратой в «Свободно»
   (минимальный путь — вычислять итог раздела «без отметки» и не выбрасывать его в `monthSpentByFact` и трёх
   повторах фильтра; одна функция-помощник в `finance.ts`, без копий).
2. `paymentFits` считает «такой» строку без живой отметки, только пока у пары «цель · месяц» нет отметки с другой
   строкой (минимум из хвоста 967).

## Тесты

- `finance.test.ts`: рассрочка без обязательства 80 000 → в «Свободно» как трата; подписка с отметкой → не трата; две
  строки по 15 000, отмечена одна → трата 15 000, не 0 и не 30 000.
- `matching`/`operations` тест: вторая строка того же продавца в месяце с отметкой — не плановая.

## Критерии приёмки

- На стенде (выписка с двумя переводами одного продавца) «Свободно» меняется ровно на неотмеченную строку.
- `npm run build && npx vitest run` зелёные; накопительный `frontend/e2e` зелёный.

## Вне скоупа

- Изменение словаря разделов и экранов «Траты» («Не разобрано» 990 — не берём).

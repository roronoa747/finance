## Задача

1. Наблюдатель по подписи живых целей правил платежа (id, сумма месяца, `estimate`, `deletedAt` обязательств и
   кредитов) → `reapply(all.value)` и запись тем же путём, что `settleReleased`. Подпись — строкой/числом, чтобы не
   будить пересчёт на каждое изменение документа (синк будит часто — см. память «focus будит синк»).

## Тесты

- `operations.test.ts`: удалить обязательство-цель → строка уходит из планового раздела; изменить сумму вне допуска →
  тоже; изменение имени — пересчёта нет (счётчик вызовов).
- Мутация: убрать наблюдатель → тест красный.

## Критерии приёмки

- На стенде: «Отменить подписку» → её строка в «Неделе» становится тратой, «Свободно» уменьшается.
- `npm run build && npx vitest run` зелёные.

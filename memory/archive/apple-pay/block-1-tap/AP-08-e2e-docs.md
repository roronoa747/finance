## Задача

1. Фейк: `statementsFor` — `listOperations` отдаёт и надгробия; хелпер `serverTap(st, user, op)` — операция «пришла с
   телефона» (`source: 'tap'`, `category_id: null`, как пишет AP-03).
2. `ap-block1-tap.test.ts`, сценарии:
   - касание → `pull` → «Неделя» member-а: трата в сумме недели; незнакомый продавец — в «Без раздела»; ответ на вопрос
     «куда отнести?» → раздел, итог партнёра в общем документе обновился; партнёр операции не видит;
   - валюта: операция USD с `amount 0` — нет в итогах до курса; курс есть — тенге по `fxToTenge`;
   - выписка с той же покупкой → одна операция, надгробие ушло; второй телефон того же человека после `pull` — без
     телефонной; фантом внутри периода убран;
   - «Отключить» в настройках → ручка отключения вызвана, карточка «Подключить»;
   - viewer и демо: ни карточки, ни строки, ни запросов `applepay`.
3. Доки: `backend/README.md` — раздел «Apple Pay» (ручки, ключ хешем, лимит 200/сутки, env, заглушки стенда);
   DESIGN.md — строки `/settings` (карточка «Apple Pay», лист `?applepay=1`) и `/week` (тихая строка), §6 — тексты
   карточки и листа (после `/ux` правит он).

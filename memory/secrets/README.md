# secrets/ — локальные секреты (НЕ в git)

Каталог для значений, которым нельзя попадать в git: тест-креды, локальные DSN,
токены. В `.gitignore` игнорируется всё содержимое, кроме этого README; плюс
pre-commit-хук (`memory/process/hooks/pre-commit`, включается
`git config core.hooksPath memory/process/hooks`) блокирует staged-файлы из `secrets/`
и секрето-подобные строки в диффе.

Правила:
- В доках/бэклогах/Handoff-ах — только ИМЯ переменной или ссылка на файл здесь
  (`memory/secrets/<файл>.md`), никогда не значение.
- Прод-секреты здесь тоже не хранить — их место в env/секрет-менеджере на сервере;
  здесь только локальные/тестовые значения, нужные сессиям.
- Файлы отсюда не прикладывать в промпты и не копировать в git-каталоги.

Ты — исполнитель Блока $1 бэклога «$0» (роль — `memory/process/BACKLOG-GUIDE.md`
«Протокол сессий»). Прочитай по порядку и работай строго по ним:
1. `memory/backlog/$0/00-backlog.md` — решения §2, протокол §5, контекст §6.
2. Все ТЗ каталога `memory/backlog/$0/block-$1-*/` по порядку ID + цель блока и
   промпт исполнителя в его `SESSION.md` (там блок-специфика: факты прошлого
   блока, среда).

Правила: задачи по одной, в порядке ID; решения §2 не пересматривать; живые доки
целиком не читать — факты в ТЗ, при пробеле точечный grep; из кода читать только
файлы из ТЗ; новых библиотек/абстракций сверх ТЗ не вводить; ТЗ противоречит коду
→ минимальное локальное решение + запись в Handoff. Каждая задача = отдельный
коммит (`<ID>-NN: …`). Секреты — только в `memory/secrets/`, в доки — ссылка.

По завершении: верификация из критериев каждого ТЗ (билд + тесты + реальная
среда), статусы §4 ⬜→✅, Handoff в SESSION.md блока (коммиты, сделанное,
отклонения с причинами, грабли среды, верификация), своя ✅ в трекер. К следующему
блоку НЕ переходить. Финал: короткий разбор для владельца (режим наставника) +
следующий шаг — `/critic $0 $1`.
